# 这些词在本库里各指一件确切的事，猜不出来就查这里

> **它收什么**：写文档时用的那批自造词 —— 跨多份文档共用的那些。
>
> **它不收什么**：游戏里的名词（物品名、地名、角色名、招式名）—— 那些的家是[正典](../canon/world/世界观.md)与[文案写作规范](../production/文案写作规范.md)；也不收只在一份文档里用的词 —— 那些在各自那份的「术语」节里。
>
> 返回 [总索引](../README.md)｜相关：[系统文档与提案索引](../design/README.md) · [WORKFLOW](../WORKFLOW.md)｜台账：[`DOC-89`](../spec/issues/README.md)

## 怎么用

想查一个词，先看它在不在本页。不在，就翻你手上那份文档的「术语」节 —— 那里装的是只有那一份在用的词。两处都没有，说明写的人漏了，按[待办台账](../spec/issues/README.md)记一条。

**本页有两种词条，形状不同：**

- **方法论词** —— 全库找不到别的定义处，所以**本页就是它的家**。改它要改这里。
- **领域词** —— 权威定义在某份正典或系统文档里。本页只给一句白话加一个指路，**不复制那一份的正文**。想知道精确规则就点进去。

## 收词判据

一个词进本页要同时过两道：

1. **跨页** —— 它出现在 **3 份以上**系统文档里。只在一两份里出现的词归那一份自己的「术语」节，因为那通常是「本页与它的直接下游」，不是共用词汇。**这个阈值的家就是这一行**，模板与别处只链接、不复述。
2. **猜不出来** —— 一个没读过本库的人看字面读不出它的意思。这一道是人判的，没有机器判据。

还有一条是做的时候撞出来的：**同一套分类、同一对概念的各项同进同出**，按其中出现最广的那一项判。把「控制类」留在某一页而「参数类」放进本页，读者要翻两处才凑得齐一套三项的分类 —— 那比两处都不解释更糟。

**反过来的两条也写死**：本页每个词条至少要被一份系统文档真的用到（否则这张表在膨胀）；同一个词不许同时出现在本页与某份文档的「术语」节（否则它有两个家）。这两条有守卫（`DOC-93`）。

**「词条」指哪些**：下面那两张定义表里、表格行首加粗的那个词。最后那张「会撞」的表不是定义，它是一份交叉索引 —— 同一个词在那里再出现一次是应该的。

## 方法论词：本页就是它们的家

这批词描述的是「我们怎么写文档、怎么判一件事成不成立」，与游戏内容无关。

| 词 | 它指什么 | 为什么不用大白话代替 |
| --- | --- | --- |
| **判据** | 一条可检验的标准，用来判「这东西归谁」或「这条规则成不成立」。判据的作用是让**新东西也能自己找到位置** | 「规则」「原则」都不含「可检验」这一层 |
| **反证** | 一条反过来证明规则真在起作用的用例。写法是**先破坏前提，再确认结果真的跟着变** —— 例如「把可见集清空后 AI 找不到目标」证明 AI 真的在读那一份可见集 | 普通测试只证明「正常情况下对」，反证证明「它真的接上了」 |
| **承重项** | 一条被别处依赖的结论，拆掉会连带塌一片。文档点名它，是为了让改它的人先看见代价 | 「重要」是语气，「承重」说得出谁压在上面 |
| **读口** | 一个**只读的查询入口**。它现算或转发，**不自己存一份** —— 所以它永远不会与真数据对不上 | 「接口」不含「不存第二份」这一层，而那正是它存在的理由 |
| **量纲** | 一个量的单位与意义（帧、天、格、铜、百分比），**不含具体数值**。系统文档只定量纲，值归参数表 | 「单位」漏掉了「合法范围与意义」；「数值」正好是它要避开的东西 |
| **闸门** | 一道「够不够、允不允许」的前置检查。它只放行或拦下，**不改任何状态** | 「检查」不含「拦下之后什么都没发生」这一层 |
| **管道** | 一串顺序固定的环节，同类的东西**一律走它**、不许抄近路。例如产出 → 归属 → 付酬 → 入库 | 「流程」听起来可以有例外，管道的意思是没有例外 |
| **接缝** | 两个系统之间**唯一**的那处接触面，而且方向写死（谁问、谁答）。接缝只有一处，是为了不出现互相触发 | 「交互」「调用」都不含「只有一处、方向固定」 |
| **挂载点** | 一个系统允许别人挂东西进来的那几个**固定位置**。文档会写「到此为止」——下次加东西先问它挂在哪一个，而不是顺手插一个新的 | 「扩展点」不含「数量封闭」这一层 |
| **档位** | 一条离散阶梯上的一级。**机制一律读档位、不读原始数值**，所以数值怎么调都不会改机制 | 「等级」在本作另有含义（技能等级、强化等级） |
| **额度** | 一个周期内能做几次的上限（一天一次教学、能同时接几条委托）。**用完只拒，不排队** | 「限制」太宽，额度特指「按周期计次」 |
| **载入校验** | 读内容数据时做的一致性检查，**不通过就当场报错**，不静默兜底 | 「校验」不含「在载入那一刻、失败即崩」这一层 |
| **结构约束** | 一条「这东西在结构上根本不存在」的约束，区别于「存在但被禁用」。例如俯视那台动作机**没有**空中相位，不是有但禁了 | 分不清这两者，写出来的测试会去验一个不存在的东西 |
| **落点** | 一条结论最终写在哪份文档的哪一节，或代码落在哪个文件 | 「位置」太泛，落点特指「唯一的那个家」 |
| **记账** | 把一件**超出当前范围**的事登进[待办台账](../spec/issues/README.md)，而不是顺手做掉 | 它是一条纪律的名字，不只是「记下来」 |
| **立项** | 给一件事分配一个编号并进台账。编号一旦写出就是跨文档引用的稳定标识 | 「新建任务」不含「编号不可复用」这一层 |
| **归位** | 判断一样东西该归哪个系统、哪一层、哪份文档 | 「分类」的结果是标签，归位的结果是一个家 |
| **上升** | 一条结论从系统文档提到正典里去。系统文档**不整份上升**，只有稳定下来的那几条会 | 「提升」有褒义，上升在这里只是换层 |
| **体裁** | 一份文档属于哪一类（正典／系统／模型／提案／决策记录），决定它放哪、活多久、写哪几节 | 「类型」已经被文件头的 `type` 占了，两者说的是同一件事而口径要对得上 |
| **漂移** | 同一个事实在两处各写了一份，随时间慢慢对不上，而**没有任何机制能发现** | 「不一致」是结果，漂移强调它是悄悄发生的 |
| **同名不同物** | 两处用同一个词指不同的东西。发现了要在「边界与非目标」里点出来，**不许靠上下文区分** | 直说「重名」会让人以为改个名就完了，而有时两者都该保留 |
| **正交** | 两条轴互不影响、可以任意组合，所以**四个角都得存在**（例如稀有度与品质） | 「独立」不含「组合出来的每一格都要有内容」 |
| **实机** | 在 Godot 里真跑起来看。表现、手感、可读性一律实机验收，没有机器判据 | 「测试」会让人以为有自动化判定 |
| **求值** | 要用的时候**现算一次**，不存结果。所以它永远不会与真数据对不上（与「读口」是同一条思路的两种说法：读口是入口，求值是那一刻做的事）| 「计算」不含「不存结果」这一层，而那正是它的要点 |

## 领域词：一句白话加一个指路

这批词的**权威定义在别处**，本页只帮你认出它是什么、该去哪读。精确规则点进去看。

**指路一律指到文档，不指到节** —— 节名会改，而一个词在哪份文档里定义是稳定的。只有那一份写得特别分散的才点到节。

| 词 | 一句话 | 精确定义在 |
| --- | --- | --- |
| **正典** | 已经确认、优先级最高的设计事实。低层文档只能补细节，不能静默改写它 | [总索引 · 权威层级](../README.md) |
| **上游** | 约束本页的那些更高层文档。系统文档必须有正典上游，没有就说明它在替正典做决定 | 同上 |
| **下游** | 读本页产出的那些系统与代码。「下游同步」那一节写的就是「谁得跟着改」 | 同上 |
| **载体** | 角色身上**能同时挂着**的那些修饰共用的那一份数据（硬直、伤病、词条、光环、永久增益都在里面） | [状态效果系统 · 载体的字段](../design/状态效果系统.md) |
| **动作机** | 管「这一帧角色在做什么」的那台状态机。它持有**一次只能有一个**的姿态 | [`角色动作状态系统`](../design/角色动作状态系统.md) |
| **姿态** | 动作机里的一个状态（站、走、攻击、受击、倒地）。同一层同一时刻只能有一个 | 同上 |
| **运动层** | 动作机的一层，管「角色在怎么移动」（站、走、跑、跳、闪避位移，以及被控时的受击与倒地样子） | 同上 |
| **动作叠加层** | 动作机的另一层，管「角色在主动做什么」（攻击、防御、施法、采集）。它给运动层一个「定身」标志 | 同上 |
| **定身** | 出招期间不能移动。它是动作叠加层压给运动层的那个标志，不是一条独立状态 | 同上 |
| **动作集** | 一个角色**自己声明**它有哪些动作。流转表是全集，一个角色的实际动作机是它声明的那些导出的子图 | 同上 |
| **连通性** | 声明的每个动作都要有一条从站立**进得去**的路、一条**出得来**回站立的路。两条都是载入校验 | 同上 |
| **全集** | 流转表里列的是**全部可能的**姿态与流转，而一个角色只有它自己声明的那些 —— 缺一个不算例外 | 同上 |
| **读条** | 一个带进度、可被打断、移动即取消的持续动作（采集、劳作、钓鱼、施法的一种） | 同上 |
| **失衡值** | 挨打累积的那个量，越过韧性上限就进失衡姿态。它**只是个量**，不打不还会自己回落 | 同上 |
| **后摇** | 一招打完到能做下一件事之间那段不可打断的收尾 | 同上 |
| **顿帧** | 命中瞬间双方短暂静止，是「打得实」的主要来源 | [战斗与关卡 · 打击反馈](../canon/gameplay/战斗与关卡.md) |
| **纵深带** | 侧视战斗里那条可以上下挪步的窄带。它让侧视有第三个轴，但不是自由平面 | [`战斗与关卡`](../canon/gameplay/战斗与关卡.md) |
| **失衡** | **两件事共用这个词。** 战斗里指被削韧到锁死的那个姿态；「活跃失衡」指全作唯一的那个全局量 | [`战斗与关卡`](../canon/gameplay/战斗与关卡.md)／[`活跃失衡系统`](../design/活跃失衡系统.md) |
| **境况** | 一个城区当前好不好过，由活跃失衡换算成档位。商店上架、事件权重都读它 | [活跃失衡系统 · 境况事件声明它动哪几组，可正可负](../design/活跃失衡系统.md) |
| **韧性** | 挨打到什么程度会进失衡姿态的那条上限 | [`角色与成长`](../canon/gameplay/角色与成长.md) |
| **派生表** | 把属性、装备、天赋与状态汇总成一张表，**是下游读角色数据的唯一入口** | [`成长系统`](../design/成长系统.md) |
| **基底** | 一个量由属性给的那一部分，与「来源」（宝物、宝石、天赋、状态给的那部分）分两栏记 | 同上 |
| **派生量** | 由别的量算出来的量。**它不单独存** —— 改了基底它就跟着变，所以不会与真数据对不上 | 同上 |
| **互斥组** | 一组互相冲突的条目（一组特质，或天赋树里一行节点）。**同一组里最多持有一条**，先得到哪条，同组其余以后就不再进 | 同上 |
| **硬直** | 挨打之后那一小段动不了。它是一条按帧计的**效果**，姿态由动作机问载体拿 | [`状态效果系统`](../design/状态效果系统.md) |
| **控制类** | 载体上三类效果之一：**锁住操作**的那类（硬直、失衡、冻结、眩晕）。它会让动作机切被控姿态 | 同上 |
| **参数类** | 三类之二：**只改数值或判定**、不动动作机的那类（无敌、减速、增益、词条、光环） | 同上 |
| **纯描述类** | 三类之三：**什么都不改、只显示一行字**的那类（考差的评语、伪装用的旧伤）。它是一等成员，不是界面自己编的字 | 同上 |
| **时长单位** | 一条效果按什么计时：**帧、天、永久**三种，各有各的推进点。同一条效果只能有一种 | 同上 |
| **永久项** | 时长单位是「永久」的效果：不推进、不过期，**只能被显式移除**（失衡增益、专长、特质） | 同上 |
| **叠加** | 同一种效果再次施加时怎么办：刷新时长、叠层数，还是取更强的那个。**每种效果自己声明**，没有全局默认 | 同上 |
| **显示字段** | 状态栏读的那个值。它与「实际字段」默认相同，**只在被显式伪装时才不同** | 同上 |
| **实际字段** | 结算读的那个值。主角手环的读数是假的，靠的就是这两个字段分开 | 同上 |
| **薪尽火传** | 主角出征时常挂的那条永久效果：**降他自己、升在队学生**，两侧各一项、来源相同 | 同上 |
| **技能位** | 能装主动技的那几个格子。**被动与光环不占位**，也不设数量上限 | [`技能系统`](../design/技能系统.md) |
| **主动技** | 技能的三种形态之一：要玩家按键放出来的那种。**只有它占技能位** | 同上 |
| **被动技** | 三种形态之二：学会就一直生效、不用按键。不占技能位、不设数量上限 | 同上 |
| **光环** | 三种形态之三：常驻、不占技能位，但自带「同类只取最大」与「必带可感负面」两条规则 | 同上 |
| **瞬发** | 施放形态之一：像挥一刀那样短前后摇、生根、不可打断。另一种是「读条」 | 同上 |
| **技能孔** | 镶在主动技上的孔，**宝石进这里改的是机制**。按实战值档位一档开一个 | 同上 |
| **宝物孔** | 镶在宝物上的孔，**宝石进这里给的是属性**。孔数是「稀有度给基础 ＋ 强化给附加」 | [`装备系统`](../design/装备系统.md) |
| **强化** | 花钱把一件宝物或一颗宝石往上提一级。**不会失败**，走经济系统那条唯一的支出管道 | 同上 |
| **专属栏** | 每个角色各有的那几格装备位，格数**由角色定义声明**，不是全员同一个数 | 同上 |
| **决策循环** | 不由玩家操作的角色每一帧走的那条链：从它声明的动作集里选一个做。**敌人与队友走同一条** | [`战斗AI系统`](../design/战斗AI系统.md) |
| **行为档** | 队友身上那两个档号的统称。**两条轴不合成一个号** | 同上 |
| **操作档** | 两个档号之一：**读实战值**，管「他打得好不好」 | 同上 |
| **配合档** | 两个档号之二：**读关系档位**，管「他跟你配合得好不好」 | 同上 |
| **分级面板** | 杂兵、精英与 BOSS 用的是**同一套面板的子集**，不给敌人开专用通道 | 同上 |
| **预警** | 一次攻击发动前给玩家的那个可见提示。它是**攻击定义上的显式声明**，不是通用规则 | 同上 |
| **对策** | 玩家应对某次攻击的办法（挡、闪、跳、拉开）。它也是攻击定义上的声明，且有一条载入校验要求全部敌人合起来覆盖到每一种 | 同上 |
| **警戒** | 敌人那台「有没有发现玩家」的状态机。发现之后的传播**只有一跳** | 同上 |
| **脱战** | 敌人从警戒退回不警戒。它有自己的条件，**不是「看不见就立刻忘」** | 同上 |
| **残影** | 目标离开视野后画面上留下的那个影子。它只是记忆项的表现，**不是第二份数据** | [`感知与视野系统`](../design/感知与视野系统.md) |
| **显形** | 一样原本看不见的东西进入视野、在画面上露出来那一刻 | 同上 |
| **撤离** | 从关卡里主动退出去。它与「往前」「往回」走同一条转场规则，只是方向不同 | [`关卡系统`](../design/关卡系统.md) |
| **转场** | 片段之间的切换：按键加读条，**不是无缝滚动**。所以接缝处刻意不要求地面对齐 | [`关卡系统`](../design/关卡系统.md) |
| **种子** | 一关的随机数起点。**同一个种子必须拼出同一张图**，所以拼装不许读任何会变的外部状态 | 同上 |
| **资源点** | 关卡里可以采的那些东西，**按作业对象分类**，各类共用一条动作管道、各指一项生活技能 | 同上 |
| **实战值** | 一个角色**用某个技能**打出来的熟练程度，按「角色 × 技能」记 | 同上 |
| **生活技能** | 做事的熟练度（种植、钓鱼、伐木、交易这类），与放出来的战斗技能是两类东西 | [`角色与成长`](../canon/gameplay/角色与成长.md) |
| **加点** | 升级拿到属性点之后分配它。**分完不可撤销**（天赋那一侧可以洗点，属性不行）| 同上 |
| **专长** | 生活技能升到某一档时选的一件事，**选定不可更改** | 同上 |
| **工位** | 一个可以派人去干的活儿。清单的家只有一处 | [`时间与经营`](../canon/gameplay/时间与经营.md) |
| **归属** | 一件产出算谁的。**产出一律归主角**，干活的人拿按基础价比例算的酬劳 | [`角色与成长`](../canon/gameplay/角色与成长.md) |
| **渠道** | 一条产出路径（开荒、种植、畜牧、钓鱼、加工、烹饪）。**它们共用同一条管道**，只在几格上不同 | [`生产系统`](../design/生产系统.md) |
| **地块** | 基地地面上一格可耕种的地。它有自己的状态流转（未清理 → 可耕 → 已播种 → 待收） | 同上 |
| **工序** | 做成一件东西要的那套步骤：**配方 ＋ 制作者的那项生活技能等级** | 同上 |
| **类别** | 一个物品「是什么」。**一个物品只有一个类别值、全局一致**，不是一堆标签 | [`物品系统`](../design/物品系统.md) |
| **堆** | 容器里占一格的那一摞同种东西。**堆的标识是「种类 ＋ 品质」**，所以同名不同品质分两堆 | [`背包系统`](../design/背包系统.md) |
| **堆上限** | 一堆最多能摞多少个。超了就要占下一格 | 同上 |
| **格位** | 容器里的格子。**一格一堆**，容量量的是堆数而不是种类数 | 同上 |
| **满载** | 格子用完了。这时**只拒不丢** —— 装不进的东西留在世界里，不会凭空消失 | 同上 |
| **翻包** | 在关卡里打开背包。**翻包暂停世界，用道具不暂停** | 同上 |
| **网格** | 建造用的坐标格。**有两套**：地面那套与地块共用，室内那套每类建筑各自声明 | [`建造系统`](../design/建造系统.md) |
| **仓储级数** | 仓库建筑升到第几级。它是**仓库格数的唯一入口**，别处不许再开一条扩容路径 | 同上 |
| **施工** | 下单之后到建成之间那段状态。**施工中就占地**，让冲突在下单那一刻就爆出来 | 同上 |
| **基础价** | 一件货的底价，是三层定价的第一层。品质并进这一层，不另当一个乘数 | [`经济系统`](../design/经济系统.md) |
| **成交价** | 这一刻真正付的钱。**只有三层**：基础价 × 需求 × 供给，每层都报得出当前值与一条原因 | 同上 |
| **需求** | 三层之二：这地方现在多想要这件货 | 同上 |
| **供给** | 三层之三：这地方现在有多少这件货 | 同上 |
| **支出管道** | 全作**唯一**那条花钱的路。现金不够一律只拒不赊、不产生欠款 | 同上 |
| **上架** | 商店这一刻摆出来卖的那些货。读的是所在区的境况档位 | 同上 |
| **订货** | 不在店里、先下单、延迟一天到手。它与到店买**同价同货** | 同上 |
| **报酬引用** | 一条委托上写的不是钱数，而是一个指向价格的引用。**在经济那一侧才解析成一笔具体的钱** | 同上 |
| **就近读** | 读**所在区**那一层，不是全城总量。失衡那几个读口都按这条 | [`活跃失衡系统`](../design/活跃失衡系统.md) |
| **境况事件** | 一件会改动失衡的事。它声明自己动哪几组、可正可负，**代价付在别人身上的必须双向** | 同上 |
| **双向** | 一件事把好处给这边、代价压给那边时，两侧都要显式写出来，不许只写好处 | 同上 |
| **委托** | 任务的一类：占接取额度、有截止、会失败。另两类是主线任务与个人请求 | [`任务系统`](../design/任务系统.md) |
| **目标条目** | 一条任务里的一个小目标。**一条任务可以有多个**，采集类计数不区分物品来源 | 同上 |
| **委托板** | 城里贴委托的那块板。它每天先作废超期的、再补满到固定条数 | 同上 |
| **撤退** | 在入口撤离时还有目标没达成。**奖励不发，但已获物品照样留着** | 同上 |
| **超期作废** | 每日结算里那一步：把过了截止的委托从板上撤掉 | 同上 |
| **补满** | 紧跟着的那一步：把委托板补回固定条数。**顺序是先作废后补满**，反了就会少补 | 同上 |
| **课堂授课** | 教学的两种形态之一：一次覆盖当天在基地的全部学生 | [`教育系统`](../design/教育系统.md) |
| **单独指导** | 两种形态之二：只教一个人，收益更大、效率掉得也更多 | 同上 |
| **掌握度** | 一个角色对一本书读到什么程度，按「角色 × 书」各记一份 | 同上 |
| **吸收效率** | 一个学生这一刻学得进多少，按学生记。**满值因人而异**，而闲置攒不出超过自己满值的余量 | 同上 |
| **连教** | 连着教同一个人。每次收益都低于上一次，**是一条下坡不是一道悬崖** | 同上 |
| **爱心** | 关系值在界面上的刻度。**机制一律读档位，不读爱心** —— 爱心只是给玩家看的 | [`人际系统`](../design/人际系统.md) |
| **填充量** | 当前档位里已经走了多少。它是**这套系统唯一的正反馈出口**，但机制不读它 | 同上 |
| **恋爱资格** | 角色定义上的一个字段。缺了载入报错 —— 恋爱是叠在一对关系上的状态，不是第六档 | 同上 |
| **步序** | 每日结算那一串固定的步骤。它**标着「固定，不得改动」**，步数一个不增一个不减 | [`时间与经营`](../canon/gameplay/时间与经营.md) |
| **事务** | 整串步序加那次自动存档合起来算一次，**要么全生效、要么一步都不生效** | [`每日结算系统`](../design/每日结算系统.md) |
| **结算摘要** | 结算完给玩家看的那份清单。它是**一个读口、不是第二份账** | 同上 |
| **接管输入** | 一个界面把键盘手柄接过去、世界停住。判据落在这件事上，不落在「它长得像不像弹窗」 | [`玩法定位`](../canon/gameplay/玩法定位.md) |
| **演出脚本** | 一段剧情的那串指令。**正式对话是其中一类指令**，所以只含对话指令的脚本就是一次纯对话 | [`剧情演出系统`](../design/剧情演出系统.md) |
| **跳过** | 玩家按住键直接结束这段演出。**它必须把脚本声明的状态变更一次性全部应用**，不许漏 | 同上 |
| **快进** | 加速播放，与跳过是两件事：快进仍然会走完每一步 | 同上 |
| **后果** | 一条事件触发之后做的那些事。**一律是对已有入口的调用**，那张表里没有「本页自己算」这一格 | [`事件系统`](../design/事件系统.md) |
| **权重** | 一条随机事件被抽中的相对可能性。它读失衡档位，方向是**只读** | 同上 |
| **一次性** | 事件的一个声明项：触发过就永不再来。判据是**后果可不可逆** | 同上 |
| **关系小事件** | 两个角色之间那类只有「触发 → 后果」的小事。按判据它是事件不是任务 | 同上 |
| **持续引导** | 玩家卡住时反复给的那类提示。它与事件共用同一份记账，可回查清单是那份记账的**读口** | 同上 |
| **气泡** | 角色头上冒出来的一句话。**不接管输入、不暂停世界、不承载必要信息** | [`气泡对话系统`](../design/气泡对话系统.md) |
| **语料** | 气泡能说的那些句子的集合。每条声明自己在什么上下文下可用 | 同上 |
| **上下文键** | 一条语料声明的适用条件。**没声明的键视为任意**，所以通用句兜得住、专用句够细 | 同上 |
| **冷却池** | 记「这句最近说过了」的地方，按「角色 × 条目」记。**只记真说出口的那一条** | 同上 |
| **纪事** | 日记两类条目之一：记发生了什么。存的是模板键加参数快照，**不存渲染好的句子** | [`日记系统`](../design/日记系统.md) |
| **心声** | 两类之二：记这个角色怎么看这件事 | 同上 |
| **节点** | 主线上的一个台阶。**解锁条件里没有天数**，只有「前置节点已完成」与「某位标记已置位」 | [`主线推进系统`](../design/主线推进系统.md) |
| **置位** | 把一位布尔标记从否改成是。**只置位、不回落** | 同上 |
| **只增** | 一个集合只往里加、不往外拿。推进那几样都是只增的 | 同上 |
| **存档位** | 玩家能存几份档里的一份。它与「续玩点」不是一回事 | [`存档系统`](../design/存档系统.md) |
| **原子替换** | 写档的做法：先写临时文件，写成了再整个换过去。**中途断电不会留下半份坏档** | 同上 |
| **隔离** | 缺 mod 时那些解析不到的东西的处置：**标成不可用、不进任何计数，但不删除**。装回 mod 一件不少 | 同上 |
| **玩家级偏好** | 设置、键位这类跨存档位的东西。它是**第三样东西**，既不是正式存档也不是续玩点 | 同上 |
| **埋点** | 往总线上发的一条统计事件：标识、发出者、一组带名字的量 | [`统计事件总线系统`](../design/统计事件总线系统.md) |
| **收录** | 图鉴里「这个我见过」的那一条记录。**只有一级**，对外只有一个幂等且不可撤销的写入口 | [`图鉴系统`](../design/图鉴系统.md) |
| **见过** | 触发收录的那一刻。**不是通用定义** —— 每一类各声明自己那个时刻（物品取进过容器、敌人取显形、技能取学会） | 同上 |
| **内容定义** | 一种内容的那一张表，条目自己声明它有哪几项能力。**「没声明」与「漏填」必须分得出来** | [ADR-0018](../decisions/ADR-0018-内容定义按声明扩展.md) |
| **拓扑** | 城区之间怎么连。它是**写死的**，不是算出来的 | [`地图与导航系统`](../design/地图与导航系统.md) |
| **边界点** | 一张图边上通往另一张图的那个口。**两边各声明一次，载入时互相对账**，不成对就报错 | 同上 |
| **分层** | 界面从世界内到最上层那几层。层次已经在代码里，文档只指路 | [`界面系统`](../design/界面系统.md) |
| **导航栈** | 一层层打开的界面叠成的那一摞，返回时按相反顺序退 | 同上 |
| **界面载体** | 一处界面挂在哪种东西上（手环、弹窗、HUD、世界内）。**取值直接用代码里那个已有分类** | 同上 |
| **世界内** | 画在游戏世界里、随镜头移动的那一层（气泡、引导提示、名字）。它不接管输入 | 同上 |
| **平衡判据** | 一条「这套数值算不算合理」的不等式。它由推演脚本逐条判，不靠手感 | [`数值模型`](../design/数值模型.md) |
| **尚未给值** | 一个量已经定了量纲与约束形式，但具体值还没定。它们登记在一张专门的表里，各写校准办法 | 同上 |
| **接口常量** | 一个结构上写死的数（几个技能位、几档、几张图）。它**不进参数表** —— 改它是改结构，不是调参 | 同上 |
| **派工** | 按天把角色指到工位上。一个角色一天只占一格，**后一次被拒而不是覆盖** | [`生产系统`](../design/生产系统.md) |
| **分片** | 存档不是一整块，而是若干片的集合，**每片由持有它的系统自己声明** | [`存档系统`](../design/存档系统.md) |
| **正式存档** | 跨过一次睡眠还成立的那些东西存这里。它只在睡眠那一刻写 | 同上 |
| **续玩点** | 只在这一次游戏里有意义的东西存这里（在哪张图、关卡进度、气泡说过哪句） | 同上 |
| **钩子** | 一个「发生了这件事」的询问时点。事件**只在被触到那一刻被问**，不轮询 | [`事件系统`](../design/事件系统.md) |
| **片段** | 手工搭好的一屏关卡。一关是若干片段按规则接成的一串 | [`关卡系统`](../design/关卡系统.md) |
| **可见集** | 这一帧谁看得见谁的那一份数据。**全作只算一次**，AI、画面、资源点显形都从它读 | [`感知与视野系统`](../design/感知与视野系统.md) |
| **记忆项** | 目标离开视野后留下的「最后一次看到他在哪」。它**不跟着目标走** | 同上 |
| **稀有度** | 一件东西**难不难得到**。与品质正交 | [`物品系统`](../design/物品系统.md) |
| **品质** | 这一件**做得好不好**，每个实例各带一个，且必须在物品上看得见 | 同上 |
| **副词条** | 一件宝物生成时掷出来的附加词条，**掷定即不可变** | [`装备系统`](../design/装备系统.md) |
| **掷定** | 生成那一刻随机决定、此后不再变。没有重掷入口 | 同上 |

## 这几个词会撞，写的时候要带全名

同名不同物在本库里是真实存在的坑。**各系统自己那份「边界与非目标」里点出与它相关的那一对**，本页只列跨多份文档都会遇到的：

| 词 | 它可能指 | 怎么办 |
| --- | --- | --- |
| **事件** | 随机事件、境况事件、关系小事件，以及统计事件总线上那条埋点 | **每处写全名**，不许写光秃秃的「事件」 |
| **失衡** | 战斗里那个被锁死的姿态，或全作唯一那个全局量 | 指全局量时写「活跃失衡」 |
| **档位** | 关系档位、境况档位、实战值档位、AI 分档、委托档位…… | 带上它是什么的档位 |
| **一次性** | 事件那个「触发过就永不再来」的声明项，或书那种「读完即消耗」 | 按上下文写全 |
| **孔** | 宝物孔（给属性）与技能孔（改机制），两者不通用 | 两个名字都已分开，不许再写「宝石孔」 |
| **支线** | 完美结局条件里那几条重要支线，或共同体选择链上那些可选支线 | 后者不是前者的一部分，写明是哪一类 |
| **标记** | 主线那种只置位的布尔位、装备那个唯一性标记，或玩家给敌人标的优先目标 | 三样毫无关系，带上它是什么的标记 |
| **目标** | 任务的目标条目，或关卡里那块放着要打的东西的目标片段 | 前者是任务的字段，后者是地图的一块 |

## 它什么时候该改

- **加词**：一个词过了上面「收词判据」那两道。加进来时同时确认它没有留在某一份的「术语」节里 —— 两处都有就是两个家。
- **删词**：没有任何系统文档在用它了。守卫会报出来。
- **改释义**：方法论词的释义改这里；领域词的释义**改被指向的那一份**，本页那一句白话跟着对齐即可。
- **不改**：游戏内名词的口径一律不进本页，它们在正典与[文案写作规范](../production/文案写作规范.md)。
