# Godot 实现教学

> **给谁看**：作者 —— 美术与设计出身、Godot 新手、有 Java 底子。**回答什么**：一件事在 Godot 里
> 怎么搭，用哪个节点，检查器里那些格子改了会怎样，以及本项目为什么有几处刻意不照通用教程做。
>
> **不回答什么**：某个系统的规则（那在 [`design/`](../../design/README.md) 下）、C# 语法
> （[C# 学习](../学习CSharp-Java程序员向.md)）、已经踩过的具体坑（[踩坑记录](../踩坑记录.md)）、
> 代码风格（代码仓 `CONVENTIONS.md`）、分层边界（代码仓 `ARCHITECTURE.md`）。这批文档只写
> **引擎怎么用**，碰到规则就写链接、不复述。

## 版本基线

引擎是 Godot 4.7.2 的 .NET 版，目标框架 `net10.0`，见 [ADR-0005](../../decisions/ADR-0005-技术基线.md)。
本机装了哪个版本，跑 `python tools/setup_godot.py --check` 看。

**官方文档一律查 4.7 那一版**：<https://docs.godotengine.org/en/4.7/>。搜引擎问题时网上大量答案是
4.0 到 4.2 的，节点名与属性名都变过 —— 最典型的是瓦片地图，老教程里的 `TileMap` 已经弃用，现在
是 `TileMapLayer`（[类参考](https://docs.godotengine.org/en/4.7/classes/class_tilemaplayer.html)）。
照老文章做而它不报错，是本项目最容易浪费时间的一类。

## 分工线：这批文档教的是你那一半

[ADR-0009](../../decisions/ADR-0009-编辑器主导的开发模式.md) 把工作切成两半：**代理写业务逻辑**
（状态机、判定与结算、数据加载、把节点接到规则上的胶水代码），**作者管场景与节点树、碰撞区域、
素材裁切与导入、动画帧、检查器里的参数值、摆位**。交界面是 `[Export]` 属性与 `Resource`：代理
定义并写清每一项是什么、量纲、合法范围，你填值。

所以每篇文档里有两种段落，都标着：

- **你要做的**：在编辑器里点哪里、填什么、填错了画面上会怎样。
- **代理会写成什么样**：好让你知道那个导出格子是从哪来的、为什么长这样。你不必自己写，但看得懂
  之后就能说「这个量不该在这里」。

## 四条贯穿全部文档的口径

这四条是本项目与通用 Godot 教程差别最大的地方，每篇都会再碰到，所以在这里说一次。

1. **`[Export]` 不许留能用的默认值。** 通用教程满地写 `@export var speed := 200.0`；这里是缺配置
   当场报错。理由在 ADR-0009：一个值如果既有代码默认值、又能在场景里存，场景那份会**静默胜出**，
   之后两边都要花时间在「为什么跟常量不一样」。
2. **内容定义走数据文件，不走 `Resource`。** 作物、物品、技能、敌人这类「一张表」的东西落
   `res://data/` 下的 JSON（[ADR-0022](../../decisions/ADR-0022-内容清单的家是数据文件.md)）。
   `[Export]` 只用在**场景几何与素材**那一层：占地几格、门朝哪、站位点摆哪、用哪张图。
3. **脚本不自己建场景树。** 脚本挂在你建好的节点上；缺子节点就报错说清缺谁，不自己补建 ——
   否则「忘了摆」会被静默兜底，而兜出来的表现是「这东西好像没效果」。
4. **游戏内时间不靠 `Timer` 节点表达，暂停也不给任何一页留开关。** 按天的事挂在每日结算那串固定
   步序上；界面暂停由导航栈整体决定（栈里有层就暂停），而战斗里的顿帧是另一套「当帧不推进」的
   闸门，与暂停不是一回事。展开在[时间与帧推进](./时间与帧推进.md)与[界面控件](./界面控件.md)。

## 两条边界写在最前面

**这批文档描述的是目标形状，而代码现状分两半。**

**经营那一侧已经是目标形状了**：`src/World/Farm/` 下那四个脚本就是「你搭树、脚本读 `[Export]`」，
跟着[一块地能种出东西](./一块地能种出东西.md)做就是。**战斗那一侧还没换过来** —— `scenes/` 下那两个
场景各只有一个节点，地形、碰撞框、精灵、摆位全在 `_Ready()` 里用代码建出来，编辑器里什么都看不见。
把它改过来是[待办台账](../../spec/issues/README.md)里 `GP-14`（训练房先行）与 `ENG-21`（其余跟上）；
手感数值改成检查器里可调是 `ENG-20`。所以打开工程看到战斗那几个场景是空的 —— 那不是你装错了。

**表现与手感没有机器判据。** 图形探针那一套已随 ADR-0009 删除，所以动画切得顺不顺、读条被取消
那一下看不看得出来、两块片段接起来像不像同一个地方，全靠你实机看。每篇末尾都有一节写**该看
什么**，不写怎么调 —— 怎么调是你拖两下就知道的事，隔着算式谁也判断不出「哪个更爽」。
