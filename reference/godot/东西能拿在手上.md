# 东西能拿在手上

> **这一篇是跟着做的，别篇是查的。** 它把[从哪里开始](./从哪里开始.md)里同名那一格的里程碑做到能玩：
> 收上来的菜进背包，打开手环看得到每一堆是什么、什么品质、几件，能挪、能排、能筛、能丢；
> 背包满了再收，看得出被拒，地里那一株还在。
>
> **它与[一块地能种出东西](./一块地能种出东西.md)交错着做。** 农场少了即时提示、手环或物品图标都起不来，
> 所以那一篇的「第六步：接上地块状态机」指到这里的第一步与第二步，「第七步：画作物，配素材」指到第三步，
> 做完回去接着做那一篇。第四步与「跑一遍验收」要那片地能种能收，放在那一篇做完之后；睡没睡过一觉都行。
>
> **谁做哪一半**：即时提示那一行摆在哪、长什么样、停多久，手环摆进农场，每个物品的图标框哪一格，归你；
> 背包、背包页的格子与按钮、丢弃前那一问、收获进背包、随身栏读背包与存档，代码已经写好了（`ADR-0009`
> 的分工）。每一步搭错了会得到一条说清缺谁的报错，不是静默不工作。
>
> **怎么读**：与[一块地能种出东西](./一块地能种出东西.md)同一个写法 —— 每一步是**目标**、**做什么**（照着点的表）、
> **跑起来该看到什么**、**看不到就是**、**为什么这样**。「加子节点」「附加脚本」「往格子里拖」这些说法怎么点，
> 在那一篇「开工前先确认」末尾那张表里。

## 做完是什么样

按 `F6`，按 `G` 往背包里放一批种子，种一格、按 `N` 到成熟，点一下收上来：

1. 输出面板说收上来的东西进了背包。
2. 按 `B`，手环打开、直接落在背包页：深色厚框里一行四格，收上来的那一堆画着图标、件数、品质点与稀有度框；
   变了的那一株与没变的分成两堆。
3. 鼠标指着一格，下面一行写它的名称、品质与件数。
4. 点一堆拿起来，再点一格，两格互换。开头标着格号的那几格就是随身栏，挪进去就拿到手上了。
5. 右边一列从上往下是排序、筛选、一键整理与丢弃，最下面写还剩几个空格。拿起一堆按丢弃，先弹一问，点了确认才丢。
6. 背包满了再收：屏上一行字说背包满了，地里那一株还在；丢掉一堆再收，收进来了。

手环开着时世界停着；按 `Esc` 或再按一下 `B` 关上。

## 开工前先确认

| 确认什么 | 怎么做 | 该看到 |
| --- | --- | --- |
| 那片农场搭到了第六步 | 照[一块地能种出东西](./一块地能种出东西.md)做到「第六步：接上地块状态机」，随身栏已经摆好 | `UI` 下面有 `CarryBar` |
| 工程构建过 | 在代码仓根目录跑 `dotnet build` | 0 错 0 警。这一篇用到的几个脚本没构建过的话，附加时找不到 |
| 素材资源在 | 文件系统面板里找 `res://assets/self-drawn/ui/ui_art.tres` | 找得到，随身栏接的也是它 |

## 你会搭出来的节点树

在那片农场上加这几样（标「新」的）：

```
Farm                 Node2D
├── InputRouter      Node
├── UI               Node              ← 挂 src/UI/UIRoot.cs
│   ├── CarryBar     Control
│   ├── Notice       Control           ← 新：挂 src/UI/InstantNoticeView.cs，跑起来挪到即时提示那一层
│   │   └── Line     Label             ← 新：被拒时屏上那一行字
│   └── Wristband    Control           ← 新：挂 src/UI/WristbandPanel.cs，跑起来挪到面板那一层
├── ……               地形、耕地、Actors、Cursor 与 Terrain，照那一篇
└── Field            Node              ← 挂 src/World/Farm/FarmField.cs；Notice、Wristband 与 Item Icons 那几格在这里接
```

**物品图标不在树上**：每个物品一份 `.tres`，存在 `res://assets/self-drawn/crops/` 下，拖进 `Field` 的 `Item Icons`。

**背包页的格子、右边那一列按钮与丢弃前那一问都由代码搭**，树上没有它们，编辑器里也看不到，跑起来才有。
理由在第四步末尾。

## 第一步：摆即时提示那一行

**目标**：一个动作被拒时，屏上出一行字说清是哪一种，停一会儿自己收起。

**做什么**：

| 选中 | 操作 | 填什么 |
| --- | --- | --- |
| `UI` | 加子节点 `Control` | 改名 `Notice`，附加脚本 `src/UI/InstantNoticeView.cs`；检查器 Layout → `Anchors Preset` 选 `Full Rect` |
| `Notice` | 加子节点 `Label` | 改名 `Line`；`Anchors Preset` 选 `Top Wide`；`Horizontal Alignment` 选 `Center` |
| `Notice` | 检查器 `Line` | 拖 `Line` |
| `Notice` | 检查器 `Art` | 从文件系统拖 `res://assets/self-drawn/ui/ui_art.tres` |
| `Notice` | 检查器 `Seconds Shown` | `2`（一行字停几秒；**没有默认值**，填 0 当场报错） |

`Field` 上那一格（`Notice`）在那一篇「第六步：接上地块状态机」的接线表里接，回去建 `Field` 时一起拖。

**跑起来该看到什么**：这一步做完还跑不起来，农场还缺手环、作物素材与物品图标。回那一篇按 `F6` 时，报的是
作物没有素材那一条（那一篇写着这正是下一步要做的事）；报的是下面几条之一，就是这一步没搭对。

**看不到就是**：

| 报错说 | 意思 |
| --- | --- |
| `InstantNoticeView`（节点 `Notice`）不在界面根下面 | `Notice` 没摆在 `UI` 下面 |
| `InstantNoticeView`（节点 `Notice`）的 `Line` 没接上，或者 `Line`「不在它下面」 | `Notice` 的 `Line` 格没拖，或拖的那一行摆在了别处 |
| `InstantNoticeView`（节点 `Notice`）的 `SecondsShown` 是 0 | `Seconds Shown` 没填 |
| `InstantNoticeView`（节点 `Notice`）的 `UIArt` 没接上 | `Notice` 的 `Art` 格没拖那一份素材资源 |

**为什么这样**：

- **那一行由你摆**，与随身栏相反：界面根跑起来把 `Notice` 铺满一屏，`Line` 摆在哪就出现在哪。先放在顶上居中是为了
  一眼看得见；字是浅色的，压在地上读不清就挪个地方，或者照[睡一觉能推进一天](./睡一觉能推进一天.md)那个窗的 `Box`
  给它垫一层 `PanelContainer` —— 收起时藏的是整个 `Notice`，垫的底也跟着收。
- **它不接管输入**，出现时世界照走；新的一条顶掉旧的、不排队。**手环与弹窗开着时它也在最上面**：背包页里丢不掉的
  那一下也走这一行，所以它那一层在面板与弹窗之上。
- **停多久是还没有值的量**，归[数值模型](../../design/数值模型.md)的尚未给值表。`2` 只是先跑通用的，看着改，
  调完把数说一声。
- **摆在 `UI` 下面、不要自己建 `CanvasLayer`**：理由与随身栏那一条相同，在[一块地能种出东西 · 第六步：接上地块状态机](./一块地能种出东西.md)。

## 第二步：摆手环

**目标**：农场里按 `Tab` 打开手环、按 `B` 直达背包页，开着时世界停着。

**做什么**：

| 选中 | 操作 | 填什么 |
| --- | --- | --- |
| `UI` | 加子节点 `Control` | 改名 `Wristband`，附加脚本 `src/UI/WristbandPanel.cs` |
| `Wristband` | 检查器 `Router` | 拖 `InputRouter` |
| `Wristband` | 检查器 `Art` | 从文件系统拖 `res://assets/self-drawn/ui/ui_art.tres` |

**只摆这一个节点。** 页签、外框、背包页的格子与按钮、丢弃前那一问都由代码搭。`Field` 上那一格（`Wristband`）
同样在那一篇的接线表里接。

**跑起来该看到什么**：与上一步一样，这一步做完还跑不起来；报的是下面几条之一，就是这一步没搭对。
全部配完之后它长什么样在第四步。

**看不到就是**：

| 报错说 | 意思 |
| --- | --- |
| `WristbandPanel` 的 `Router` 没接上 | `Wristband` 那个节点自己的 `Router` 格没拖 |
| `WristbandPanel`（节点 `Wristband`）的 `UIArt` 没接上 | `Wristband` 的 `Art` 格没拖那一份素材资源 |
| `WristbandPanel`（节点 `Wristband`）不在界面根下面 | `Wristband` 没摆在 `UI` 下面 |
| 界面「wristband」没登记到界面根上 | `Wristband` 摆在了 `UI` 下面别的节点里，没直接摆在 `UI` 下面 |

**为什么这样**：

- **摆在 `UI` 下面、只摆这一个节点**：界面根跑起来把它挪到面板那一层。开着时世界停着，常驻显示那一层整层藏起来，
  所以随身栏在手环开着时看不见，关上就回来。
- **键**：`Tab` 打开手环，`B`、`M`、`C` 直达背包、地图与角色面板那三个页签；每个键都是按一下开、再按一下关，
  开着时按别的直达键换过去，`Esc` 也关得上。别的界面开在最上面时这几个键不理。手柄只绑了 `Start`，进了手环靠焦点走。
  键位表在[输入](./输入.md)。
- **手环开着时按 `Tab` 会把它关上**：`Tab` 是开关手环的键。在格子与按钮之间走用方向键。
- **编辑器里看不到页签、格子与像素字体**，跑起来才有，与[睡一觉能推进一天](./睡一觉能推进一天.md)那两个窗同一个情况，
  不是没接上。

## 第三步：配物品图标

**目标**：随身栏与背包页的格子里画着那一样东西的图标，变异的那一堆画变异那一张。

**每个物品一份 `ItemIcon`**，作物那几样每种两份：种子一份、收获物一份，各对一份 `data/items/` 下的 json。
图从作物素材表上框：种子第 7 列，收获物第 8 列，变异收获物第 9 列；`x` 与 `y` 怎么算照
[一块地能种出东西 · 第七步：画作物，配素材](./一块地能种出东西.md)开头那两张表。框法也与那一步一样：
每一格新建一个 `AtlasTexture`、`Atlas` 拖 `crop1.png`、勾 `Filter Clip`。

**做什么** —— 先配好第一种：

| 选中 | 操作 | 填什么 |
| --- | --- | --- |
| 文件系统面板里的 `crops` 目录（`res://assets/self-drawn/crops/`） | 右键 → 新建 → 资源，搜 `ItemIcon` | 存成 `crop_01_seed.tres` |
| `crop_01_seed.tres` | `Item Id` | `crop_01_seed`，**与 `data/items/crop_01_seed.json` 里的 `id` 逐字符一致** |
| 同上 | `Icon` | 新建 `AtlasTexture`，`Region` 是 `(96, 0, 16, 16)`（第 7 列） |
| 同上 | `Mutated Icon` 与 `Mutated Same As Icon` | 都不动：种子没有品质 |
| 文件系统里的 `crop_01_seed.tres` | 右键 → 创建副本（Duplicate） | 存成 `crop_01_harvest.tres` |
| `crop_01_harvest.tres` | `Item Id` 改成 `crop_01_harvest`；`Icon` 的 `Region` 的 `x` 改成 `112`（第 8 列） | 收获物有品质，所以下一行那一格要配 |
| 同上 | `Mutated Icon` | 新建 `AtlasTexture`，`Region` 是 `(128, 0, 16, 16)`（第 9 列）。哪一种不另画变异那一张，就不配这一格、改勾 `Mutated Same As Icon` |

再配其余的：

| 选中 | 操作 | 填什么 |
| --- | --- | --- |
| 其余作物 | 照上面两份各复制、改：`Item Id` 改成那一行的标识，每个 `Region` 的 `y` 改成那一行的 | 第 2 行是 `crop_02_seed` 与 `crop_02_harvest`，`y` 是 `16` |
| `Field` | 检查器 `Item Icons` | 数组大小填成物品的种数（`data/items/` 下有几份 json 就是几），每一格拖一份 `.tres` |

**全部配完才跑得起来**：哪一样还没有图标，载入时就报错点名，农场不开工。配错的地方一次全报，一行一处，
照着那几行一起改完再跑。复制整份 `.tres` 文件没有「从别的格子粘贴」那个问题：那几格存在那份文件里，复制出来的是另一份。

**跑起来该看到什么**：这一步与那一篇第七步的作物素材都配完之后按 `F6`，农场起得来；按一下 `G`，随身栏的格子里
出现种子的图标。

**看不到就是**：

| 症状 | 原因 | 怎么办 |
| --- | --- | --- |
| 报「Item Icons 第 N 项是空的」 | 数组开大了，有一格没拖 `.tres` | 拖进去，或把数组改小 |
| 报「物品「x」在册但没有图标」 | `Item Icons` 里没把那一样的 `.tres` 拖进去 | 上面那张表最后一行。一份都还没配时，这几行就是要配的那张清单 |
| 报「物品「x」有品质，缺变异那一张」 | 收获物那一份的 `Mutated Icon` 没配 | 区域取第 9 列；不另画就勾 `Mutated Same As Icon` |
| 报「声明了无品质，变异那一格……用不上」 | 种子那一份配了 `Mutated Icon` 或勾了同原图 | 两格都清掉 |
| 报「第 N 项与第 M 项……都配给了物品「x」」 | 复制出来的那份没改 `Item Id` | 打开报错点名的那一项，改 `Item Id` |
| 报「图标配的物品「x」不在册」 | `Item Id` 与 json 里的 `id` 不一致 | 逐字符对一遍 |
| 随身栏里的种子画成了别的东西 | 那一份图标的区域算错了，复制出来的那份最常见的是漏改了 `y` | 照那一篇第七步开头按列、按行的表对一遍 |

**为什么这样**：

- **物品图标不进作物素材**：种子与收获物是物品，背包、随身栏与以后的商店都画它们，而它们不都是作物。所以一个物品
  一份图标、资源上写它是哪个物品，物品定义上没有这一格（[`物品系统`](../../design/物品系统.md)字段表的「图标」与
  「变异时的图标」两行）。
- **变异那一张不另画时勾同原图，不要把图标那一张再拖一遍**：拖一遍与复制出来忘了改看起来一模一样。
- **靠标识配对而不是靠数组顺序**：顺序对不上不报错，只表现为「萝卜画成了土豆」。

## 第四步：把背包页用一遍

**目标**：收上来的东西在背包页里看得到；挪格、排序、筛选、一键整理与丢弃各走一遍。

**前提**：那一篇做完、农场起得来，地里收过几样东西。

**做什么**：

| 要做什么 | 怎么做 |
| --- | --- |
| 打开背包页 | 按 `B`；或者按 `Tab` 打开手环、点背包那个页签。手柄按 `Start` |
| 看一格是什么 | 鼠标指着它，或用方向键把焦点停上去；下面一行写名称、品质与件数 |
| 挪一堆 | 点那一堆（外面套一圈选中框），再点目标格：空格就搬过去，有东西就两格互换。点回原来那一格是放回去 |
| 放到手上 | 挪进开头标着格号的那几格：那就是随身栏，关上手环按那个数字键就选到它 |
| 排序 | 右边一列最上面那一行，按一个键就照它排一次；按下去的那个就是当前排序键 |
| 筛选 | 下一行的两个按钮，一个按类别、一个按品质，按一下换一档；被筛掉的格画成用不了的格子，点不到 |
| 一键整理 | 再下一行左边那个：同一样东西分散的几堆并起来，再照当前排序键排 |
| 丢弃 | 先拿起那一堆，再按一键整理右边那个；弹出的那一问里点确认才丢，点取消或按 `Esc` 什么都不变 |

**跑起来该看到什么**：

1. 每一格画格子、图标、件数（多于一件才写）、品质点与稀有度框；种子没有品质，不画品质点；空格只画格子。
2. 同一种菜，变了的与没变的是两堆，品质点颜色不同。
3. 排序与一键整理之后，开头标着格号的那几格一格不动，后面的照键排好。
4. 那一问写明丢的是哪一样、什么品质、几件；焦点先落在取消上。
5. 右边一列最下面写还剩几个空格，丢掉一堆之后多一个。

**看不到就是**：

| 症状 | 原因 |
| --- | --- |
| 按 `B` 没反应 | 别的界面开在最上面（比如醒来那个窗），先关掉它；或者正在睡，醒来之前按什么都不起作用 |
| 点一格没反应 | 那一格被筛掉了，或者那一格是空的、手上又没拿东西。把两个筛选按钮按回全部 |
| 丢弃是灰的 | 手上没拿东西：先点一堆 |
| 排完开头几格没动 | 本来就这样：随身栏那几格排序与整理不碰，理由在下面 |
| 屏上说「……不能丢」 | 那一样声明了不可丢弃。现在的物品都丢得掉，碰到就是 `data/items/` 下那一份被改过 |
| 格子或按钮上出现 `◆缺文本:` 开头的一串 | 文本表（代码仓 `data/text/zh-CN.json`）里缺那一条，多半是被改过 |

**为什么这样**：

- **格子与按钮由代码拼，你只摆手环那一个节点**：一行几格、格距、整页多高归规则层（代码仓 `rules/UI/BagPageLayout.cs`），
  由测试管着；背包升了级多出几格只多几行，不用重摆。
- **排序与一键整理不碰随身栏那几格**：随身栏读的就是背包开头那几格，排一次就换掉你手上那一格，而你没按任何键。
  所以那几格只在你自己挪格时才变，格号标在那里就是为了让你看得出这一点。规则在
  [`背包系统` · 分堆的代价由排序、筛选与一键整理来付](../../design/背包系统.md)。
- **挪格是点两下，不做拖拽**：键盘、手柄与鼠标走同一套焦点，手柄上没有拖这个动作。
- **丢弃每一次都问**：整堆丢掉找不回来，而丢的收益只是空出一格。判据在
  [`界面系统` · 弹窗那一层：结算摘要与二次确认](../../design/界面系统.md)。
- **排序键与筛选条件不进存档**：它们是看东西的方式，停掉游戏再进来，照旧从按类别排、全部都看开始。

## 跑一遍验收

## 卡住了：按症状查

**先看输出面板。** 这几个脚本的报错都写清了缺哪一样、要的是什么；每一步末尾那张表按那一步查，这一张按症状查。

| 症状 | 最可能的原因 |
| --- | --- |
| 按 `F6` 一开场就报物品没有图标 | 第三步还没配完。报错那几行就是还要配的清单 |
| 被拒时屏上什么都没出 | `Line` 摆到了屏幕外面，或者字压在地上读不清；照第一步「为什么这样」那一条挪个地方或垫个底 |
| 屏上那一行一出就没 | `Seconds Shown` 填得太小 |
| 手环打开了，随身栏不见了 | 本来就这样：面板开着时常驻显示那一层整层藏起来，关上就回来 |
| 手环开着时按 `Tab`，它关上了 | 本来就这样：`Tab` 是开关手环的键。在格子与按钮之间走用方向键 |
| 收获时屏上说背包满了，作物还在地里 | 背包装满了，而且背包跟着存档走。在背包页里拿起一堆不要的、按丢弃、在那一问里确认，空出一格再收 |
| 第二批种子不在随身栏里 | 它们落在背包里第一个放得下的格，多半在随身栏后面那几格。在背包页里挪到开头标着格号的那几格 |
| 编辑器里看不到背包页的格子与字 | 本来就这样：它们由代码搭，跑起来才有 |
