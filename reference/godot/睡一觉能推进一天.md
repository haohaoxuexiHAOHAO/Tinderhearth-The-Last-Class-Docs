# 睡一觉能推进一天

> **这一篇是跟着做的，别篇是查的。** 它接着[一块地能种出东西](./一块地能种出东西.md)搭好的那片农场往下做，
> 把[从哪里开始](./从哪里开始.md)里同名那一格的里程碑做到能玩：走到床边睡一觉，画面暗下去、亮回来，
> 弹一份摘要说清这一夜变了什么；停掉游戏再进来，进度还在。
>
> **谁做哪一半**：床、遮罩与两个窗的节点、它们的图与排版、淡出淡入那两段动画归你；结算、存档与把这几样
> 接到规则上的代码已经写好了（`ADR-0009` 的分工）。每一步搭错了会得到一条说清缺谁的报错，不是静默不工作。
>
> **怎么读**：与[一块地能种出东西](./一块地能种出东西.md)同一个写法 —— 每一步是**目标**、**做什么**（照着点的表）、
> **跑起来该看到什么**、**看不到就是**、**为什么这样**。「加子节点」「附加脚本」「往格子里拖」这些说法怎么点，
> 在那一篇「开工前先确认」末尾那张表里。

---

## 做完是什么样

站到床边按一下交互键（鼠标左键或 `F`）：

1. 画面一档一档暗下去，整屏盖住。
2. 这一夜结算完、存档写上，画面再一档一档亮回来。
3. 弹出简版摘要：最上面一行是**刚过完的那一天**，下面每个有变化的项一行，比如「作物枯死 2 格」「作物变异 1 格」；
   一项变化都没有的那天只有一行「没有要紧的变化」。
4. 按窗上的按钮或 `Esc` 关掉，接着玩。

暗下去到窗弹出之前按什么都不起作用；窗开着时世界停着。输出面板逐格打出完整明细。按 `N` 走的是同一条路。

**存档写不上的那天弹的是另一个窗**：第一句是「存档没写上，这一天没有推进」，后面是原因、存档在哪、
「处理好之后再睡一次」。日期与地都停在睡前那一刻。

## 开工前先确认

| 确认什么 | 怎么做 | 该看到 |
| --- | --- | --- |
| 那片农场能种地 | 照[一块地能种出东西](./一块地能种出东西.md)做完，按 `F6` | 锄、播、浇、收都通，`N` 推得动一天 |
| 工程构建过 | 在代码仓根目录跑 `dotnet build` | 0 错 0 警。这一篇用到的几个脚本没构建过的话，附加时找不到 |
| 知道存档在哪 | 跑一次农场，看输出面板 `[存档]` 开头那一行 | 写着存档文件的绝对路径。存档只有一位，删掉那个文件就是重开 |

## 你会搭出来的节点树

在那片农场上加这几样（标「新」的）：

```
Farm                     Node2D
├── InputRouter          Node
├── UI                   Node              ← 挂 src/UI/UIRoot.cs
│   ├── CarryBar         Control
│   ├── Curtain          Control           ← 新：挂 src/UI/SleepCurtain.cs，跑起来挪到遮罩层
│   │   ├── Shade        TextureRect       ← 你画的点阵图，平铺满一屏
│   │   └── Animator     AnimationPlayer   ← 淡出与淡入那两段
│   ├── Summary          Control           ← 新：挂 src/UI/WakeDialog.cs，跑起来挪到弹窗那一层
│   │   └── Center       CenterContainer
│   │       └── Box      PanelContainer    ← 浅底那一块
│   │           └── VBox VBoxContainer
│   │               ├── Title   Label
│   │               ├── Body    Label
│   │               └── Close   Button
│   └── NotAdvanced      Control           ← 新：同一个脚本，Summary 复制一份
├── …
├── Actors               Node2D
│   ├── Player           CharacterBody2D
│   └── Bed              Node2D            ← 新：挂 src/World/Farm/Bed.cs
│       ├── Sprite       Sprite2D
│       └── Reach        Area2D
│           └── Shape    CollisionShape2D
├── …
├── Field                Node
└── Wake                 Node              ← 新：挂 src/World/Farm/SleepPresentation.cs
```

**这几个脚本都已经写好了**，每一步会讲它读你搭的哪一样、为什么要读。

⚠️ **遮罩与两个窗都摆在 `UI` 下面，不要自己建 `CanvasLayer`。** 界面根跑起来时把它们铺满一屏、挪到各自那一层，
理由与随身栏那一条相同（[一块地能种出东西 · 第六步：接上地块状态机](./一块地能种出东西.md)）。

## 第一步：摆一张床

**目标**：站到床边按交互键就睡；走开几步再按，照旧是锄地或浇水。

**做什么**：

| 选中 | 操作 | 填什么 |
| --- | --- | --- |
| `Actors` | 加子节点 `Node2D` | 改名 `Bed`，附加脚本 `src/World/Farm/Bed.cs` |
| `Bed` | 在 2D 视图里拖到草地上 | 离那片地的边至少两格（32 像素），见下面那条 ⚠️ |
| `Bed` | 加子节点 `Sprite2D` | 改名 `Sprite`；`Texture` 拖一张床的图，还没画就随便拖一张占位，代码不读它 |
| `Sprite` | 检查器 Offset 那一组 | `Centered` 取消勾选；`Offset` 填 `(−图宽 ÷ 2, −(接地那一行 + 1))`。32×32、接地在最底一行的图就是 `(-16, -32)` |
| `Bed` | 加子节点 `Area2D` | 改名 `Reach` |
| `Reach` | 加子节点 `CollisionShape2D` | 改名 `Shape`；`Shape` 那一格新建 `RectangleShape2D`，`Size` 先填 `32 × 24` |
| `Reach` | 检查器 `Collision` 那一组与 `Monitoring` | 保持默认：`Layer` 与 `Mask` 都只勾第 1 层，`Monitoring` 开着。`Player` 默认也在第 1 层 |
| `Bed` | 检查器 `Reach` | 拖 `Reach` |
| `Bed` | 检查器 `Sleeper` | 拖 `Player` |
| `Bed` | 检查器 `Field` | 拖 `Field` |

⚠️ **床要摆得离开那片地。** 站在床的范围里时，交互键一律是睡、不作用在当前操作格上；交互键在键鼠上是鼠标左键，
而当前操作格跟着鼠标走，所以范围里点哪一格都是睡。范围是以 `Bed` 的原点为中心的那个框，`32 × 24` 的话上下左右
各伸出半个框；你站在田边干活时，脚下那一格不能落进这个框里。

**跑起来该看到什么**（按 `F6`）：输出面板里一条报错，说这片地摆了床、却没有醒来那一套 —— 那一套在第四步，
**这条报错说明床已经接上了**。这时站到床边按交互键已经能睡：还没有淡出也没有窗，输出面板里多出
`[结算] 推进到` 那一行，作物长了一阶段。走开几步再按，是锄地或浇水。

**看到的是别的报错**：

| 报错说 | 意思 |
| --- | --- |
| `Bed` 的 `Reach` 没接上 | 检查器里那三格漏了一格，`Sleeper` 与 `Field` 同理 |
| 范围下面没有能用的碰撞形状 | `Reach` 下面没有 `CollisionShape2D`，或它的 `Shape` 那一格空着，或它被禁用了 |
| 关着 `Monitoring` | `Reach` 的 `Monitoring` 被关了。关着它就不记谁走进来，站进去也睡不了 |
| 掩码勾的层与角色所在的层一层都对不上 | `Reach` 的 `Mask` 没勾 `Player` 所在的那一层。报错里两边各是第几层都写着 |

**为什么这样**：

- **摆在 `Actors` 下面**，它才和角色一起按 y 排序：走到床后面被床挡住，走到床前面压在床上。排序看的是 `Bed` 的
  原点，所以 `Offset` 要让图的接地那一行落在原点上 —— 算法与理由同[一块地能种出东西 · 第三步：让角色走在上面](./一块地能种出东西.md)
  里那个 `Offset`。
- **层与掩码为什么保持默认就对**：范围要看见角色走进来，掩码就得勾上角色所在的层；两边默认都是第 1 层。规矩在
  [交互点与站位点 · 层与掩码怎么配](./交互点与站位点.md)。
- **站在范围里为什么一律是睡**：反过来让地优先的话，床边只要有一格够得着的地，这张床就睡不了。这一下由代码写死，
  不看引擎给的先后（[交互点与站位点 · 四、多个交互点同时够得着时怎么办](./交互点与站位点.md)）。床搬进室内之后
  这件事就没了，那是 `GP-130`。
- **床挡不挡路是另一回事**：要挡就在 `Bed` 下面再加一个带形状的 `StaticBody2D`，与范围无关。
- **范围画多大归你实机定**：站在看起来该能睡的地方能睡，走开几步再按是锄地或浇水。`32 × 24` 只是起步值。

## 第二步：做遮罩，画淡出与淡入那两段

**目标**：睡下时画面一档一档暗下去，醒来时一档一档亮回来。

**先画图。** 怎么画归你；下面是最省事的一种，照它画就能跑通。几张一样大的小点阵图，从稀到密，整屏平铺、一帧换一张：

| 文件 | 画什么 |
| --- | --- |
| `res://assets/self-drawn/curtain/fade1.png` | 4×4 像素，16 个像素里均匀点上 4 个，其余全透明 |
| `res://assets/self-drawn/curtain/fade2.png` | 同样大小，点上 8 个（棋盘格） |
| `res://assets/self-drawn/curtain/fade3.png` | 点上 12 个 |
| `res://assets/self-drawn/curtain/fade4.png` | 16 个全点上，就是一块实色 |

颜色取色板里最暗的那一档 `outline 1`（代码仓 `assets/self-drawn/palette.gpl` 最上面那条）。从哪条色带取了，就在那条色带
上方「借给」那一行注释里补一句，规矩写在那份文件的开头。画完在代码仓根目录跑
`python tools/check_art.py assets/self-drawn/curtain`：色板外的像素与半透明的像素它都会报出来。

**再搭节点**：

| 选中 | 操作 | 填什么 |
| --- | --- | --- |
| `UI` | 加子节点 `Control` | 改名 `Curtain`，附加脚本 `src/UI/SleepCurtain.cs`；检查器 Layout → `Anchors Preset` 选 `Full Rect` |
| `Curtain` | 加子节点 `TextureRect` | 改名 `Shade`；`Anchors Preset` 选 `Full Rect`；`Stretch Mode` 选 `Tile`；`Texture` 先空着 |
| `Curtain` | 加子节点 `AnimationPlayer` | 改名 `Animator` |
| `Animator` | 底部动画面板 →「动画」按钮 → 新建 | 名字 `fade_out`；时钟图标旁边那个时长填 `0.4`；循环按钮保持关着 |
| `Animator` | 同上，再新建一段 | 名字 `fade_in`；时长 `0.4`；循环关着 |
| `Curtain` | 检查器 `Animator` | 拖 `Animator` |
| `Curtain` | 检查器 `Fade Out` 与 `Fade In` | 填 `fade_out` 与 `fade_in` |

**最后打关键帧**，两段都打在 `Shade` 的 `Texture` 上：

| 那一段 | `0` 秒 | `0.1` 秒 | `0.2` 秒 | `0.3` 秒 |
| --- | --- | --- | --- | --- |
| `fade_out` | `fade1.png` | `fade2.png` | `fade3.png` | `fade4.png` |
| `fade_in` | `fade4.png` | `fade3.png` | `fade2.png` | `fade1.png` |

打一帧是这几下：在动画面板里选中那一段，把时间光标拖到那个时刻（或在面板顶上的时间框里填）；选中 `Shade`，从文件系统
把那张图拖进检查器的 `Texture`；再点 `Texture` 那一格旁边出现的钥匙图标。第一次点钥匙时它问要不要建轨道，
**「创建 RESET 轨道」那一项不勾**。选中 `Shade` 之后动画面板要是换走了，先点面板右上角的图钉把 `Animator` 钉住。

打完两段，**把 `Shade` 的 `Texture` 清空，再存场景。**

**跑起来该看到什么**：还是第一步那条「摆了床却没有醒来那一套」，别的没变；淡出淡入要到第四步接上才看得到。
这一步自己缺了什么会多一条：

| 报错说 | 意思 |
| --- | --- |
| `SleepCurtain` 的 `Animator` 没接上 | `Curtain` 的 `Animator` 那一格没拖 |
| `FadeOut` 没填 | `Fade Out` 那一格空着，`Fade In` 同理 |
| `FadeOut` 填的是「……」，`Animator` 里没有这一段 | 名字打错了。报错后面列着播放器里有哪几段 |
| 那一段设成了循环 | 动画面板里那一段的循环按钮开着。循环的永远播不完，睡下之后输入就一直关着 |
| 那一段长度是 0 秒 | 那一段的时长要比零长 |
| 动画播放器关着 `Active`，或 `Speed Scale` 不大于零，或 `Callback Mode Process` 是 `Manual` | 这几种都让动画一帧都不往前走，播不完。改回默认 |
| `UIRoot` 下面只能放界面节点 | `AnimationPlayer` 摆到了 `UI` 正下方。它要摆在 `Curtain` 下面 |
| 第一次睡下时整屏先闪一下 | 多半是存场景时 `Shade` 的 `Texture` 里还留着一张图。清空再存 |

**为什么这样**：

- **像素画面不许用半透明淡出**：透明度只有全透与全不透两种，半透明会算出色板外的颜色
  （[像素绘制原则 · 硬边、抗锯齿与点绘](../../production/像素绘制原则.md)）。所以「暗下去」是一档一档盖上去，
  不是把透明度从 0 拉到 1。
- **图放 `curtain/`、不放 `ui/`**：`ui/` 那个目录由界面素材生成器（代码仓 `tools/ui_art.py`）管着，清单外的图会被它
  报成多余。
- **快慢就是时间轴上拉的长短**，代码里没有时长；`0.1` 秒一档是起步值，「跑一遍验收」里再调。两段都不开循环，
  因为代码要等它播完才往下走。
- **存之前清空、不勾 RESET**：代码在淡出开始那一刻才把这一块显出来。存成带图的话，第一次睡下时可能先闪一下那张图。
  有了 RESET 轨道，存场景时引擎按它把 `Texture` 写回去（`AnimationPlayer` 的 `Reset On Save` 默认开着），你清空了也白清。
  淡入不用打一个「清空」的关键帧：播完代码就把这一块藏起来。
- **这一块盖着的时候世界没有暂停**，只是按什么都不起作用：遮罩不进导航栈，栈里有东西世界才停；输入是代码在门面上
  关的（[每日结算系统 · 结算期间没有输入入口](../../design/每日结算系统.md)）。

## 第三步：摆两个窗

**目标**：两个窗摆好、排好，平时看不见。

两个窗用同一个脚本，各摆一块：形状一样（最上面一行、下面几行、一个按钮），装的字不一样。先摆好简版摘要那一个，
再复制出另一个。

**做什么**：

| 选中 | 操作 | 填什么 |
| --- | --- | --- |
| `UI` | 加子节点 `Control` | 改名 `Summary`，附加脚本 `src/UI/WakeDialog.cs`；`Anchors Preset` 选 `Full Rect` |
| `Summary` | 加子节点 `CenterContainer` | 改名 `Center`；`Anchors Preset` 选 `Full Rect` |
| `Center` | 加子节点 `PanelContainer` | 改名 `Box`；检查器 Theme 那一组的 `Theme Type Variation` 填 `ContentInset`；Layout 那一组的 `Custom Minimum Size` 的 `x` 填 `240` |
| `Box` | 加子节点 `VBoxContainer` | 改名 `VBox` |
| `VBox` | 加子节点 `Label` | 改名 `Title`；`Theme Type Variation` 填 `PaperLabel` |
| `VBox` | 加子节点 `Label` | 改名 `Body`；`Theme Type Variation` 填 `PaperLabel`；`Autowrap Mode` 选 `Word (Smart)`；`Max Lines Visible` 保持 `-1` |
| `VBox` | 加子节点 `Button` | 改名 `Close`；别的都保持默认 |
| `Summary` | 检查器 `Title`、`Body`、`Close Button` | 依次拖 `Title`、`Body`、`Close` |
| `Summary` | `Ctrl+D` 复制一份 | 改名 `NotAdvanced` |
| `NotAdvanced` | 看一眼检查器里那三格 | 指的要是它自己下面那三个；不是就重拖 |
| `NotAdvanced` 下面的 `Body` | `Max Lines Visible` | `4` |

排版时可以在 `Title`、`Body` 里先打几个字看效果，跑起来会被换掉；按钮上的字也是代码填的。**编辑器里看到的是引擎
默认字体**，像素字体与按钮的样子跑起来才挂上。

**跑起来该看到什么**：两个窗都看不见（界面根把它们挪到弹窗那一层、先藏起来）。报错仍只有第一步那一条，
这一步缺了什么会多一条：

| 报错说 | 意思 |
| --- | --- |
| `WakeDialog` 的 `Title` 没接上 | 那三格漏了，`Body` 与 `CloseButton` 同理 |
| 按钮 `Action Mode` 不是 `Button Release` | `Close` 的 `Action Mode` 被改了，改回默认 |
| 按钮 `Focus Mode` 是 `None` | `Close` 的 `Focus Mode` 被改了，改回默认 |

**为什么这样**：

- **容器为什么这样套**：`Summary` 铺满一屏，`Center` 把 `Box` 摆在正中，`Box` 画浅底并给里面的字留边，`VBox`
  把那几样从上往下排。界面根跑起来会把 `Summary` 铺满一屏；编辑器里也选 `Full Rect`，排版时看到的才是跑起来的样子。
- **框用浅的那一族**：弹窗压在别的东西上面，成段的字左对齐（[界面绘制约定](../../production/界面绘制约定.md)）。
  `ContentInset` 是像素主题里那块浅底，`PaperLabel` 是浅底上的深字。**这两个名字填错不报错**，表现是浅底上一行浅字。
  字体与按钮的样子不用你配：跑起来代码给这两块挂上像素主题（[界面控件 · 七、主题与主题覆盖](./界面控件.md)）。
- **框要定一个宽**：`Body` 开了自动换行，而开了自动换行的 `Label` 不再按字撑宽，不定宽的话正文一个字一列地竖着排。
  `240` 是起步值，排版归你。
- **`Word (Smart)`**：中文怎么折都一样，路径与系统给的那句英文要它才折得对
  （[文字与文本框 · 二、自动换行：中文随便选都一样，差别全在西文](./文字与文本框.md)）。
- **字多了分页**（[文字与文本框 · 六、字放不下：对话框分页，别处按整行滚](./文字与文本框.md)）：`Max Lines Visible`
  就是一页几行，`-1` 是一页放全部。分页时按钮上的字是「下一页」，最后一页是「知道了」。「这一天没有推进」那个窗要装
  原因与存档路径，都可能很长，所以它分页、简版那个不分。
- **按钮那两项为什么不许改**：按下就算的话，关窗那一下同时是交互键刚按下，窗一关世界恢复，站在床边会紧接着又睡一次；
  `Focus Mode` 是 `None` 的话拿不到焦点，键盘与手柄就按不到它。

## 第四步：接上醒来那一套

**目标**：睡下去走完整套：淡出、结算、淡入、弹窗。

**做什么**：

| 选中 | 操作 | 填什么 |
| --- | --- | --- |
| `Farm` | 加子节点 `Node` | 改名 `Wake`，附加脚本 `src/World/Farm/SleepPresentation.cs` |
| `Wake` | 检查器那几格 | 按下表 |

| `Wake` 的格子 | 拖谁 |
| --- | --- |
| `Field` | `Field` |
| `UI` | `UI` |
| `Router` | `InputRouter` |
| `Curtain` | `Curtain`（`UI` 下面那个） |
| `Summary` | `Summary` |
| `Not Advanced` | `NotAdvanced` |
| `Art` | 从文件系统拖 `res://assets/self-drawn/ui/ui_art.tres`，与随身栏接的是同一份 |

**跑起来该看到什么**：第一步那条报错没了；输出面板多一行 `[界面] 像素字体`，后面是导入属性核对了几项、几项一致。

| 报错说 | 意思 |
| --- | --- |
| `SleepPresentation` 的 `Curtain` 没接上 | 上面那张表漏了一格，别的格同理 |
| `Summary` 与 `NotAdvanced` 接的是同一块 | 两格拖了同一个窗。两个窗各摆一块 |
| `Summary`（……）不在界面根（`UI`）下面 | 那一块摆在了 `UI` 外面 |
| `SleepPresentation` 的 `UIArt` 没接上 | `Art` 那一格空着 |
| 这片地接了两套醒来的表现 | 场景里摆了两个挂 `SleepPresentation.cs` 的节点。一片地只摆一套 |

**为什么这样**：

- **`Wake` 为什么要接 `UI`**：两个窗与遮罩必须在界面根下面，界面根才会把它们挪到自己那一层。不在界面根下面的窗
  不会被挪到弹窗那一层，打开时世界停了、窗却不显出来，所以接线时就核。
- **`Art` 为什么要接**：农场不经过主场景，两个窗上的像素字体与按钮的样子要由这一套自己装，装的时候从那一份素材资源取图。
  缺了它当场报错，不悄悄退回引擎默认的样子。

## 第五步：睡一觉，再退出重进

**目标**：整套走一遍，停掉游戏再进来，进度还在。

**做什么**：

| 做什么 | 该看到什么 |
| --- | --- |
| 种几格、浇上水，站到床边按交互键 | 暗下去、亮回来，弹出简版摘要；最上面一行写的是刚过完的那一天 |
| 窗开着时按方向键、按 `N` | 角色不动，推不动一天 |
| 按窗上的按钮或 `Esc` | 窗关上，接着玩 |
| 暗下去到窗弹出之前按方向键、`N`、`B` | 都不起作用，角色站着 |
| 看输出面板 | `[结算] 推进到 …` 一行；变了的格子一格一行，比如 `[结算] (3, 4) 的作物1长成时变异了`；再一行 `[存档] 写成 …` |
| 按 `N` | 与睡觉一样：暗下去、亮回来、弹窗、写一次档 |
| 停掉游戏，再按 `F6` | `[存档] 读回存档：…`，日期是睡醒那一天；地还是睡醒那一刻的样子 |

完整明细的家是手环上那一页，那一页还没有，归 `UI-20`；现在先打在输出面板上。

**想看变异**：把 `Field` 的 `Mutation Base Chance` 临时改成 `0.5`（`Mutation Chance Cap` 照旧 `0.5`），种几格、睡到长成
那一晚：摘要里多一行「作物变异」，输出面板为变了的每一格打一行。看完改回 `0.1`。

**想看枯死**：要让一株作物碰上换季，而它不在下一季里。

1. 种下 `crop_01`（随身栏第一批的第一格），睡一觉存下来，停掉游戏。
2. 用文本编辑器打开存档文件（路径在 `[存档]` 那一行）。它长这样，`plots` 那一段省略了：

   ```json
   {
     "version": 1,
     "shards": {
       "calendar": {
         "year": 1,
         "season": "Spring",
         "day": 2
       },
       "plots": { … }
     }
   }
   ```

3. 把 `day` 改成这一季的最后一天，存盘。一季几天见[时间与经营 · 时间](../../canon/gameplay/时间与经营.md)。
4. 打开代码仓 `data/crops/crop_01.json`，把 `seasons` 改成只剩当季那一个：存档里 `season` 是 `Spring`，就改成 `["Spring"]`。
5. 按 `F6`、睡一觉：那几格枯死，摘要里多一行「作物枯死」。
6. **看完把 `crop_01.json` 的 `seasons` 改回原来那四季。**

**为什么这样**：

- **窗开着时世界停着**：两个窗走导航栈，栈里有东西世界就暂停；关上交回。暗下去那一段不进栈，靠门面关输入，所以那一段
  世界没停、只是按什么都不起作用。
- **为什么换季那天枯死**：每日结算里枯死排在按天推进之前，不当季的作物在新的一季第一天之前就枯了
  （[一块地能种出东西 · 第八步：把这一天走完](./一块地能种出东西.md)）。

## 第六步：让它写不上

**目标**：写不上的那天说清这一天没有推进，日期与地都不动。

**做什么**：

| 做什么 | 该看到什么 |
| --- | --- |
| 在文件管理器里找到存档文件（路径在 `[存档]` 那一行），右键 → 属性 → 勾「只读」→ 确定。不用停游戏 | — |
| 睡一觉 | 弹的是另一个窗：第一句「存档没写上，这一天没有推进」，后面是原因（先一句中文，括号里是系统原话）、存档在哪、「处理好之后再睡一次」。字多时按钮是「下一页」 |
| 关掉窗 | 日期与地都还是睡前那样 |
| 去掉只读，再睡一次 | 这回推进了，弹的是简版摘要 |

**看不到就是**：设成只读了、睡下去还是推进了，多半是只读设在了存档目录上。**设在文件上**，设在目录上挡不住
（[文件读写与存档 · 怎么故意让它写不上](./文件读写与存档.md)）。

**为什么这样**：写档是这一夜最后一件会失败的事，它失败时整夜作废、日期与地都不动，所以玩家看到的是「这一天没有推进」，
而不是推进了一半。原因先给一句中文，是因为系统原话是英文，只给它的话读不懂；只给中文的话，少见的那几种又说不清。

## 跑一遍验收

**机器判得出的那一半**：在代码仓根目录跑 `python tools/verify.py`，每一步都该过。它判的全是代码那一侧 ——
**一条都不判这一套看着好不好。**

**只能你实机看的**：前提是第四步搭完、按 `F6` 不报错。从上往下走；每一行的名字是给台账里的实机清单对号用的。

| --- | --- | --- |

| **一档一档暗下去、亮回来** | 睡一觉，盯着画面 | 一档一档走，每一档都是整像素的点阵，没有一帧是半透明的 |

| **手感** | 床的范围、两个窗的排版、淡出淡入的快慢，各改几轮再跑 | 各调到合适 |

## 卡住了：按症状查

**先看输出面板。** 这几个脚本的报错都写清了缺哪一样、为什么要它；每一步末尾那张表是按报错查，这一张按症状查。

| 症状 | 最可能的原因 |
| --- | --- |
| 报错说 `Bed` 的 `Reach` 没接上，或范围下面没有能用的碰撞形状 | **缺床的范围**：第一步那个 `Area2D` 没拖进去，或它下面的形状没建、没画、被禁用了 |
| 站在床边按交互键是锄地，不是睡 | 角色没站进范围：范围画小了，或 `Sleeper` 拖的不是 `Player` |
| 在地里点一格却睡了 | 床的范围盖到了你干活时站的地方。床挪远一点，或把范围画小 |
| 报错说 `SleepPresentation` 的 `Summary` 没接上，或它不在界面根下面 | **缺弹窗**：第三步那一块没摆、没拖，或摆在了 `UI` 外面 |
| 报错说 `SleepPresentation` 的 `Curtain` 没接上，或 `SleepCurtain` 那两段没填、填的不存在 | **缺遮罩**：第二步那一块没摆、没接，或动画名字打错了 |
| 报错说这片地摆了床，却没有醒来那一套 | 第四步的 `Wake` 没摆，或它自己报了别的错没接上，往上找它那一条 |
| 睡下去画面没暗，过一会儿直接弹窗 | `Shade` 的 `Texture` 上没有关键帧，或打在了别的节点上。回第二步的关键帧表 |
| 一开场就报「存档 …… 读不出来，没有开新档」，后面说那片地对不上 | **存档对不上那片地**：存过档之后改了 `Field` 的 `Field Origin` 或 `Field Size In Cells`。报错里两边各多出哪几格写着，看得出是挪了还是改了大小。改回去，或者删掉那个存档文件重开 |
| 一开场就报「存档 …… 读不出来，没有开新档」，后面说不是一份读得通的 JSON、有认不出的分片、或缺了哪一项 | **存档被拒**：多半是手改存档时改坏了。改回去，或者删掉重开。它**不会自己开新档**：开了的话，下一次睡觉就把那份存档盖掉了 |
| 窗弹出来了，字浅得看不清 | 框是浅的那一族，`Title` 与 `Body` 的 `Theme Type Variation` 没填 `PaperLabel` 或填错了 |
| 正文一个字一列地竖着排 | `Body` 开了自动换行，外面那一块却没有宽。给 `Box` 的 `Custom Minimum Size` 填一个 `x` |
| 窗上出现 `◆缺文本:` 开头的一串 | 文本表（代码仓 `data/text/zh-CN.json`）里缺那一条，多半是被改过 |
| 存档文件设成只读了，睡下去还是推进了 | 只读设在了存档目录上，没设在文件上 |
