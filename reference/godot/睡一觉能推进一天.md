# 睡一觉能推进一天

> **这一篇是跟着做的，别篇是查的。** 它接着[一块地能种出东西](./一块地能种出东西.md)搭好的那片农场往下做，
> 把[从哪里开始](./从哪里开始.md)里同名那一格的里程碑做到能玩：走到床边睡一觉，画面暗下去、亮回来，
> 弹一份摘要说清这一夜变了什么；停掉游戏再进来，进度还在。
>
> **谁做哪一半**：床、遮罩与两个窗的节点、它们的图与排版、淡出淡入那两段动画归你；结算、存档与把这几样
> 接到规则上的代码已经写好了（`ADR-0009` 的分工）。每一步搭错了会得到一条说清缺谁的报错，不是静默不工作。
>
> **预计两到三小时。** 花时间的是淡出淡入那两段与两个窗的排版，接线本身很快。

---

## 做完是什么样

站到床边按一下交互键（鼠标左键或 `F`）：

1. 画面一档一档暗下去，整屏盖住。
2. 这一夜结算完、存档写上，画面再一档一档亮回来。
3. 弹出简版摘要：最上面一行是**刚过完的那一天**，下面每个有变化的项一行，比如「作物枯死 2 格」「作物变异 1 格」；
   一项变化都没有的那天只有一行「没有要紧的变化」。
4. 按窗上的按钮或 `Esc` 关掉，接着玩。

暗下去到窗弹出之前按什么都不起作用；窗开着时世界停着。输出面板逐格打出完整明细。按 `N` 走的是同一条路。

**存档写不上的那天弹的是另一个窗**：第一句是「存档没写上，这一天没有推进」，后面是原因、存档在哪、
「处理好之后再睡一次」。日期与地都停在睡前那一刻。

## 开工前先确认

1. **[一块地能种出东西](./一块地能种出东西.md)做完了**：农场按 `F6` 跑得起来，锄、播、浇、收都通，`N` 推得动一天。
2. **工程构建过**：这一篇用到的几个脚本是新的，没构建过的话附加脚本时找不到它们。跑一次 `dotnet build`。
3. **知道存档在哪**：跑一次农场，输出面板里 `[存档]` 开头那一行写着存档文件的绝对路径，不用自己拼。
   存档只有一位，删掉那个文件就是重开。

## 你会搭出来的节点树

在那片农场上加这几样（标「新」的）：

```
Farm                   Node2D
├── InputRouter        Node
├── UI                 Node              ← 挂 src/UI/UIRoot.cs
│   ├── CarryBar       Control
│   ├── Curtain        Control           ← 新：挂 src/UI/SleepCurtain.cs，跑起来挪到遮罩层
│   │   ├── Shade      TextureRect       ← 你画的那一块，铺满一屏
│   │   └── Animator   AnimationPlayer   ← 淡出与淡入那两段
│   ├── Summary        Control           ← 新：挂 src/UI/WakeDialog.cs，跑起来挪到弹窗那一层
│   │   └── Box …                        ← 你排的那一块，里面有 Title、Body、Close
│   └── NotAdvanced    Control           ← 新：同一个脚本，另摆一块
├── …
├── Actors             Node2D
│   ├── Player         CharacterBody2D
│   └── Bed            Node2D            ← 新：挂 src/World/Farm/Bed.cs
│       ├── Sprite     Sprite2D
│       └── Reach      Area2D
│           └── Shape  CollisionShape2D
├── …
├── Field              Node
└── Wake               Node              ← 新：挂 src/World/Farm/SleepPresentation.cs
```

**这几个脚本都已经写好了**，每一步会讲它读你搭的哪一样、为什么要读。

⚠️ **遮罩与两个窗都摆在 `UI` 下面，不要自己建 `CanvasLayer`。** 界面根跑起来时把它们挪到各自那一层，
理由与随身栏那一条相同（[一块地能种出东西 · 第六步：接上地块状态机](./一块地能种出东西.md)）。

## 第一步：摆一张床

**目标**：站到床边按交互键就睡；走开几步再按，照旧是锄地或浇水。

1. 选中 `Actors`，加子节点 → `Node2D` → 改名 `Bed`，附加 `res://src/World/Farm/Bed.cs`。
   **摆在 `Actors` 下面**，它才和角色一起按 y 排序：走到床后面被床挡住，走到床前面压在床上。
2. 选中 `Bed`，加子节点 → `Sprite2D` → 改名 `Sprite`，拖一张床的图。还没画就先用占位的，代码不读它。
3. 选中 `Bed`，加子节点 → `Area2D` → 改名 `Reach`；选中 `Reach`，加子节点 → `CollisionShape2D` →
   改名 `Shape`，`Shape` 那一格新建一个 `RectangleShape2D`，在 2D 视图里拖成「站在这里该能睡」那么大。
4. `Reach` 的层与掩码照[交互点与站位点 · 层与掩码怎么配](./交互点与站位点.md)：掩码勾上 `Player` 所在的那一层，
   `Monitoring` 开着（默认就开着）。
5. 选中 `Bed`，检查器里三格：

| 格子 | 拖谁 |
| --- | --- |
| `Reach` | `Reach` |
| `Sleeper` | `Player` |
| `Field` | `Field` |

⚠️ **床要摆得离开那片地。** 站在床的范围里时，交互键一律是睡、不作用在当前操作格上；交互键在键鼠上是鼠标左键，
而当前操作格跟着鼠标走，所以范围里点哪一格都是睡。反过来让地优先的话，床边只要有一格够得着的地，这张床就睡不了。
这一下由代码写死，不看引擎给的先后（[交互点与站位点 · 四、多个交互点同时够得着时怎么办](./交互点与站位点.md)）。
床搬进室内之后这件事就没了，那是 `GP-130`。

**床挡不挡路是另一回事**：要挡就在 `Bed` 下面再加一个带形状的 `StaticBody2D`，与范围无关。

**跑起来该看到什么**：输出面板里一条报错，说这片地摆了床、却没有醒来那一套 —— 那一套在第四步，
**这条报错说明床已经接上了**。这时站到床边按交互键已经能睡：还没有淡出也没有窗，输出面板里多出
`[结算] 推进到` 那一行，作物长了一阶段。走开几步再按，是锄地或浇水。

**看到的是别的报错**：

| 报错说 | 意思 |
| --- | --- |
| `Bed` 的 `Reach` 没接上 | 检查器里那三格漏了一格，`Sleeper` 与 `Field` 同理 |
| 范围下面没有能用的碰撞形状 | `Reach` 下面没有 `CollisionShape2D`，或它的 `Shape` 那一格空着，或它被禁用了 |
| 关着 `Monitoring` | `Reach` 的 `Monitoring` 被关了。关着它就不记谁走进来，站进去也睡不了 |
| 掩码勾的层与角色所在的层一层都对不上 | `Reach` 的掩码没勾 `Player` 那一层。报错里两边各是第几层都写着 |

## 第二步：做遮罩，画淡出与淡入那两段

**目标**：睡下时画面一档一档暗下去，醒来时一档一档亮回来。

**像素画面不许用半透明淡出**：透明度只有全透与全不透两种，半透明会算出色板外的颜色
（[像素绘制原则 · 硬边、抗锯齿与点绘](../../production/像素绘制原则.md)）。所以「暗下去」是一档一档盖上去，
不是把透明度从 0 拉到 1。**怎么画归你**，常见的一种：几张一样大的小点阵图，从稀到密，最后一张整格实色，
颜色取色板（代码仓 `assets/self-drawn/palette.gpl`）里最暗的那一档；整屏用它平铺，一帧换一张。

1. 选中 `UI`，加子节点 → `Control` → 改名 `Curtain`，附加 `res://src/UI/SleepCurtain.cs`。
2. 选中 `Curtain`，加子节点 → `TextureRect` → 改名 `Shade`，布局选「铺满」（Full Rect），`Stretch Mode` 选 `Tile`。
3. 选中 `Curtain`，加子节点 → `AnimationPlayer` → 改名 `Animator`。在动画面板里新建两段，比如叫 `fade_out`
   与 `fade_in`：
   - `fade_out` 在 `Shade` 的 `Texture` 上逐档打关键帧，从最稀那张走到实色那张；
   - `fade_in` 反过来，最后一帧把 `Texture` 清空。
   - **两段都不开循环**；快慢就是你在时间轴上拉的长短，代码里没有时长。
4. 选中 `Curtain`，检查器里：`Animator` 拖 `Animator`，`Fade Out` 填 `fade_out`，`Fade In` 填 `fade_in`。
5. 存场景之前把 `Shade` 的 `Texture` 留空：代码在淡出开始那一刻才把这一块显出来，存成实色的话，第一次睡下时
   可能先闪一下整屏。

**这一块盖着的时候世界没有暂停**，只是按什么都不起作用：遮罩不进导航栈，栈里有东西世界才停；输入是代码在门面上
关的（[每日结算系统 · 结算期间没有输入入口](../../design/每日结算系统.md)）。

**跑起来该看到什么**：还是第一步那条「摆了床却没有醒来那一套」，别的没变。这一步自己缺了什么会多一条：

| 报错说 | 意思 |
| --- | --- |
| `SleepCurtain` 的 `Animator` 没接上 | 第四格漏了 |
| `FadeOut` 没填 | `Fade Out` 那一格空着，`Fade In` 同理 |
| `FadeOut` 填的是「……」，`Animator` 里没有这一段 | 名字打错了。报错后面列着播放器里有哪几段 |
| 那一段设成了循环 | 动画面板里那一段的循环按钮开着。循环的永远播不完，睡下之后输入就一直关着 |
| 那一段长度是 0 秒 | 那一段的长度要比零长 |
| 动画播放器关着 `Active`，或 `Speed Scale` 不大于零，或 `Callback Mode Process` 是 `Manual` | 这三种都让动画一帧都不往前走，播不完。改回默认 |
| `UIRoot` 下面只能放界面节点 | `AnimationPlayer` 摆到了 `UI` 正下方。它要摆在 `Curtain` 下面 |

## 第三步：摆两个窗

**目标**：两个窗摆好、排好，平时看不见。

两个窗用同一个脚本，各摆一块：形状一样（最上面一行、下面几行、一个按钮），装的字不一样，排版你各自定。

1. 选中 `UI`，加子节点 → `Control` → 改名 `Summary`，附加 `res://src/UI/WakeDialog.cs`。
2. 在 `Summary` 下面排你的那一块：一个框（比如 `PanelContainer` 或 `NinePatchRect`），里面一个 `VBoxContainer`，
   依次放 `Title`（`Label`）、`Body`（`Label`）、`Close`（`Button`）。
   - 弹窗压在别的东西上面，框建议用浅的那一族，成段的字左对齐（[界面绘制约定](../../production/界面绘制约定.md)）。
   - **给框定一个宽**（`Custom Minimum Size` 的 x）：下一条要开自动换行，而开了自动换行的 `Label` 不再按字撑宽。
3. `Body` 的 `Autowrap Mode` 选 `Word (Smart)`。中文怎么折都一样，路径与系统给的那句英文要它才折得对
   （[文字与文本框 · 二、自动换行：中文随便选都一样，差别全在西文](./文字与文本框.md)）。
4. 字多了分页（[文字与文本框 · 六、字放不下：对话框分页，别处按整行滚](./文字与文本框.md)）：`Body` 的
   `Max Lines Visible` 填一页几行；不填（-1）就是一页放全部。分页时按钮上的字是「下一页」，最后一页是「知道了」。
5. 框用浅的那一族时，`Title` 与 `Body` 的 `Theme Type Variation` 填 `PaperLabel`（浅底上的深字）。
   **填错不报错**，表现是浅底上一行浅字。字体与按钮的样子不用你配：跑起来时代码给这两块挂上像素主题
   （[界面控件 · 七、主题与主题覆盖](./界面控件.md)）。
6. 按钮的 `Action Mode` 与 `Focus Mode` 保持默认（松开才算按下；拿得到焦点）。改了会当场报错，理由在下表。
7. 选中 `Summary`，检查器里：`Title` 拖 `Title`，`Body` 拖 `Body`，`Close Button` 拖 `Close`。
8. 再摆 `NotAdvanced`：选中 `Summary` 复制一份（`Ctrl+D`），改名 `NotAdvanced`，按它要装的字改排版 ——
   原因与存档路径都可能很长，它比简版更需要分页。**复制完看一眼它检查器里那三格**，指的要是它自己下面那三个；
   不是就重拖。

排版时可以在 `Title`、`Body` 里先打几个字看效果，跑起来会被换掉；按钮上的字也是代码填的。

**跑起来该看到什么**：两个窗都看不见（界面根把它们挪到弹窗那一层、先藏起来）。报错仍只有第一步那一条，
这一步缺了什么会多一条：

| 报错说 | 意思 |
| --- | --- |
| `WakeDialog` 的 `Title` 没接上 | 第七步那三格漏了，`Body` 与 `CloseButton` 同理 |
| 按钮 `Action Mode` 不是 `Button Release` | 按下就算的话，关窗那一下同时是交互键刚按下，窗一关世界恢复，站在床边会紧接着又睡一次 |
| 按钮 `Focus Mode` 是 `None` | 拿不到焦点，键盘与手柄就按不到它 |

## 第四步：接上醒来那一套

**目标**：睡下去走完整套：淡出、结算、淡入、弹窗。

1. 选中 `Farm`，加子节点 → `Node` → 改名 `Wake`，附加 `res://src/World/Farm/SleepPresentation.cs`。
2. 检查器里：

| 格子 | 拖谁 |
| --- | --- |
| `Field` | `Field` |
| `UI` | `UI` |
| `Router` | `InputRouter` |
| `Curtain` | `Curtain`（`UI` 下面那个） |
| `Summary` | `Summary` |
| `Not Advanced` | `NotAdvanced` |
| `Art` | 从文件系统拖 `res://assets/self-drawn/ui/ui_art.tres`，与随身栏接的是同一份 |

**跑起来该看到什么**：第一步那条报错没了；输出面板多一行 `[界面] 像素字体`，后面是导入属性核对了几项。

| 报错说 | 意思 |
| --- | --- |
| `SleepPresentation` 的 `Curtain` 没接上 | 上面那张表漏了一格，别的格同理 |
| `Summary` 与 `NotAdvanced` 接的是同一块 | 两格拖了同一个窗。两个窗各摆一块 |
| `Summary`（……）不在界面根（`UI`）下面 | 那一块摆在了 `UI` 外面。不在界面根下面，它不会被挪到弹窗那一层，打开时世界停了、窗却不显出来 |
| `SleepPresentation` 的 `UIArt` 没接上 | `Art` 那一格空着 |
| 这片地接了两套醒来的表现 | 场景里摆了两个挂 `SleepPresentation.cs` 的节点。一片地只摆一套 |

## 第五步：睡一觉，再退出重进

**目标**：整套走一遍，停掉游戏再进来，进度还在。

1. **种几格、浇上水，站到床边按交互键**：暗下去、亮回来，弹出简版摘要。最上面一行写的是刚过完的那一天。
2. **窗开着时世界停着**：角色不动，按什么都推不动一天。按窗上的按钮或 `Esc` 关掉。
3. **暗下去到窗弹出之前按什么都不起作用**：按着方向键角色也站着，`N` 与 `B` 也不响应。
4. **输出面板逐格打完整明细**：`[结算] (3, 4) 的作物1长成时变异了` 这样一格一行。手环上那一页还没有，归 `UI-20`。
5. **按 `N` 也一样**：暗下去、亮回来、弹窗、写一次档。
6. **想看变异**：把 `Field` 的 `Mutation Base Chance` 临时调到接近 `Mutation Chance Cap`，种到长成那一晚，
   摘要里多一行「作物变异」。看完改回。
7. **停掉游戏再按 `F6`**：`[存档]` 那一行写着读回了存档、今天是哪一天；地还是睡醒那一刻的样子。
8. **想看枯死**：种下 `crop_01`、睡一觉存下来，停掉游戏。用文本编辑器打开存档文件，把 `calendar` 里的 `day`
   改成这一季的最后一天（一季几天见[时间与经营 · 时间](../../canon/gameplay/时间与经营.md)）；再把代码仓
   `data/crops/crop_01.json` 的 `seasons` 改成只剩当季那一个。再跑、睡一觉：那几格枯死，摘要里多一行「作物枯死」。
   **看完把作物文件改回去。**

## 第六步：让它写不上

**目标**：写不上的那天说清这一天没有推进，日期与地都不动。

1. 在文件管理器里把存档文件设成只读（右键 → 属性 → 勾「只读」），不用停游戏。**设在文件上**，设在存档目录上
   挡不住（[文件读写与存档 · 怎么故意让它写不上](./文件读写与存档.md)）。
2. 睡一觉：弹的是另一个窗。第一句「存档没写上，这一天没有推进」，后面是原因（先一句中文，括号里是系统原话）、
   存档在哪、「处理好之后再睡一次」。关掉之后日期与地都还是睡前那样。
3. 去掉只读，再睡一次：这回推进了，弹的是简版摘要。

## 跑一遍验收

**机器判得出的那一半**：在代码仓根目录跑 `python tools/verify.py`，每一步都该过。它判的全是代码那一侧 ——
**一条都不判这一套看着好不好。**

**只能你实机看的**：

- [ ] 站到床边按交互键就睡；走开几步再按，是锄地或浇水而不是睡。
- [ ] 淡出与淡入一档一档走，没有一帧是半透明的；快慢合适。
- [ ] 两个窗的排版、字放不放得下；「这一天没有推进」那一个装得下长路径，要分页就分页。
- [ ] 窗开着时世界停着，关掉之后接着玩；暗下去到窗弹出之前按什么都不起作用。
- [ ] 停掉游戏再跑，日期与每一格地都是睡醒那一刻的样子。
- [ ] 存档文件设成只读再睡，窗上说清这一天没有推进与原因，日期与地都没变；去掉只读再睡一次，这回推进了。

## 卡住了：按症状查

**先看输出面板。** 这几个脚本的报错都写清了缺哪一样、为什么要它；每一步末尾那张表是按报错查，这一张按症状查。

| 症状 | 最可能的原因 |
| --- | --- |
| 报错说 `Bed` 的 `Reach` 没接上，或范围下面没有能用的碰撞形状 | **缺床的范围**：第一步那个 `Area2D` 没拖进去，或它下面的形状没建、没画、被禁用了 |
| 站在床边按交互键是锄地，不是睡 | 角色没站进范围：范围画小了，或 `Sleeper` 拖的不是 `Player` |
| 在地里点一格却睡了 | 床的范围盖到了你干活时站的地方。床挪远一点，或把范围画小 |
| 报错说 `SleepPresentation` 的 `Summary` 没接上，或它不在界面根下面 | **缺弹窗**：第三步那一块没摆、没拖，或摆在了 `UI` 外面 |
| 报错说 `SleepPresentation` 的 `Curtain` 没接上，或 `SleepCurtain` 那两段没填、填的不存在 | **缺遮罩**：第二步那一块没摆、没接，或动画名字打错了 |
| 报错说这片地摆了床，却没有醒来那一套 | 第四步的 `Wake` 没摆，或它自己报了别的错没接上，往上找它那一条 |
| 一开场就报「存档 …… 读不出来，没有开新档」，后面说那片地对不上 | **存档对不上那片地**：存过档之后改了 `Field` 的 `Field Origin` 或 `Field Size In Cells`。报错里两边各多出哪几格写着，看得出是挪了还是改了大小。改回去，或者删掉那个存档文件重开 |
| 一开场就报「存档 …… 读不出来，没有开新档」，后面说不是一份读得通的 JSON、有认不出的分片、或缺了哪一项 | **存档被拒**：多半是手改存档时改坏了。改回去，或者删掉重开。它**不会自己开新档**：开了的话，下一次睡觉就把那份存档盖掉了 |
| 窗弹出来了，字浅得看不清 | 框是浅的那一族，`Title` 与 `Body` 的 `Theme Type Variation` 没填 `PaperLabel` 或填错了 |
| 正文一个字一列地竖着排 | `Body` 开了自动换行，外面那一块却没有宽。给框定一个宽 |
| 窗上出现 `◆缺文本:` 开头的一串 | 文本表（代码仓 `data/text/zh-CN.json`）里缺那一条，多半是被改过 |
| 存档文件设成只读了，睡下去还是推进了 | 只读设在了存档目录上，没设在文件上 |
