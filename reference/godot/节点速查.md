# 节点速查

> 你在别处看到一个节点名、想知道它是干什么的，来这里查一行。
>
> **这里只给一句话加一个链接**，展开都在对应那一篇。**「详见」那一栏空着的，表示本项目现在用不到它** ——
> 那也是有用的信息（看到教程里在用，你会知道我们为什么没用）。总纲在[本目录索引](./README.md)。

---

## 位置与层级

| 节点 | 一句话 | 本项目用在哪 | 详见 |
| --- | --- | --- | --- |
| `Node` | 最基础的节点，没有位置。纯逻辑容器 | 输入门面、界面根 | [脚本与节点接线](./脚本与节点接线.md) |
| `Node2D` | 有位置、旋转、缩放的 2D 节点。**几乎所有世界里的东西都派生自它** | 场景根、纵深可视根、各种容器节点 | [编辑器与场景](./编辑器与场景.md) |
| `Marker2D` | 只在编辑器里画一个十字，运行时什么都不画。**就是「一个位置」** | 站位点、落点、镜头机位 | [交互点与站位点](./交互点与站位点.md) |
| `CanvasLayer` | 一个独立的绘制层，默认不受相机影响 | 界面六层 | [界面控件](./界面控件.md) |
| `RemoteTransform2D` | 把自己的变换同步给另一个节点 | 没用到。想让 A 跟着 B 走，本项目直接挂父子 | |

| `VBoxContainer` / `HBoxContainer` | 竖着／横着排一列 | 列表、技能位横排 |
| `GridContainer` | 按固定列数排格子 | 背包、图鉴 |
| `ScrollContainer` | 内容超出时可滚动 | 长列表 |

| `FlowContainer` | 排到边就换行 | 标签一类 |

## 刻意不用的那几个，各自的理由

**看到教程在用而本项目没用，来这里对一下。** 这几条都是有理由的，不是漏了。

| 节点 | 为什么不用 |
| --- | --- |
| `TileMap` | **已被引擎弃用**，现在是 `TileMapLayer`（一个节点一层） |
| `ParallaxBackground` 加 `ParallaxLayer` | 同上，被 `Parallax2D` 取代 |
| `RigidBody2D` | 动作游戏要的是「按住方向就以这个速度走」，刚体给的是「施加一个力之后它自己算」—— 后者的手感调不出来 |
| `Timer` | 游戏内时间不按真实秒算，而且它不认顿帧（顿帧期间它照走，硬直会静默短几帧）。替代形状在[时间与帧推进](./时间与帧推进.md)第七节 |
| `AnimationTree` | 互斥姿态的状态机在规则层，要能脱引擎单测；而且冻结与眩晕复用同一个被控姿态，不各建一个节点 |
| `NavigationRegion2D` / `NavigationAgent2D` | **本作不做寻路**（战斗 AI 那一份明写：本页决定往哪去，怎么绕障碍是实现） |
| `LightOccluder2D` | 视野遮挡按片段声明的区域判，不走引擎的光照遮挡与射线 —— 射线取错层不报错（已经踩过一次） |
| `HTTPRequest` | 不联网 |
| `LineEdit` | 没有要玩家打字的地方 |

## 几条跨节点的通用约定

这几条对**所有**节点都成立，所以放在这里而不是某一篇里：

- **`[Export]` 不留能用的默认值**，缺配置当场报错 —— [脚本与节点接线](./脚本与节点接线.md)第四节。
- **不覆盖 `TextureFilter`。** 每个 `CanvasItem` 都有这一格，默认是「继承项目设置」。改成线性过滤的
  表现是那一个节点（以及它的子树）像素糊掉。
- **不缩放像素素材。** `Scale` 保持 1，两种视角各画一套。
- **位置尽量填整数。**
- **订阅信号必须在 `_ExitTree` 里解绑**，用具名方法不用 lambda —— 自动解绑对自定义信号与捕获变量的
  lambda 都不成立。
- **`ProcessMode` 默认继承就对**，只有输入门面那类「暂停时也要跑」的才显式设。
- **脚本不自己建节点。** 节点由你在编辑器里搭，脚本找不到就报错说清缺谁。
