# GP-167：背包改成网格：先合堆，再找第一块够大的空地

## 目标

主角的背包是一张网格：东西进来先合进同标识、没满的那一堆，再放进从上到下、从左到右第一块放得下它整块占地的空地；放不下时整份被拒，原因分得开「满了」与「放不下这么大的」。

## 来源

- PRD：[`spec/prd-grid-bag.md`](../prd-grid-bag.md) 的 `US-002`。

## 依赖

- `GP-166`：一块多大读物品的占地。
- 每一级网格多大先用占位值，写在需求「技术考虑」那一节；正式的值与 C7 重算归 `GP-7`。

## 验收标准

- [ ] 可测试：同种同品质先合进没满的那一堆，到堆上限再放新的一块；同种不同品质各占一块。
- [ ] 可测试：放新的一块时，从上到下、从左到右找第一个放得下它整块占地的位置；那一块里的每一格都必须空着、都在网格里面。
- [ ] 可测试：网格里空格的数目够、却凑不出一块够大的空地时，被拒；挪开挡着的一堆之后，同一件放得进去。
- [ ] 可测试：一次放进去的那一份放不下时整份被拒，背包一件不变。
- [ ] 可测试：被拒有两种原因，分得开：一格空的都没有（满了），与有空格但凑不出这么大的一块。
- [ ] 可测试：网格每一级几行几列从代码仓 `data/config/game.json` 读，缺了当场报错；没有能用的默认值，占位值标明是占位。
- [ ] 可核对：设计仓 `design/numeric-model-params.json` 里背包那一项跟着改成几行几列，`python tools/simulate_week.py --check-doc` 跑过、摘要里没有失败项。
- [ ] 可核对：代码仓 `rules/Economy/Bag.cs` 与 `tests/Economy/BagTests.cs` 注释里引的[`背包系统`](../../design/背包系统.md)旧节名换成现在的节名。
- [ ] 可核对：代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。
