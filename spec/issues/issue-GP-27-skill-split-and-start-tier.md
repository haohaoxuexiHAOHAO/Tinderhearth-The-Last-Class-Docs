# GP-27：技能分战斗与生活两类，开局物资档与战斗难度分开

## 目标

在正典里把技能切成两类（战斗技能是放出来的动作、生活技能是熟练度），并新增一层只管经营侧的开局物资档。

## 来源

- PRD：[`spec/prd-base-and-production.md`](../prd-base-and-production.md) 的 `US-004`，以及 `US-008` 里开局物资档那一半

## 依赖

无。它与 `GP-25`／`GP-26` 改的是正典的不同小节，可以并行。

## 验收标准

- [ ] [角色与成长](../../canon/gameplay/角色与成长.md)写明两类：战斗技能（占技能位、耗蓝、有读条与冷却）与生活技能（钓鱼、种植、畜牧、烹饪、加工、交易六项，不占技能位）
- [ ] 写明统一的防刷判据 —— **凡是熟练度，只在真的做成那件事时涨**
- [ ] 写明生活技能的持有方是将来的 `成长系统`（`GP-30`），本条只定两类与取值
- [ ] 交易技能写明**只影响买卖点差**，[定价三层](../../canon/gameplay/时间与经营.md)一字不动
- [ ] 正典新增一层**开局物资档**，只影响起始资金、粮食与材料
- [ ] 同时写明[战斗与关卡](../../canon/gameplay/战斗与关卡.md)那两层难度**仍然不改变资源产出与经济压力**，并写清理由（一个开关调两样，玩家调不准自己想要的）
- [ ] 写明平衡判据按**物资最少的那一档**判定
- [ ] `python tools/check_docs.py` 0 FAIL
