# GP-151：日历与地块两个分片，存进去读出来一样

## 目标

日历与那片地各是正式存档里的一个分片：存进去再读出来完全一致，分片按什么顺序读结果都一样；地块那一份存的项与设计里那张清单一致，而那张清单补上它漏掉的一项。

## 来源

- PRD：[`spec/prd-sleep-advances-day.md`](../prd-sleep-advances-day.md) 的 `US-004` 第三、四、七、八格，`FR-21`、`FR-41`。
- 地块存什么在[`地块系统` · 一格要存什么](../../design/地块系统.md)，进哪一侧的判据在[`存档系统` · 进哪一侧：判据一句话](../../design/存档系统.md)。

## 依赖

- `GP-148`：存的是那份世界状态。
- `GP-150`：分片按那里的声明注册。

## 验收标准

- [ ] 可测试：日历与地块两个分片存进去再读出来完全一致；地块逐格逐项比，含变异那一位。
- [ ] 可测试：分片按逆序、乱序读，结果与顺序读一致。
- [ ] 可测试：地块分片存的项与[`地块系统` · 一格要存什么](../../design/地块系统.md)那张清单逐项一致。
- [ ] 可核对：那张清单补上「这一茬实际经过了几天」：它是产量系数的分母，由别的项算不出来（代码仓 `rules/Economy/Plot.cs`）。
- [ ] 可测试：一格地存的项彼此矛盾时载入被拒并点名哪一格（例：没有作物的状态带着作物标识、计数为负、阶段超出那种作物的阶段数）。
- [ ] 可测试：两个分片的存档默认值就是开新档时那一份：日历是开局那一天，地块是场景里那片地的起始状态。
- [ ] 可核对：分片里没有派生量；摘要不进存档。
- [ ] 可核对：代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。
