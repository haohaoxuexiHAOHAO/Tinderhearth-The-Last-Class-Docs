# GP-116：图鉴改成按存档位各记一份

## 目标

开第二个存档位时敌人与物品重新变成未知的，重玩有东西可以重新发现。

## 来源

PRD：`spec/prd-richness-and-feel.md` 的 `US-021`。

立项理由：[`图鉴系统`](../../design/图鉴系统.md)那份记录现在跨全部存档位，而它自己写明了后果 —— **第二个存档位从第一天起就有上一位见过的全部条目与对策**，二周目的「重新发现」被提前消掉了。而那正是重玩理由本来可以放东西的位置：[`多周目系统`](../../design/多周目系统.md)已经逐条排掉了世界线继承、难度继承与内容解锁条件，二周目的差异全部来自玩家自己的兑换选择。图鉴跨位记这一条还在反向扣它。

## 依赖

无强依赖；跟 `GP-54`（存档）同侧落地。**它改的是 `GP-58` 已经写下的一条结论**，所以那一条的备注要跟着改。

## 验收标准

- [ ] 那份记录改成存档位内的一个分片，跟着正式存档走
- [ ] 原先「不按存档位各记一份」那段论证连同它写下的代价一起替换
- [ ] 可测试：新建存档位时图鉴为空
- [ ] 那条「不给以未收录量为分母的计数」**不动**
- [ ] [`多周目系统`](../../design/多周目系统.md)那批跨存档位的东西（积分与已解锁）不受影响，且写明图鉴为什么不在其内
- [ ] 那条「两级收录重判」的欠账跟着复述一次现状（它依赖的敌人内容与对策声明都还不存在）
- [ ] `python tools/check_docs.py` 0 FAIL
