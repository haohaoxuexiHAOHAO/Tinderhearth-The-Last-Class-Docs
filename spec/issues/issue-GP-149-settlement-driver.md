# GP-149：结算驱动：一个入口，按步名把正典那串逐步调到

## 目标

推进一天只有一个入口，它按正典那串步序把每一步各调一次、一步不增减；日期、换季与作物那三步有活干，其余是空步，各写明归谁。

## 来源

- PRD：[`spec/prd-sleep-advances-day.md`](../prd-sleep-advances-day.md) 的 `US-002`、`US-001`（换季与作物那两格），`FR-2` 到 `FR-6`、`FR-8`、`FR-9`。
- 结构在[`每日结算系统`](../../design/每日结算系统.md)，步序在[时间与经营 · 结算顺序（固定，不得改动）](../../canon/gameplay/时间与经营.md)，本条都不复述。

## 依赖

- `GP-148`：驱动推的是那份世界状态，日期推进那一步用它的日历。

## 验收标准

- [ ] 可测试：推进一次，步名表里每一步恰好被调到一次，顺序与表一致；用例按名字比，不按序号。
- [ ] 可测试：步数是一个常量，用例钉住它等于步名表的项数；步名不重复。
- [ ] 可测试：交给驱动的步少一步、多一个表里没有的名字、或同一步给两次，构造当场被拒并说清是哪一步。
- [ ] 可核对：有活干的是「日期推进」「季节更替判定」「作物生长与枯死结算」；「生成结算摘要」「自动存档」「次日 6:30 醒来」三步在 `GP-152` 接上；其余每一步是空步，注释写明归设计仓台账哪一条。
- [ ] 可测试：「日期推进」把日期推进一天。
- [ ] 可测试：换季那天，「季节更替判定」把不在新季节列表里的作物标成枯死；不换季的那天一格都不动。
- [ ] 可测试：换季那天被标成枯死的那一格，在「作物生长与枯死结算」里不再长，也不掷变异；其余各格照地块那台状态机过一夜。
- [ ] 可测试：这一夜枯死与变异的每一格都记在这一天的结果里（哪一格、哪种作物、枯死还是变异），摘要从这里算。
- [ ] 可测试：「主动睡」与「强制结束」两个来源各推同一份世界一次，结果完全一致。
- [ ] 可测试：整串跑完之后经过一处询问事件的调用点，排在最后一步之后；现在是空的，注释写明归设计仓台账 `GP-52`。
- [ ] 可核对：调试键 `N` 改走这个入口，输出面板照旧为这一晚变异的每一格打一行；代码里推进日期与调地块按天推进的地方只在这几步里。
- [ ] 可核对：代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。
