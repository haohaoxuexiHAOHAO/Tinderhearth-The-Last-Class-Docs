# UI-5：相机五项行为

## 目标

俯视跟随、侧视 2 倍缩放、边界钳制、屏幕震动、演出镜头五项行为一次定完并落成一份两种视角共用的实现。

## 来源

- PRD：[`spec/prd-ui-framework.md`](../prd-ui-framework.md) 的 `US-003`
- [玩法定位 · 系统清单](../../canon/gameplay/玩法定位.md)点名这五项并写明"**行为不定下来，两种视角会各写一套**"

## 依赖

`UI-3`（侧视 2 倍缩放的有效视野是逻辑分辨率的一半，得先有分辨率）。

## 验收标准

- [ ] 俯视跟随主角且有死区：角色在死区内移动时镜头不动
- [ ] 侧视为 2 倍整数缩放，有效世界视野 320×180
- [ ] 相机在场景边界处被钳制，视口不越出地图，边界处不出现空白
- [ ] 基地建造时相机可滚动，角色接近可建造区边缘时自动推镜（作者 2026-08-30 选的方案：不做缩放）
- [ ] 屏幕震动可在设置里关闭；关闭后重击不产生任何位移
- [ ] 演出脚本能接管相机并在结束时归还，归还后跟随行为与接管前一致
- [ ] 两种视角共用同一份相机实现，不是各写一套
- [ ] 作者实机确认
