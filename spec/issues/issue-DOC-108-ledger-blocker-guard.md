# DOC-108：还开着的条目，它的「卡在」那一格不许指已关闭的编号

## 目标

台账里那种「这件事卡在某个编号上，而那个编号早就关了」的过期指针，要有东西查得出来。

## 来源

台账 `DOC-108`。原先的守卫（`check_closed_issue_refs`）判的是 `canon/` 与 `design/`，而卡点格子全在台账自己那一页上 —— 那个编号关闭之后，指针就地过期而守卫碰不到。

**立项时卡着的那个问题**：合法的历史引用与过期的卡点**形状相同**（「它是从某个已关闭编号拆出来的」是对的，「卡在某个已关闭编号」是错的），而「已归档编号」那张表整张都在引已关闭的号。按位置分还是按措辞分定不下来就会误报，而**误报多的门禁会被绕过**。

## 依赖

无。

## 验收标准

- [x] 判定面按实测定，不按猜：先量台账里指向已关闭编号的引用落在哪种格子，结果写进下面「设计决策」。
- [x] 守卫只判**还开着的行**的**「卡在」那一格**，别的格子一个都不碰。
- [x] 「已归档编号」那张表不在判定面内（那一列是每行自己的身份，不是指针）。
- [x] 反证：把一个还开着的条目的「卡在」改成指已关闭编号，**报 FAIL 并指名是哪两个编号**。
- [x] 反证的另一半：**已关闭的行**那一格里出现已关闭编号时**不报**。
- [x] 覆盖量为零判失败 —— 表格形状一变它不许静默空转。
- [x] 上线当下**零误报**：`python tools/check_docs.py` 0 FAIL。

## 实现笔记

### 设计决策

- **模糊点**：立项时那个问题 —— 按位置分还是按措辞分。
- **选择**：**按格分，而且只收「卡在」那一格；再叠一条「只看还开着的行」。**
- **理由（实测，不是推断）**：写了个只读探针把台账里指向已关闭编号的引用按格分类 ——

  | 落在哪 | 处数 | 读下来是什么 |
  | --- | --- | --- |
  | 「卡在」那一格 | 1 | 那一行**已经关闭**，所以是历史 |
  | 备注其余部分 | 83 | 全是合法历史叙述（「那一轮记账」「关闭时未交的那几项归 X」「同批带走 X」「它吸收了 X」）|
  | 「已归档编号」表的 id 列 | 那张表每一行各一个 | 是行自己的身份，不是指针 |

  **所以按措辞分（把「依赖」「跟着…走」也算上）会把那 83 处一并卷进来，收益是零。** 而只收「卡在」那一格之后，今天的误报是零。
- **为什么这一格判得了、别的格判不了**：这一格的语义只有一个 —— **什么挡着它**。挡着一件还没做完的事的，只能是另一件还没做完的事。所以「开着的行 ＋ 卡在 ＋ 已关闭编号」是一个真不变式，而不是措辞偏好。备注其余部分天然混着历史，没有这样的不变式可用。
- **「只看还开着的行」这一条不是为了避开那 1 处误报而加的补丁**，它本身就是不变式的一半：已关闭的行那一格记的是「当时卡在什么上」，那是历史。加了它之后，那 1 处不用改一个字就自然落在判定面外。
- **放过形式沿用既有那一条**（写成指台账的链接），不另立一套。

### 偏离

**无。**

### 权衡

- 考虑过整页扩面（把 `spec/` 加进 `CLOSED_REF_SCOPE`）。**没选**：那会一次报出 84 处，而其中真正的过期指针是 0 处 —— 台账那一行自己写的「误报多的门禁会被绕过」正是这个后果。
- 考虑过给「已归档编号」那张表加一条豁免、然后整个备注都判。**没选**：豁免只挡得住那一张表，剩下 83 处历史叙述照样报。豁免是每加一处就补一格的债。
