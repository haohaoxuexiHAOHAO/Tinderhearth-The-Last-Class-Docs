# DOC-48：正典那几处挂上链接

## 目标

让正典里提到存档、统计事件总线、每日结算与经营侧劳作的地方都点得进对应的系统文档，**而正典的意图一个字不改**。

## 来源

- PRD：[`prd-save-settlement-and-stats-bus.md`](../prd-save-settlement-and-stats-bus.md) 的 `US-007`
- 起因：`type: system` 的文档有一条硬判定 —— **必须被至少一份 `canon/` 链接到**，链接不在就当场 FAIL。而本批三份新文档落地之后，正典那几处提到它们的地方原来只有散文、没有去处。

## 依赖

`GP-54`／`GP-55`／`GP-56`（三份文档要先存在）。

- [x] 改完之后 `python tools/check_docs.py` 的「长期规格上游覆盖量」里三份新文档都有正典引用，且 0 项必须修复（与本批其余几条合并之后才成立）。
- [x] 正典里**不新增任何状态陈述**：进度仍只在[待办台账](./README.md)一处，别处写链接不复述。

## 实现笔记

### 设计决策

- **模糊点**：经营侧那台动作机要不要也在正典里有一处落点 —— 它并进了[`角色动作状态系统`](../../design/角色动作状态系统.md)，而那一份本来就已经被正典链接到了（`upstream` 指[战斗与关卡](../../canon/gameplay/战斗与关卡.md)）。
- **选择**：在[时间与经营 · 学生与派工](../../canon/gameplay/时间与经营.md)工位那一行补一条链接。
- **理由**：那一份的硬判定已经满足，所以这一条不是为了过检查。加它的理由是**读者路径**：一个来查「派工在世界里是什么动作」的人从经营侧那一册进来，而那一册原来一处都没有提到动作机。

### 偏离

- **方案怎么说**：PRD 的 `US-007` 列了「[时间与经营 · 学生与派工](../../canon/gameplay/时间与经营.md)或[时间与经营 · 生产](../../canon/gameplay/时间与经营.md)其中一处」。
- **实际怎么做**：挂在学生与派工那一处。
- **为什么**：工位清单在那一节，而劳作动作的清单就是工位清单 —— 链接挨着它最短。挂在生产那一节的话，读者会以为只有生产类劳作才走那台机器。

### 权衡

**「在正典写明本批那几条结论」考虑过**（例如把「跨过一次睡眠还成立的进正式存档」那条判据直接写进正典）。没选：那是系统文档刚刚做出的结构选择，还没有被第二批系统按它答过 —— 上升条件写在[`存档系统`](../../design/存档系统.md)的「下游同步」里，到时候再上。**低层文档不能静默改写高层意图，但也不该急着把自己的选择塞上去。**

### 待确认

无。本条只挂链接，没有留下待验证的假设。
