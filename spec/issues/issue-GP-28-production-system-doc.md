## 验收标准

- [ ] 按 [SYSTEM 模板](../../templates/SYSTEM.md)八节写全，`type: system`、文件名以「系统」结尾、`upstream` 指[时间与经营](../../canon/gameplay/时间与经营.md)，并被至少一份正典链接到
- [ ] 持有共用管道：产出从哪来、归谁、付不付酬、怎么入库、满了留在哪、品质读谁的生活技能
- [ ] 写明**工序 ＝ 配方 ＋ 制作者的生活技能等级**
- [ ] 写明**设备的价值是自动化**（不占派工位、添料不占时间与体力、只有主角能添），代价是产量低于人工、要烧料、占室内格子
- [ ] 写明**一台设备不得净产出自己所需的燃料**（烧木出煤可以，烧煤出更多煤不行）
- [ ] 钓鱼写明是**世界里的动作**：时机条画在角色身上、不暂停世界、受击中断且不消耗饵料；参数只有窗口宽度、指针速度、命中次数三项
- [ ] 写明时机条可复用到采集稀有点与加工精制
- [ ] 接口表列全挂载点并写明「到此为止」，入库那条指[`背包系统`](../../design/背包系统.md)、不复述它的规则
- [ ] 全文一个玩法数值都没有
- [ ] 作者实机确认：钓一次鱼（手柄与键鼠各一次）、摆一台设备并添料
- [ ] `python tools/check_docs.py` 0 FAIL
