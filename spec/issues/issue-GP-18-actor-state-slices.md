# GP-18：完整角色状态 —— 动作机姿态与状态载体扩容

## 目标

让角色身上「一次只能一个的」与「能并存的」各有一个家，并把状态载体从只支持帧级的两个槽扩成能装下按天与永久项的结构。

## 来源

- 设计已交付，规则与理由都在那里，本条只排落地顺序：
- [`角色动作状态系统`](../../design/角色动作状态系统.md) —— 姿态与完整流转表
- [`状态效果系统`](../../design/状态效果系统.md) —— 三类、三种时长单位、载体字段、显示与实际分离
- 分家的判据：**一次只能一个的归动作机，能并存的归效果。**

## 依赖

`GP-10`／`GP-11`／`GP-15`（都已完成，现行实现在代码仓 `rules/Combat/`）。

**载体扩容这一半不依赖任何玩法，可以先做。**

## 验收标准

### 载体扩容（六步，前两步随时可做）

- [ ] 加字段但不改行为 —— **A1 回归必须全绿**
- [ ] 定长两槽换成可扩结构（`rules/Combat/StatusEffects.cs` 里 `Index(kind)` 那套固定索引会被换掉，**这是破坏性改动**）
- [ ] 三种时长单位各自的推进点：帧走战斗逻辑帧、天走每日结算那一步、永久不推进
- [ ] 叠加与刷新按种类声明，外加多条控制类同时在场时的优先级
- [ ] 纯描述类与「显示／实际分离」并接进状态栏
- [ ] 跨场景与存档：离场清帧级项，按天与永久项带来源进档

**前两步随时可做；三种时长单位那步之后，每一步都跟着对应的玩法切片走。**

### 姿态（按切片推进）

- [ ] 防御与失衡
- [ ] 异常状态（冻结、眩晕复用同一个被控姿态）
- [ ] 技能与读条
- [ ] 死亡与倒下
- [ ] 精准闪避与空中攻击帧

### 防御那一片要接的新形状

正典已定（[战斗与关卡 · 防御与失衡](../../canon/gameplay/战斗与关卡.md)），流转表跟着收：

- [ ] **防御即定身** —— [`角色动作状态系统`](../../design/角色动作状态系统.md)里「防御／施法／读条同理锁住**或**限制移动」那句留了两种读法，要收成一种
- [ ] 流转表的防御那一行写明**精准防御是按下后的起始窗口，不是一个并列分支**
- [ ] 同一行写明**连点防御键不刷精准窗口**
- [ ] 防御朝向就是角色朝向，所以防御不需要独立的方向输入
