# GP-128：播种取随身栏选中那一格的种子

## 目标

一块地里种得下两种以上作物，全程不改配置、不重启。

## 来源

- PRD：[`spec/prd-carry-slots.md`](../prd-carry-slots.md) 的 `US-003` 与端到端那一条 `US-007`
- 现状：`src/World/Farm/FarmField.cs` 上那个写死作物标识的导出属性是脚手架，
  它的存在理由与要换掉的原因都在那个类的注释里

## 依赖

`UI-34`（随身栏那条六格）—— 没有「选中哪一格」这个读口，本条无从取值。

## 验收标准

- [ ] 选中作物 A 播一格、换成 B 播另一格，两格长出来的是各自那一种
- [ ] 选中的那一格**不是种子**时，对已锄的地按下去被拒**且说得出是这一种原因**
- [ ] 选中的那一格是**空的**时，同上被拒且原因与上一条**分得开**
- [ ] 那一格状态不允许播种时被拒，原因与前两种**都分得开**
- [ ] `src/World/Farm/FarmField.cs` 里那个写死作物标识的导出属性**被删掉** ——
      换来源不是两条路并存
- [ ] 端到端走完主路径：选中第 N 格 → 那一格是种子 → 对已锄的格播种 → 地里长的是那一种
- [ ] 端到端测试独立可重复，自己准备与清理数据（规则层，不启动引擎）
- [ ] 代码仓 `python tools/verify.py` 五步全绿
- [ ] **作者实机确认**：换一种种子再播，这一下顺不顺手
- [ ] **作者实机确认**：三条被拒路径各撞一次，分不分得出是哪一种
