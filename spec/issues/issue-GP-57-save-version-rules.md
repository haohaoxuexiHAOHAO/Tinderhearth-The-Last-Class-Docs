# GP-57：存档版本与兼容口径的落地反证

## 目标

载入时先判这份存档还打不打得开，再处理缺的与多的字段；ADR-0015 与 ADR-0017 的每一条各有一条用例钉住。

## 来源

- PRD：[`spec/prd-sleep-advances-day.md`](../prd-sleep-advances-day.md) 的 `US-004` 第五、六格，`FR-23` 到 `FR-28`。
- 口径在 [ADR-0015](../../decisions/ADR-0015-存档的版本与缺字段口径.md) 与 [ADR-0017](../../decisions/ADR-0017-版本更新对旧存档的两种后果.md)，顺序在[`存档系统` · 载入：先读分片，再统一解析标识](../../design/存档系统.md)，本条都不复述。
- 本编号原先只登了一行；这份需求把它并进来，才有了条目文件。

## 依赖

- `GP-150`：判的是那份文件的外形与那几个已注册分片。

## 验收标准

- [x] 可测试：比当前旧、而不低于最低兼容版本的存档缺一个字段，按那个分片的存档默认值补上，载入成功；整个分片缺了也一样。读法是代码仓 `rules/Foundation/Save/SaveFile.cs` 的 `ReadFormalSave`，测试在 `tests/Foundation/SaveVersionTests.cs`。
- [x] 可测试：与当前同版本的存档缺一个字段，载入被拒，并说清是哪个分片缺哪一项。缺整个分片也被拒。
- [x] 可测试：版本比当前新的存档被拒。
- [x] 可测试：版本低于最低兼容版本的存档被拒，被拒的说法分得出是这一种；这时没有任何一个分片被交给持有者。指向更新公告那一句归 `UI-23`，那一页还不存在。被拒的那几种在代码仓 `rules/Foundation/Save/SaveRejectedException.cs`；测试还核了被拒时连存档默认值都没取。
- [x] 可测试：把最低兼容版本调到等于当前，原先落在区间里、能补齐的那一份转为被拒（钉住那个常量真的在被读）。
- [x] 可测试：分片里多出来的字段被丢弃，再写回时不带它。
- [x] 可测试：存档里出现一个没注册的分片，载入被拒并点名它；它不被丢掉（隔离那条路归 `ENG-7`）。
- [x] 可测试：只往作物定义里加一种作物，旧存档照样打得开。这一条在代码仓 `tests/Economy/WorldShardsTests.cs`，走的是真的日历与地块两个分片。
- [x] 可核对：把「同版本缺字段」临时改成补默认值跑一次，那条用例失败；改回。
- [x] 可核对：当前版本号与最低兼容版本是两个规则常量、放在同一处，注释指向那两份 ADR。
- [x] 可核对：代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。

## 实现笔记

### 设计决策

- **模糊点**：被拒的那几种怎么交给调用方。
- **选择**：一种专门的异常，带一个「是哪一种」：读不出来、低于最低兼容版本、比当前新、同版本缺字段、有认不出的分片。
- **理由**：界面对这几种说的话不一样：低于最低兼容版本那一种要指向更新公告（`UI-23`），比当前新的要说是更新的游戏写的，写坏了的要说是文件坏了。只给一句话，界面就得去拆那句话。

- **模糊点**：现在当前版本与最低兼容版本相等，「落在区间里」那一段怎么测。
- **选择**：读法多一个由调用方给版本界限的重载，游戏里一律用不带界限的那个；那几条按「当前第 3 版、最低兼容第 2 版」演练。
- **理由**：两个规则常量都是 1，靠它们演练不出中间那一段。不带界限的那个是否真的读那两个常量，由「低于最低兼容」与「比当前新」两条走它的用例钉住：把它改成别的界限，那两条会失败。

- **模糊点**：缺字段补到哪一层、多出来的丢到哪一层。
- **选择**：只在分片的第一层；分片里一格是什么形状由持有者读的时候自己判。
- **理由**：分片的结构归持有者，存档这一层只知道「这个分片有哪几格」。地块那一块按项排正是为了让新加的一项落在第一层（`GP-151`）。

- **模糊点**：几道检查的先后。
- **选择**：先读最外层，再判版本，再拒认不出的分片，最后补或拒缺字段；同版本缺的字段一次全报。
- **理由**：判版本排在碰任何一个分片之前，被拒时才不会读出半份世界；认不出的分片排在补字段之前，因为它决定的是这份存档还要不要往下读。

### 偏离

无。

### 权衡

- **异常不派生自读不出数据那一种**：.NET 里那个类型是密封的，所以它直接派生自最一般的异常。调用方要同时接住它与分片持有者抛的「这一格读不出来」，两者都说清是哪一处。

### 待确认

无。
