# DOC-149：任务奖励的东西一律送到家旁边的货物箱

## 目标

文档里写定：委托、主线任务与个人请求的奖励物品一律当作货物送到家旁边的货物箱（订货送达的那个送达点），不直接进背包，玩家回基地自己去取；背包入口那一节不再写入口的个数。

## 实现笔记

### 设计决策

- **委托、主线任务与个人请求一律送货物箱，不只是放不下的那一份**；钱照旧直接进钱包。只送放不下的那一份，同一份奖励会按结算那一刻背包满不满拆成两处。理由与被放弃的两条在[`背包系统`](../../design/背包系统.md)的理由那一节。
- **货物箱就是订货的送达点**，只出不进：能往里放的话，它就是一个不占仓储级数、也装不满的仓库。
- **规则的家在背包系统那张入口表**，任务系统与经济系统各写一句、指回去。
- **箱子本身另立 `GP-164`**，这一条只写规则。它跟最先往里送东西的那个系统落地（订货 `GP-43` 或任务结算 `GP-41`）：没有往里送东西的系统时，建了它也没有读者。
- **标题改成「每个入口各有一条明确的拒绝路径」**：加一行之后不用再改标题。正文与验收里写着入口条数的几处一起改成不带数的说法。

### 偏离

- **方案怎么说**：只有背包放不下的那一份送货物箱。
- **实际怎么做**：任务奖励的东西一律送货物箱，委托、主线任务与个人请求都一样。
- **为什么**：奖励只落在一处，玩家从箱里挑着放进背包，不必按那一刻背包满不满去两边找；见上面「设计决策」那一条。

### 权衡

- **玩家每次都要走一趟货物箱**，背包空着时也一样。换来的是奖励只在一处，结算那一屏写一句「送进了货物箱」就说全了。
