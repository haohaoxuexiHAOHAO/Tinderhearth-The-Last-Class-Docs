# UI-42：HUD 按场合放：关卡收进顶上那一段，基地照旧贴四角

## 目标

关卡里站到屏幕任何位置都不被 HUD 挡住；基地的 HUD 照旧贴四角。

## 来源

- PRD：[`spec/prd-ui-art-baseline.md`](../prd-ui-art-baseline.md) 的 `US-002`，外加 `FR-22`（主场景在检查器里选场合）。
- 依据在[战斗与关卡 · 可行走纵深是怎么算出来的](../../canon/gameplay/战斗与关卡.md)与 [ADR-0013](../../decisions/ADR-0013-战斗片段就是一屏.md)；界面侧那条约束写在[`界面系统` · 常驻那一层：战斗与经营的抬头显示](../../design/界面系统.md)。
- 排法照那份 PRD `US-002` 那张表（标着假设，落地时由下面的测试判）。

## 依赖

- 技能栏与随身栏按格子那一档排，那一档是 `rules/UI/UIMetrics.cs` 的 `Cell`（`UI-41` 加的）。
- 与 `ENG-24` 有交界：`rules/UI/HudLayout.cs` 里乘侧视缩放的那两处由本条改，相机与纵深带不动。

## 实现笔记

### 设计决策

- **模糊点**：PRD 那张表里基地资源块只写了「按竖的精力条重算」，没有排法。
- **选择**：标签与那支竖的精力条在左，隔一个栅格是两行两列的状态位；竖管按中段平铺拉到与状态位一样高。与关卡那一块同宽。
- **理由**：竖管照画布原样摆时，这一块右边与下面空着一大片；拉到整块那么高之后，精力每变一点在管子里看得更清楚，状态位两行两列与关卡那一行能放的个数一样多。空管中间那一段每一行都一样，液面中间那一段（两个气泡一轮）首尾接得上，所以按行平铺不走样，平铺那一段写在素材资源那两格的九宫格边距里。
- **技能栏的位置按队友块的尺寸算，不看它显不显示。** 放置只吃尺寸，所以单人出征时技能栏不动；位置固定才有肌肉记忆。
- **技能栏两组之间不再空一个栅格。** 画好的那条栏是等距的；手柄上哪几格归哪个扳机，靠按住扳机时那一组连着高亮与每格里的面键记号。
- **基地 HUD 单独一份视图模型，不与关卡那份并成一个。** 基地里没有技能位、任务目标与队友，并成一个就得给那三样造「空」值，而本该有却给成空的格子不报错。
- **主场景的场合是一个第一项为「没选」的枚举，不直接导出场合本身。** 场合那个类型的第一项是基地，导出它等于留了一个能用的默认值。
- **精力条按液面那一段露出，不按整张图的高。** 画好的液面上下各空两行透明（实测），按整张图算的话精力剩一点时露出来的全是透明行。

### 偏离

- **方案怎么说**：界面件换成素材资源里的那几张，归 `UI-44` 的接线。
- **实际怎么做**：基地那支精力条（空管与液面）与四条资源的标签图标在本条就从素材资源取。
- **为什么**：这几件没有占位图，而排法就是照它们的尺寸定的；先造一份占位再换掉是白做。

### 权衡

- 关卡那一套全挤在顶上，换来的是下面整幅宽都不压人；左右两组中间那段顶上留给背景。占屏照旧由测试判在一成以下。
- 演示数据里那份「HUD 用到的全部文本键」删了：它的注释说启动时拿它核文本表，实际没有调用方；缺键照旧显成那个看得见的占位串。

### 待确认
