# UI-42：HUD 按场合放：关卡收进顶上那一段，基地照旧贴四角

## 目标

关卡里站到屏幕任何位置都不被 HUD 挡住；基地的 HUD 照旧贴四角。

## 来源

- PRD：[`spec/prd-ui-art-baseline.md`](../prd-ui-art-baseline.md) 的 `US-002`，外加 `FR-22`（主场景在检查器里选场合）。
- 依据在[战斗与关卡 · 可行走纵深是怎么算出来的](../../canon/gameplay/战斗与关卡.md)与 [ADR-0013](../../decisions/ADR-0013-战斗片段就是一屏.md)；界面侧那条约束写在[`界面系统` · 常驻那一层：战斗与经营的抬头显示](../../design/界面系统.md)。
- 排法照那份 PRD `US-002` 那张表（标着假设，落地时由下面的测试判）。

## 依赖

- 技能栏与随身栏按格子那一档排，那一档是 `rules/UI/UIMetrics.cs` 的 `Cell`（`UI-41` 加的）。
- 与 `ENG-24` 有交界：`rules/UI/HudLayout.cs` 里乘侧视缩放的那两处由本条改，相机与纵深带不动。

## 验收标准

- [ ] 可测试：HUD 每一块的锚点按场合给，关卡一套、基地一套。
- [ ] 可测试：关卡那一套每一块的底边都不超过纵向账留给 HUD 的那一段；640 宽与撑宽后的宽度各判一次。
- [ ] 可测试（反证）：把关卡任一块挪进纵深带，上面那条红。
- [ ] 可核对：那一段的高度写成一个注明出处的常量。纵深带改宽改窄时要复核它，那一格已经记在 `ENG-24` 条目里。
- [ ] 可测试：基地那一套照旧按跟随死区判可读区，但不再乘侧视缩放；`ENG-24` 条目里 `rules/UI/HudLayout.cs` 那一格同步勾掉。
- [ ] 可测试：两种场合各自占屏不超过一成、各块两两不重叠、都在安全边距内、块宽都是偶数。
- [ ] 可测试：关卡资源块恰好三条、基地资源块恰好一条；条数对不上照旧当场抛。
- [ ] 可核对：状态位那一行只留位置，内容跟状态系统走，界面侧不新增读口。
- [ ] 可测试：技能栏与随身栏同宽、都贴右，横坐标对齐。
- [ ] 可核对：位置固定 —— 单人出征时队友块收起，技能栏不跟着上移。
- [ ] 可核对：主场景能在检查器里选预览哪个场合，基地那一套带随身栏的演示数据。
- [ ] 可核对：代码仓 `ARCHITECTURE.md` 三轴表里排版量那一行的「块不许压角色可读区」按场合改写；`rules/UI/HudLayout.cs` 里 `ActionBar` 那段「底边右侧」的注释与台账 `UI-34` 那一行的同一说法跟着改。
- [ ] **作者实机确认**：主场景里两种场合各看一遍，把窗口拉宽各看一遍不错位。**人站进纵深带那一眼要等 `ENG-24` 把侧视相机改成不缩放之后才看得准**，在那之前这一格记「不适用（已记账）」。
