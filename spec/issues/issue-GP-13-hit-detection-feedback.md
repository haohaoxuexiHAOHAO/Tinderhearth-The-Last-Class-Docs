# GP-13：引擎层命中检测与打击反馈四件套

## 目标

引擎层做命中检测与打击反馈四件套，木桩受击有反应但不还手、不死。

## 来源

- PRD：[`prd-combat-feel-core.md`](../prd-combat-feel-core.md) 的 `US-004`
- SPEC：[`spec-combat-feel-core.md`](../spec-combat-feel-core.md) 的 §2.2、§5、`Hitbox`/`Hitstop`/`TrainingDummy`

## 依赖

`GP-12`——要有能动的主角才谈命中与反馈。屏幕震动复用 `GameCamera.Rig.Shake()` 与 `ShakeEnabled`（`UI-5`/`UI-12` 已建）。

## 验收标准

- [ ] 攻击判定框仅在 Active 帧启用；同一次挥击对同一受击框只结算一次
- [ ] 命中触发：顿帧（双方与相机一同静止）、受击闪白、击退位移随轻重不同、重击触发屏幕震动
- [ ] 屏幕震动经 `ShakeEnabled` 可关，关闭后重击**零位移**（可测）
- [ ] 木桩受击进入硬直（走 `GP-11` 统一状态载体），不还手、不移动（除击退）、不死、无血条、无伤害数字
- [ ] 顿帧期间不接受新输入推进，结束后继续
- [ ] 作者实机确认：四件套合起来「打得实」，且顿帧不长到打断连击的输入节奏
