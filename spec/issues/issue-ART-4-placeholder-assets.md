# ART-4：占位素材生成器与素材槽位登记表

## 目标

有一条可重跑的入口按最终规格产出占位素材，并有一份登记表记住每个槽位的规格与来源，使作者用自己的像素资源替换时不需要改任何代码。

## 来源

- 作者 2026-08-30 定的工作方式：占位素材先跑通逻辑，最终由他用自己的像素资源替换。他画图需要时间，不可能一次性提供全部素材。
- PRD：[`spec/prd-ui-framework.md`](../prd-ui-framework.md) 第 8 节「占位素材」三条约束

## 依赖

无。但它阻塞 `UI-8`（HUD 要素材才摆得出来）与 `ENG-10`（守卫要登记表才能比对尺寸与槽位）。

## 验收标准

- [ ] 生成器是可重跑的入口，不是一次性脚本；重跑产出逐字节一致（否则每次跑都会污染 git diff）
- [ ] 生成的占位件**一眼可辨是占位**，不会被误当成品
- [ ] 生成的占位件符合[像素绘制原则 §9](../../production/像素绘制原则.md)：透明度只用完全透明或完全不透明
- [ ] 生成的占位件带 1px 细节（描边），因此不会被 `ENG-10` 的"每个 2×2 块同色＝放大来的"那条误判
- [ ] 登记表每个槽位有：路径、用途、尺寸、帧数、来源与授权、是否待替换
- [ ] 登记表与实际文件比对一致（多、少、尺寸不符都能查出来）
- [ ] 下载类素材（角色精灵与动画）标明来源链接与许可证；CC0 来源可用，其余标明"不得进发行包"
- [ ] 作者实机确认：占位件在 640×360 下看得出布局意图
