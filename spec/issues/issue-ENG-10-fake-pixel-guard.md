# ENG-10：假像素守卫（半透明像素、错误缩放与槽位登记比对）

## 目标

代码仓有一条守卫能自动检出三类机器可判的素材缺陷：半透明像素、放大得来的假像素、与登记表不符的尺寸或槽位。

## 来源

- 台账已有条目，原文写明"**须在第一张素材进仓前就位**"，理由是这类缺陷静默累积、第 1 张免费第 200 张就是审计。
- 时机现在到了：`UI-1` 的 HUD 样板就是放第一批素材的地方（作者 2026-08-30 确认插进本轮）。
- 规则来源：[像素绘制原则 §9](../../production/像素绘制原则.md)「透明度只使用完全透明或完全不透明」，以及 §11 明确只给这一条立守卫的理由。

## 依赖

`ART-4`（登记表比对那一半需要登记表存在）。前两条检查不依赖它，可以先落地。

## 验收标准

- [ ] 检出 alpha ∉ {0, 255} 的像素，报出文件与坐标
- [ ] 检出"全图每个 2×2 块同色"的整图放大件，报出文件
- [ ] 与 `ART-4` 的登记表比对：文件多了、少了、尺寸或帧数不符都判失败
- [ ] 自报覆盖量（扫了几个文件、跳过几个、为什么跳过）；扫到 0 个文件必须判失败，不能静默通过
- [ ] 接进代码仓 `tools/verify.py`，门禁只调那一条
- [ ] 自证：按真实缺陷形状各注入一次（造一个半透明像素、造一个 2× 放大件、改一个尺寸），确认三条都拦得住，还原后复验通过
- [ ] 阈值类检查（亮部比例、对比、色数、孤点）**不做** —— 理由见[像素绘制原则 §11](../../production/像素绘制原则.md)
