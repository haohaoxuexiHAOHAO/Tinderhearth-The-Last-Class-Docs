# GP-152：整串是一次事务，写档成功才算数

## 目标

结算在世界状态的副本上跑，写档成功那一刻才换上去；在那之前任何一步出错或写档失败，世界一格不动，结果说得清这一天没有推进与原因。摘要在「生成结算摘要」那一步产出、在「次日 6:30 醒来」那一步交出，写档失败时交出零次。

## 验收标准

- [ ] 可测试：结算在世界状态的副本上跑；让写档之前的任意一步抛出（逐步各一条用例），世界状态一格不变，写档一次都没发生，结果写着这一天没有推进与原因。
- [ ] 可测试：让写档失败，世界状态一格不变，结果写着这一天没有推进与失败的原因。
- [ ] 可测试：写档成功之后世界换成推进过的那一份，写出去的正是它。
- [ ] 可测试：摘要在「生成结算摘要」那一步产出、在「次日 6:30 醒来」那一步交出；写档失败的那条用例里交出零次。
- [ ] 可测试：摘要写着结算的是哪一天、这一夜枯死几格与变异几格，以及每一格是哪种作物、枯死还是变异；那个日期取自日历那一处。简版与完整明细读的是同一份。
- [ ] 可测试：一项变化都没有的那天也交出一份摘要，只是没有项。
- [ ] 可核对：代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。
