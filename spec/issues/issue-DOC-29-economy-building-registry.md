# DOC-29：这一批的新量登记与规模基准补行

## 目标

让这一批新出现的量都有登记与校准办法，而不是等实现时才发现没人定过它。

## 来源

- PRD：[`spec/prd-economy-and-building.md`](../prd-economy-and-building.md) 的 `US-005`

## 依赖

`GP-43`、`GP-44` 与 `GP-45`（登记哪些量由那三条定出来）。

## 验收标准

- [x] 新量登记进[`数值模型` · 尚未给值的量，各自写明校准办法](../../design/数值模型.md)，各写校准办法与归属，至少覆盖：交易点差的幅度与上限、商店库存量与补货间隔按档位的偏移、建筑各级的材料与金钱代价、施工与升级占的天数、移动与拆除的返还比例、各级仓库格数按仓储等级的对应、生活技能档位阈值、各条专长的幅度。
- [x] 每条登记都写明**给值那一轮必须同时把判据接上**，形式与那张表已有各行一致。
- [x] **点差那一行额外写明一条约束形式**：点差不得大到让「买进卖出」本身有利可图（否则原地套利成为最优解），给值那一轮必须把它接成判据。
- [x] **商店库存偏移那一行要接进那个正反馈的刹车**（[`活跃失衡系统` · 三个新读口带来一个正反馈，刹车必须先在](../../design/活跃失衡系统.md)），不是单独登记一个幅度。
- [x] **接口常量不进那张表**并写明归属，至少覆盖：三层的层数、货币的级数、建筑的类数、生活技能的项数、档数与节点数。**免得以后被当数值搬走。**
- [x] [内容规模基准](../../canon/gameplay/玩法定位.md)里生活技能那两行按重排后的表与新档数改写；**建筑与室内那两行按名引用、不重复建筑清单**。
- [x] 那张表补一行**专长条目的起步量**，写明它是「两项技能配满全部节点，外加交易那一项配第二档一个节点」算出来的，理由句写清这个量级够试出什么（阶梯的分量与轴的异质性）。**满配那个数不写进表** —— 它不是起步量，写进去会让全部平衡判据按一个第一版不存在的规模算账。
- [x] `python tools/simulate_week.py` 全部判据成立（条数由脚本自报，本条不复述）。**改了内容规模基准就必须重跑。**
- [x] `python tools/simulate_week.py --check-doc` 无分叉。**参数路径必须写全键名，不许用通配符指代。**
- [x] `python tools/check_docs.py` 0 项必须修复。

## 实现笔记

> 由 `/note-it` 在实现和评审之后填写。

### 设计决策

- **模糊点**：生活技能那一行的档数怎么登记 —— 原来那一行叫「生活技能熟练度的档数」，是一个待定值。
- **选择**：那一行**改写成档位阈值与专长幅度**，档数从表里拿掉。
- **理由**：档数已经定了（五档），而且它是**接口常量**：改一档就要连带改各节点的专长内容与界面。接口常量留在尚未给值表里，下一个人会以为它还能调 —— 而那正是「被当数值搬走」的形状。留在表里的是真的还没定的东西：**做成多少次升一档**，以及各条专长的幅度。

第二处：新加的两行（定价与债务那一组、建造那一组）各带**约束形式**而不只是「等内容存在」。点差那一条是「不许原地买进卖出就赚钱」，库存偏移那一条是「要算进活跃失衡那条刹车」；建造那一组是「仓库格数只随仓储级数变」与「外观占地不随级数变」。**不写约束形式的登记行等于只记了一笔账、没记它的判据**，而给值那一轮的人正需要那个判据。

### 偏离

- **方案怎么说**：验收写「[内容规模基准](../../canon/gameplay/玩法定位.md)里生活技能那两行按重排后的表与新档数改写」。
- **实际怎么做**：**那两行都不再写数字** —— 项数那一行改成指链接，档位那一行整行换成「生活技能专长 27 条起步」。
- **为什么**：项数与档数都是接口常量，家在正典那张表；基准表再写一遍就是同一个数两个家。而基准表该记的是**内容量** —— 那才是「要做多少内容」这个问题的答案，也才是平衡判据该按之算账的东西。这一条沿用上一批得出的分工判据（基准表回答「要做多少内容」，尚未给值表回答「这个参数取多少」）。

### 权衡

「专长起步量按九项全配满记」考虑过。没选：那是一百零八条，远超「试得出这个设计成立」所需，而基准表是全部平衡判据的算账基准 —— 按一个第一版不会出现的规模算账，判据从一开始就对不上实际。**满配那个数刻意没写进表**。

「把满配量也写进理由句当参考」考虑过。没选：那个数写进去就会被当成目标，而它不是。

### 待确认

无。
