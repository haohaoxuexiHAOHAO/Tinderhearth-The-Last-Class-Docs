# GP-29：开荒与地块状态机

## 目标

让一片荒地要玩家自己清出来，清出来的东西还能当材料；地块从未清理到待收的流转写清。

## 来源

- PRD：[`spec/prd-base-and-production.md`](../prd-base-and-production.md) 的 `US-006`

## 依赖

依赖 `GP-28` —— 它是六条渠道里唯一有自己状态机的那条，先有共用管道才判得出它要不要独立成篇。

## 验收标准

- [ ] 地块状态与流转写清（未清理 → 可耕 → 已播种 → 待收），换季枯死与跨季作物接既有正典
- [ ] 清理物**只产初级材料**且供应受重生速率限制；进阶材料仍靠加工或购买
- [ ] 清理物**只在未开垦区域重生**，已开垦地块不长，理由写明（不罚离家出征的玩家）
- [ ] 开局那一小块已开垦的种植区按[玩法定位 · 开局](../../canon/gameplay/玩法定位.md)保留 —— 不要求玩家第一天先开荒
- [ ] **拆分判据写进文档**：这一节篇幅超过其余五条渠道之和就拆成 `design/种植系统.md`，判据是「有没有自己的状态机」
- [ ] 全文一个玩法数值都没有（重生速率、清理产量归 `GP-2`）
- [ ] `python tools/check_docs.py` 0 FAIL
