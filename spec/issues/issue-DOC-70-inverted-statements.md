## 验收标准

- [ ] 可核对：[`活跃失衡系统`](../../design/活跃失衡系统.md)接口表里那两行的方向改对 —— 它们写「**档位越低**，有益事件的权重越高」与「**档位越低**，卖的东西品质越好」，而同一页自己定的是「失衡越低、**档位越好**」；它还与本页那条刹车论证（失衡低 → 好事更多）和[时间与经营 · 商店卖什么，读它所在那一区的失衡档位](../../canon/gameplay/时间与经营.md)那张表（很差／偏差只出低级低品质）三处相反。
- [ ] 可核对：[`活跃失衡系统`](../../design/活跃失衡系统.md)里降个体值的入口与它自己的验收一致 —— 正文另开了「剧情」与「照护」两个入口，而验收写「学生个体值只有教学能降，其余入口一律拒绝」；正典给的是教学与改善境况两条。
- [ ] 可核对：[`每日结算系统`](../../design/每日结算系统.md)里摘要的产出时点与[结算顺序（固定，不得改动）](../../canon/gameplay/时间与经营.md)一致（生成结算摘要在自动存档之前），并把「**产出**」与「**弹出**」分成两件事写 —— 现在验收那句把两者当成一件。
- [ ] 可核对：[`每日结算系统`](../../design/每日结算系统.md)那张流程图不把正典那串的末尾几步说成「整串之外」 —— 生成摘要、自动存档、次日醒来弹摘要都在那串里。
- [ ] 可核对：[`建造系统`](../../design/建造系统.md)里外观占地的单位改对 —— 它写「在地面网格上占几格，长宽都取 16 的倍数」，而正典是一格 16px、「取 16 的倍数」说的是像素；按现在那句，正典给的常规 7×4 格与封顶 8×6 格**全是非法值**。
- [ ] 可核对：[`建造系统`](../../design/建造系统.md)与[`生产系统`](../../design/生产系统.md)对「未清理的格能不能盖房」给出同一个答案 —— 前者只拒「已播种或待收」，后者把「也能盖房」写在可耕那一格；两页共用同一套地面网格。
- [ ] 可核对：`python tools/check_docs.py` 0 项必须修复。
