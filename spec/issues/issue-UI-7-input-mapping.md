# UI-7：输入映射（键鼠与手柄，6 技能位走修饰键组合）

## 目标

键鼠与手柄都能完整操作战斗与界面，6 个技能位在手柄上靠修饰键组合触发且当前组合有可见提示。

## 来源

- PRD：[`spec/prd-ui-framework.md`](../prd-ui-framework.md) 的 `US-006`
- [战斗与关卡 · 按键与连击](../../canon/gameplay/战斗与关卡.md)：按键结构与"手柄按键不够，映射方案归 `UI-1`"
- 修饰键组合（而非技能轮盘）由作者 2026-08-30 定。轮盘被排除的理由：它要么暂停要么减速，与正典"关卡内不暂停"冲突。

## 依赖

`UI-3`。`UI-8`（HUD）依赖本条，因为修饰键提示要显示在 HUD 上。

## 验收标准

- [ ] `InputMap` 覆盖轻攻击、重攻击、防御、闪避／冲刺、跳跃、交互与 6 个技能位，键鼠与手柄各一套
- [ ] 手柄 6 技能位由修饰键组合触发（两个肩键 × 面键）
- [ ] 修饰键按下时能查询到"当前这一组是哪三个技能"（HUD 的显示落在 `UI-8`，本条只保证数据可取）
- [ ] 面板导航在手柄上可用：列表与标签页走焦点移动，网格摆放走光标移动
- [ ] 按键提示图标随最后使用的输入设备切换
- [ ] 动作名与设备无关，为将来"完全重映射"（正典设置里那一组）留出改键的位置，不写死按键
- [ ] 作者实机确认：手柄接上后六个技能位都按得出来，且知道自己按的是哪个
