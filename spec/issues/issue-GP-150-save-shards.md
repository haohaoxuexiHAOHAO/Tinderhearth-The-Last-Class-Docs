# GP-150：存档按分片声明与注册，一份存档文件的外形

## 目标

每个分片由持有它的系统显式声明并注册，声明缺一项或重复注册当场被拒；有一个读口列得出全部已注册的分片；一份存档文件最外层只有一个版本号与各分片，是明文 JSON。

## 来源

- PRD：[`spec/prd-sleep-advances-day.md`](../prd-sleep-advances-day.md) 的 `US-004` 第一、二、九格，`FR-18` 到 `FR-20`、`FR-22`。
- 结构在[`存档系统` · 一个分片要声明什么](../../design/存档系统.md)，格式在 [ADR-0015](../../decisions/ADR-0015-存档的版本与缺字段口径.md)，本条都不复述。

## 依赖

无。

## 验收标准

- [ ] 可测试：分片声明里的标识、持有者、进哪一侧与存档默认值各缺一次，都注册被拒，并说清缺的是哪一项。
- [ ] 可测试：同一个标识注册两次被拒；「进哪一侧」只有正式存档与临时续玩点两个取值。
- [ ] 可测试：已注册分片的读口列出的正是注册过的那几个，不多不少；没注册的不在里面，也没有自动发现。
- [ ] 可测试：写出来的存档文件最外层只有一个版本号与各分片，每个已注册分片一格。
- [ ] 可核对：明文 JSON，缩进排好，用文本编辑器打得开、看得懂。
- [ ] 可核对：代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。
