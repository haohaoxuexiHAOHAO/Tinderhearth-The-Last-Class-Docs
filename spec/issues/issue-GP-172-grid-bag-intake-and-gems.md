# GP-172：收获与调试键照新放法进背包，加四颗大宝石

## 目标

收获与调试键照新的放法进背包，放不下时屏上说清是哪一种原因；作者画的四颗大宝石各是一件占 2×2 的物品，调试键放得进背包，供实机看大图。

## 来源

- PRD：[`spec/prd-grid-bag.md`](../prd-grid-bag.md) 的 `US-007`。作者把宝石图放进代码仓、配图标资源那一格在 `ART-36`。

## 依赖

- `GP-167`：新的放法与两种被拒原因。
- `GP-168`：调试键那一批种子要落进随身栏那一排。
- `GP-170`、`GP-171`：宝石占 2×2，背包里有了它，挪格与排序都得照块走；只认占 1 格的排序碰到它会当场抛。

## 验收标准

- [ ] 可测试：收获照旧走生产那条管道进主角的背包；放不下时那一格照旧待收、一件不变，屏上那一行写的是两种被拒原因里的那一种。
- [ ] 可测试：开发期调试键那一批种子照旧先落进随身栏那一排，放不下整批被拒。
- [ ] 可核对：四颗大宝石（工作区 `gem3.png`，一颗 32×32）各是一件物品：类别是宝石（新加一份类别数据），占地 2×2，声明有品质；名字与价钱先用占位值并标明占位，正式的由作者定。
- [ ] 可测试：调试键能把这几颗大宝石放进背包；放不下时被拒、说清原因。
- [ ] 可核对：代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。
