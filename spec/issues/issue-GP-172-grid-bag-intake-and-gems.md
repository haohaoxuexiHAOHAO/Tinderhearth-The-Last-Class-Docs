# GP-172：收获与调试键照新放法进背包，加四颗大宝石

## 目标

收获与调试键照新的放法进背包，放不下时屏上说清是哪一种原因；作者画的四颗大宝石各是一件占 2×2 的物品，调试键放得进背包，供实机看大图。

## 来源

- PRD：[`spec/prd-grid-bag.md`](../prd-grid-bag.md) 的 `US-007`。作者把宝石图放进代码仓、配图标资源那一格在 `ART-36`。

## 依赖

- `GP-167`：新的放法与两种被拒原因。
- `GP-168`：调试键那一批种子要落进随身栏那一排。
- `GP-170`、`GP-171`：宝石占 2×2，背包里有了它，挪格与排序都得照块走。

## 验收标准

- [x] 可测试：收获照旧走生产那条管道进主角的背包；放不下时那一格照旧待收、一件不变，屏上那一行写的是两种被拒原因里的那一种。原因在代码仓 `rules/Economy/Harvesting.cs`（`HarvestStatus` 多了「放不下这么大的」），屏上那一行在 `rules/Economy/FarmNotices.cs`；用例在 `tests/Economy/HarvestingTests.cs`：一行三格的背包收一样占 2×2 的东西，被拒的原因是放不下这么大的，那一格照旧待收。
- [x] 可测试：开发期调试键那一批种子照旧先落进随身栏那一排，放不下整批被拒。原来那几条用例管着：`tests/Economy/ItemsInBagE2ETests.cs` 里第一批落进随身栏那一排，`tests/Economy/SeedBatchesTests.cs` 里放不下时一件不放。

## 实现笔记

### 设计决策

- **放不下的原因由背包在拒收之后答**：入库被拒时背包一件没变，这时问它为什么放不下，答的就是这一次的原因；管道那一格照旧只说入没入库，不另带一个原因。两种说法各一条文本键，满了要先腾东西，放不下这么大的挪一挪就行。
- **宝石要与它们的图标同一次提交**：农场启动时核每一件在册物品的图标（代码仓 `src/World/Farm/FarmField.cs` 的 `IndexItemIcons`），宝石进了在册物品却没有图标，或者有图标而宝石不在册，农场都起不来。物品标识定为 `gem_01` 到 `gem_04`，照 `gem3.png` 从左到右；图标资源归 `ART-36`。
