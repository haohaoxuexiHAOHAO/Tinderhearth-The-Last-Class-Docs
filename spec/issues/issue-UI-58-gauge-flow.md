# UI-58：资源条回复时中段流动，精力管的气泡一直往上浮

## 目标

看一眼就知道哪一条正在涨；基地那支精力管里的气泡是活的。

## 来源

- 界面素材那份需求（[`spec/prd-ui-art-baseline.md`](../prd-ui-art-baseline.md)）里 `UI-45` 落地时提出：条里气泡浮动与流动的效果用代码做，不画新图。那份需求没有这一项，所以单立一条（超边界记账）。
- 画法那一侧在[界面绘制约定 · 代码管什么、你画什么](../../production/界面绘制约定.md)，本条不复述。

## 依赖

- `UI-45`：「数值往上走」由它的追给出 —— 显示的长度正朝数值往上追的那段时间就是流动的时间，所以要等追与留一截落地。

## 验收标准

- [x] 可测试：横的资源条只在显示的长度往上追的那段时间里流动：填充中段按整像素往右挪，挪满一个周期回到原样；追到了就停，停在当时那一格，不跳回起点。扣减与留一截那一段不流。整像素与挪满一段回到原样在代码仓 `tests/UI/GaugeFlowTests.cs`；「在往上追」读的是 `GaugeChase.Rising`，`tests/UI/GaugeChaseTests.cs` 钉着；接到条上在 `src/UI/GaugeBar.cs`，无界面实跑看过（见验证结果）。
- [x] 可测试：精力管的液面中段一直按整像素往上挪，与数值涨不涨无关；同样挪满一个周期回到原样。接在代码仓 `src/UI/BaseHud.cs`，无界面实跑看过一轮回到原样。
- [x] 可核对：挪的只是作者画的中段，两头不动；不出现色板外的颜色与半透明；流动不改条的长度与裁剪，`UI-45` 那几条照旧成立。挪开的那几张由代码仓 `src/UI/FlowFrames.cs` 从原图切出，只把中段的像素换个起点；长度与裁剪那几层没动。
- [x] 可核对：横条流多快、精力管浮多快是作者在检查器里调的两个量，代码里没有能用的默认值；缺了载入报错。两个量与追、停那两个放在同一份资源里（代码仓 `src/UI/GaugeMotion.cs`），四个缺哪个启动时一次说全。
- [x] **作者实机确认**：回一大截时看得出在涨、挨打时不流；基地里精力管的气泡浮得不抢眼。两个速度调到顺手为止。

## 实现笔记

### 设计决策

- **横条只在回复时流，精力管一直浮。** 关卡里一直动会和战斗抢眼，回复时才动正好说「在涨」，与追条是同一个时机。精力只在睡觉时回满（[时间与经营 · 精力](../../canon/gameplay/时间与经营.md)），白天只减不涨，按「回复时才动」它白天一直不动；基地节奏慢、那支管子又小，慢慢浮不抢眼。
- **只挪画好的中段，不另画帧。** 中段本来就是首尾接得上的一段（平铺靠的就是这一点），按整像素循环挪看不出接缝，也不会多出色板外的颜色。形状要变的效果（气泡破掉、液面晃）才要逐帧画，不在本条。
- **挪的是贴图，不是节点。** 每张填充按它自己的九宫格边距切出中段，先做好挪开一格、两格……直到挪满一段之前的那几张（第 0 张就是原图），流的时候换贴图。平铺照旧由引擎铺，所以接缝照旧接得上，两头不动；一段多长就是中段多长，几张填充各按各的。
- **按那一帧开头算在不在追**：追到数值的那一帧也流满再停。

### 偏离

无。

### 权衡

- 被放弃的两种：全部一直流（关卡里抢眼）；全部只在回复时流（精力管白天永远不动）。
- 换贴图之外考虑过两种做法：着色器挪贴图坐标（九宫格那几段的贴图坐标得自己重算一遍）；把条拆成左头、中段、右头三个节点自己摆（等于重写一遍九宫格）。两样都比换贴图多一处会出错的地方，换贴图只多几张小图。

### 待确认

- **哪几张挪得出效果**（实测：把代码仓 `assets/self-drawn/ui/hud/` 下那几张填充的中段逐列、精力管液面的中段逐行比过）：生命、体力、法力三条与精力管液面的中段都带花纹，挪了看得见；经验条与扣减那一截的中段每一列都一样，挪了也看不出来 —— 扣减那一截本来就不流。
- 两头不动，花纹流到端头那里会被截断；实机看流动时没发现问题。
