# DOC-97：正典对账，口径分叉与过期引用

## 目标

把正典与已闭环的系统设计对一遍账。两侧对同一件事只留一种说法，正典里每个「以后再定」都指得到一个活着的归处。

## 来源

设计闭环之后的一次人工交叉核对（`design/` 那批系统文档对 `canon/`）。

发现它的那一轮需求（系统文档读得懂）的非目标写明不改结论、不动 `canon/`，所以按「超出边界不许顺手修」记账。那一轮已归档在 [`archive/spec/DOC-89-doc-readability/`](../../archive/spec/DOC-89-doc-readability/prd.md)（**历史背景·非依据**）。

下面每条口径都已由作者定过，结论直接写在各条验收里。

## 依赖

无。那一轮需求已归档，本条是下一个需求的锚点。**它当初卡在 `DOC-94`** —— 那一条最后要判的是「这一轮有没有改到结论」，而本条改的全是结论，混进同一批 diff 就判不出来了。
