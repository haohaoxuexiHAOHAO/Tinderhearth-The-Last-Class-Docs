# UI-6：界面层级、导航栈与手环容器骨架，含栅格与边距规范

## 目标

界面有一套集中定义的层级与导航栈，手环是带标签页的统一容器，并交出一组写下来的排版单位供后续所有界面与 `DOC-2` 使用。

## 来源

- PRD：[`spec/prd-ui-framework.md`](../prd-ui-framework.md) 的 `US-004` 与 `US-005`（两条合并：排版单位要在容器上落地才算定下来）
- 手环形态取"统一容器带标签页"由作者 2026-08-30 定；[世界观](../../canon/world/世界观.md)原写"手环的界面形态与交互结构待玩法与界面设计确定"

## 依赖

`UI-3`。

## 验收标准

- [ ] 层级自下而上固定为 世界 → 世界空间 UI → HUD → 面板 → 弹窗 → 过场遮罩，且有一处集中定义而非各场景自行摆放
- [ ] 导航栈支持压入与弹出，返回键逐层退出；栈空时返回键不吞掉输入
- [ ] 手环容器有标签页，**关卡内操作类标签页禁用、查看类可用**（[玩法定位 · 跨系统约定](../../canon/gameplay/玩法定位.md)）
- [ ] 关卡内打开背包时游戏**不暂停**，HUD 仍可见且世界仍在运行（[时间与经营 · 背包与仓库](../../canon/gameplay/时间与经营.md)）
- [ ] 给出栅格单位、面板内边距、元素间距、屏幕安全边距四个数，都是整数且与 16px 基础单位对齐
- [ ] 给出图标尺寸档位（至少 16px 与 32px 两档）
- [ ] 骨架里没有任何绝对像素坐标，全部由锚点与容器定位；改窗口宽高比后布局不错位
- [ ] 四个数与图标档位交付 `DOC-2`
- [ ] 作者实机确认
