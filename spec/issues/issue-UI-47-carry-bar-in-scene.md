# UI-47：随身栏能由作者摆进场景

## 目标

作者在编辑器里把随身栏摆进一个俯视场景、接上门面，它就照常工作。

## 来源

- PRD：[`spec/prd-ui-art-baseline.md`](../prd-ui-art-baseline.md) 的 `US-007` 里那一格（`FR-21`）。
- 起因：`src/UI/CarrySlotBarView.cs` 原先只有一个带参构造函数，而 Godot 的 C# 脚本要从场景实例化必须有无参构造函数（[社区报错实例](https://forum.godotengine.org/t/resource-load-causes-missingmemberexception/48154)，本工程没实测）。所以作者摆不进场景，`UI-34` 与 `GP-128` 剩下的「接进真场景」都卡在这里。

## 依赖

- 无硬前置。格框与选中框先读现有的图；`UI-44` 落地时换成从素材资源取，本条的接线不用重做。
- **排在界面这份需求的第一个做**：农场要它才跑得起来（[一块地能种出东西](../../reference/godot/一块地能种出东西.md)里接线那一步缺了随身栏当场报错），而 `UI-44` 要把 HUD、随身栏、手环、读条圆环与当前操作格的接线全换一遍，等它农场就得一直停着。

## 验收标准

- [x] 可核对：随身栏能由作者在编辑器里摆进场景、接上门面；摆进去之后换格、件数与选中框照常工作。摆进去、接上门面、挂到常驻显示那一层由一次性无头场景核过（见验证结果）；换格与画格子那几段代码没动，照常工作与否由下面那条实机确认。
- [x] 可核对：缺门面时报错说清缺谁，不自己补建（[ADR-0009](../../decisions/ADR-0009-编辑器主导的开发模式.md)）。随身栏没有要作者搭的子节点，见偏离；界面根下面摆了别的东西同样当场报错。
- [x] 可核对：台账 `UI-34` 与 `GP-128` 两行的「卡在」跟着改回只卡作者（`GP-87` 那一行也卡在本条，一起改了）。
- [ ] **作者实机确认**：在俯视的农场场景里摆一条随身栏，按数字键与十字键各换几格，右下角那一条的选中框跟着走。步骤在[一块地能种出东西 · 第六步：接上地块状态机](../../reference/godot/一块地能种出东西.md)前两步，只摆 `UI` 与 `CarryBar` 就看得到。**播种那一下的实机不在本条**，在[作物素材表那份需求](../prd-crop-sheet.md)的 `US-009`：播种要每一种在册作物都配了素材，农场才跑得起来，而素材表接进游戏归那一份。

## 实现笔记

### 设计决策

- **作者把它摆成界面根的子节点，界面根就绪时把它挪到常驻显示那一层**（代码仓 `src/UI/UIRoot.cs`、`src/UI/IPlacedUI.cs`）。两条既有约束一起只剩这一条路：场景里不许自己摆 `CanvasLayer`（层号只在界面根一处定），而作者摆的节点又必须进屏幕空间那一层 —— 留在场景根下它画在世界坐标里，有相机之后跟着地面滚走，而那不报错。界面根只认声明了所在层的界面节点，摆了别的当场报错。
- **层由节点的类型声明，不进检查器**：一个界面属于哪一层是它是什么决定的，放进检查器就多一个能填错、而填错只表现为「被别的东西挡住」的格子。
- **随身栏本体在构造时就有**（`CarrySlotBar.Empty()`），不等 `_Ready`：读它、往里装东西的 `FarmField` 可能排在它前面就绪。
- **图标来源改成一个属性，由往格子里装东西的那一方设**；没设却装了东西，画到那一格时当场报错，不悄悄画成空框。`FarmField` 现在明说种子还没有图标（返回空，格子只画框），物品定义落地时换（`GP-22`）。
- **尺寸变化的订阅挪到 `_EnterTree`**：挪层时节点离开再进一次树，`_Ready` 不再跑，写在那里的订阅挪完就丢了。这条写进了代码仓 `CONVENTIONS.md` 事件订阅那一节。

### 偏离

- **格子仍由代码搭，作者只摆这一个节点。** 验收原写「缺子节点…报错」，而随身栏没有要作者搭的子节点：HUD 的尺寸与放置归规则层、由测试判，与 `LevelHud` 同一个理由；改成作者搭的节点树是 `UI-50`，明确后置。
- **顺带修了一处摆位。** 块的内容区原先只有格子那么宽，比 `rules/UI/HudLayout.cs` 给的内容尺寸窄一个栅格；贴角偏移按内容最小尺寸算（代码仓 `ARCHITECTURE.md` 记的那两个坑的第二个），于是整块往外偏这一格、右边贴到屏幕边。内容区撑满之后落回安全边距。以前没露出来，是因为这个视图从没被建出来过。

### 权衡

- 件数那一行字读的是主题字体，而主题只在主场景装；农场里每格一件、件数不显示，所以现在看不出来。件数换迷你字归 `UI-46`，那时字体由它自己指定。

### 待确认

无。原先那条「无参构造函数才实例化得出来」没有实测，改法让它不再要紧：构造函数删掉了，摆进场景的实测见下表。
