# UI-47：随身栏能由作者摆进场景

## 目标

作者在编辑器里把随身栏摆进一个俯视场景、接上门面，它就照常工作。

## 来源

- PRD：[`spec/prd-ui-art-baseline.md`](../prd-ui-art-baseline.md) 的 `US-007` 里那一格（`FR-21`）。
- 现状：`src/UI/CarrySlotBarView.cs` 只有一个带参构造函数，而 Godot 的 C# 脚本要从场景实例化必须有无参构造函数（[社区报错实例](https://forum.godotengine.org/t/resource-load-causes-missingmemberexception/48154)，本工程没实测）。所以作者现在摆不进场景，`UI-34` 与 `GP-128` 剩下的「接进真场景」都卡在这里。

## 依赖

- `UI-44`：格框与选中框从素材资源取，摆进场景之后读的是同一份。

## 验收标准

- [ ] 可核对：随身栏能由作者在编辑器里摆进场景、接上门面；摆进去之后换格、件数与选中框照常工作。
- [ ] 可核对：缺子节点或缺门面时报错说清缺谁，不自己补建（[ADR-0009](../../decisions/ADR-0009-编辑器主导的开发模式.md)）。
- [ ] 可核对：台账 `UI-34` 与 `GP-128` 两行的「卡在」跟着改回只卡作者。
- [ ] **作者实机确认**：在俯视的农场场景里摆一条随身栏，按数字键与十字键各换几格，再播一次种。
