# ART-33：草与浅水那一套改画成石壁

## 目标

农场的水边是一道石壁：北岸看得到一整面亮的石墙、墙脚一道亮的水线、墙面在水里的倒影；左右两岸是石壁的侧面，只露一窄条暗石头；南岸看不见墙，只有草边；内外拐角都接得上。作者照参考包的形式画，纹理画在图里；我核事实、接进游戏。

## 来源

- PRD：[`spec/prd-shore-stone-wall.md`](../prd-shore-stone-wall.md) 的 `US-002`。

## 依赖

- `ENG-36`：四个方向各自的规范边声明得出来，检查才判得了按方向画的格边。
- `DOC-155`：每个方向画什么、为什么，在[场景绘制约定 · 草与浅水之间是一道石壁](../../production/场景绘制约定.md)。
- `ENG-42`：瓦片集交来之后怎么接进游戏，在那一条定；下面验收里讲文件名、四角同色、方向声明与纹理的那几格跟着它改。

## 验收标准

- [ ] 可核对：作者交的这一套只用色板色，过得了地形检查；检查判什么跟着 `ENG-42` 定的接法。
- [ ] 作者实机确认：北岸看得到墙面，墙脚一道亮的水线，墙面下方的水里有倒影。
- [ ] 作者实机确认：南岸看不见墙、只有草边；左右两岸是石壁的侧面，只露一窄条暗石头；内外拐角都接得上。
- [ ] 作者实机确认：草地与水面的纹理一直铺到石壁，石壁、水线与倒影没有被纹理换掉。
- [ ] 作者实机确认：朝水走过去，人停在墙顶的岸上，看着不像浮在水面上，也不像陷进墙里。
- [ ] 可核对：文件名照旧是代码仓 `assets/self-drawn/tiles/grass-shallow.png`，四角同色那两张仍是草与浅水的主色、整张纯色。
- [ ] 可核对：新图与这一套的方向声明放进代码仓同一次提交，`python tools/check_dualgrid.py` 与 `python tools/verify.py` 通过。

## 实现笔记

### 设计决策

- **作者画，我核事实、接进游戏**：这一套是全套地形瓦片集的一部分，照参考包的形式画，纹理画在图里（[ADR-0033](../../decisions/ADR-0033-地面纹理直接画进图块.md)）。交来之后我对照游戏要的格子组合与格边规矩，列出缺哪几块、哪条边对不上。

### 偏离

- **方案怎么说**：我照参考包的画法出草稿，作者审过、精修。
- **实际怎么做**：作者照参考包的形式自己画。
- **为什么**：地形图块归作者画，我只核事实、接进游戏。

### 权衡

无。

### 待确认

- 瓦片集交来之后，按 `ENG-42` 定的接法改这一条的验收：文件名、四角同色那两张、方向声明与提交那一格，以及「纹理铺到石壁」那一格里「没有被纹理换掉」那半句（它是照纹理图那条路写的）。
- 交图那一次提交里，代码仓 `tools/check_dualgrid.py` 的 `SETS` 上面那段注释跟着改：「草土、草水两套里深绿画在草那一侧，棕与蓝画在对侧地面上」那一句，草水那一套改成石壁之后不再成立。
