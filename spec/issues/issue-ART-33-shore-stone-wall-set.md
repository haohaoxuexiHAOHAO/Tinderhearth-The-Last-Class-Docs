# ART-33：草与浅水那一套改画成石壁

## 目标

农场的水边是一道石壁：北岸看得到墙面、墙脚一道亮的水线、墙面在水里的倒影；南岸只露墙沿；左右两岸是墙的侧面；内外拐角都接得上。我照参考包的画法出草稿，作者审过、精修。

## 来源

- PRD：[`spec/prd-shore-stone-wall.md`](../prd-shore-stone-wall.md) 的 `US-002`。

## 依赖

- `ENG-36`：四个方向各自的规范边要先声明得出来，外圈模板才出得来；照着模板画，格边才过得了检查。
- `DOC-155`：每个方向画什么、为什么，在[场景绘制约定 · 草与浅水之间是一道石壁](../../production/场景绘制约定.md)，照它画。

## 实现笔记

### 设计决策

- **草稿在工作区根 `art-source/self-material/tiles-draft/`**，与 `ART-34` 的两套放在一起：`grass-shallow.png`（16 张）、`grass-shallow-ring.png` 与 `-x8`（照草稿声明出的外圈模板）、`preview-grass-shallow.png`（放大 8 倍，下面列着每个方向两侧的像素），三套合拼的一屏 `mockup-x2.png` 与只有地面的 `mockup-terrain-x2.png`。预览图里铺的是第二批纹理草稿，摆的是作者画的树、灌木、石头与小物件。
- **画法照参考包、不搬像素**：学它石块砌的水岸、墙脚亮的水线与草压过石沿的那几簇草；颜色照作者画的石头走，`stone` 一条，最暗一档描边。
- **每个方向格边上的像素**（从界线往外数），也就是交图时要写进声明的那几串：

  | 岸 | 草那一侧 | 浅水那一侧 |
  | --- | --- | --- |
  | 北岸（`A在上`） | `stone 5`、`stone 6`、`stone 1` | `stone 4`、`stone 3`、`stone 3`、`stone 1`、`water 6`、`water 3`、`water 3` |
  | 南岸（`A在下`） | `stone 5`、`stone 6`、`stone 1` | `stone 1` |
  | 西岸、东岸（`A在左`、`A在右`） | `stone 5`、`stone 6`、`stone 1` | `stone 4`、`stone 1` |

  草那一侧四个方向一样，是墙沿：外沿 `stone 5`、受光的顶面 `stone 6`、挨着草的暗边 `stone 1`。这样拐角处墙沿连成一条，人停下时站在墙沿上。北岸水那一侧是三行墙面（越往下越暗）、墙脚一行暗影、亮的水线、两行倒影，用满了半格减去格角那一个像素；墙想再高只能少画一行倒影。南岸水那一侧只有墙沿下沿一道暗线，东西两岸是一窄条侧面加暗边。
- **图块中间**：墙沿与墙面每隔几个像素一道石缝，墙面的缝与墙沿错开；水线上零星几个 `highlight 1`；墙沿外那一行暗边上零星几簇草压过来。都只画在离格边至少两个像素的中间，格边那一圈照上表。
- **拐角的形状**：水占一个角的那几张，水是以那个角为圆心、半径半格的四分之一圆；水占三个角的，是草那个角的四分之一圆挖掉。半径正好半格，圆弧落在格边正中，所以格边那一圈与直边那几张一致。

### 偏离

- **方案怎么说**：作者照外圈模板画。
- **实际怎么做**：我照参考包的画法出草稿，作者审过、精修。
- **为什么**：作者要求的，PRD 的「分工」跟着改了。

### 权衡

- **墙沿画在草那一侧**：也可以画在水那一侧，人停下时就站在墙沿外的草上。画在草那一侧，北岸、南岸、两侧的墙沿是同一串，拐角最好接。

### 待确认

- 作者审草稿：石壁的高低、墙沿的粗细、颜色深浅、拐角顺不顺。格边那一圈要改，先告诉我新的那几串，我改声明、重出模板。
- 交图那一次提交里，代码仓 `tools/check_dualgrid.py` 的 `SETS` 上面那段注释跟着改：「草土、草水两套里深绿画在草那一侧，棕与蓝画在对侧地面上」那一句，草水那一套改成石壁之后不再成立。
