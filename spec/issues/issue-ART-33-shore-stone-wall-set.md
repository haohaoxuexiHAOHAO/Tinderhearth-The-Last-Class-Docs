# ART-33：草与浅水那一套改画成石壁

## 目标

农场的水边是一道石壁：北岸看得到一整面亮的石墙、墙脚一道亮的水线、墙面在水里的倒影；左右两岸是暗的侧面；南岸看不见墙，只有草边；内外拐角都接得上。我照参考包的画法出草稿，作者审过、精修。

## 来源

- PRD：[`spec/prd-shore-stone-wall.md`](../prd-shore-stone-wall.md) 的 `US-002`。

## 依赖

- `ENG-36`：四个方向各自的规范边要先声明得出来，外圈模板才出得来；照着模板画，格边才过得了检查。
- `DOC-155`：每个方向画什么、为什么，在[场景绘制约定 · 草与浅水之间是一道石壁](../../production/场景绘制约定.md)，照它画。

## 实现笔记

### 设计决策

- **草稿在工作区根 `art-source/self-material/tiles-draft/`**，与 `ART-34` 的两套放在一起：`grass-shallow.png`（16 张）、`grass-shallow-ring.png` 与 `-x8`（照草稿声明出的外圈模板）、`preview-grass-shallow.png`（放大 8 倍，下面列着每个方向两侧的像素）、`compare-x6.png`（参考包那一块水塘与我们这一套并排），三套合拼的一屏 `mockup-x2.png` 与只有地面的 `mockup-terrain-x2.png`。预览图里铺的是第二批纹理草稿，摆的是作者画的树、灌木、石头与小物件。
- **照参考包那一块水塘的画法、不搬像素**：水塘是凹下去的。北岸那一面墙朝着人，画两层石块，石块受光、最亮；左右两岸只看得到石块背光的侧面，暗；南岸那一面背着人，不画石块，只有草边，草簇压在水上。四面都有草簇压过石壁的边，石壁外沿有几处鼓出来一格，不是一条直线。颜色照作者画的石头走，`stone` 一条，最暗一档描边。
- **每个方向格边上的像素**（从界线往外数），也就是交图时要写进声明的那几串：

  | 岸 | 草那一侧 | 浅水那一侧 |
  | --- | --- | --- |
  | 北岸（`A在上`） | `stone 5`、`stone 1` | `stone 5`、`stone 2`、`stone 4`、`stone 3`、`stone 1`、`water 6`、`water 3` |
  | 南岸（`A在下`） | `moss 1`、`moss 2` | 无 |
  | 西岸、东岸（`A在左`、`A在右`） | `stone 1` | `stone 2`、`stone 2`、`stone 1.5`、`water 6`、`water 3` |

  北岸草那一侧是上层石块的顶与它外沿的暗边；水那一侧是上层石块的下半、两层之间的横缝、下层石块、墙脚暗缝、亮的水线、一行倒影，用满了半格减去格角那一个像素。东西两岸是一层暗的石块、墙脚暗边、水线、倒影。南岸草那一侧是贴着水的一行暗草根，水那一侧什么都没有。
- **石缝落在固定的那几列、那几行**：北岸上层石块的缝在第 4、9、14 列，下层在第 3、7、11、15 列，错开；东西两岸的缝在第 4、9、14 行。格边那一列、那一行正好在一块石头中间，所以图块拼起来时格边两侧是同一块石头，不会出现两道缝挨在一起。
- **图块中间**：石块顶上零星一点 `stone 6` 的亮，水线上零星几个 `highlight 1`，南岸草簇之间零星几点 `water 6` 的水光；都只画在离格边至少两个像素的中间，格边那一圈照上表。
- **拐角的形状**：水占一个角的那几张，水是以那个角为圆心、半径半格的四分之一圆；水占三个角的，是草那个角的四分之一圆挖掉。半径正好半格，圆弧落在格边正中，所以格边那一圈与直边那几张一致。

### 偏离

- **方案怎么说**：作者照外圈模板画；南岸只露墙沿。
- **实际怎么做**：我照参考包的画法出草稿，作者审过、精修；南岸看不见墙，只有草边，左右两岸画成暗的侧面。
- **为什么**：都是作者要求的。南岸与两侧那一条照参考包那一块水塘：从南边斜着看，只有北岸那一面受光，两侧背光，南岸那一面背着人。PRD 与场景绘制约定那一节跟着改了。

### 权衡

- **北岸的墙一半在草那一侧**：上层石块的顶画在草那半格，人停在界线上时正好站在墙顶；整面墙都画进水那半格的话，七个像素装不下两层石块。

### 待确认

- 作者审草稿：石壁的高低、石块的大小、亮暗、拐角顺不顺。格边那一圈要改，先告诉我新的那几串，我改声明、重出模板。
- 交图那一次提交里，代码仓 `tools/check_dualgrid.py` 的 `SETS` 上面那段注释跟着改：「草土、草水两套里深绿画在草那一侧，棕与蓝画在对侧地面上」那一句，草水那一套改成石壁之后不再成立。
