# ART-33：草与浅水那一套改画成石壁

## 目标

农场的水边是一道石壁：北岸看得到一整面亮的石墙、墙脚一道亮的水线、墙面在水里的倒影；左右两岸是石壁的侧面，只露一窄条暗石头；南岸看不见墙，只有草边；内外拐角都接得上。作者照参考包的形式画，纹理画在图里；我核事实、接进游戏。

## 实现笔记

### 设计决策

- **作者画，我核事实、接进游戏**：这一套是全套地形瓦片集的一部分，照参考包的形式画，纹理画在图里（[ADR-0033](../../decisions/ADR-0033-地面纹理直接画进图块.md)）。交来之后我对照游戏要的格子组合与格边规矩，列出缺哪几块、哪条边对不上。

- **石壁接南岸草簇的那几段拐角另算**：石壁从草那一侧一圈圈收窄，两三行收进草边，不在斜岸的每个台阶上鼓出一块。
- **石壁外面草那一侧收一圈草边**，照草那一套的草边画，也画在这一套里（草边跟着草走，见 `ART-34`）。

### 偏离

- **方案怎么说**：我照参考包的画法出草稿，作者审过、精修。
- **实际怎么做**：作者照参考包的形式自己画；拐角改圆、石壁收尾与石壁外的草边是作者要我直接在他的图上改的，像素取自他画的直边格，他看过之后定稿。
- **为什么**：地形图块归作者画，我只核事实、接进游戏；这几处是照他画好的直边格挪像素，不画新的笔画。

另一处：

- **方案怎么说**：文件名照旧是 `grass-shallow.png`，四角同色那两张整张纯色，新图与这一套的方向声明同一次提交。
- **实际怎么做**：这一套画在一张图块表里，下面那一种留透明，开阔地取整块；交图检查判同一类格边逐像素一样，没有方向声明。
- **为什么**：地形改成按顺序叠（[地形与崖改用图块表画](../prd-outdoor-tile-sheet.md)）。
