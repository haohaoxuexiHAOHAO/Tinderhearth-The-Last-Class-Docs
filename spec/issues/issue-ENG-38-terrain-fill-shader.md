# ENG-38：显示层按世界坐标铺纹理

## 目标

显示层里每种天然地形的主色，按世界坐标换成那种地形的纹理图上同一位置的像素；一项都没声明时地面照现在的样子画。

## 来源

- PRD：[`spec/prd-terrain-texture.md`](../prd-terrain-texture.md) 的 `US-001` 与 `US-002`（接线那一半）。

## 依赖

- `ENG-37`：配置对不对由那一条的判定说；这一条只把引擎里读到的东西交过去、把结论报出来。

## 验收标准

- [ ] 可核对：代码仓 `src/World/Terrain/DualGridPainter.cs` 多一个导出项，每一项声明一种地形：一张纹理图，或明确不铺。显示层的材质由代码设，作者不手挂。
- [ ] 可核对：一项都没声明时，显示层不挂材质，地面照现在的样子画；输出面板说一句没配纹理，只在进树时说一次，不随刷地形重复。
- [ ] 可核对：声明了任意一项时，主色从每套双网格图里四角全同那一张读出来，连同声明交给 `ENG-37` 的判定；有问题时运行时抛、编辑器里只警告，几处一次全报，与这个类现有那几条同一个口径。
- [ ] 可核对：着色器按世界坐标取纹理图上的像素，只换主色那些像素、不混色；比颜色按 8 位整数比。
- [ ] 可核对：编辑器里刷一笔，纹理跟着显示层一起出来；改了导出项之后点「重画显示层」，材质跟着重挂。
- [ ] 可核对：双网格那几套图与 `tools/check_dualgrid.py` 没有改动。
- [ ] 可核对：代码仓 `python tools/verify.py` 全过。
