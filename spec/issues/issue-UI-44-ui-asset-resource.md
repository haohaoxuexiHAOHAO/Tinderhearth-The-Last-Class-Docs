# UI-44：素材资源：界面件一律从作者改得动的那份资源取

## 目标

作者在 Godot 里换一张界面图、重跑就看到它；代码里不再写死任何界面件的路径，缺了哪一项启动时一次说全。

## 来源

- PRD：[`spec/prd-ui-art-baseline.md`](../prd-ui-art-baseline.md) 的 `US-005` 代码那一半，与 `US-007` 里接线、底板与手环那几格（`FR-14`、`FR-15`、`FR-24`）。
- 字段清单就是[界面绘制约定](../../production/界面绘制约定.md)那几张表，本条不复述。

## 依赖

- `ART-27`：界面件已交付，主场景那一批要的图都在；它剩下的主菜单标题、底图与建筑图标不在那一批里，不挡本条。
- 载入时核尺寸用的格子与迷你两档是 `rules/UI/UIMetrics.cs` 的 `Cell` 与 `Mini`（`UI-41` 加的）。
- 图标页签挂在两级页签的顶层那一级上，顶层页签的标识就是那张图标的文件名，家在代码仓 `rules/UI/Wristband.cs`（`UI-53` 落地的）。

## 验收标准

- [ ] 可核对：素材资源这个类型能在 Godot 的「新建资源」里找到。
- [ ] 可核对：资源的字段就是约定那几张表里的件（内容图标除外，它们由内容数据引用），每一格写明它是什么、多大、有哪几种状态。**先接进游戏的只是主场景那一批**（清单在[界面素材那份需求 · US-006（作者）：交模板，生成器切件补件，一次交付](../prd-ui-art-baseline.md)），其余格子载入时照样核尺寸，接线跟各自那一页走 —— 这样整批交付的尺寸一次就核完。
- [ ] 可测试：尺寸能由排版单位推出的那几类（格子、图标几档、迷你、头像框、条高）按排版单位核，九宫格件按「画布大于两倍边距」核；代码里没有散落的数字字面量。
- [ ] 可核对：九宫格边距是资源里的格子，代码那一侧先照约定的数填；字离框多远是内容边距，从排版单位取 —— 两者分开。
- [ ] 可核对：一份空的素材资源载入时，报错列出全部缺项，每一项带名字、尺寸与状态。
- [ ] 可核对：代码那一侧按约定的文件名把交付的图填进一份素材资源，载入不再报缺；作者在检查器里核过一遍。
- [ ] 可核对：按钮、面板这类控件的主题由素材资源组装，不在主题编辑器里手敲项名。
- [ ] 可核对：HUD、随身栏、手环、读条圆环、当前操作格用到的界面件一律从素材资源取；代码仓里不再有写死的界面件路径（按 `assets/placeholder/ui/` 搜，引擎层与规则层为零）。**技能与物品图标是内容**，由调用方给；演示数据里那几张占位内容图留在演示那一处。
- [ ] 可核对：HUD 各块的底换成作者画的细框，不再是代码画的纯色框；代码仓 `rules/UI/HudPalette.cs` 里只为那种纯色框存在的面板底与面板边两个占位色随之删掉。
- [ ] 可核对：手环换成图标页签，外加一行当前页标题；外壳用作者画的那张面板，尺寸照[界面绘制约定 · 个人界面那一套](../../production/界面绘制约定.md)那个推荐值、居中。
- [ ] **作者实机确认**：主场景里两种场合的 HUD 与手环各看一遍；换一张图重跑能看到变化；删掉一格重跑，报错说得清缺哪一格。
