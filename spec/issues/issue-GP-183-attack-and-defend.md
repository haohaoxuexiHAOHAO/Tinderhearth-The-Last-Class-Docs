# GP-183：普通攻击与防御：命中、伤害、暴击、格挡与冷却

## 目标

出手照 desc 的公式算命中、伤害、暴击与格挡；出手之前算得出要显示的命中几率与伤害。

## 来源

- PRD：[`spec/prd-first-grid-battle.md`](../prd-first-grid-battle.md) 的 `US-006` 规则那一半与 `US-002` 冷却那一格。瞄准时写数、伤害数字在 `UI-70`。

## 依赖

- `GP-182`（已关闭）：冷却与格挡都按自己的回合算，自己的回合从哪开始在代码仓 `rules/Combat/Battle.cs`；一回合一件占回合的事怎么记在代码仓 `rules/Combat/Turn.cs`。

## 验收标准

- [ ] 可测试：指向一个人的招，目标要在施放距离以内，距离照走路的数法；不在距离里被拒。这一份不算视野。
- [ ] 可测试：命中几率照[各类公式计算 · 命中](../../../desc/各类公式计算.md)算：攻方命中率减守方真实闪避几率；挨着时距离倍率 50%，再远的倍率从配置读；限制在 5%–95%。掷骰走注入的随机源。
- [ ] 可测试：伤害照[各类公式计算 · 伤害](../../../desc/各类公式计算.md)的先后算，防御减免里的 K 从配置读；算完向下取整，最少 1 点。暴击照「暴击」那一节算，打空不掷暴击。
- [ ] 可测试：防御给自己挂「格挡」，轮到自己行动时解除；挂着时受到的伤害降低，降低多少从配置读。
- [ ] 可测试：冷却 N 的招用过之后，过 N 个自己的回合才能再用；冷却 1 的每回合都能用。
- [ ] 可测试：放占回合的招照代码仓 `rules/Combat/Turn.cs` 那一套记：一回合只放得了一招占回合的，第二招被拒；放完剩下的行动力减半；放完行动力用完，这一回合自动结束。
- [ ] 可测试：出手之前算得出命中几率与不暴击时的伤害，与真打时用的是同一套算法。
- [ ] 可核对：代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。
