# UI-63：物品图标资源，缺图一次全报

## 目标

每个物品在 Godot 里配一份图标资源，配漏了、配重了启动当场一次全报；变异品质的那一堆画变异那一张。

## 来源

- PRD：[`spec/prd-items-in-bag.md`](../prd-items-in-bag.md) 的 `US-009`。

## 依赖

- `GP-157`：物品定义与有无品质那一格。
- `GP-158`：作物那几样物品要先在册。

## 验收标准

- [ ] 可核对：每个物品一份图标资源；有品质的另配变异那一张，或明写同原图。作物那几样每种两份：种子那份框素材表（代码仓 `assets/self-drawn/crops/crop1.png`）第 7 列，收获物那份框第 8 列、变异那一张框第 9 列。
- [ ] 可测试：在册物品缺图标、有品质却没写变异那一张、两份图标配给同一个物品，载入时一次全报，一行一处；判在规则层，引擎层只交出每一格配没配。
- [ ] 可观察：随身栏与背包页的格子里画物品的图标；品质是变异的那一堆画变异那一张。
- [ ] 可核对：代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。
