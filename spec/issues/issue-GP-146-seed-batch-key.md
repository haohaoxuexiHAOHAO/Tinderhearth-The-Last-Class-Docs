# GP-146：开发期换批键：随身栏换成下一批种子

## 目标

作者在地里把素材表上每一种作物都种一遍：一个开发期调试键挨批往背包里放种子（键与放法随 `UI-60` 落地）。

## 来源

- PRD：[`spec/prd-crop-sheet.md`](../prd-crop-sheet.md) 的 `US-007`（`FR-14`）。

## 依赖

- `GP-145`：作物要比随身栏的格数多，换批才有意义。

## 验收标准

- [x] 可核对：一个开发期调试键挨批给种子（按标识排序、一批的种数与随身栏格数相同），最后一批之后回到第一批。键是 `G`，往背包里放下一批、每样一满堆，整批放不下一件不放；怎么排、怎么分批在代码仓 `rules/Economy/SeedBatches.cs`，有测试。键与放法随 `UI-60` 落地。
- [x] 可核对：它与 `N` 一样直接读按键、不进输入映射，所以不会出现在玩家能改键的那份清单里。两个键在代码仓 `src/World/Farm/FarmField.cs` 的同一处读，键登在代码仓 `rules/UI/DebugKeys.cs`。
- [ ] **作者实机确认**：每一种都种下去、长到成熟看过一遍。第二批起种子落在随身栏后面那几格，要在背包页里挪到前面来（`UI-66`）。

## 实现笔记

### 设计决策

- **模糊点**：分批放在引擎层的农场里，还是规则层。
- **选择**：规则层一个静态类，引擎层只记「现在是第几批」、按键时换批再装一遍。
- **理由**：「最后一批之后回到第一批」是会错一格的那种算术，放在规则层才测得到。它收的是作物、给的是往背包里放的那几份，所以在规则层的经营那一侧；一批几种由调用方给（随身栏几格），经营这一侧不依赖界面那一侧。

- **模糊点**：批号越界时绕回还是报错。
- **选择**：取第几批时越界当场报错，绕回只在「下一批」那一处。
- **理由**：两处都绕的话，一个算错了的批号会被悄悄绕成一个合法的批，表现只是「换批好像跳了一批」。

### 偏离

无。

### 权衡

- **放种子不改选中第几格**：变的是背包里装什么，与随身栏「填内容不动选中位」那条规矩一致。

无。
