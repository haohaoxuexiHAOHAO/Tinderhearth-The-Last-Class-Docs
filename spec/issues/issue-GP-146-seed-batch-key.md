# GP-146：开发期换批键：随身栏换成下一批种子

## 目标

作者在地里把素材表上每一种作物都种一遍：一个开发期调试键把随身栏换成下一批种子。

## 来源

- PRD：[`spec/prd-crop-sheet.md`](../prd-crop-sheet.md) 的 `US-007`（`FR-14`）。

## 依赖

- `GP-145`：作物要比随身栏的格数多，换批才有意义。

## 验收标准

- [x] 可核对：一个开发期调试键把随身栏换成下一批种子（按标识排序、每批装满随身栏），最后一批之后回到第一批。键是 `B`；怎么排、怎么分批在代码仓 `rules/UI/SeedBatches.cs`，有测试。
- [x] 可核对：它与 `N` 一样直接读按键、不进输入映射，所以不会出现在玩家能改键的那份清单里。两个键在代码仓 `src/World/Farm/FarmField.cs` 的同一处读。
- [ ] **作者实机确认**：每一种都种下去、长到成熟看过一遍。

## 实现笔记

### 设计决策

- **模糊点**：分批放在引擎层的农场里，还是规则层。
- **选择**：规则层一个静态类，引擎层只记「现在是第几批」、按键时换批再装一遍。
- **理由**：「最后一批之后回到第一批」与「不足一批补空格」是会错一格的那种算术，放在规则层才测得到；它收的是标识、给的是随身栏的格子，与随身栏同在界面那一层。原先农场里那段「排序、取前几个、补空格」并进了它，所以只有一处。

- **模糊点**：批号越界时绕回还是报错。
- **选择**：取第几批时越界当场报错，绕回只在「下一批」那一处。
- **理由**：两处都绕的话，一个算错了的批号会被悄悄绕成一个合法的批，表现只是「换批好像跳了一批」。

### 偏离

无。

### 权衡

- **换批不改选中第几格**：换的是格子里装什么，与随身栏「填内容不动选中位」那条规矩一致；手上那一格换成了别的种子，下一次播的就是它。

### 待确认

无。
