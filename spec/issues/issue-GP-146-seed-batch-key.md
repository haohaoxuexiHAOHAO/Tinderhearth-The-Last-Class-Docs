# GP-146：开发期换批键：随身栏换成下一批种子

## 目标

作者在地里把素材表上每一种作物都种一遍：一个开发期调试键把随身栏换成下一批种子。

## 来源

- PRD：[`spec/prd-crop-sheet.md`](../prd-crop-sheet.md) 的 `US-007`（`FR-14`）。

## 依赖

- `GP-145`：作物要比随身栏的格数多，换批才有意义。

## 验收标准

- [ ] 可核对：一个开发期调试键把随身栏换成下一批种子（按标识排序、每批装满随身栏），最后一批之后回到第一批。
- [ ] 可核对：它与 `N` 一样直接读按键、不进输入映射，所以不会出现在玩家能改键的那份清单里。
- [ ] **作者实机确认**：每一种都种下去、长到成熟看过一遍。
