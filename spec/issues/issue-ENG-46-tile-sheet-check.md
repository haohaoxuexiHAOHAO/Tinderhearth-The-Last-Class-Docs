# ENG-46：交图检查照图块表的排法判

## 目标

改了图块表一跑就知道格边还接不接得上：同一类格边、崖边两头对不上时，说清是哪一张、哪一套或哪一块、哪一格、哪条边；`verify.py` 照旧跑它。

## 来源

- PRD：[`spec/prd-outdoor-tile-sheet.md`](../prd-outdoor-tile-sheet.md) 的 `US-001` 后三格，`FR-13` 到 `FR-16`。

## 依赖

- `ENG-45`：检查从那份排法读每一块在哪。

## 验收标准

- [ ] 可核对：检查对代码仓里的图块表通过：宽高对；每一套里同一侧、两端地形一样的格边逐像素一样；崖边北沿、西边、东边每一种格两头一样，四个角接得上；草顶另画的那几格同样。
- [ ] 可测试（一次性，跑完删）：一份副本在一套里改掉一条格边的一个像素，另一份在崖边一种格的一头改掉一个像素，检查各报一条，说清哪一张、哪一套或哪一块、哪一格、哪条边。删了什么写在「验证结果」里。
- [ ] 可核对：`verify.py` 里判双网格素材那一步改跑这个检查；认不出它的输出形状照旧拒绝判过。
- [ ] 可核对：旧的双网格检查删掉，连同按方向声明的规范边与外圈模板；代码仓里提到它的注释跟着改（`tools/palettelib.py`、`tools/requirements.txt`、`tools/verify.py`）。工作区模板目录里那几张外圈模板与 `dualgrid-16-guide.png` 删掉，作者的 `grass-dirt.aseprite` 留着。
- [ ] 可核对：代码仓 verify 全过。
