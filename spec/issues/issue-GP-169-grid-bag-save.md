# GP-169：背包存每一堆的位置，存档升一版，旧档迁过来

## 目标

背包那一片存档记下每一堆在网格里的位置与随身栏那一排，写出去读回来一格不差；上一版的存档读进来东西一件不少，手上那几格还在手上。

## 来源

- PRD：[`spec/prd-grid-bag.md`](../prd-grid-bag.md) 的 `US-008`。

## 依赖

- `GP-168`：网格与随身栏那一排的形状定了，才知道这一片存什么。

## 验收标准

- [ ] 可测试：背包那一片存每一堆在网格里的位置（它左上角那一格），也存随身栏那一排；存进去读出来，每一堆的种类、品质、件数、序号与位置都不变。
- [ ] 可核对：存档版本升一级（代码仓 `rules/Foundation/Save/SaveFile.cs`），最低兼容版本不动。
- [ ] 可测试：上一版的存档读进来：原来开头那几格（随身栏格数那么多）进随身栏那一排、原来的位置不变，其余的按原来的格号从左上往右下摆进网格；东西一件不少。
- [ ] 可测试：同一版的存档缺位置被拒；两堆的位置压在一起，或者有一堆出了网格，载入被拒并说清是哪两堆、哪一堆。
- [ ] 可测试：存档里网格的行列比现在配置的大时，载入被拒并说清两边各多大；小的照新的大小读。
- [ ] **作者实机确认**：摆好几堆、睡一觉，停掉游戏再进来，每一堆还在原来的位置。串在 `GP-173` 的清单里。
- [ ] 可核对：代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。
