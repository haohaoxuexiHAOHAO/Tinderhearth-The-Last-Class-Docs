# ART-8：反派与常驻 NPC 补视觉锚点

## 目标

每个有编号的角色都答得出记忆点四个杠杆的前三项，反派那一侧同时守住视觉红线。

## 来源

- PRD：[`spec/prd-canon-hardening.md`](../prd-canon-hardening.md) 的 `US-007`
- 起因：[反派与要角](../../canon/narrative/反派与要角.md)的十一人只有身份、性格与命名说明，**一个视觉锚点都没有**；[常驻NPC](../../canon/narrative/常驻NPC.md)的十二人只有零散外观句，无签名色、无审计。而[人物 · 剪影防撞审计](../../canon/characters/人物.md)要求的是「新增角色时」就做

## 依赖

无。与 `ART-7` 同形、可并行。**它顺带还掉 `NR-3` 漏交的「最终 BOSS 的形象」那一项**（见 `DOC-71`）。

## 验收标准

- [ ] 可核对：[反派与要角](../../canon/narrative/反派与要角.md)与[常驻NPC](../../canon/narrative/常驻NPC.md)里每个有编号的角色各答得出[记忆点四个杠杆](../../canon/characters/人物.md)的前三项。
- [ ] 可核对：反派那一侧同时满足[人物 · 反派视觉红线](../../canon/characters/人物.md) —— 只用黑铁、熔岩、断翼轮廓、紊乱魔纹与失衡灵流；**魔纹无规则扩散、绝不成套徽记**；不含现实信仰标志、旗帜、制服、经文排版与可识别手势。
- [ ] 可核对：审计**按组做**并写出结论：四将首之间、矮人工匠兄弟与锻子之间、两名文学导师之间。
- [ ] 可核对：`NR-13` 定下的最终战第二段那个对手也有视觉锚点（它是本条与 `NR-13` 的交界；`NR-13` 只定「它是谁、读什么」）。
- [ ] 可核对：[常驻NPC](../../canon/narrative/常驻NPC.md)里 C-8 那条「性别由制作规格层确定」与视觉锚点的关系写清 —— 剪影能不能在性别未定时成立，答得出来。
- [ ] 可核对：一处编辑错误一并改掉 —— [常驻NPC](../../canon/narrative/常驻NPC.md)里 C-5 那条写成「她和苏怀的关系是……」，而那一节的主语就是苏怀本人。
- [ ] 可核对：**具体色值不在本条**，理由同 `ART-7`。
- [ ] 作者实机确认：按组把黑剪影并排放一屏，逐对看分不分得开。
- [ ] 可核对：`python tools/check_docs.py` 0 项必须修复。
