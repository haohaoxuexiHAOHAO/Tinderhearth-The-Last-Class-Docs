# DOC-144：指南第七步改成从一张素材表上框格子

## 目标

作者照指南从一整张作物素材表配出全部作物素材，不用先把它切成一张张小图。

## 来源

- PRD：[`spec/prd-crop-sheet.md`](../prd-crop-sheet.md) 的 `US-008`。
- 要改的是[一块地能种出东西 · 第七步：画作物，配素材](../../reference/godot/一块地能种出东西.md)。

## 依赖

- `GP-144`：作物素材里多出的变异成熟那一格要先在。
- `GP-145`：素材表每一行对应哪一种作物（标识）要先定。

## 验收标准

- [x] 可核对：[一块地能种出东西 · 第七步：画作物，配素材](../../reference/godot/一块地能种出东西.md)改成：素材表放进 `assets/self-drawn/crops/`，每格用一个 AtlasTexture 框出来，配好第一种之后复制一份、改行号。
- [x] 可核对：那一节写清素材表每一列对应作物素材的哪一格，以及区域怎么由列号、行号与格宽算出来。
- [x] 可核对：[一块地能种出东西 · 卡住了：按症状查](../../reference/godot/一块地能种出东西.md)加上「缺变异成熟那张」与「框错一格」。加在第七步自己那张症状表里，理由见偏离。
- [ ] **作者实机确认**：照着配完全部作物，载入不报缺。

## 实现笔记

### 设计决策

- **模糊点**：每一格的 `AtlasTexture` 单独存成文件，还是建在那一种作物的素材 `.tres` 里。
- **选择**：建在作物素材那份 `.tres` 里，每一格在检查器里新建。
- **理由**：「配好第一种、复制一份、改行号」靠的是复制出来的那份自带一套格子。单独存成文件的话，复制出来的作物素材还引着第一种的那几个文件，改区域会连带改掉第一种，而这不报错。物品图标那三列另有约定（[界面绘制约定 · 文件放哪、叫什么](../../production/界面绘制约定.md)），它们现在不框。

### 偏离

- **方案怎么说**：本条验收写的是把「缺变异成熟那张」与「框错一格」加进[一块地能种出东西 · 卡住了：按症状查](../../reference/godot/一块地能种出东西.md)。
- **实际怎么做**：加在第七步自己那张症状表里。
- **为什么**：这两样只在配作物素材时出现，而第七步那张表里已经有「缺枯死那张」这一类。放进通用那张，同一类症状就要分两处查。

- **方案怎么说**：PRD 的「技术考虑」写的是作者配第一种时看一眼格子边缘，串了再打开 `filter_clip`。
- **实际怎么做**：指南让每一格都勾上 `Filter Clip`。
- **为什么**：哪一种作物没配素材，农场载入时就报错、不开工，所以配完第一种时看不到地里的样子；等看得到时全部都已配完，再回头一格格改。按推断本来不会串，勾上不改变画面。

### 权衡

- **全部配完才跑得起来**：缺素材当场报错是作物素材的规矩，指南没有为「先看一种」开口子；第七步写明了这一点，并让作者在复制之前先用检查器里的缩略图核第一种。
