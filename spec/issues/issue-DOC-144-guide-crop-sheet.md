# DOC-144：指南第七步改成从一张素材表上框格子

## 目标

作者照指南从一整张作物素材表配出全部作物素材，不用先把它切成一张张小图。

## 来源

- PRD：[`spec/prd-crop-sheet.md`](../prd-crop-sheet.md) 的 `US-008`。
- 要改的是[一块地能种出东西 · 第七步：画作物，配素材](../../reference/godot/一块地能种出东西.md)。

## 依赖

- `GP-144`：作物素材里多出的变异成熟那一格要先在。
- `GP-145`：素材表每一行对应哪一种作物（标识）要先定。

## 验收标准

- [ ] 可核对：[一块地能种出东西 · 第七步：画作物，配素材](../../reference/godot/一块地能种出东西.md)改成：素材表放进 `assets/self-drawn/crops/`，每格用一个 AtlasTexture 框出来，配好第一种之后复制一份、改行号。
- [ ] 可核对：那一节写清素材表每一列对应作物素材的哪一格，以及区域怎么由列号、行号与格宽算出来。
- [ ] 可核对：[一块地能种出东西 · 卡住了：按症状查](../../reference/godot/一块地能种出东西.md)加上「缺变异成熟那张」与「框错一格」。
- [ ] **作者实机确认**：照着配完全部作物，载入不报缺。
