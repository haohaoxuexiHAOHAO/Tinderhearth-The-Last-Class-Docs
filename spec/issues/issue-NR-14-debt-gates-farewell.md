# NR-14：「债务清零」做「告别」那个节点的解锁标记

## 目标

三条长期线里的经营线有一个出口 —— 那位标记从「谁都不读」变成「有一个读者」。

## 来源

- PRD：[`spec/prd-canon-hardening.md`](../prd-canon-hardening.md) 的 `US-002`
- 起因：[玩法定位 · 推进与胜负](../../canon/gameplay/玩法定位.md)与[人物 · 基地、债务与传承](../../canon/characters/人物.md)都写「还债是离场的前置，不是可选的加分项」，而[主线故事](../../canon/narrative/主线故事.md)的两种结局条件里没有它、[`主线推进系统`](../../design/主线推进系统.md)持有的那位标记**没有任何读者**

## 依赖

无。

## 验收标准

- [ ] 可核对：[主线故事](../../canon/narrative/主线故事.md)里「告别」那个节点写明它有一个前置，并写明它**不是**完美结局条件之一、也不影响结局判定（判定与告别是两个时点）。
- [ ] 可核对：[`主线推进系统`](../../design/主线推进系统.md)里那个节点的「需要哪些标记」一格写上它。
- [ ] 可核对：[`主线推进系统`](../../design/主线推进系统.md)的**结局判定那张表不动** —— 反向核对，改到它说明改法选错了。
- [ ] 可核对：[`主线推进系统`](../../design/主线推进系统.md)那张「三条长期线各收束成什么」的表里，经营线那一行现在指得出读者是谁。
- [ ] 可测试：那位标记未置位时「告别」不可解锁；置位后可解锁。
- [ ] 可测试：**这条条件里没有任何天数、日期或季节序号**（[ADR-0016](../../decisions/ADR-0016-推进挂在曾经发生过的事上.md)），也**不新开第三类条件类型** —— 它落在「标记已置位」那一类里。`NR-12` 那条反证的适用范围跟着扩一格。
- [ ] 可核对：那位标记的置位入口仍然只有[`经济系统`](../../design/经济系统.md)那条还款路径，**本条不新增置位入口**。
- [ ] 可核对：`python tools/check_docs.py` 0 项必须修复。
