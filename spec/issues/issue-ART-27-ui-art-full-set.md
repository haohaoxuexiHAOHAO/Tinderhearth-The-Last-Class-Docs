# ART-27：照界面绘制约定画完全部界面素材

**无，只卡作者。** 代码那一半（`UI-41` 起那几条）等的是界面件，界面件已交付；本条剩下的那几张不挡它们。

## 实现笔记

### 设计决策

- **模糊点**：作者画的是整图（一整张面板、一条 8 格栏、32 个图标按钮挤在一张上），约定要的是一件一个文件、几种状态同一张画布。
- **选择**：写一个生成器，模板原样切、状态按色板换档派生、模板里没有的小件用字符格画；不走 SVG。
- **理由**：会做第二次的事落成入口；字符格每个字符只能对一个色板项，所以画不出色板外的颜色、也没有抗锯齿要关。

### 偏离

- **约定怎么说**：格子 24×24、资源条槽高 6、厚框边距 8、气泡浅底、手环外壳铺满屏。
- **实际怎么画**：格子 22×22（图标在 (3,3)）、资源条外高 10（填充通道 6）、厚框边距 18／18／18／22、气泡深底、面板推荐 560×328。另有几处配色改了模板：法力条亮一档（`fruitblue` 主色从 2 档换成 3 档）；精力条从水色改成绿；内容区与左栏盒子从 `ember 3` 换成 `soil 7` 的浅底；没选中的子页签从 `soil 4` 深到 `soil 3`；HUD 细框的底取 `ember 1`；说明框的底从 `skin 3` 提到 `skin 5`。
- **为什么**：前五样是作者画的，约定照画改。法力条原来那档转灰度后与生命条只差 8（Rec.601 明度），三条战斗资源条要靠明度分得开；水色的精力条在种地的游戏里会被读成水壶里还剩多少水。后四处是字的对比度：`ember 3` 是中间调，什么字色放上去都到不了 4.5:1；`skin 3` 上只有最黑那档字过线，加成正负那两档都不到 3，而物品词条正好摆在说明框里。换完之后每一对字色与底色都过 4.5:1（表在约定「排版：间距、行宽、行距与字色」那一节）。

### 权衡

- 内容区换成浅底之后，面板从「整块橙」变成「橙框里一张米色的纸」，暖色调还在；读字的地方一律浅底深字，深底只留给 HUD、气泡、主菜单与没选中的页签。
