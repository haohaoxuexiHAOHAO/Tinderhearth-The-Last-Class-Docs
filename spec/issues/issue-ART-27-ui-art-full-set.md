# ART-27：照界面绘制约定画完全部界面素材

## 目标

[界面绘制约定](../../production/界面绘制约定.md)那几张表里的件全部画完、按约定的目录与文件名放进代码仓，一次交付给代码那一侧接线。

## 来源

- PRD：[`spec/prd-ui-art-baseline.md`](../prd-ui-art-baseline.md) 的 `US-006`，外加 `US-005` 里那一格作者确认（照约定画，不用回来问）。
- 尺寸、状态、九宫格、哪几层会被染色、放哪都在那份约定里，本条不复述。

## 依赖

**无，只卡作者。** 代码那一半（`UI-41` 起那几条）反过来等本条交付。

**不等 `ART-17` 那批试片**：那一批验的是角色与地形的尺寸口径，而界面件的尺寸取自排版单位，不随它变。本条自己的试片是下面「先画试片」那一格。

**不在本条的**：地图底图归 `ART-19`，立绘、它的「暂无」占位与名字带归 `ART-20`，小头像归 `ART-28`；物品、技能、状态这些内容图标跟各自的内容清单走。它们的尺寸同样在约定里。

## 验收标准

- [ ] **先画试片**：一件细框、一个格子加一个图标、一条资源条，在 Godot 里用 `NinePatchRect` 与 `TextureRect` 拉到实际尺寸看过，再铺开。不过的那一项回头改约定，不改素材去迁就。
- [ ] 通用件（`kit/`）交付，含迷你记号、迷你字与鼠标指针。
- [ ] HUD 那一组（`hud/`）交付。
- [ ] 世界那一层（`world/`）交付。
- [ ] 面板那一组（`panel/`）与页签图标（`tab/`）交付。
- [ ] 对话与演出那一组（`dialog/`）交付，名字带除外。
- [ ] 主菜单那一组（`menu/`）交付。
- [ ] 按键图标（`glyph/`）交付；开始、选择与右摇杆按下那几个等 `UI-24`，不在这一格。
- [ ] 季节与天气图标交付（`icons/season/`、`icons/weather/`）。
- [ ] 照约定的「交付前自查」过一遍，其中三条战斗资源条转灰度那一项单独看。
- [ ] **照约定画的过程中，没有哪一件要回来问画多大、几种状态、放哪**；有就回改约定，改完再勾这一格。
- [ ] 交付时告诉代码那一侧，代码从 `UI-41` 开始动。
