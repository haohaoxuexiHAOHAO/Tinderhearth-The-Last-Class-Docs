# GP-148：日历按天、季、年走，世界状态整份复制得出来

## 目标

日期按天、季、年往前走，开新档从开局那一天开始；日期与那片地合成一份世界状态，整份复制之后改副本不碰原件。

## 来源

- PRD：[`spec/prd-sleep-advances-day.md`](../prd-sleep-advances-day.md) 的 `US-001`（日历那一半）与 `FR-1`。
- 结构要求：[`每日结算系统` · 下游同步](../../design/每日结算系统.md)那条「世界状态要复制得出来」。
- 日历的量在[时间与经营 · 时间](../../canon/gameplay/时间与经营.md)，开局那一天在[玩法定位 · 开局](../../canon/gameplay/玩法定位.md)，本条都不复述。

## 依赖

无。

## 验收标准

- [ ] 可测试：日期往前推一天；一季最后一天之后是下一季第一天；最后一季最后一天之后是下一年第一季第一天；年份一直往上加，很大的年份照样进一年。
- [ ] 可测试：日历里季节的先后是一张写出来的表，季节枚举里每一个都恰好出现一次；往枚举里加一个季节而不排进这张表，测试失败。
- [ ] 可测试：年小于 1、日不在一季的天数之内时，日期被拒。
- [ ] 可核对：日历只有年、季、日三个量，没有「月」；一季几天与季节先后各只写一处，注释指向设计仓正典「时间与经营」的「时间」一节。
- [ ] 可测试：开新档时日期是开局那一天；它是一个规则常量，注释指向设计仓正典「玩法定位」的「开局」一节。
- [ ] 可测试：世界状态复制之后，改副本的日期与任意一格地（清理、锄、播、浇、推进一天），原件一格不变；复制出来的每一格逐项与原件相同，含变异那一位。
- [ ] 可核对：那片地改由规则层的世界状态持有，农场节点（代码仓 `src/World/Farm/FarmField.cs`）读写它、自己不再持有地块。
- [ ] 可核对：代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。
