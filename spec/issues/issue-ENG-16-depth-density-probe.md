# ENG-16：纵深密度实机探针

## 目标

用满编占位角色实机验证 48px 纵深够不够——正典那笔账只证明「放得下、看得清」，没证明「打起来爽」。

## 来源

- 正典：[战斗与关卡 · 48px 是怎么算出来的](../../canon/gameplay/战斗与关卡.md)「这是几何账，不是好玩账。密度成不成立只能实机看，验法与判据归 `ENG-16`」
- SPEC：[`spec-combat-feel-core.md`](../spec-combat-feel-core.md) 的纵深模型一节

## 依赖

`GP-15`（纵深运动）、`ENG-15`（排序与影子——不排序就看不出前后，等于没验）。

## 验收标准

- [ ] 探针场景放**满编**：15 个敌人占位 + 5 个角色占位 + 至少 2 个互动物件（巨石、宝箱）占位，全部在 48px 纵深带内
- [ ] 机器可判的部分：全部实体的纵深都在带内、绘制顺序与纵深值一致、同屏实体数达标、帧时间不异常
- [ ] 存证：截图落 `logs/`，能看出前后关系与遮挡
- [ ] **作者实机确认**：能不能看清谁在前谁在后、纵深挪步躲得开不、48px 是否够用（不够就按本条记结论回改正典的 48px，那是有依据的改）
- [ ] 结论写回本条与正典对应处；若改数，`GP-15` 的钳制与 `ENG-15` 的排序要一并复跑
