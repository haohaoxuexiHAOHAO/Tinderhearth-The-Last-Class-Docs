# ART-17：按新口径画一批试片，实机看拼得对不对

## 目标

用最少的几张图验证这一轮定下的尺寸与画法真的拼得起来 —— 在画正式美术之前。

## 来源

- 从 `GP-82` 那一轮的验收里拎出来的：`ART-9`、`ART-12` 与 `DOC-105` 各剩一条作者实机确认，而**归档件只读，留在里面的待办没有人查得到**（与 `DOC-101` 从 `DOC-97` 里被拎出来同一形状）。三条合成本条，因为它们是同一次坐下来做的事。
- 口径都在[场景绘制约定](../../production/场景绘制约定.md)与[玩法定位 · 像素基准](../../canon/gameplay/玩法定位.md)，本条不复述。

## 依赖

不卡任何人。**但它卡着正式美术** —— 试片没过就开始批量画，错的口径会乘以角色数与片段数。

## 验收标准

- [ ] **俯视三样拼一起**：一块地面、一栋楼、一个角色，看 45 度投影有没有冲突（立面压没压扁、屋顶伸出占地对不对、角色站在地上而不是浮着）
- [ ] **俯视角色四向各一张**，看左右两向不靠翻转画出来之后不对称标志有没有换边
- [ ] **双网格试一小片**：草与天然裸土交界刷一段，看分界线是不是落在格子中线上、16 张有没有缺哪一种组合
- [ ] **耕地试一小片**：锄出一个孤立格与一小片连片，看边界是不是贴着格子边、孤立一格读不读得出「就是这一格」、**连片里数不数得出有几格**（沟纹要在一格之内自成单元，跨格连成大弧铺开会露出周期性断裂）
- [ ] **耕地与天然裸土并排看**，色相分不分得开 —— 两者长得像，混成一样玩家就看不出哪一格锄过
- [ ] **耕地压在草地上看**：它的硬直边挨着双网格那条有机曲线读起来违和不违和。**两种边界语言不一样是刻意的**（人锄的对自然长的），缓和它的那两笔画法在[场景绘制约定](../../production/场景绘制约定.md)
- [ ] **湿耕地**与干的并排看，色带换过之后还读得出是同一种地面
- [ ] **侧视一屏背景按组件拼出来**，看重复感能不能接受（远景允许明显复用，点睛物放角色带附近）
- [ ] **动态水**：水面几帧循环加静止岸线，看接缝处会不会「水在动而岸在抖」
- [ ] 每一项不过的那条，**回头改的是[场景绘制约定](../../production/场景绘制约定.md)或正典，不是偷偷改素材去迁就** —— 试片的全部意义是趁便宜的时候发现口径错了
