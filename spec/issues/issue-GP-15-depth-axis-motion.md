# GP-15：规则层纵深轴运动

## 目标

把主角运动从单平面改成带连续可行走纵深的模型：横向、纵深、跳跃高度三轴分离，纵深带 48 世界像素。

## 来源

- 正典：[战斗与关卡 · 战斗关卡的空间模型](../../canon/gameplay/战斗与关卡.md)（作者 2026-09-09 定）
- PRD：[`prd-combat-feel-core.md`](../prd-combat-feel-core.md) 的 `US-001`、`US-003`（2026-09-09 范围变更）
- SPEC：[`spec-combat-feel-core.md`](../spec-combat-feel-core.md) 的运动模型一节

## 依赖

`GP-10`（已完成，`MotorState` 与 `CombatFeel` 在那里）。**这是对 `GP-10` 已实现模型的改造**，不是新建：`GP-10`／`GP-12`／`GP-13` 的机器验收都是在单平面模型下通过的。

## 验收标准

- [ ] 纵深是**连续**的，不是固定轨道；纵深位置钳在 48px 带内
- [ ] 三轴分离：横向速度、纵深速度、跳跃高度互不串。**空中不改纵深**（离地期间纵深锁定），落地后恢复
- [ ] 纵深移动速度作为独立可调量进 `CombatFeel`，标未校准初值、归 `GP-6`
- [ ] 出招时纵深与横向一同定身（沿用 `GP-10` 的 `attacking` 封锁口径）
- [ ] 闪避方向取按下瞬间的输入（`GP-9` 口径不变），但方向现在是**横向与纵深的二维输入**
- [ ] 规则层单测覆盖：纵深钳制、空中锁纵深、落地解锁、三轴不串、出招定身
- [ ] `rules/Combat` 仍不引用 Godot
