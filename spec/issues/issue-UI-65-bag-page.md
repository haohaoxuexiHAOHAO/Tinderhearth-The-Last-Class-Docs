# UI-65：背包页：每一堆看得见种类、品质与件数

## 目标

手环里的背包页画出每一格的图标、件数、品质点与稀有度框，写着还剩几个空格与选中那一格是什么；整页用画好的件拼，样子照作者给的参考图。

## 来源

- PRD：[`spec/prd-items-in-bag.md`](../prd-items-in-bag.md) 的 `US-008` 前半。
- 规则与必须显示的几项在[`界面系统` · 手环上：背包](../../design/界面系统.md)。

## 依赖

- `GP-159`：背包本体。
- `UI-61`：农场里要先有手环。
- `UI-63`：格子里要画物品的图标。

## 验收标准

- [ ] 可观察：每一格画格子、图标、件数（多于一件才写）、品质点（按品质那一档的显示色染；无品质的不画）与稀有度框（按稀有度那一档的显示色染）；空格只画格子。
- [ ] 可观察：页上写着当前排序键、当前筛选条件与还剩几个空格；选中一格时下面一行写它的名称、品质与件数。
- [ ] 可核对：整页用素材资源里已有的件拼出来（厚框、格子各态、选中框、品质点与稀有度框）：深色厚框里一行四格，格数多了往下加行。一行几格写在规则层的排版单位里（代码仓 `rules/UI/WristbandLayout.cs` 一类），有测试管着。
- [ ] **作者实机确认**：同名不同品质分得出来；16 像素图标上的件数与品质点分得清；一屏同名多行读得下去。串在 `GP-163` 的清单里。
- [ ] 可核对：代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。
