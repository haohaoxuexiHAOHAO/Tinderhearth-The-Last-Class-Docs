# DOC-92：其余二十七份按五批补齐

## 目标

`design/` 下每一份都达到样板的标准 —— 查哪一份都不用重新适应。

## 来源

PRD：[`spec/prd-doc-readability.md`](../prd-doc-readability.md) 的 `US-004`。

## 依赖

`DOC-91` 的风格确认。作者没认可样板就铺开，等于把返工面从三份放大到三十份。

## 为什么是一条而不是五条

五批的验收形状完全一样（术语节、导语、图、长句、不改结论、门禁绿）。拆成五条就是**同一份验收清单有五个副本**，而那正是「事实只许有一个家」要挡的。所以清单在下面写一次，进度**按份勾而不是按批勾** —— 粒度比拆五条还细。

## 每份改完算什么

下面每一个勾选框都代表一份文档同时满足这些：

- 术语节（过渡期是「摘要」节内的三级标题）只列本页专属词，每个词在正文出现过，没有一个与共用术语表重复。
- 摘要首段是白话导语，不使用两张术语表之外的自造词。
- 有状态机、有固定顺序链或有依赖关系的**各有一张图**，带重画条件那一行；判定为不需要图的**在实现笔记里写明理由**。
- 多重从句的长句已拆，且拆句没有改变任何一句的结论。
- 那一份的 `git diff` 逐处复核过，没有一条结论被改动。
