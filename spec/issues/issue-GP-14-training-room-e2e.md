# GP-14：训练房场景与端到端

## 目标

组装可运行的侧视训练房场景，走通端到端并由作者实机确认整套手感。

## 来源

- PRD：[`prd-combat-feel-core.md`](../prd-combat-feel-core.md) 的 `US-006`
- SPEC：[`spec-combat-feel-core.md`](../spec-combat-feel-core.md) 的 §2、§8
- 纵深三条（本条 2026-09-12 扩范围时补进来的依据）：[`issue-GP-15`](./issue-GP-15-depth-axis-motion.md)（纵深轴运动）、[`issue-GP-16`](./issue-GP-16-depth-hit-tolerance.md)（纵深容差命中）、[`issue-ENG-15`](./issue-ENG-15-depth-sorting-shadow.md)（纵深排序与影子）
- 工具：[`issue-ENG-6`](./issue-ENG-6-frame-tuning-tools.md)（`CombatDebugOverlay`，已完成）

## 依赖

`GP-10`、`GP-11`、`GP-12`、`GP-13`、`GP-15`、`GP-16`、`ENG-15`、`ENG-6`——端到端收尾，依赖全部前序条目。

## 范围在 2026-09-12 扩过一次（重要）

**本条原验收标准写于 2026-09-07，早于整个纵深系统。** 那一版描述的是一个**单平面**训练房：没有纵深带、没有纵深容差命中、没有按纵深排序与影子，轻击也还是三段共用一组帧。照原样实现会做出一个比现状**倒退**的场景 —— 而倒退不会报错，它只会让「训练房做完了」这句话变得不可信。

所以下面的验收标准已按当前事实重写。三处口径同时更正：轻击是**三段各有独立动画与判定框**（`ART-6`，2026-09-11）、重击是**单招**（`HeavyChainLength=1`）、闪避是**闪步**且移动加速档叫**奔跑**（`MotorPhase.Run`，2026-09-12 定名，设计文档里的「冲刺」指同一件事）。

**`ENG-16`（48px 纵深带够不够）并入本条一起验**，不单开一轮：作者 2026-09-09 与 09-11 两次实机都反馈「活动区域偏窄、上下留白多」，而那个判断需要**真实背景 + 满编密度**才成立 —— 那正是本条要搭的东西。单独再搭一个满编场景是重复劳动。

## 验收标准

- [ ] `scenes/TrainingRoom.tscn`：侧视场景，含 `InputRouter`、`GameCamera(SideView)` 跟随主角、**48px 纵深带的带状地形**、`PlayerActor`、`TrainingDummy`、`CombatDebugOverlay`（默认关）、`DepthSortedLayer`
- [ ] **不改动** `scenes/Main.tscn` 及其启动探针链（那是 `UI-1` 验收执行体，`verify.py` 跑产物与专项守卫都读它）
- [ ] **三轴都能用**：横向移动/奔跑、跳跃、`W`/`S` 走纵深；角色按纵深偏移绘制并排序、影子留地面（`ENG-15` 的能力在本场景里真的接上，不只是在 `DepthDev` 里能看）
- [ ] **命中是纵深感知的**（`GP-16`）：同一横向距离，纵深对齐打得到、错开一排打空 —— 这是 `DepthDev` 当时刻意没接的那一半
- [ ] 自动化端到端走主路径：待机 → 轻击三段各段（各段独立动画与判定框）→ 命中产生硬直与顿帧 → 重击单招 → 闪避（闪步）进无敌窗 → 回待机；条数与 `verify.py` 静态计数一致
- [ ] 覆盖失败/边界：连段超时回落、**打空不续段**（命中确认，`GP-10` 方案 b）、无方向输入时闪避取向、屏幕震动关零位移、空中连击落地打断
- [ ] `CombatDebugOverlay` 在本场景可开关（`V`/`P`/`.`），帧步进不改变结算
- [ ] 代码仓 `python tools/verify.py` 全绿（构建/测试/导出/跑产物），`temp/` 干净
- [ ] 本轮手感参数快照与帧步进截图存证落 `logs/`
- [ ] **`ENG-16` 并入**：放满编（15 敌 + 5 角色 + 互动物件）实机看 48px 带够不够 —— 排位读不读得清、打起来挤不挤。结论若是不够，按结论回改 `DepthBand.WidthWorldPx` 并连同正典那笔几何账一起重算（**不许凭手感改数**）
- [ ] 作者实机确认（PRD `US-006` 清单）：移动跳跃/轻击三段与重击/闪避与奔跑/四件套「打得实」/纵深挪步与排位可读/帧步进复核；1080p 与 1440p 各看一遍字与像素清晰
