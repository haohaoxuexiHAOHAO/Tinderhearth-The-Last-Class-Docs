# GP-168：随身栏成为背包上单独一排，只放占 1 格的东西

## 目标

随身栏是背包上单独一排、格数与技能位条数相同，只放得进占 1 格的东西；占 1 格的新东西先找这一排的空格，播种照旧用手上那一格的种子。

## 来源

- PRD：[`spec/prd-grid-bag.md`](../prd-grid-bag.md) 的 `US-003`。

## 依赖

- `GP-167`：这一排挂在网格背包上，先合堆、再找空地的次序要把它排在网格前面。

## 验收标准

- [ ] 可测试：随身栏是背包上单独一排格子，格数照旧与技能位条数相同；它不属于网格，网格里的位置不会挪进它。
- [ ] 可测试：占地大于 1×1 的东西放进随身栏被拒，原因说清是太大；那一堆留在原处。
- [ ] 可测试：新进来的东西先合进同标识没满的那一堆（先找随身栏、再找网格）；还要放新的一块时，占 1 格的先找随身栏的空格、再找网格，大的直接找网格。
- [ ] 可测试：播种取随身栏选中那一格的种子，扣一颗；选中的是收获物时被拒，原因是「不是种子」。随身栏那几条已有的用例照样通过。
- [ ] 可观察：屏幕底边那条随身栏照旧一格 22 像素，画的是随身栏那一排里的东西。看得见要实机，串在 `GP-173` 的清单里。
- [ ] 可核对：代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。
