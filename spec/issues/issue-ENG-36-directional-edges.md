# ENG-36：双网格的规范边按方向分别声明

## 目标

一套双网格素材的四个方向（A 在上、A 在下、A 在左、A 在右）可以各画各的交界，检查照样逐像素判得了，外圈模板照方向各出一圈；没声明方向的套照旧四个方向共用一串。

## 来源

- PRD：[`spec/prd-shore-stone-wall.md`](../prd-shore-stone-wall.md) 的 `US-001`。
- 起因在「地形纹理怎么加」那一轮实测到：交界的影子绕着草一圈、四个方向一样粗，与[场景绘制约定 · 交接处那些光影归谁](../../production/场景绘制约定.md)要求的「暗带只画在岸在上方的那几张上」对不上。

## 依赖

无。

## 验收标准

- [ ] 可核对：代码仓 `tools/check_dualgrid.py` 里一套素材可以给四个方向各声明一串交界像素；没声明方向的套，四个方向照旧共用一串。
- [ ] 可核对：`python tools/check_dualgrid.py --emit-ring <目录>` 照新的声明出外圈模板，四个方向各是自己那一串。
- [ ] 可核对：现有三套不改声明，代码仓 `python tools/verify.py` 里双网格那一步照旧通过。
- [ ] 可测试：一张图块的某条边与它那个方向的规范边差一个像素时，检查报出是哪一张、哪条边、哪个方向。
