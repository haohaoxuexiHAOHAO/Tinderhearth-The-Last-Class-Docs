# GP-161：收上来的菜经生产那条管道进背包，放不下那一株还在

## 目标

主角收获时，收成走生产那条管道进他的背包；背包放不下时那一格照旧待收、一样不变，屏上一行字说清。

## 来源

- PRD：[`spec/prd-items-in-bag.md`](../prd-items-in-bag.md) 的 `US-004`。

## 依赖

- `GP-158`：收成要落成一个在册的收获物。
- `GP-159`：背包本体与「整份拒收」。
- `UI-64`：放不下那一行字靠即时提示显示。

## 验收标准

- [ ] 可测试：主角在地里收获走生产那条管道的四个环节（[生产系统 · 一条管道，四个环节，顺序固定](../../design/生产系统.md)）：产出是这一株的件数与品质，归属是主角，不付酬，入库进主角的背包。
- [ ] 可测试：变异那一株收上来是变异品质；没变的是寻常。寻常是种植技能落地之前的占位，代码那一处注释指向 `GP-45`。
- [ ] 可测试：放不下时那一格照旧待收，件数、品质与变异那一位都不变；腾出位置再收，收到的与第一次本该收到的一样。代码仓 `rules/Economy/Plot.cs` 的 `TryHarvest` 要拆成先算、放得下再改。
- [ ] 可观察：放不下时屏上当场出现一行字，说清是背包满了；它不进手环的事件流。
- [ ] **作者实机确认**：背包满了再收，看得出被拒、那一株还在；丢掉一堆再收，收进来了。串在 `GP-163` 的清单里。
- [ ] 可核对：代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。
