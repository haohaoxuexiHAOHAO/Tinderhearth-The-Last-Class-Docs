# UI-67：背包页画成网格

## 目标

背包页是一张格子挨着格子的网格，大东西画在它占的那一块上；随身栏那一排画在网格上面，拿起一堆之后看得出放不放得下。

## 来源

- PRD：[`spec/prd-grid-bag.md`](../prd-grid-bag.md) 的 `US-006`，方向键那一条之外。方向键那一条在 `UI-68`。

## 依赖

- `GP-170`、`GP-171`：这一页的点击与按钮都调到它们管着的那几条规则。

## 验收标准

- [ ] 可观察：网格一格 16 像素、格与格之间不留缝；每一堆的图画在它占的那一块上，不缩放；件数、品质点与稀有度框画在那一块上。看得见要实机。
- [ ] 可观察：随身栏那一排画在网格上面，每格标着它在随身栏里是第几格。
- [ ] 可观察：拿起一堆之后，指着的地方画出它要占的那一块，放得下与放不下画得不一样（形状不同，不只换颜色）。
- [ ] 可观察：选中框与焦点框画在那一块的里面一圈，不压到旁边那一格。
- [ ] 可测试：配置里每一级的背包，整页都放得进手环的内容区，宽与高都算上右边那一列按钮；一页看全，不滚也不分页。
- [ ] **作者实机确认**：16 像素的格子线看得清；大东西的图看得清细节；一格里的件数与品质点不把图盖掉太多；拿起、放下顺手；两种被拒的说法看得懂。串在 `GP-173` 的清单里。
- [ ] 可核对：代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。
