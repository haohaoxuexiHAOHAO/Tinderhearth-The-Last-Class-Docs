# UI-31：技能升档当场给一条提示

## 目标

玩家在关卡里练出一个新档位时当场知道，而世界不因此暂停。

## 来源

PRD：`spec/prd-richness-and-feel.md` 的 `US-018`。

立项理由：实战值到档位会解锁技能孔，而[角色与成长](../../canon/gameplay/角色与成长.md)写明**升档那一刻不弹界面**（理由是对的：弹界面等于给玩家一次免费暂停）。结果是升档在关卡里**完全不可见** —— 而它是全作唯一的解锁式成长反馈。

作者已定：给一条不接管输入的提示（气泡或屏幕边缘），**不做角色闪光**。选择照旧攒到手环里做。

## 依赖

无强依赖。与 `UI-30` 口径一致（那一屏给的是结算里的汇总，本条给的是关卡内的当场提示）。

- [ ] 提示落在[`界面系统`](../../design/界面系统.md)世界那一层，形状与气泡、引导提示**分得开**（那条要求已经在那份文档里）
- [ ] 明确不做角色闪光
