# UI-60：随身栏是背包的前六格，种一颗少一颗

## 目标

随身栏显示背包前六格、自己不存东西；播种用掉选中那一格的一颗种子；开发期调试键 `G` 往背包里放种子。

## 实现笔记

### 设计决策

- **背包换成随身栏的格子由调用方做**：规则层的界面这一侧不依赖经营那一侧（随身栏在 `Rules.UI`，背包在 `Rules.Economy`），所以 `ProjectionOf` 收的是已经换好的格子，只管「取前几格、少了就抛」。换法只有一行，农场与测试各写一次、写法相同。
- **扣种子在规则层的经营那一侧**：`TryPlantFromBag` 读背包那一格、判法照旧交给 `TryPlant`，播成了才扣一颗。随身栏只是投影，扣的是背包；随身栏那边一个增减件数的入口都没加，那条反证照旧成立。
- **整批放不下一件不放**：一批里有好几样，背包一样一样放、半路放不下就会留下半批。先在一份副本上放一遍，全成了才换上去；放不下时这一批也不往后挪，腾出位置再按给的还是这一批。
- **放种子不走生产那条管道**：它是开发期的调试键，不是产出；管道只管基地产出那几条渠道。

### 偏离

无。

### 权衡

- **第二批起种子落在随身栏后面那几格**：放种子走背包那一套「先合进同标识堆、再按格号占空格」，背包开头那几格被第一批占着时，后面几批落在随身栏看不见的格子里，要在背包页里挪到前面来（`UI-66`）。不另给它一套「直接放进随身栏那几格」的放法：那一套在随身栏那几格放着别的东西时，要么替玩家挪东西、要么整批被拒，而背包页能挪格之后它没有用处。所以 `GP-146` 那一格实机「每一种都看一遍」，第二批起要在背包页里挪格。
- **选到收获物那一格的实机也要先能挪格**：收上来的东西落在第一个空格，背包开头那几格被种子占着时它落在后面。
