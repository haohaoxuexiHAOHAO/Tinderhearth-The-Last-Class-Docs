# UI-60：随身栏是背包的前六格，种一颗少一颗

## 目标

随身栏显示背包前六格、自己不存东西；播种用掉选中那一格的一颗种子；开发期调试键 `G` 往背包里放种子。

## 来源

- PRD：[`spec/prd-items-in-bag.md`](../prd-items-in-bag.md) 的 `US-005`。
- 它交付 `UI-35` 的全部：随身栏改成读背包前六格的投影。

## 依赖

- `GP-158`：种子要是在册的物品，作物定义写明用哪一样种子。
- `GP-159`：背包本体。
- `ENG-34`：调试键先登进绑定表，换键时冲突测试判得到。

## 验收标准

- [ ] 可测试：随身栏显示背包的前六格，随身栏自己不存任何物品（代码仓 `rules/UI/CarrySlots.cs`）；随身栏那几条已有用例与「播种取选中那一格」那几条用例（`UI-34`、`GP-128`）一条不改照样通过 —— 换内容来源不重做载体，这一条是承重项。
- [ ] 可测试：播种成功从选中那一格扣一颗种子；扣到零那一格变空。
- [ ] 可测试：选中那一格放的是收获物时播种被拒，原因是「不是种子」；那一格与地都不变。屏上一行字说清（`UI-64`）。
- [ ] 可测试：调试键 `G` 往背包放一批种子：按标识排，一批的种数与随身栏格数相同，每种一满堆；放不下时整批被拒并说清；按到最后一批之后回到第一批。它不进输入映射。原来的换批键 `B` 与代码仓 `rules/UI/SeedBatches.cs` 里那份按批填随身栏的脚手架一起退掉。
- [ ] 可核对：指南里讲换批键 `B` 的几处改成 `G`、改成往背包里放一批（[一块地能种出东西](../../reference/godot/一块地能种出东西.md)那一篇与 `GP-146` 的条目文件）。
- [ ] **作者实机确认**：数字键选到种子那一格播得下去、那一格少一颗；选到收获物那一格播不下去，屏上说清原因。串在 `GP-163` 的清单里。
- [ ] 可核对：代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。
