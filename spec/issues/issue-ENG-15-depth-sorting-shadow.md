# ENG-15：纵深排序与代码影子

## 目标

引擎层按纵深排序绘制，并由代码持有角色影子——它是纵深与跳跃高度的主要提示。

## 来源

- 正典：[战斗与关卡 · 战斗关卡的空间模型](../../canon/gameplay/战斗与关卡.md)「绘制按纵深排序」（作者 2026-09-09 定）
- SPEC：[`spec-combat-feel-core.md`](../spec-combat-feel-core.md) 的绘制顺序与影子一节
- 素材侧口径见 [`issue-ART-6`](./issue-ART-6-role-action-frames.md)：**影子不画进帧里**

## 依赖

`GP-15`（要有纵深位置才排得了序）、`GP-12`（主角节点）。

## 验收标准

- [ ] 纵深靠后的先画、靠前的压在上面；同纵深时按脚底位置排。排序**与命中判定用的是同一份纵深值**，不许各存一份
- [ ] 影子由代码绘制，不进精灵帧：位置取角色的**地面投影点**（纵深位置），不随跳跃升高
- [ ] 跳跃时影子留在地面，并按高度变化（缩小或变淡），作为高度提示
- [ ] 影子参数（尺寸、透明度、随高度的变化）集中进 `CombatFeel` 或同级落点，标未校准初值
- [ ] 引擎探针判据：两角色纵深交换时绘制顺序随之交换；跳跃全程影子的地面位置不变；落地后影子与脚底重合
- [ ] 不新增 `Camera2D` 派生类，不破坏 `Main.tscn` 探针链与既有相机专项
