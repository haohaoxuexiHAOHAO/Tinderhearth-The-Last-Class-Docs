# ART-5：下载素材里的柔和投影怎么处理

## 目标

定一次「下载来的素材带柔和投影时怎么办」，让它不必在每个素材包上重新决定一遍。

## 来源

`UI-5` 收 `fantansy lands` 那套俯视素材时撞出来的（2026-08-31）。[像素绘制原则 §9](../../production/像素绘制原则.md) 把「透明度只使用完全透明或完全不透明」定为**绝对规则**，`ENG-10` 的守卫（代码仓 `tools/check_assets.py`）当场拦下。

实测（`python tools/inspect_art_inbox.py`）：五张图全带软 alpha，值是 77／102／148／163，最多的一张 8,371 处。那些像素是屋檐、门与雨棚底下的柔和投影，不是脏点。

## 为什么要定一次而不是每次临时决定

**这会在每个下载包上复发。** 带柔和投影是现成像素素材的常见做法，不是这一个包的特例。每次临时决定的后果是判据漂移：这次放行、下次拦下，而两次的理由都记不住。

## 候选做法

| 做法 | 代价 |
| --- | --- |
| **阈值化**（alpha ≥128 → 255，<128 → 0） | 77 与 102 的投影整片消失，148 与 163 变成实心灰块。**观感比原图差**，而且是不可逆的破坏 |
| **抖动**成 50% 棋盘格的实心投影色 | 像素画伪造半透明的传统做法，保住投影的读感且满足硬 alpha。要写一个转换入口，且**每张都要人看一眼**效果 |
| 把 §9 降级为「建议」 | **不推荐。** 它是正典里的绝对规则，为占位素材改它不成比例；而且降级之后没有任何东西挡住软 alpha 进入自绘件 |
| **只对登记为「不得进发行包」的素材放行软 alpha** | 作者 2026-08-31 定「发行包只用自绘素材」之后才成立：下载件既然一定会被替换，满不满足 §9 只影响开发期观感，而 §9 要守的是成品质量。代价是守卫多一个例外口子 —— 例外条件必须写死在守卫里并自证，否则它会慢慢扩大 |

## 决定（2026-09-02）

**走「只对不得进发行包的素材放行软 alpha」**（候选第四条）。

放弃其余三条的理由：
- 阈值化与抖动都是对一定会被扔掉的素材花工夫，不合比例。
- 降级 §9 会打开自绘件的软 alpha 口子，代价不成比例。

例外条件单一：`可进发行包 == false`，机器可验证，不扩展到其他条件。自绘件（`可进发行包: true`）无论如何都必须通过 §9。

## 实现笔记

**执行体**（2026-09-02 落地）：

- `tools/check_assets.py`：`check_alpha` 加 `skip_if_non_releasable` 参数；主循环读登记表的 `可进发行包` 字段决定是否跳过。
- `tools/inspect_art_inbox.py`：`describe` 函数对 `other-material` 桶（对应下载件）传 `skip_if_non_releasable=True`；`self-material` 桶仍强制执行。
- `tools/selfcheck_verify.py`：新增两条 `DIRECT_CASES`——「自绘件软 alpha 仍被拦」与「下载件软 alpha 被放行」，构成反证对。
- `production/像素绘制原则.md` §9：在最后段落补充例外说明，含执行体落点与不扩展声明。

## 验证结果

| 命令 | 结果 | 判定 |
| --- | --- | --- |
| `python tools/selfcheck_verify.py --list` 核新增两条用例是否已登记 | 两条均出现在 DIRECT_CASES | ✓ |
| `fantansy lands` 五张图重跑（凡登记为下载件、`可进发行包=false`） | 软 alpha 被放行，不再报 FAIL | ✓ 符合新政策 |
| 对生成占位件（`可进发行包=false` 但属于生成槽位）注入软 alpha | 仍被拦 —— 例外条件只看字段，不看素材来源分类 | ✓ 正确收窄 |
