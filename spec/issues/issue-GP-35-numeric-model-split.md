# GP-35：数值模型的派生公式与参数表按攻防分离改

## 目标

让推演算的是攻防分离之后那套公式，而不是悄悄算着旧的「一份攻击力、一份防御」。

## 来源

- PRD：[`spec/prd-growth-skill-damage.md`](../prd-growth-skill-damage.md) 的 `US-006`
- 现状：[`数值模型` · 四项属性：每一项在一天里都有用](../../design/数值模型.md)那张表写的是「体力 → HP、SP、防御」，派生公式只有一份 `攻击力` 与一份 `防御`；`tools/simulate_week.py` 的判据 C1 就按那一份算。

## 依赖

`GP-30`（派生表的最终形状）与 `DOC-18`（参数键 `stamina.*` → `vigor.*` 那一批）。

## 验收标准

- [ ] [`数值模型` · 四项属性：每一项在一天里都有用](../../design/数值模型.md)那张表与派生公式按 `GP-33` 重写，参数路径跟着分成物理与魔法两份；**两份防御都保留「基数 ＋ 系数 × 体质」的一次式形状**。
- [ ] [`数值模型` · 减伤用软化分母，因为堆防御必须递减](../../design/数值模型.md)补上穿透与暴击，公式与 `GP-32` 的结算顺序**逐字对得上**。
