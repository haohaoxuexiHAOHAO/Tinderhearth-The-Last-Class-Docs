# ENG-47：每一层取图块表上哪一格

## 目标

给一个显示格四个角压着的地形，规则层算得出每一种地形那一层取图块表上哪一格，或者空着。

## 来源

- PRD：[`spec/prd-outdoor-tile-sheet.md`](../prd-outdoor-tile-sheet.md) 的 `US-002` 前三格，`FR-2` 到 `FR-8`。

## 依赖

- `ENG-45`：每一套与每一块整块在哪、四角编码那张映射表，都在那份排法里。

## 验收标准

- [ ] 可测试：四个角都算这种地形时，取整块里第 (x mod 宽, y mod 高) 那一格，x、y 是显示格坐标，负数取向下的模；只有几个角算时，按四角编码取那一套里的一格；一个都不算时空着。
- [ ] 可测试：顺序在后面的地形也算前面那一种。四个角是草与浅水时，裸土与草两层取整块，浅水那一层取那一套里的一格，深水那一层空着；裸土没有那一套，只在四个角都算裸土时取整块。
- [ ] 可测试：数据层范围外的角按最近的边缘格算；范围内没刷的格、刷的那一块没标地形的，都不算任何一种地形。
- [ ] 可核对：代码仓 verify 全过。
