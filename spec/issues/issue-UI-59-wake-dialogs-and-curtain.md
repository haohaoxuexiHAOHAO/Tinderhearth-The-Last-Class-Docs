# UI-59：醒来的两个弹窗与转场遮罩

## 目标

睡下时淡出、结算完淡入，淡入播完弹简版摘要；存档没写上时弹「这一天没有推进」；这一段里第二次推进被拒、玩家输入不起作用、世界不暂停；完整明细在手环那一页落地之前打在输出面板上。

## 来源

- PRD：[`spec/prd-sleep-advances-day.md`](../prd-sleep-advances-day.md) 的 `US-007`、`US-003` 第四、五格，`FR-16`、`FR-17`、`FR-39`、`FR-40`、`FR-42` 到 `FR-44`。
- 两个弹窗各答什么问题：[`界面系统` · 弹窗那一层：结算摘要与二次确认](../../design/界面系统.md)，以及[`界面系统` · 主菜单那一侧：读档位列表、更新公告、设置](../../design/界面系统.md)里「存档写入失败」那一段。

## 依赖

- `GP-154`：床与 `N` 是触发这一段的两处。

## 验收标准

- [ ] 可核对：醒来弹简版摘要（弹窗那一层，作者排版）：一行写结算的是哪一天，下面每个有变化的项一行；一项变化都没有时只有一行「没有要紧的变化」。
- [ ] 可核对：存档没写上时弹另一个弹窗，写「存档没写上，这一天没有推进」、原因、存档路径与「处理好之后再睡一次」。
- [ ] 可核对：手环那一页落地之前，完整明细打在输出面板上：每一格一行，写哪一格、哪种作物、枯死还是变异；作物素材表那份「这一晚变异的每一格各打一行」由它接替。
- [ ] 可核对：弹窗开着时世界暂停，关掉之后交回操作；用的是既有的暂停判定，不另写。
- [ ] 可核对：睡下时播作者做的淡出，结算完播淡入，淡入播完才弹窗；遮罩不进导航栈，这一段不碰 `SceneTree.Paused`。
- [ ] 可测试：从睡下到弹窗弹出之前，第二次推进被拒。
- [ ] 可核对：那一段里玩家输入不起作用：输入门面关着，`N` 与 `B` 两个直读按键也不响应。
- [ ] 可核对：两个弹窗或遮罩缺一个，当场报错说清缺谁；新增的字都在文本表里（代码仓 `data/text/zh-CN.json`）。
- [ ] 可核对：代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。
- [ ] **作者实机确认**：两个弹窗的排版、字放不放得下，转场快慢合不合适。串在 `GP-155` 的清单里。
