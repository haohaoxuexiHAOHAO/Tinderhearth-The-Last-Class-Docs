# ENG-35：数据层配错时当场报错，不让水悄悄能走

## 目标

数据层被停用、它的碰撞被关掉、或者同一种地形的几张标记瓦片碰撞没画齐时，运行时当场报错、一次全报，编辑器里只警告。

## 来源

- PRD：[`spec/prd-terrain-blocks-walking.md`](../prd-terrain-blocks-walking.md) 的 `US-002`，外加 `US-003` 里改代码注释那一格（同一个文件，跟这一条一起改）。

## 实现笔记

### 设计决策

- **判在规则层，引擎层只交「每一张标了什么、带不带碰撞」与那两个开关**：与作物素材、物品图标那几条载入核对同一个形状，所以用例不用引擎；两个开关也交进去，是为了与不齐那几条一起一次报全。
- **「带不带碰撞」按任何一个物理层上有没有碰撞形状算**：数据层现在只有一个物理层；将来多一层时，同一种地形照旧只该有一个答案。
- **瓦片在报错里写成「哪张图（第几个源）的哪一格」**，与 TileSet 面板里看到的对得上；备选瓦片另写备选编号。
- **只在进树时核一次，不跟着重画核**：刷地形时每一笔都发 `Changed`，配到一半时输出面板会被同一条警告刷满。代价是编辑器里改完 TileSet 要重开场景或按 `F6` 才看得到新的核对结果。
- **放在 `Tinderhearth.Rules.Foundation.Terrain`**：俯视地形基地与城区都用，正典的系统清单里属跨系统基础设施。

### 偏离

无。

### 权衡

- **一张都没画碰撞也算齐，不报**：代码不知道哪一种地形是水，「没有一种地形挡人」在一张没有水的图上是对的。水能不能走留给实机。

### 待确认

无。
