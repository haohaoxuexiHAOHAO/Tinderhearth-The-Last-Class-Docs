# ENG-35：数据层配错时当场报错，不让水悄悄能走

## 目标

数据层被停用、它的碰撞被关掉、或者同一种地形的几张标记瓦片碰撞没画齐时，运行时当场报错、一次全报，编辑器里只警告。

## 来源

- PRD：[`spec/prd-terrain-blocks-walking.md`](../prd-terrain-blocks-walking.md) 的 `US-002`，外加 `US-003` 里改代码注释那一格（同一个文件，跟这一条一起改）。

## 依赖

无。

## 验收标准

- [ ] 可测试：给一组「哪种地形、哪一张、带不带碰撞」，同一种地形里有的带、有的不带时，判定报出那种地形与它的每一张；全带或全不带时不报；几种地形同时不齐时一次报全。
- [ ] 可测试：只看数据层那个地形集里标了地形的瓦片，别的地形集与没标地形的不参与。
- [ ] 可测试：数据层 `Enabled` 关着、`Collision Enabled` 关着各报一条，信息说清怎么改；与不齐那几条一起一次报全。
- [ ] 可核对：运行时当场抛出；编辑器里只警告，显示层照旧跟着刷（与这一段接线现有那几条同一个口径）。
- [ ] 可测试：一次性无头场景各造一种配错跑一次，各报出该报的那一条；配好的那一份不报。跑完删，在下面记下删了什么。
- [ ] 可核对：代码仓 `src/World/Terrain/DualGridPainter.cs` 里数据层那段注释不再说关 `Enabled` 也行。
- [ ] 可核对：代码仓 `python tools/verify.py` 全过。
