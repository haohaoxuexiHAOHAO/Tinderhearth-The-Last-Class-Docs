# DOC-14：新量登记、判据 C10 与重跑推演

## 目标

让这一批新加的量都有家，并且能自动判出「某条经营渠道是不是比出征还赚」。

## 来源

- PRD：[`spec/prd-base-and-production.md`](../prd-base-and-production.md) 的 `US-008`

## 依赖

依赖 `GP-26`（工资与渠道要先在正典里成立）与 `GP-27`（判据按哪一档判取决于物资档）。

## 验收标准

- [ ] [内容规模基准](../../canon/gameplay/玩法定位.md)补行：家畜、鱼、设备、燃料、料理配方、室内场景、清理物、生活技能
- [ ] 工资比例、燃料料耗、设备产量差、清理物重生速率与产量、食物增益幅度与时长、钓鱼三项参数、索取额度件数全部登记进[`数值模型`](../../design/数值模型.md)的「尚未给值」表，各写校准办法与归属
- [ ] **食物增益不得成为通关前提**这条约束形式写进数值模型
- [ ] 新增判据 **C10：任何经营产出渠道的每小时与每点体力收益不得高于同期委托**，由 `python tools/simulate_week.py` 判定
- [ ] 工资作为一条日常支出进现金流；重跑推演，报告 `P3` 与 `P4` 是否仍成立（不成立先调工资比例，再动物资档）
- [ ] 判据按**物资最少的那一档**判定；宽松档只作参考打印
- [ ] 失败路径：把工资比例调到极端值，推演**必须有判据不成立** —— 证明 C10 与现金流判据没有空转
- [ ] `python tools/simulate_week.py --check-doc` 无分叉；`python tools/check_docs.py` 0 FAIL
