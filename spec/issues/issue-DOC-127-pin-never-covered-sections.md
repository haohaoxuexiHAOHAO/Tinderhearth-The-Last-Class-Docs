# DOC-127：核一遍那批指纹从未覆盖过的正典节

## 目标

`DOC-117` 修好锚点之前，那批正典节的指纹钉的是**别的节** —— 它们自己改过没改过，没有任何东西报得出来。要确认引它们的那些「上游约束」现在还成不成立。

## 来源

台账 `DOC-127`，`DOC-117` 修完锚点之后暴露出来。那一轮的重录**建立的是第一份正确基线，不是一次复核** —— 这一条就是把那次复核补上。

待核的节在 [`issue-DOC-117` 的附录](./issue-DOC-117-pin-anchor-precedence.md)，**本条不复述那份清单**。

## 依赖

`DOC-117`（锚点要先修对，否则核的还是错的那一节）。

## 验收标准

- [x] 那批节与引它们的每一处「上游约束」配成对，配对方式可复跑。
- [x] 每一对都有结论，而**结论的依据写得出来** —— 不用「看过了」充当依据。
- [x] 判不了的那部分明说判不了，并换一个判得准的问法。
- [x] 真查出不一致的就修，修完重录指纹。
- [x] `python tools/check_docs.py` 0 FAIL。

## 实现笔记

### 设计决策

- **模糊点**：67 对引用，逐对眼读既不可靠也说不出依据。
- **第一次尝试（失败，留着当教训）**：写了个脚本把引用方那句「正典说了什么」按顿号切片，逐片查它在被引那一节里有没有逐字出处。**结果 67 对里有 63 对被标红、145 处片段「找不到」** —— 因为「上游约束」按定义是**转述**（模板要求它说明约束了本页的哪一部分，不是抄原文）。**逐字比对判不了这件事**，这正是项目那条判据：按词核对落不成守卫，机器搜得出一个词在几处、判不出那几处说的是不是同一件事。
- **换的问法（可判）**：**那一节的正文，在引用方写下那句话之后改过没有？** 没改过就不可能漂。用 git 比两份文件最后一次改动的提交时间：正典那份不晚于引用方 → 引用方的作者看到的就是现在这段文字。
- **粒度写明**：比的是**文件级**（整份正典），所以「要人读」那一侧是**上界**而不是确证 —— 正典因为别的节被改动也会落进来。这个方向是安全的：它只会多报，不会漏报。

### 偏离

**无。**

### 权衡

考虑过把这套「时间窗」判定落成 `tools/` 下的常驻守卫。**没选**：它判的是「有没有可能漂」而不是「有没有真漂」，常驻之后每次改正典都会报一批要人读的对，而其中绝大多数是文件级粒度带来的假阳性 —— 那正是「误报多的门禁会被绕过」。这一轮它是一次性的窄化工具，用完即删。

### 待确认

**无。**

**顺带修掉一处**：[`伤害系统`](../../design/伤害系统.md)引的节名是「战斗中的位置」，而那一节的真标题是「战斗中的位置：教练，而非输出核心」—— 靠子串匹配才通过，于是**同一节有两个指纹键**。改成全名之后守卫自己报出「那个键已经没人引了」，重录把它去掉。**这是这一轮唯一真查出来的不一致**，而它不是内容漂移，是引用写得不全。
