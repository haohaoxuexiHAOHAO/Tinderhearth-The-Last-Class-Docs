# GP-180：一间屋：格子、墙与站位

## 目标

一场仗的地方是一张格子图：哪几格是墙、谁站在哪、是哪一边的，载入时核对，摆错了点名是哪一格。

## 来源

- PRD：[`spec/prd-first-grid-battle.md`](../prd-first-grid-battle.md) 的 `US-003` 规则那一半。场景里怎么摆、灰盒由谁搭在 `UI-70`。

## 依赖

## 验收标准

- [ ] 可测试：一间屋读得出哪几格是墙，以及每个站位的格子、角色定义与阵营。
- [ ] 可测试：站位落在墙上、两个站位同一格、站位指的角色定义不在册，载入被拒并点名哪一格。
- [ ] 可测试：我方没有烬或没有学生、敌方一个人都没有，载入被拒。
- [ ] 可核对：代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。
