# GP-170：拿起、放下、合堆、丢弃按块走，压到别的东西就不动

## 目标

在背包里点一堆拿起、点一个地方放下：放得下就挪过去，指到同标识的堆上就合进去，压到别的东西或出了网格就什么都不变；丢弃照旧丢整堆、先问一声。

## 来源

- PRD：[`spec/prd-grid-bag.md`](../prd-grid-bag.md) 的 `US-004`。

## 依赖

- `GP-168`：网格与随身栏那一排之间也照同一套挪，大的进不了随身栏。

## 验收标准

- [ ] 可测试：点到一堆占地里的任何一格都是拿起那一堆；放下时，拿起时点的那一格对准现在指的那一格。
- [ ] 可测试：要放的那一块全空着（拿起的那一堆自己原来占的格算空），就挪过去，件数、品质、序号都不变。
- [ ] 可测试：指到一堆同种同品质的东西上时，合进那一堆，到堆上限为止；剩下的留在原处。
- [ ] 可测试：要放的那一块压到别的东西、或者有一格出了网格，就放不下，什么都不变；被压的那一堆也不动，不做互换。
- [ ] 可测试：网格与随身栏之间照同一套挪：占 1 格的两边都能放，大的进不了随身栏。
- [ ] 可测试：丢弃照旧丢整堆、先弹一道确认，取消时一件不变；声明了不可丢弃的被拒并说清。
- [ ] 可核对：代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。
