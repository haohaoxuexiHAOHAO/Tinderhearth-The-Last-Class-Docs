# GP-170：拿起、放下、合堆、丢弃按块走，压到别的东西就不动

## 目标

在背包里点一堆拿起、点一个地方放下：放得下就挪过去，指到同标识的堆上就合进去，压到别的东西或出了网格就什么都不变；丢弃照旧丢整堆、先问一声。

## 来源

- PRD：[`spec/prd-grid-bag.md`](../prd-grid-bag.md) 的 `US-004`。

## 依赖

- `GP-168`：网格与随身栏那一排之间也照同一套挪，大的进不了随身栏。

## 验收标准

- [x] 可测试：点到一堆占地里的任何一格都是拿起那一堆；放下时，拿起时点的那一格对准现在指的那一格。规则在代码仓 `rules/Economy/Bag.cs`（`AnchorOf`、`Move`），用例在 `tests/Economy/BagTests.cs`：从盾的右下那一格拿起、指着 (2, 2) 放下，盾的左上角落在 (1, 1)。
- [x] 可测试：要放的那一块全空着（拿起的那一堆自己原来占的格算空），就挪过去，件数、品质、序号都不变。上面那一条的盾挪过去时盖着自己原来的一格，挪完那一堆与挪之前逐项相等。
- [x] 可测试：指到一堆同种同品质的东西上时，合进那一堆，到堆上限为止；剩下的留在原处。那一堆满了就什么都不动。用例在 `tests/Economy/BagArrangementTests.cs`，随身栏那一排与网格之间合堆也有一条。
- [x] 可测试：要放的那一块压到别的东西、或者有一格出了网格，就放不下，什么都不变；被压的那一堆也不动，不做互换。往右、往下、往左上出了网格与压着石头各一下，石头指到盾上也是放不下。
- [x] 可测试：网格与随身栏之间照同一套挪：占 1 格的两边都能放，大的进不了随身栏。从盾占地里的哪一格拿起，指到随身栏都说「太大」；随身栏里的石头指到盾上放不下，不互换。
- [x] 可测试：丢弃照旧丢整堆、先弹一道确认，取消时一件不变；声明了不可丢弃的被拒并说清。点到大东西占地里的任何一格都是丢那一整堆，它那一块全空出来（`tests/Economy/BagTests.cs`）；不可丢弃的被拒与那一问的字照旧由原来那几条用例管着，那一问只在点了确认之后才丢，页上的接法没改（代码仓 `src/UI/BagPageView.cs`）。
- [x] 可核对：代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。

## 实现笔记

### 设计决策

- **先找占着那一格的是哪一堆**：`AnchorOf` 给出盖着一格的那一堆记在哪（网格里是它左上角那一格），拿起、丢弃与筛选都先经它，所以点到一堆占地里的任何一格都是那一堆，被筛掉的那一堆盖着的格也一起点不到。
- **先看指着的那一格，再看那一块**：指着的那一格是另一堆同标识的，就合堆，不管那一块摆不摆得下；不然才照拿起时点的那一格对准它，算出那一块落在哪、核它全空着且整个在网格里。指到自己身上不算合堆，就是挪到原处或挪开几格。
- **合堆不改先后的意思**：被合进去的那一堆记两堆里较近的那个序号，与一键整理并堆同一个口径；挪过去的那一堆什么都不改。
- **放不下时手里照旧拿着**：背包页上点到放不下的地方，背包不动，选中框也不收，可以再点别处；点回原来那一格是放回去。占不止一格的东西指到随身栏，屏上那一行字照旧说「太大」，手里也照旧拿着。
- **空格拿不起来是调用方的错**：拿起的那一处空着当场抛，界面上空格本来就拿不起来。

### 偏离

无。

### 权衡

- **没选放不下时把手里那一堆放回去**：那样每点错一次都要回去重新拿；Stoneshard 一类的网格背包放不下时东西也还在手上。
- **背包页这一版还是一格一个按钮**：大东西画在它那一块上、指着时画出要占的那一块归 `UI-67`。现有的物品全占 1 格，这一版的页上碰不到盖着别的格的大东西。
