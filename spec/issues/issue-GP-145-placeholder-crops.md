# GP-145：素材表上每一种作物都有一份占位数据，启动时就解析

## 目标

素材表上每一行都是一种种得下去的作物：各有一份作物定义、一个名字与一段描述，游戏一启动就逐份解析，坏一份当场报错。

## 来源

- PRD：[`spec/prd-crop-sheet.md`](../prd-crop-sheet.md) 的 `US-006`（`FR-12`）。
- 素材表每一列是什么在那份需求的「概述」里，本条不复述。

## 依赖

无。数据是占位：正式的作物清单归 `GP-88`，阶段天数这类数值归 `GP-7`。

## 验收标准

- [ ] 可核对：代码仓 `data/crops/` 下素材表每一行一份作物定义，标识按行号补零取，排序与行序一致；试验用的那一份删掉。
- [ ] 可核对：每份都是三个计时阶段各 1 天、只收一次、四季都能种，文件里写明这是占位值、归 `GP-88` 与 `GP-7`。
- [ ] 可核对：文本表每种作物一个名字、一个描述，占位写成「作物N」「作物描述N」；正式文案只改这一处。
- [ ] 可核对：游戏启动时逐份解析作物定义并打出在册数；有一份解析失败，代码仓 `python tools/verify.py` 的跑产物那一步判失败。
