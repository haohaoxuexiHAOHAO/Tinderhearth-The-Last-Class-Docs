# UI-34：随身栏那条六格

## 目标

玩家不打开任何界面就看得到随身的那几样东西，并且换得动手上那一样。

## 来源

- PRD：[`spec/prd-carry-slots.md`](../prd-carry-slots.md) 的 `US-001`、`US-002`、`US-006`
- 上游：[那份键位提案](../../design/proposals/键鼠技能位挪到右手.md)里「数字键那一排空出来，刻意不补」
  那一节 —— 它为本条留了键位，原话是留给「将来真要一条快捷道具栏」

## 依赖

`UI-14`（键鼠战斗键位重排）。**六个技能位现在仍然绑在数字键上**，不挪走就与本条抢同六个键。

## 验收标准

- [ ] 六格显示在常驻那一层，每格能显示一个图标与一个数量；数量为 1 时不显示数字
- [ ] **不新增 HUD 块** —— `rules/Ui/HudLayout.cs` 里 `HudBlock` 的取值个数不变
- [ ] 那一块的宽度与六个技能位那一块**相等**，且宽度按同一个数算出来（不是两处各写一个常量）
- [ ] `HudLayout.BlocksOverActorBand` 在 640×360 与拉宽的窗口下都返回空
- [ ] 按 `1`–`6` 分别选中第 1–6 格，选中序号与按的键一一对应
- [ ] **空格子也选得中** —— 那等于「手上没东西」，不是拒绝换格
- [ ] 选中的那一格与其余五格当场分得出来
- [ ] 手柄上十字键左右能移动选中位，且六格都到得了
- [ ] 手柄那套切换不与两个扳机冲突（扳机现在切两组技能位）
- [ ] 每个新动作在两个设备族上要么有绑定、要么有一条带理由的豁免登记（这条已有测试盯着）
- [ ] 输入一律经 `src/UI/InputRouter.cs` 那个门面，没有直接轮询引擎输入
- [ ] 存档为本条新增的字段**恰好一个**（当前选中第几格）
- [ ] 代码仓 `python tools/verify.py` 五步全绿
- [ ] **作者实机确认**：格子边框、选中框、数量角标在 16px 图标上分不分得清
- [ ] **作者实机确认**：左手按住移动键时右手够不够得到那六个键
- [ ] **作者实机确认**：手柄上切到最远那一格要按几下，烦不烦
