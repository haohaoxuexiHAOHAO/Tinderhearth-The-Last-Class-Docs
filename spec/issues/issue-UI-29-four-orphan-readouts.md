# UI-29：四个被声明的读口各有一处界面接住

## 目标

玩家看得到学生今天还吸收得进去多少、这一科考了多少、和某人的关系走到哪、这一片过得怎么样。

## 来源

PRD：`spec/prd-richness-and-feel.md` 的 `US-006`。

立项理由：这四个读口被各自的系统文档写进了接口表，而[`界面系统`](../../design/界面系统.md)里接住它们的页不存在 —— 系统在、读口在、页不在，**而没有任何东西会报错**。四处各是：

| 读口 | 谁声明了它 |
| --- | --- |
| 知识吸收效率 | [`教育系统`](../../design/教育系统.md)（还把「看一眼是否就知道今天该教谁」列成实机项） |
| 考试成绩明细 | [`教育系统`](../../design/教育系统.md)（简版弹窗列成绩、明细进手环） |
| 关系填充量（爱心） | [`人际系统`](../../design/人际系统.md)（读口表指向角色面板与手环） |
| 境况档位 | [`活跃失衡系统`](../../design/活跃失衡系统.md)（读口表指向手环状态栏与角色面板） |

## 依赖

`GP-108`（考试成绩改成按书数折算）—— 成绩明细那一处要显示折算之后的口径，先改算式再定显示。

## 验收标准

- [x] 四处都有页接住，各按那份文档既有的三样写：**吸收效率、关系（档名加填充量）、他自己那一份境况档**进角色面板总览子页；**每一片那一份境况档**进手环地图页；**考试成绩按科目的明细**进手环那份结算完整明细
- [x] **一页都没新开**（手环标签页条数一个未增，写成了一条结构约束）；缺值显示成最低档或零、不留空白
- [x] 「不装本轮之外的界面」那条边界跟着改口径，写明这几处**是例外而不是把那条放宽** —— 它们的读口早就在接口表里，缺的只是页，而「系统在、读口在、页不在」不报错
- [x] 关系那一处只给档名与填充量、取不到精确值；另写明**填充量不许藏**（它是那套系统唯一的正反馈出口），以及它为什么紧挨着战斗评级那一行（配合档读的正是关系档位）
- [x] 境况那一处只给档位、且**就近读**：角色面板那一份是他自己的、地图页那一份是每一片的，**显示的不是全城总量**（显示总量会让「帮谁」失去对象）
- [x] 持有它们那三份文档的读口行跟着修（见下面「偏离」）：[`活跃失衡系统`](../../design/活跃失衡系统.md)原先把落点写成「手环状态栏」，[`人际系统`](../../design/人际系统.md)原先写「角色面板与手环」而手环那一半没有页，[`教育系统`](../../design/教育系统.md)的挂载点表原先没有这两个读数那一行
- [x] 验收项进[`界面系统`](../../design/界面系统.md)：读口表那三行各指得到一页、标签页条数未增、关系取不到精确值、境况不上 HUD、没有书的科目不显示成零、吸收效率是连续读数而不是是非

## 实现笔记

> 由 `/note-it` 在实现和评审之后填写。

### 设计决策

- **模糊点**：「境况档位」该挂哪一页。它有两层（他自己那一份、每一片那一份），而立项时当成一个读口。
- **选择**：**拆开挂**。角色面板总览子页显示**他自己那一份**，手环地图页显示**每一片那一份**。
- **理由**：两层答的是两个问题。他自己那一份是「他现在处境怎么样」，而它顺带答掉 `GP-102` 留下的那条「他为什么不闪避」；每一片那一份是「这一片过得怎么样」，而**组的划分与城区图对齐**（[`活跃失衡系统`](../../design/活跃失衡系统.md)原句），所以地图上本来就有「哪一片」这个坐标 —— 档位只是给每一片多一格，不构成第二个问题。**合在一页会撞上那条「就近读」** —— 一页上只放一个档位，玩家读到的必然是全城总量，而那正好把「帮谁」的对象取消掉。
- **另一处**：关系那一处**紧挨着战斗评级那一行**，因为配合档读的正是关系档位 —— 玩家看到档名之后紧接着问的是「还差多少到下一档」，而填充量正是那个答案。

### 偏离

- **方案怎么说**：「四个读口各在[`界面系统`](../../design/界面系统.md)里有一页或一项接住。」读起来像是只动界面那一份。
- **实际怎么做**：另外修了**持有它们那三份文档的读口行**。[`活跃失衡系统`](../../design/活跃失衡系统.md)原先把落点写成「**手环状态栏**」；[`人际系统`](../../design/人际系统.md)原先写「角色面板与手环」而手环那一半没有页可挂；[`教育系统`](../../design/教育系统.md)的挂载点表里原先根本没有这两个读数那一行。
- **为什么**：[`界面系统`](../../design/界面系统.md)立着一条「**本页一条读口都不新建**」，所以落点写错或没写时，改的必须是持有方那一行 —— 那一份自己记着这条撞过一次（派工那一页要的「今天谁在哪个工位」原先读不到，落点最后定在生产侧）。**「手环状态栏」那一处不是笔误，它把落点定到了抬头显示那一层**，而抬头显示的判据是「玩家在动作进行中需不需要它」—— 境况档按天、按事件变，不在一次挥刀之间变。所以那一行改成容器粒度（角色面板、手环），页由界面那一份定，并写明**不上 HUD**。
- **第二处**：验收原话是「四处」，而实际是**四个读口落在三页上**（境况那一个占两页，教育那两个分在两页）。勾选框按读口数写，页数不等于读口数。

### 权衡

吸收效率也可以挂**派工页**（那一页本来就把学生列在一起，「看一眼就知道今天该教谁」当场成立）。否决理由：**课堂授课不占派工位**（[`教育系统`](../../design/教育系统.md)明写成本全在主角侧），把这个读数摆进一张按格位安排人的页里，玩家会以为「教学」是派工的一种 —— 而那条「成本全在主角侧」正是课堂能成为真选项的原因。**代价写明了**：本轮这个读数只在角色面板上逐个查，那条「看一眼就知道教谁」的实机项要等一张把学生列在一起的页（名册与编队，仍在那条「不装本轮之外的界面」里）才判得到。
