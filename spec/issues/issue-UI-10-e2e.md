- [ ] 覆盖失败路径：窗口尺寸小于逻辑分辨率
- [ ] 覆盖失败路径：队友数为 0
- [ ] 覆盖失败路径：目标进度为 0 与已完成
- [ ] 测试独立可重复，自己准备与清理场景数据
- [ ] 代码仓 `python tools/verify.py` 全绿（构建、测试、导出、跑产物四步）
- [ ] 测试条数与从测试源码静态数出来的条数一致（[踩坑记录 29](../../reference/踩坑记录.md)）
