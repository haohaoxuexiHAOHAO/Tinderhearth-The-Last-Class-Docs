# DOC-56：这一批的新量登记与规模基准复看

## 目标

让这一批新出现的量都有登记、校准办法与归属；而**本批到底有没有新量**这件事也要写成结论加理由，免得它被当成漏登记。

## 来源

- PRD：[`prd-progression-and-endgame.md`](../prd-progression-and-endgame.md) 的 `US-007`
- 起因：[`数值模型` · 尚未给值的量，各自写明校准办法](../../design/数值模型.md)是值的唯一来源，而[内容规模基准](../../canon/gameplay/玩法定位.md)是全部平衡判据的算账基准 —— 新系统落地时这两处不复看，判据的前提就会静默失效。

## 依赖

`NR-11`（要登记的量出自那一份）。

## 验收标准

- [x] **逐样判一遍并写明结论**：主线节点数、标记数、参与者名单规模、结局阈值、关系最高档，各自是**接口常量**、**内容**、还是**已经登记在别处的量**。
- [x] **结局阈值不新开一行** —— 它已经登记在[`数值模型`](../../design/数值模型.md)里活跃失衡那一行，连同那条刹车约束；本条只确认它够用，不动那一行的措辞。
- [x] 真有新量就进那张尚未给值表，并写明**校准办法与归属**，同一处写明**给值那一轮必须同时把判据接上**；一个都没有就把「零个」写成**结论加理由**（理由不许抄前几批那几次）。
- [x] [内容规模基准](../../canon/gameplay/玩法定位.md)**逐样重判**要不要补行，**理由不许抄前几批任何一次的结论**；判断过程写进本条，不写进那张表。
- [x] **不复述主线节点数**（接口常量，家在[主线故事](../../canon/narrative/主线故事.md)）；补行时按「写描述加节名链接」而不是抄类别名。
- [x] 动了[`数值模型`](../../design/数值模型.md)或[内容规模基准](../../canon/gameplay/玩法定位.md)就跑 `python tools/simulate_week.py` 与 `python tools/simulate_week.py --check-doc`，**两个方向都记下脚本自报的覆盖量**；没动就写「不适用」并说明为什么。
- [x] 报「判据前提仍成立」时**写明它是人看的** —— 那张表的表头已经写清推演一处都不读它。

## 实现笔记

### 设计决策

**逐样判，本批给参数表加的量是零个：**

| 样 | 判成什么 |
| --- | --- |
| 主线节点数 | **接口常量**，家在[主线故事](../../canon/narrative/主线故事.md) |
| 标记 | **内容**（`ENG-5`）。它还不是一个「量」—— 见下面那条理由 |
| 参与者名单规模 | **内容**；而它的量级正典已经写了（[主线故事 · 四条贯穿线索](../../canon/narrative/主线故事.md)写明那条链贯穿哪几个节点、每个节点挂几条可选支线）|
| 结局阈值 | **已经登记在别处** —— [`数值模型`](../../design/数值模型.md)活跃失衡那一行，连同那条刹车约束。**不新开行** |
| 关系最高档 | **接口常量**，家在[角色与成长](../../canon/gameplay/角色与成长.md) |

- **理由（零个量这件事）**：本页持有的全是「有没有发生过」这一位，**而位没有量纲** —— 没有边界、没有幅度、没有时长可校准。这条理由与前几批那几次「零个量」各不相同：上一批那三份分别是「每一步的量各归各处」「它没有状态」「没有队列所以没有上限」。

**[内容规模基准](../../canon/gameplay/玩法定位.md)逐样重判，结论是不补行：**

| 样 | 判成什么 |
| --- | --- |
| 主线节点 | **不补。** 这张表记的是「起步做多少条才试得出设计成立」，而节点数不是一个可以「起步少做几个」的量 —— 那些节点是故事本身，做一半就没有故事了；补一行就是给正典那个数开第二个家 |
| 标记 | **不补。** 它根本不是这张表的记账对象：一位标记没有内容（没有文本、没有参数、没有变体），只是一个名字，跟着那件事的持有者出现，**不用写** |
| 可选支线与参与者 | **不补。** 那个量正典已经写了（每个节点挂几条），补一行就是同一个数两个家 —— 而这张表最怕的正是那个 |
| 公共建设项 | **不补。** 穹盾那几项在[世界观 · 穹盾](../../canon/world/世界观.md)有自己的表；一般公共建设项的内容类型还没有家，本批不给它立 |

### 偏离

- **方案怎么说**：`US-007` 写「真有新量就进那张尚未给值表」。
- **实际怎么做**：那张表**一行未改**，零个量写成结论加理由落在[`主线推进系统`](../../design/主线推进系统.md)的「下游同步」里。
- **为什么**：登记一条「本批没有量」等于在那张表里放一行永远不会被给值的东西。**结论加理由的家是那一份自己**，照上一批三份的形状走。

### 权衡

**「给参与者名单补一行起步量」考虑过** —— 它是本批唯一真的带内容的新东西，而「多出一批参与者」确实要几个组织标识才看得出来。没选：正典那句已经给了量（每个节点挂几条可选支线），而这张表补一行就会出现两个可以各自被改的数。

### 待确认

无。**但有一条要写明是人看的**：那张表的表头写清推演一处都不读它，所以「判据的前提还成不成立」这一轮是**人工复核**，不是脚本报的。本轮复核的结论是本批不动那张表的任何数，因此全部平衡判据的前提原样成立。
