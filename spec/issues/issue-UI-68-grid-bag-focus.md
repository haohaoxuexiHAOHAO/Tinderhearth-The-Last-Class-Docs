# UI-68：键盘与手柄的方向键在网格里走得通

## 目标

键盘与手柄的方向键在背包页的网格里走得到每一堆、每一格空地，走不到被筛掉的那些；大小不一的几块挨着时，按一下走到的是那个方向上挨着的那一块。

## 来源

- PRD：[`spec/prd-grid-bag.md`](../prd-grid-bag.md) 的 `US-006` 里方向键那一条。

## 依赖

- `UI-67`：网格那一页本体。

## 还没验证的

现在的背包页靠 Godot 自带的焦点按位置找下一个控件（代码仓 `src/UI/BagPageView.cs`）。块大小不一时它会不会跳着走，要做出来用方向键走一遍才知道。走不顺就改用按格走的光标：代码仓 `rules/UI/PanelNavigation.cs` 里有一个 `GridCursor`，现在没有人用。
