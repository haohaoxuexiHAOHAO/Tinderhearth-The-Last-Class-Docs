# UI-68：键盘与手柄的方向键在网格里走得通

## 目标

键盘与手柄的方向键在背包页的网格里走得到每一堆、每一格空地，走不到被筛掉的那些；大小不一的几块挨着时，按一下走到的是那个方向上挨着的那一块。

## 实现笔记

### 设计决策

- **格子之间怎么走算在规则层**（代码仓 `rules/Economy/BagPageFocus.cs`）：背包页在焦点停着的那一格收下方向键，照它算出来的那一格挪（`src/UI/BagPageView.cs`）；那一边网格里没有了，才交给引擎去找网格外面的那一个（右边那一列、上面的子页签）。
- **按一下，指着的东西换一样**：一堆占几格都只停一下，走进一块落在对着原来那一行（列）的那一格；拿起来的那一堆例外，它那一块里一格一格走，因为放下时拿起的那一格对准指着的那一格，挪一格就得指得到那一格。
- **被筛掉的跳过去，不斜着拐**：先找同一行（列）上的；这一行上没有了，才去那一边最近的那一样。「最近」照 Android 找焦点那一处（`FocusFinder`）的加权：顺着方向差的那一段先平方再乘 13，按的是右，走到的就主要是右边。
- **摇杆只认推过去的那一下**：输入门面多了一个 `IsJustPressedBy`，与引擎挪焦点同一个判法；推着不放、同一帧里来好几下，都只走一格。键盘按住不放的连发照旧算。

### 偏离

- **没用 `GridCursor`**（代码仓 `rules/UI/PanelNavigation.cs`）：它一格一格走、停在格子上，是建造那一页摆位置用的；背包页要一堆只停一下，还要走得到网格外面那一列按钮，鼠标指着与焦点停着又共用每一格那个按钮。
- **走出网格那一下仍用引擎的找法**：从现在这一样朝那一边的边上、对着玩家这一行（列）的那一格往外找（代码仓 `rules/Economy/BagPageFocus.cs` 的 `EdgeToward`），挨着这一行（列）的才排得上；大东西从中间那一格往外找，先碰上的是同一块里的另一格。找到的若还是网格里的一格（只有一半在那一边的那一块），就改从整张网格找。
