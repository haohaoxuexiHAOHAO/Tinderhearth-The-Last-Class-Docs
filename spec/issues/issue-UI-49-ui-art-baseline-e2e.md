# UI-49：界面素材那份需求的端到端

## 目标

这一份需求的主路径与失败路径都有测试走一遍，作者照一份清单在主场景里看完全部改动。

## 来源

- PRD：[`spec/prd-ui-art-baseline.md`](../prd-ui-art-baseline.md) 的 `US-008`。

## 依赖

- `UI-42`、`UI-43`、`UI-46`、`UI-47`、`UI-48`：它们各自的测试是这一条要串起来的东西；`UI-41`、`UI-44`、`UI-45` 经它们间接在内。

## 验收标准

- [ ] 自动化测试走完主路径：两档尺寸由既有单位推出 → 两种场合的 HUD 各自放置 → 关卡那一套不进纵深带 → 界面色全部对得上色板 → 世界那一层的偏移由目标报的高度算出。
- [ ] 覆盖失败路径：关卡任一块挪进纵深带被判出；色板里被引用的一档改了值被判出；目标没报高度被判出；素材资源缺项时一次列全。
- [ ] 测试独立可重复：规则层测试自己准备数据，读色板的那条只读不写。
- [ ] 代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。两个都看脚本自己打的摘要，不只看退出码。
- [ ] **作者实机确认清单**：打开主场景 → 检查器里选关卡场合，看 HUD 全在顶上、窗口拉宽不错位 → 选基地场合，看随身栏与精力那一块 → 打开手环看外壳与页签 → 删掉素材资源里一格重跑，看报错是不是一次说全 → 把一张图换掉重跑，看画面跟着变。
