# UI-46：格子角上的件数与按键提示、倒地记号、当前操作格、鼠标指针换成画的

## 目标

画面上那几处用文字或染色凑的记号，换成作者画的图，而且在 12 像素字塞不下的地方也读得出来。

## 来源

- PRD：[`spec/prd-ui-art-baseline.md`](../prd-ui-art-baseline.md) 的 `US-007` 里那几格（`FR-16` 到 `FR-20`）。
- 格子那一圈怎么分、迷你字有哪些字形、指针的热点在哪，都在[界面绘制约定](../../production/界面绘制约定.md)，本条不复述。

## 依赖

- `UI-44`：这几样图从素材资源取。

## 验收标准

- [ ] 可核对：随身栏的件数用迷你字。迷你字走 Godot 的图片字体导入（[ResourceImporterImageFont](https://docs.godotengine.org/en/stable/classes/class_resourceimporterimagefont.html)），字距调到两个字的描边并成一条。
- [ ] 可核对：HUD 格子上的键盘提示是迷你字的键名，按约定放在格子左上角，件数在右下角。手柄提示（面键小图标）跟手柄适配一起后置到 `UI-54`，那一半不在本条的验收里。
- [ ] 可核对：倒地队友是盖在头像上的一张记号图，不再给头像框染色；代码仓 `rules/UI/HudPalette.cs` 里那个倒地头像色随之删掉。
- [ ] 可核对：当前操作格「够得到」与「够不到」是两张形状不同的图，不只换色；台账 `UI-27` 那一行「填那两个颜色」跟着改。
- [ ] 可核对：自定义鼠标指针按当前整数倍最近邻放大，窗口尺寸变了跟着换；热点照 `python tools/ui_art.py --list` 那一行，不在代码里另写一份。
- [ ] **作者实机确认**：格子角上的件数与键名读不读得清；1080p 下指针是不是 3 倍大。

### 待确认

- **图片字体没实测过**：验法是导一张 0–9 的图，看「20」显示得对不对、两个字之间的描边是不是一条。
- **鼠标指针在 4.7.2 上没实测过**：`Input.SetCustomMouseCursor` 按系统分辨率画，要在窗口变化时按整数倍放大原图（[Godot 论坛，Godot 4.6](https://forum.godotengine.org/t/is-there-a-good-way-to-change-the-cursor-image/140173)）。验法是上面那一格实机确认。
