# UI-64：即时提示：被拒时屏上一行字

## 目标

一个动作被拒时屏上马上出现一行字说清为什么，后一条顶掉前一条；它不接管输入，世界不停。

## 来源

- PRD：[`spec/prd-items-in-bag.md`](../prd-items-in-bag.md) 的 `US-010`。

## 依赖

无。

## 实现笔记

### 设计决策

- **它是一层，不在常驻那一层里。** 代码仓 `rules/UI/UILayer.cs` 在弹窗与幕布之间多一层：面板开着时被拒的那一下（背包页里丢不掉那一样，`UI-66`）也要看得见，而常驻那一层在面板开着时整层藏起来。它不接管输入，却在世界暂停时照走：跟着停的话，面板里被拒的那一行就一直挂着、收不起来。
- **出、顶、收判在规则层**（代码仓 `rules/UI/InstantNotice.cs`）：只有「现在那一行」，没有队列可读；新的一条与同一句再出一次都从头算停留。
- **写哪一句由被拒的那一方挑**，键在代码仓 `rules/Economy/FarmNotices.cs`，字在文本表里；输出面板打的也是同一句，不另写一套原因。「这一格不许播」在游戏里到不了（动作按格子状态派发），规则层答得出它，也给了一句。
- **收起时藏整一块，不只藏那一行**，所以作者给那一行垫底框时框也跟着收。那一块必须直接摆在界面根下面，否则它不会被挪到自己那一层、画在世界里还不报错 —— 子节点先于父节点就绪，所以就绪那一刻还看得出它摆在哪。
- **呈现形状写进[`界面系统`](../../design/界面系统.md)**，在「即时提示那一行：被拒那一下当场说清，一条，不排队」一节：它不是第二条通知渠道、和升档提示不是一条通道。

### 偏离

- **与升档提示那一行分开，理由不是丢弃语义。** 两条都是新的一条盖掉旧的；分开是因为量的不是同一件事（升档那一条要对上一次交锋，这一行要对上读完一句与玩家下一个动作之间那一下），也不在同一层。[数值模型](../../design/数值模型.md)那一行写的是这条理由。

### 权衡

- **农场现在少了它就起不来。** 照[一块地能种出东西](../../reference/godot/一块地能种出东西.md)搭到第六步的场景要多摆这一块，那一步已经写上；被拒的那一下只在输出面板里打一行，玩家看不见，比起来多摆一块划算。

无。
