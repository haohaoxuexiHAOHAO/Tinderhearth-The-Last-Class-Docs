# ART-34：草与裸土、浅水与深水两套照同一个画法重画

## 目标

草地、土地与水放在一起像一个人画的：草挨着裸土的边是一簇簇探出去的小草，草的影只落在草南边的土上；深水北边是落下去的那一面。我照参考包的画法出草稿，作者审过、精修。

## 来源

- PRD：[`spec/prd-shore-stone-wall.md`](../prd-shore-stone-wall.md) 的 `US-006`。

## 依赖

- `ENG-36`：两套都按方向声明，草的影才能只画在一个方向上。
- 与 `ART-33` 同一批草稿，三套一起审。

- [ ] 作者实机确认：深水北边看得出是落下去的那一面，别的方向只有一道窄边。

## 实现笔记

### 设计决策

- **草稿与 `ART-33` 的放在一起**：工作区根 `art-source/self-material/tiles-draft/` 下的 `grass-dirt.png`、`shallow-deep.png`，各自的外圈模板与放大 8 倍的预览，三套合拼的一屏在 `mockup-x2.png`。
- **每个方向格边上的像素**（从界线往外数），也就是交图时要写进声明的那几串：

  | 一套 | 方向 | A 那一侧 | B 那一侧 |
  | --- | --- | --- | --- |
  | 草（A）与裸土（B） | `A在上`（草在上、土在下） | `moss 2` | `soil 3` |
  | 草与裸土 | `A在下` | `moss 4` | 无 |
  | 草与裸土 | `A在左`、`A在右` | `moss 2` | 无 |
  | 浅水（A）与深水（B） | `A在上`（浅水在上、深水在下） | `water 5` | `water 3`、`water 3` |
  | 浅水与深水 | `A在下`、`A在左`、`A在右` | 无 | `water 3` |

  草比土高：草边一圈暗一档（`moss 2`），朝北那一边是受光的草尖（`moss 4`）；土上那一行影（`soil 3`）只在草的南边。深水北边是从浅水落下去的那一面，两行 `water 3`，上沿那一行浅水亮一档（`water 5`）；别的方向深水边上一行。
- **图块中间**：草边每隔几个像素一簇小草探进土里，有的两格长、有的分叉；土上贴着草边零星几颗小石子。深浅水的界线有一两个像素的起伏。都只画在离格边至少两个像素的中间。
- **拐角的形状**与 `ART-33` 同一个办法：占一个角就是以那个角为圆心、半径半格的四分之一圆，圆弧落在格边正中。

### 偏离

无。

### 权衡

- **深水北边那一面用两行同一档**：分成 `water 3` 一行再加一行更深的也可以，但更深的那一档就是深水的主色，会被深水的纹理换掉。

### 待确认

- 作者审草稿：草簇的密度与大小、影的深浅、深水那一面看不看得出来。格边那一圈要改，先告诉我新的那几串，我改声明、重出模板。
