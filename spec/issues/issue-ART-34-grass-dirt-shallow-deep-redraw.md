# ART-34：草与裸土、浅水与深水两套照同一个画法重画

## 目标

草地、土地与水放在一起像一个人画的：草挨着裸土的边是一簇簇探出去的小草，草的影只落在草南边的土上；深水北边看得见水下的坑壁。作者照参考包的形式画，纹理画在图里；我核事实、接进游戏。

## 来源

- PRD：[`spec/prd-shore-stone-wall.md`](../prd-shore-stone-wall.md) 的 `US-006`。

## 依赖

- `ENG-36`：两套都按方向声明，草的影才能只画在一个方向上。
- 与 `ART-33` 一起画在全套地形瓦片集里，三套一起交。
- `ENG-42`：瓦片集交来之后怎么接进游戏，在那一条定；下面验收里讲文件名、四角同色与方向声明的那几格跟着它改。

## 验收标准

- [ ] 可核对：作者交的这两套只用色板色，过得了地形检查；检查判什么跟着 `ENG-42` 定的接法。
- [ ] 作者实机确认：草地挨着裸土的那条边是一簇簇探出去的小草，草的影只落在草南边的土上，北边与东西两边没有影。
- [ ] 作者实机确认：深水北边看得见水下的坑壁，从浅水底落到深水底那一段；别的方向看不见坑壁，只有坑沿一道细线。
- [ ] 作者实机确认：三套放在一起，草边、石壁与深水边看着是一个画法。
- [ ] 可核对：文件名照旧是代码仓 `assets/self-drawn/tiles/grass-dirt.png` 与 `assets/self-drawn/tiles/shallow-deep.png`，四角同色那几张仍是各自地形的主色、整张纯色。
- [ ] 可核对：每一套的新图与它的方向声明放进代码仓同一次提交，`python tools/check_dualgrid.py` 与 `python tools/verify.py` 通过。

## 实现笔记

### 设计决策

- **作者画，我核事实、接进游戏**：这两套与 `ART-33` 一起是全套地形瓦片集的一部分，照参考包的形式画，纹理画在图里（[ADR-0033](../../decisions/ADR-0033-地面纹理直接画进图块.md)）。交来之后我对照游戏要的格子组合与格边规矩，列出缺哪几块、哪条边对不上。

- **拐角画成圆的**：半径半格、圆心在格角的四分之一圆，从同样那两个格边中点进出，所以哪一格照直角画也接得上。
- **草边跟着草走**：草到哪里收都是同一圈草边，草叠在土上时画在草那一套里，浅水叠在草上时画在浅水那一套的草那一侧（[俯视地图用图块表拼 · 一套还是那 16 格、还是那张映射表，下面那一种的地方留透明](../../design/proposals/俯视地图用图块表拼.md)）。样板没标这一圈时，交来的浅水南岸草边画到 moss 3 就断了，所以样板与底稿把这一圈跟交界线一样标了出来。

### 偏离

- **方案怎么说**：我照参考包的画法出草稿，作者审过、精修。
- **实际怎么做**：作者照参考包的形式自己画；拐角改圆、补草边是作者要我直接在他的图上改的，像素取自他画的直边格，他看过之后定稿。
- **为什么**：地形图块归作者画，我只核事实、接进游戏；改圆与补草边是照他画好的直边格挪像素，不画新的笔画。

### 权衡

- 拐角格里原来手点的几颗亮石头与水里的亮点没留下：拐角格照直边格重排，那几点不在直边格里。要的话作者补。

### 待确认

- 瓦片集交来之后，按 `ENG-42` 定的接法改这一条的验收：文件名、四角同色那几张、方向声明与提交那一格。
- 裸土要是换了底色：代码仓 `tools/check_dualgrid.py` 的 `TERRAINS` 跟着改，裸土与耕地并排分不分得开要实机看一眼。

## 验证结果

暂无，等 `ENG-42` 接进游戏。
