# GP-179：打仗要的角色定义与技能定义

## 目标

上场的人与他会的招都是数据：加一个人、加一招只加文件，缺一格载入时当场说清。

## 来源

- PRD：[`spec/prd-first-grid-battle.md`](../prd-first-grid-battle.md) 的 `US-001`、`US-002`。冷却那一格在 `GP-183`。

## 验收标准

- [ ] 可测试：角色定义多出四项属性、行动力起步值、普通攻击、防御与战斗智慧那一档；缺任一格载入被拒，并点名哪一份、哪一格。代码仓 `data/characters/jin.json` 跟着补上。
- [ ] 可测试：面板照[各类公式计算 · 属性换算成面板](../../../desc/各类公式计算.md)从属性算出；每一项的初始值与每点属性给多少从配置读，缺了当场报错，没有能用的默认值。
- [ ] 可测试：技能定义一招一份，写占不占回合、施放距离、冷却、物理还是魔法、技能倍率、穿透、给自己挂哪个状态、兵器种类；缺任一格载入被拒并点名。角色定义指的普通攻击或防御不在册，也被拒。
- [ ] 可核对：普通攻击与防御各一份，冷却 1，都占回合。一名占位学生、两名占位敌人各一份角色定义，名字、属性与换算参数都标明占位；两名敌人的敏捷不一样。
- [ ] 可核对：代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。
