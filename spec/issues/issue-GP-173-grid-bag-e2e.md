# GP-173：网格背包的端到端

## 目标

一次走完「东西进背包、挪、整理、存档、读回」整条路，确认几块拼起来是通的；作者实机照一张清单看一遍。

## 来源

- PRD：[`spec/prd-grid-bag.md`](../prd-grid-bag.md) 的 `US-010`。

## 依赖

- `GP-169`、`GP-172`、`UI-68`：它们各自的读口是这一条要串起来的东西，`GP-166` 到 `GP-171` 与 `UI-67` 都在它们上游。

## 验收标准

- [ ] 自动化测试走完主路径：开新档 → 调试键放一批种子进随身栏 → 放进那件大东西 → 从随身栏播种 → 收获进网格 → 挪动大东西腾出地方 → 一键整理 → 写档 → 读回，每一堆的位置与件数都对。
- [ ] 覆盖失败路径：空格够数但凑不出够大的空地时收获被拒、那一株还在；把大东西放进随身栏被拒；整理摆不下时一格不动；读上一版的存档东西一件不少。
- [ ] 测试自己准备与清理数据，可以重复跑。
- [ ] 作者实机确认清单写进[东西能拿在手上](../../reference/godot/东西能拿在手上.md)那一篇「跑一遍验收」那张表：打开哪个场景、按哪个键、该看到什么。这份需求各条剩下的实机格都串在里面。
- [ ] **作者实机确认**：照那张表走一遍。
- [ ] 可核对：代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。
