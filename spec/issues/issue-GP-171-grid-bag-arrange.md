# GP-171：排序、筛选、一键整理在网格里一件不丢，摆不下就不动

## 目标

排序与一键整理之后东西一件不少；照新的先后摆不下全部时一格不动，屏上说清是摆不下；随身栏那一排与被筛掉的那几堆不挪。

## 来源

- PRD：[`spec/prd-grid-bag.md`](../prd-grid-bag.md) 的 `US-005`。

## 依赖

- `GP-168`：排序与整理不碰随身栏那一排，要先有那一排。

## 验收标准

- [x] 可测试：排序按当前的键把看得见的那些堆排好先后，再一堆一堆用「第一块够大的空地」从左上往右下摆；三个键各排一次，同键排两次结果相同。摆法在代码仓 `rules/Economy/Bag.cs`（`Sort`），用例在 `tests/Economy/BagArrangementTests.cs`：一份网格里有占 2×2 的箱子，按类别排两次是同一个样子。
- [x] 可测试：一键整理先把同标识的散堆并成满堆加至多一个零头，再照排序那样摆；前后总数一件不变。原来那几条用例照旧通过。
- [x] 可测试：照新的先后摆不下全部时，整理与排序都一格不动，屏上说清是摆不下；构造一种「原来的摆法放得下、新摆法放不下」的情形，验它确实没动。3×2 的网格摆满一个箱子与两小堆，按最近获得排时两小堆先占了左上角、箱子没有地方，排序与整理都交回「摆不下」、一格没动；背包页上屏上一行字（文本表里 `ui.bag.no_room_to_arrange`）。
- [x] 可测试：排序与整理不碰随身栏那一排。原来那两条用例照旧通过。
- [x] 可测试：筛选态下被筛掉的那些堆不挪位，排序与整理只在剩下的地方摆看得见的那些；挪与丢也只对看得见的做。被筛掉的箱子照旧盖着它那一块；看得见的在剩下的地方摆不下，同样一格不动。挪与丢在 `GP-170` 那几条用例里。

## 实现笔记

### 设计决策

- **先在一份占地图上摆一遍，全摆下了才换上去**：看得见的那几堆从图上拿开，被筛掉的照旧盖着自己那一块，再照新的先后一堆一堆找第一块够大的空地；有一堆找不到就交回「摆不下」，背包一格没改。
- **排出来的样子只由内容与被筛掉的那几堆定**：先后是原来那一套比较，每一项都比到底，所以同键排两次、整理两次都是同一个样子，不读原来的摆法。
- **摆不下时排序键照样记下**：按了「按最近获得」而摆不下，当前排序键也换成它，一键整理照它排 —— 那个按钮按下去的样子与玩家按的一致。
- **背包页上摆不下时放下手里那一堆、屏上一行字**：与摆好了时一样放下，因为排序与整理之前总是先放下。

### 偏离

无。

### 权衡

- **没选先放大的**：摆得更紧，但打乱排序的先后，理由在[`背包系统` · 分堆的代价由排序、筛选与一键整理来付](../../design/背包系统.md)。
- **没选摆不下时退一步、只摆放得下的那几堆**：那等于替玩家把东西摆丢了一部分，网格又不会因此多出地方。

### 待确认

无。
