# GP-171：排序、筛选、一键整理在网格里一件不丢，摆不下就不动

## 目标

排序与一键整理之后东西一件不少；照新的先后摆不下全部时一格不动，屏上说清是摆不下；随身栏那一排与被筛掉的那几堆不挪。

## 来源

- PRD：[`spec/prd-grid-bag.md`](../prd-grid-bag.md) 的 `US-005`。

## 依赖

- `GP-168`：排序与整理不碰随身栏那一排，要先有那一排。

## 验收标准

- [ ] 可测试：排序按当前的键把看得见的那些堆排好先后，再一堆一堆用「第一块够大的空地」从左上往右下摆；三个键各排一次，同键排两次结果相同。
- [ ] 可测试：一键整理先把同标识的散堆并成满堆加至多一个零头，再照排序那样摆；前后总数一件不变。
- [ ] 可测试：照新的先后摆不下全部时，整理与排序都一格不动，屏上说清是摆不下；构造一种「原来的摆法放得下、新摆法放不下」的情形，验它确实没动。
- [ ] 可测试：排序与整理不碰随身栏那一排。
- [ ] 可测试：筛选态下被筛掉的那些堆不挪位，排序与整理只在剩下的地方摆看得见的那些；挪与丢也只对看得见的做。
- [ ] 可核对：代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。
