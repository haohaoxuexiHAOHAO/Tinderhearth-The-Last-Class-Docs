# NR-26：三批角色的画像与内容逐个复核确认

## 目标

让那三份角色正典里的每一个角色都有一个被作者逐个过目、确认下来的时刻 —— 现在没有。

## 来源

- 设计闭环那一轮带出来的。三份角色正典是[学生群像](../../canon/narrative/学生群像.md)、[反派与要角](../../canon/narrative/反派与要角.md)与[常驻NPC](../../canon/narrative/常驻NPC.md)。
- **它吸收了 `ART-7` 与 `ART-8` 各剩的那条剪影实机确认** —— 复核可能改锚点，先看再改是白看。

## 依赖

不卡任何人（设计闭环那一轮已归档）。

**但复核之前要先读一遍改过的判定基准**，见下面第一条验收。

## 验收标准

- [ ] **先读[人物 · 可读性规则按视角分](../../canon/characters/人物.md)与同一页的剪影防撞审计** —— 那两节的判定基准已被 `ART-14` 改过：审计要**两个视角各做一遍**（俯视轮廓与侧视轮廓不是同一个形状，一个视角里分得开的两个角色可能在另一个视角里撞上），而且**不必为水平翻转让步**（[ADR-0021](../../decisions/ADR-0021-每个朝向各画一套不做水平翻转.md)，所以挂在单侧的大件仍是最有效的杠杆）。按旧基准审一遍是白审
- [ ] 三份各自逐个角色过一遍：身份、性格、弧线、节点 15 的个人选择、视觉锚点
- [ ] 每份里的剪影防撞审计结论逐对实机看过；点名最需要逐帧看的那几对优先（各份自己写明了是哪几对）
- [ ] **要遵守的那条硬约束在学生群像里铁淬那一条旁边**（`NR-19` 立的），本文不复述
- [ ] 复核改动了锚点的角色，连带看一遍它所在那组的防撞结论还成不成立
- [ ] `python tools/check_docs.py` 0 FAIL
