# UI-43：世界那一层的血条与伤害数字挂在目标自己报的头顶上

## 目标

精英的血条浮在他自己头顶上方，不论他是人形还是大体型；世界那一层不再假设剪影多大。

## 来源

- PRD：[`spec/prd-ui-art-baseline.md`](../prd-ui-art-baseline.md) 的 `US-003`。
- `rules/UI/WorldUILayout.cs` 的血条宽取 32「对齐剪影宽度」，血条与伤害数字的纵向偏移都拿 32 的一半当半个身高；而现行侧视本体按体型分档，人与大两档都比 32 高（那张表在[玩法定位 · 像素基准](../../canon/gameplay/玩法定位.md)），大体型的血条会落进身体里。**这一处不在 `ENG-24` 的清单上。**

## 依赖

- 无前置：界面件已交付（`ART-27`），本条只动尺寸与偏移。
- 精英血条换成 HUD 那一套槽、填充与扣减那一截也在本条，从 `UI-45` 交过来，理由在它的偏离里；那一套已在代码仓 `src/UI/GaugeBar.cs`。

## 验收标准

- [ ] 可测试：血条与伤害数字的纵向偏移由目标报的高度算出，`rules/UI/WorldUILayout.cs` 里不再有按 32 推的半个身高。
- [ ] 可测试：血条宽按体型档给，人形一档、大体型一档；血条高与 HUD 资源条同一个数，好让两处共用一套槽与填充。
- [ ] 可核对：精英血条换成资源条那一套槽、填充与扣减那一截（代码仓 `src/UI/GaugeBar.cs`，追与留一截照它走）；世界那一层代码画的两块色，与它们在代码仓 `rules/UI/HudPalette.cs` 里那两个占位色一起删掉。
- [ ] 可测试：目标没报高度或体型档时当场抛，说清是哪个目标缺了哪一项。
- [ ] 可核对：读条圆环仍按现有尺寸挂在身上，它不跟身高走。
- [ ] 可核对：侧视角色现在全是代码搭的，所以这一轮由角色声明报那个高度，主角用现有的实测身高；`GP-14` 条目里加一格「换成作者在场景里放的锚点节点」。
- [ ] **不做实机确认**：世界那一层现在没有任何调用方（按名搜过），出不了画面；实机那一格跟着第一个调用方落地。
