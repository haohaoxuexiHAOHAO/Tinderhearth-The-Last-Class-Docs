# UI-43：世界那一层的血条与伤害数字挂在目标自己报的头顶上

## 目标

精英的血条浮在他自己头顶上方，不论他是人形还是大体型；世界那一层不再假设剪影多大。

## 来源

- PRD：[界面素材那份需求](../../archive/spec/UI-49-ui-art-baseline/prd.md)（**历史背景·非依据**）的 `US-003`。那份需求已归档，本条还开着，所以条目文件留在这里。
- 原先血条宽取 32「对齐剪影宽度」，血条与伤害数字的纵向偏移都拿 32 的一半当半个身高；而侧视本体按体型分档，人与大两档都比 32 高（那张表在[玩法定位 · 像素基准](../../canon/gameplay/玩法定位.md)），大体型的血条会落进身体里。**这一处不在 `ENG-24` 的清单上。**

## 依赖

- 无前置：界面件已交付（`ART-27`），本条只动尺寸与偏移。
- 精英血条换成 HUD 那一套槽、填充与扣减那一截也在本条，从 `UI-45` 交过来，理由在它的偏离里。

## 实现笔记

### 设计决策

- **跟着目标画出来的脚底走，不跟角色本体走。** 侧视角色的精灵挂在纵深可视根下面、按纵深上下挪过，本体留在物理位置上；跟本体走的话，站到纵深带后面时血条会落进身体里。所以目标除了头顶高度与体型档，还报一个「画出来的脚底」节点，读条圆环、血条与伤害数字都跟它走。头顶高度从那个节点往上量。
- **血条宽两档**：小与人形一档，取人形剪影宽的上限；大体型一档，与 HUD 资源条一样长 —— 剪影宽出一截，条也长一档，一样长时一下掉了多少与玩家自己那几根比得出来。小的不另窄一档：再窄，一像素就代表太多血，看不出掉了多少。两档宽都是偶数，横着居中在脚底上不落半格，有测试判。
- **条的底边离头顶空一个组内间距**，整根浮在头顶以上、不压住脸。
- **体型档放在角色这一层**（`rules/Foundation/Actors`），不放进界面：侧视影子也按体型分套，读它的不只界面。它的第一个取值是「没报」，默认值就是它，忘了填的目标挂东西时当场报错，不悄悄当成人形。
- **伤害数字先核目标、再看开关**：伤害数字默认关着，先看开关的话，没报的目标要等玩家打开那一项才露出来。
- **读条圆环只跟脚底节点走、不读头顶高度**，所以它只要求目标报了那个节点。

### 偏离

无。

### 权衡

- 训练房那个几何木桩（代码仓 `src/World/TrainingDummy.cs`）没报这几样：世界那一层没有往它身上挂东西的调用方，要挂的那一天由它自己报。

### 待确认

- **侧视相机现在还按整数倍放大，世界那一层跟着它缩放**（按代码推断：倍数是代码仓 `rules/UI/UIMetrics.cs` 的 `SideViewZoom`，世界那一层开着跟随视口，见 `src/UI/WorldSpaceUI.cs` 的类注释），所以那根条按世界像素与 HUD 同高时，在屏上比 HUD 那根粗出那个倍数。看得准要等 `ENG-24` 把侧视相机改成不缩放；本条没有调用方、出不了画面，所以不挡本条。
