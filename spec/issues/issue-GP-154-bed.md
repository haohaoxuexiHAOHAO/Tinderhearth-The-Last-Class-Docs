# GP-154：床，以及调试键 N 走同一个入口

## 目标

站在床的范围里按交互键就睡；不在范围里照旧作用在当前操作格上；调试键 `N` 走同一个入口，每按一次也写一次档。

## 来源

- PRD：[`spec/prd-sleep-advances-day.md`](../prd-sleep-advances-day.md) 的 `US-006`，`FR-4`、`FR-37`、`FR-38`，`FR-43` 里床那一样。
- 床按交互键：[ADR-0027 · 明确不包含](../../decisions/ADR-0027-进出室内改成点一下门.md)；交互点的摆法与消歧在[交互点与站位点](../../reference/godot/交互点与站位点.md)。

## 依赖

- `GP-153`：睡下去要写档，醒来时世界是写过的那一份。

## 验收标准

- [ ] 可核对：床是作者在农场里摆的一个交互点：一个节点挂床的脚本，下面一个 `Area2D` 当范围，在检查器里接上；缺了当场报错说清缺谁。[假设] 床先摆在农场里、离开那片地，等室内场景（`GP-130`）落地再搬进去。
- [ ] 可测试：站在床的范围里按交互键是睡；不在范围里按，照旧作用在当前操作格上。这一下由规则层挑，不看引擎返回的顺序。
- [ ] 可核对：调试键 `N` 调同一个入口，所以每按一次也写一次档；床与 `N` 之外没有别的推进一天的路。
- [ ] 可核对：代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。
- [ ] **作者实机确认**：站到床边按交互键就睡；走开几步再按，是锄地或浇水而不是睡。串在 `GP-155` 的清单里。
