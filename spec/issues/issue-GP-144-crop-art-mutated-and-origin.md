# GP-144：作物素材多一格变异成熟，地里按那一位换图、按接地那一行排前后

## 目标

每种作物配一张变异成熟图，漏配一张载入就说清是哪一种；地里一眼看得出哪一株变了，人走到作物后面时被它挡住。

## 来源

- PRD：[`spec/prd-crop-sheet.md`](../prd-crop-sheet.md) 的 `US-001`、`US-005`（`FR-1`、`FR-10`、`FR-11`）。
- 一种作物交几张图在[场景绘制约定 · 作物按它声明的阶段数交付](../../production/场景绘制约定.md)，本条不复述。

## 依赖

- `GP-134`：换图读的是那一格的变异标记。素材那一格与精灵原点不等它，先做，作者配素材时就照新的那一格配。

## 验收标准

- [ ] 可核对：作物素材在检查器里多出「变异成熟」一格，排在枯死那一格前面。
- [ ] 可核对：那一格空着时，载入报错写明作物标识与缺的是变异成熟那一张。
- [ ] 可核对：作物精灵的原点落在格子底边中点、图往上画，与角色的脚底原点同一个口径。
- [ ] 可核对：待收且变异的那一格显示变异成熟那张，其余照旧。
- [ ] **作者实机确认**：故意空一种作物的那一格跑一次，报错说得清缺谁。
- [ ] **作者实机确认**：把基础值临时调高，一片地里看得到变与没变两种成熟；人站进一株作物那一格的上半截时被它挡住。
