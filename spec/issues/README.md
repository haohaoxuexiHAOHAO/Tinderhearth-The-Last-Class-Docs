## 状态词

**下面各域表里，每一行备注都以这张表里的一个词开头。** 取值互斥且穷尽，不许自造第六个。

| 状态词 | 它说什么 | 关闭了吗 |
| --- | --- | --- |
| **已完成** | 该做的都做完了，没有剩余动作 | 关闭 |
| **设计已交付** | 文档那一半交了，落地或实机那一半还没做 | 开着 |
| **进行中** | 已经动手，还有写得出来的剩余动作 | 开着 |
| **未开始** | 还没动手 | 开着 |
| **明确后置** | 刻意先不做，没有排期 | 开着 |

**为什么要固定成一张词表**：这一列是「这个编号还开着吗」唯一机器读得出的地方。原先它是备注里一句自由散文，于是活文档里指向已关闭编号的指针没有任何东西查得出来 —— 那正是 `DOC-97` 那一轮要人工搜全库的原因。执行体是 [`DOC-100`](../../archive/spec/DOC-97-canon-reconciliation/issue-DOC-100-closed-id-guard.md) 那条守卫。

**「设计已交付」与「已完成」必须分开。** 文档交付之后落地往往还差一大截，合成一个词会让守卫把一批还开着的编号判成关闭，而那比没有守卫更坏。

**已归档的编号在哪张表，判据写死在这里：**

- **整条完结、没有剩余动作的**，关闭时直接登记进下面「已归档编号」那张表 —— 那张表本身就是状态，所以那里的行不带状态词。
- **落地还在继续的留在域表**，带状态词。过程件进了 `archive/` 不等于这件事做完了，而留在域表才看得见它后续那几个编号。
- **「文件进了 `archive/`」本身不是判据**，「还有没有剩余动作」才是。这两件事原先被当成一件，于是同一批编号出现过两种做法，而说法只承认其中一种。

**域表里现存那批已归档的行不追溯搬迁。** 搬它们要逐行重写、还要给每一行补一个日期，而换来的只是表看起来整齐 —— 两处现在都查得到，而上面那条判据已经把往后的分叉堵住了。
