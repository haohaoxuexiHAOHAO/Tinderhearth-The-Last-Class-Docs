# ENG-41：水边石壁的端到端

## 目标

三套重画的地形从交图到画面走一遍：交图检查过得了作者的图块表，故意改错一个格边像素时说得清错在哪，作者照指南在农场里看完。

## 来源

- PRD：[`spec/prd-shore-stone-wall.md`](../prd-shore-stone-wall.md) 的 `US-005`，作者实机那几格来自 `US-002` 与 `US-006`。

## 依赖

- `ART-33`、`ART-34`：图已经交了，画在作者的图块表里。
- `ENG-46`：交图检查照图块表的排法判，取代原先按方向声明的规范边。
- `ENG-42`：图块表接进游戏的端到端；这一条的作者实机并进那一条的清单。
- `DOC-155`、`DOC-156`、`DOC-157`：规矩那一节，与作者照着走的指南那几行。

## 验收标准

- [ ] 自动化：交图检查对作者的图块表通过（`ENG-46`）。
- [ ] 自动化（一次性，跑完删）：一份故意改错一个格边像素的副本，报出是哪一张、哪一套、哪一格、哪条边（`ENG-46`）。
- [ ] 可核对：代码仓 verify 全过；设计仓 check_docs 0 FAIL。
- [ ] **作者实机确认清单**：并进 [`ENG-42`](./issue-ENG-42-tile-sheet-e2e.md) 的作者实机清单，水边那几行看完，这一格一起勾。

## 实现笔记

### 设计决策

- **故意改错那一格由 `ENG-46` 拿图块表的副本跑**：判的东西变了，从「格边等于那个方向的规范边」变成「同一类格边逐像素一样」，失败路径照新的检查跑一次。
- **作者实机清单搬到 `ENG-42`**：石壁这一份的实机与图块表那一份是同一趟，清单只留一份。

### 偏离

- **方案怎么说**：三套按方向声明规范边，`check_dualgrid.py` 照方向判，新图与声明同一次提交。
- **实际怎么做**：三套画在作者的一张图块表里，交图检查判同一类格边逐像素一样，没有方向声明（[地形与崖改用图块表画](../prd-outdoor-tile-sheet.md)）。
- **为什么**：地形改成按顺序叠，一套只画自己那一种、下面那一种留透明；格边上的像素由作者画，检查只要求同一类格边一样，不用另写一份规范边。理由在[俯视地图用图块表拼](../../design/proposals/俯视地图用图块表拼.md)。
