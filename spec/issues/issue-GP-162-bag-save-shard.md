# GP-162：背包进存档，存档版本升一级

## 目标

主角背包的内容是正式存档里的一个分片，写出去再读回来一格不差；上一版的存档读进来补一个空背包。

## 来源

- PRD：[`spec/prd-items-in-bag.md`](../prd-items-in-bag.md) 的 `US-006`。

## 依赖

- `GP-159`：背包本体。

## 验收标准

- [ ] 可测试：主角背包的内容是正式存档里的一个分片；写出去再读回来，每一格的种类、品质与件数都一致，空格还在原来的位置。
- [ ] 可测试：存档版本升一级（代码仓 `rules/Foundation/Save/SaveFile.cs`），最低兼容版本不动；上一版的存档读进来补一个空背包，日期与每一格地照旧。
- [ ] 可测试：同一版的存档缺背包分片，载入被拒（[ADR-0015](../../decisions/ADR-0015-存档的版本与缺字段口径.md)）。
- [ ] 可测试：存档里的物品标识在物品定义里找不到时，载入被拒并点名哪一格、哪个标识；存档里的格数比现在配置的格数多时，载入被拒并说清两边各是几格。
- [ ] **作者实机确认**：收几样东西、睡一觉，停掉游戏再进来，背包里还是那些。串在 `GP-163` 的清单里。
- [ ] 可核对：代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。
