# ENG-37：纹理声明的检查，载入时与交图时各核一遍

## 目标

作者给天然地形配纹理时，配错的那几种情形在载入时一次全报、说清错在哪；交纹理图时，交图核对判得出它是不是全不透明、宽高是不是整格。

## 来源

- PRD：[`spec/prd-terrain-texture.md`](../prd-terrain-texture.md) 的 `US-002`（判定那一半）与 `US-003`。两条核的都是「纹理图与它的声明守不守规矩」，有一条规矩相同（宽高是整格），所以合成一条。

## 依赖

无。

## 验收标准

- [ ] 可测试：规则层的判定，交进去「数据层地形集里有哪几种地形、每一项声明了什么、各地形读出来的主色、格边长」，报出：没声明的地形；声明了数据层里没有的地形；同一种地形声明了两次；一项既没给纹理图也没写不铺，或两样都给了；纹理图宽或高不是格边长的整数倍（说出实际多大）；两种地形读出来的主色相同；配了纹理图的那种地形读不出主色（没有哪一套双网格认得它）。
- [ ] 可测试：几处同时错时一次报全、顺序固定；声明齐全、尺寸都对时不报；一项都没声明时不报 —— 那是「不铺纹理」，由 `ENG-38` 照旧画地面。
- [ ] 可核对：用例进代码仓 `tests/`，`python tools/verify.py` 全过。
- [ ] 可核对：代码仓 `python tools/check_art.py` 核纹理图那个目录（`res://assets/self-drawn/tiles/fill/`）：全不透明、宽高都是格边长的整数倍，不合的逐张报出；格边长从规则层的基础单位读，不另写一个数。只用色板色那一条它本来就核。
- [ ] 可核对：拿一张故意做坏的图（带透明、宽不是整格）跑一次 check_art，两条都报出来；跑完删掉那张图，在「验证结果」里写明。
