# GP-159：背包装东西：按种类与品质分堆，满了整份拒收

## 目标

主角的背包按「种类 ＋ 品质」摞成堆、堆到上限再占下一格，满了整份拒收、一件不变；格数与堆上限都从数据读。

## 来源

- PRD：[`spec/prd-items-in-bag.md`](../prd-items-in-bag.md) 的 `US-003` 前半。

## 依赖

- `GP-157`：堆上限与有无品质读物品定义。

## 验收标准

- [ ] 可测试：同种同品质合进一堆、堆到那种物品的堆上限再占下一格；同种不同品质各占一格；无品质的只按种类分堆。反过来构造一次「不同品质被合进一堆」的断言，必须失败。
- [ ] 可测试：满载 = 没有可合的同标识堆且没有空格；格子用尽但有半满的同标识堆时照样放得进去。两个方向各一条用例。
- [ ] 可测试：一次放进去的那一份放不下时整份被拒，背包一件不变。
- [ ] 可测试：格数按背包等级从配置读（代码仓 `data/config/game.json`），缺了当场报错；等级在这一份里固定为第一级。堆上限按种类从物品定义读。
- [ ] 可核对：代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。
