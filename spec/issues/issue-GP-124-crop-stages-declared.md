# GP-124：作物阶段数由每种作物自己声明

## 目标

做得出三天成熟的速生菜；而「最快几天成熟」这个会被抄错的数字从此不存在。

## 来源

- PRD：[`prd-extensible-lists`](../prd-extensible-lists.md) 的 `US-006`
- 判据：[ADR-0025](../../decisions/ADR-0025-取值集的家由加一个的代价决定.md) —— 阶段序列是一条作物自己的声明，加一种作物不用写代码

## 依赖

无。落地跟 `GP-87` 走；素材那一半归作者（[ADR-0009](../../decisions/ADR-0009-编辑器主导的开发模式.md)）。

## 立项理由

现在[`地块系统`](../../design/地块系统.md)固定五个阶段、其中四个计时，于是算出一个「最短生长周期」。那个数被[数值模型](../../design/数值模型.md)抄了一份并且抄错了值，同一行还要求「五个阶段各几天」而实际只有四项。**放开阶段数是根治**：那个数由每种作物自己的声明算出来，没有一个全局的数可以抄错。

## 验收标准

### 形状

- [ ] 一种作物声明一个阶段序列，**第一个必须是种子、最后一个必须是成熟可收**，中间几个由它自己定
- [ ] 最少就这两个（种子 → 成熟）
- [ ] 成熟是终态、**不带天数**（到了就一直等玩家收）。这条不变，理由照旧是多一个没人读的字段填错了不报错
- [ ] 计时的阶段各至少 1 天
- [ ] 可测试：只声明种子与成熟的作物**载入成功**
- [ ] 可测试：只声明一个阶段、第一个不是种子、最后一个不是成熟，三种各一条**载入被拒**
- [ ] **循环收获那一格照旧**：填阶段号＝退回那一阶段，填成熟那一阶段被拒

### 那个数字消失

- [ ] [`地块系统`](../../design/地块系统.md)里「最短生长周期」那个算出来的数**删掉**
- [ ] [数值模型](../../design/数值模型.md)那一行不再要求「五个阶段各几天」，也不再复述最短周期
- [ ] 按词搜两个仓加 `.kiro`，那个数零残留

### 素材交付口径

- [ ] [场景绘制约定](../../production/场景绘制约定.md)的作物交付改成「按它声明的阶段数各一张，加一张枯死」
- [ ] **那一节的节名不再带张数** —— 它被按名引用着，改名要连带扫一遍引用
- [ ] 可测试：声明的阶段数与交付的素材张数对不上时报错，并说清缺哪一张。**这一条判在引擎层**，规则层看不见素材路径
- [ ] 实际重画不在本条 —— 口径改动是本条，内容归 `GP-88`
