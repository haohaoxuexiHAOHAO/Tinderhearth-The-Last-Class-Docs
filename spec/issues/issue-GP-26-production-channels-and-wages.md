# GP-26：正典补齐生产渠道、工位与派工付酬

## 目标

把畜牧、钓鱼、烹饪、开荒、设备自动化写进正典的系统清单与工位清单，并定下「经营侧产出归主角、主角付酬」这条新的经济流向。

## 来源

- PRD：[`spec/prd-base-and-production.md`](../prd-base-and-production.md) 的 `US-002` 与 `US-003`

## 依赖

依赖 `GP-25` —— 食堂与畜舍要先进建筑清单，工位才挂得上去。

## 验收标准

- [ ] [玩法定位](../../canon/gameplay/玩法定位.md)的系统清单在经营那一行补上畜牧、钓鱼、烹饪、设备与自动化、开荒
- [ ] [时间与经营 · 学生与派工](../../canon/gameplay/时间与经营.md)的工位清单补上新工位，并写明**设备添料不是派工**（一次交互，不占时间与体力，且只有主角能添）
- [ ] 食堂与灶台的分工写明：灶台一人份；食堂出更高品质的概率更高，且独占部分配方
- [ ] 畜舍写明**可多建、可升级，每级容纳固定数量**
- [ ] [角色与成长 · 战利品归属](../../canon/gameplay/角色与成长.md)写明经营侧产出归主角、主角按产出物品基础价的比例付酬
- [ ] 付酬工位的判据写成「这项派工的产出归主角吗」—— 种植、加工、饲养、照料设备付；训练、读书、照护伤员不付
- [ ] 写明**付酬与入库同时发生**（产出留在工位那天不扣钱）、**现金不足时不能派工并显示缺口**、**付酬不改变信任度**
- [ ] 索取加件数额度，「索取被拒不降低信任度」原样保留
