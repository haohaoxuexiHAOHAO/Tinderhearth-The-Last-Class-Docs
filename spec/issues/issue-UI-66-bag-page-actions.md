# UI-66：背包页的操作：排序、筛选、整理、挪格与丢弃确认

## 目标

背包页里点得到排序、筛选、一键整理、挪格与丢弃，丢之前一律弹一道确认，被拒的操作当场说清原因。

- `UI-65`：背包页本体。

## 验收标准

- [ ] 可测试：排序、筛选、一键整理、挪格与丢弃在这一页都点得到，结果与 `GP-160` 那几条用例一致；挪格是点一格、再点目标格，键盘与手柄用同一套焦点走得通。
- [ ] 可观察：点丢弃先弹一道确认，写明丢的是哪一样、几件、什么品质；点确认才丢，点取消或按返回什么都不变。确认窗在弹窗那一层、经导航栈开关。
- [ ] 可观察：被拒的操作当场说清原因，比如这一样不可丢弃。
- [ ] **作者实机确认**：排版与操作顺不顺手，丢弃那一道确认挡得住误点又不烦人。串在 `GP-163` 的清单里。
- [ ] 可核对：代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。
