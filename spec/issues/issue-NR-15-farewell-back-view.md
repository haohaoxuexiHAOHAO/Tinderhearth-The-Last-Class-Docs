# NR-15：告别那一幕改成只给背影，真容全作不出现

## 目标

「摘面具那一刻玩家看见什么」只有一处说法，而主角的发色也只有一个家。

## 来源

- PRD：[`spec/prd-canon-hardening.md`](../prd-canon-hardening.md) 的 `US-005`
- 起因：[学生群像 · 大结局的告别：面具与真容](../../canon/narrative/学生群像.md)写主角当众摘面具、脸「比所有人预想的都要年轻」、发色银白；而[人物 · 面具、右臂与伪装](../../canon/characters/人物.md)（第 2 级，权威更高）写本作不展示完整真容、头发是黑色为主体夹不规则银白发束

## 依赖

无。台词那一侧归 `NR-5`（本条只要求写明「信息量由台词承载」，不写台词）。

## 验收标准

- [ ] 可核对：[学生群像 · 大结局的告别：面具与真容](../../canon/narrative/学生群像.md)改成只给背影 —— 镜头在他身后，看得见他抬手摘面具、把面具递给灯火、看得见学生们的脸，**看不见他的脸**。
- [ ] 可核对：删掉对脸与发色的全部描述，含「比所有人预想的都要年轻」、「发色是银白」与那段眼神描写；云澜那句改成不指向长相的话。
- [ ] 可核对：**[人物](../../canon/characters/人物.md)一个字未改** —— 反向核对。那一页写的是「**可以**」让玩家看见眼神，是允许不是要求，所以只给背影严格落在允许之内。
- [ ] 可核对：面具移交给灯火那个物证**保留**，学生们笑出声那一段也保留 —— 删的只有「玩家看见了什么」。
- [ ] 可核对：发色在全库只有一个家（[人物 · 面具、右臂与伪装](../../canon/characters/人物.md)），[人物 · 主角剪影（标杆）](../../canon/characters/人物.md)那一行与它一致，别处写链接不复述。
- [ ] 可核对：那一段写明**这一幕的信息量由台词承载**、那几句是承重的，并指向 `NR-5`；**不写具体台词**（内容走内容外置）。
- [ ] 可核对：[学生群像](../../canon/narrative/学生群像.md)里「关于真容的私下讨论」那一节与新口径不打架（它现在写「这个悬念在游戏过程中始终没有答案，解答留给告别场景」）。

- [ ] 可核对：`python tools/check_docs.py` 0 项必须修复。
