# UI-62：打开手环与直达三页的键

## 目标

`Tab` 打开手环，`B`、`M`、`C` 直达背包、地图与角色面板，手柄 `Start` 打开手环；直达键开的是手环的那一页，不是第二个面板。

## 来源

- PRD：[`spec/prd-items-in-bag.md`](../prd-items-in-bag.md) 的 `US-007` 后半。
- 它交付 `UI-24` 的全部；键位照[键鼠技能位挪到右手](../../design/proposals/键鼠技能位挪到右手.md)那份提案的键位表。

## 依赖

- `UI-61`：农场里要先有手环。
- `ENG-34`：`B` 要先从调试键那边让出来，冲突测试判得到。

## 验收标准

- [ ] 可测试：打开手环、直达背包、直达地图、直达角色面板四个动作进动作清单（代码仓 `rules/UI/InputActions.cs`），键鼠依次绑 `Tab`、`B`、`M`、`C`。
- [ ] 可核对：手柄 `Start` 绑到打开手环；它的引擎自报名起一个一次性无头工程实读，写进绑定表，用完即删。
- [ ] 可测试：直达键打开的是手环的那一页；手环开着时按另一个直达键换到那一页，再按同一个键关上。
- [ ] 可测试：睡下到醒来那一段输入关着，按这几个键打不开手环。
- [ ] **作者实机确认**：农场里按 `Tab` 打开、`Esc` 关上，开着时世界停着；按 `B` 直接落在背包页。串在 `GP-163` 的清单里。
- [ ] 可核对：代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。
