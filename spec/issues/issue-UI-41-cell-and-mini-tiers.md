# UI-41：格子与迷你两档尺寸进排版单位

## 目标

格子与迷你成为代码里两档正式尺寸，各自由既有排版单位推出来，改一个单位另一个跟着变或当场红。

## 来源

- PRD：[`spec/prd-ui-art-baseline.md`](../prd-ui-art-baseline.md) 的 `US-001`。
- 两档的画法与用途在[界面绘制约定 · 尺寸阶梯](../../production/界面绘制约定.md)，本条不复述。

## 依赖

- `ART-27`：代码那一半在素材交付之后才动。
- 与 `ENG-24` 有交界：图标档那段注释由本条改，侧视缩放那个常量仍归它。

## 验收标准

- [ ] 可核对：`rules/UI/UIMetrics.cs` 有格子与迷你两档，注释写明它们由哪几个既有单位推出来。
- [ ] 可测试：两条关系各一条测试 —— 格子 ＝ 小图标 ＋ 两倍面板内边距；迷你 ＝ 栅格。改一个数另一个不跟就红。
- [ ] 可核对：图标档那段注释里过期的理由按现行正典改写，`ENG-24` 条目里那一格同步勾掉。
- [ ] 可核对：那几档的注释写明「改它要回去重算[界面绘制约定](../../production/界面绘制约定.md)里的尺寸」—— 约定里的数是引用，代码这边一改它就静默过期，而能提醒改的人的只有这一处注释。
- [ ] 可核对：[界面控件 · 八、排版量从哪来](../../reference/godot/界面控件.md)那段 `UIMetrics` 内容清单跟着补上两档，或者改成不列。
- [ ] 可核对：侧视缩放那个常量不动 —— 它还在管相机，归 `ENG-24`。
- [ ] 代码仓 `python tools/verify.py` 全绿，看它自己打的摘要。
