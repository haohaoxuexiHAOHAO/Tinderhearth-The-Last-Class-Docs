# GP-166：物品声明占地，图标尺寸与占地对不上时启动就报

## 目标

每件物品的定义写明它在背包网格里占几格宽、几格高；占地写错载入被拒，图标尺寸不等于占地乘基础单位时启动就一次全报。

## 来源

- PRD：[`spec/prd-grid-bag.md`](../prd-grid-bag.md) 的 `US-001`。

## 依赖

无。

## 验收标准

- [ ] 可测试：物品定义多一格占地，宽与高各是至少 1 的整数格；缺这一格、缺宽或高、或者不是正整数，载入被拒并说清是哪一件、哪一格。
- [ ] 可核对：代码仓 `data/items/` 下现有的每一件都补上占地 1×1。
- [ ] 可测试：图标的宽高不等于占地乘基础单位时，启动时一次全报，一行一件，写清应有多大、实际多大；变异那一张同样核。
- [x] 可核对：[`物品系统`](../../design/物品系统.md)那张字段表有占地那一行，图标那一格写的是「照占地的大小画」。
- [ ] 可核对：代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。
