# GP-181：走格子：八向、不许斜穿、同伴可穿不可停

## 目标

给定一间屋、站着的人和一笔行动力，算得出能走到哪几格、每格最少花多少，以及走过去的那一条路。

## 来源

- PRD：[`spec/prd-first-grid-battle.md`](../prd-first-grid-battle.md) 的 `US-004` 规则那一半。标格子、画路在 `UI-70`。

## 依赖

- `GP-180`：走的是那一间屋。

## 验收标准

- [ ] 可测试：八个方向都能走，一步 1 点，斜着也是 1 点；两个挡路的东西斜着挨着时，从中间斜穿被拒。
- [ ] 可测试：能从同伴那一格穿过去，不能停在那一格；墙与对面的人挡路。
- [ ] 可测试：这一步走之前和走之后都挨着敌人时花 2 点，挨着几个都只多 1 点。
- [ ] 可测试：给一笔行动力，算得出走得到的每一格与最少花多少；点一格，走得到就沿花得最少的路走过去，走不到的不动；花得一样少的路有几条时，同一局面每次取同一条。
- [ ] 可核对：代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。
