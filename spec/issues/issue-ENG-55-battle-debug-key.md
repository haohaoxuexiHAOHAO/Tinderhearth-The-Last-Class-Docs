# ENG-55：基地按调试键进这一场，打完回基地一件不变

## 目标

在基地里随时按一下就打一场；回来时基地还是进去之前的样子，这一场不进存档。

## 来源

- PRD：[`spec/prd-first-grid-battle.md`](../prd-first-grid-battle.md) 的 `US-011`。

## 依赖

- `UI-70`：进的是那个战斗场景。

## 验收标准

- [ ] 可测试：基地里一个开发期调试键进这一场；它登在调试键表里（代码仓 `rules/UI/DebugKeys.cs`），「同一个物理位不被两个动作抢」那条测试一起判它。
- [ ] 可核对：打完回到基地，日期、地、背包与存档一件不变；进去之前没存档的改动（比如刚播下的种子）也还在。
- [ ] 可核对：这一场不进存档；打到一半退出游戏，下次照存档从基地开始。
- [ ] 可核对：进战斗时把基地那一棵树从场景树上摘下、不释放，打完挂回去，各节点的 `_Ready` 不再跑、输入与每帧处理照旧。这一条是推断，落地时起一次性探针实测，用完删掉。
- [ ] **作者实机确认**：播一格种子、按调试键打一场、回来，那一格还在。串在 `GP-185` 的清单里。
- [ ] 可核对：代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。
