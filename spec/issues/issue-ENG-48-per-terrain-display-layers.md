# ENG-48：显示层一种地形一层

## 目标

刷数据层时，按裸土、草、浅水、深水从下往上叠的几层显示层在编辑器里当场跟着变；检查器里接错了、TileSet 里少建了格，一次全报，说清是哪一样。

## 来源

- PRD：[`spec/prd-outdoor-tile-sheet.md`](../prd-outdoor-tile-sheet.md) 的 `US-002` 后三格，`FR-1`、`FR-9`、`FR-11`、`FR-12`。

## 依赖

- `ENG-47`：每一层取哪一格由那一条算。

## 验收标准

- [ ] 可测试（规则层单测）：检查器里少接了一层、一种地形没指给任何一层、同一层或同一种地形指了两次，一次全报。
- [ ] 可测试：显示层那份 TileSet 里少建了要用到的格，报出少的是哪几格。
- [ ] 可核对（一次性无头场景，跑完删）：临时搭一套新的几层，刷几格数据，几层各自取的格与 `ENG-47` 算的一样。结果与删了什么写在「验证结果」里。
- [ ] 作者实机确认：在数据层上刷一笔，几层在编辑器里当场跟着变；藏起数据层之后地面还在。这一格串在 `ENG-42` 的清单里。
- [ ] 可核对：台账 `ENG-25` 那一行照新的画法改写：它写的「16 张的排列顺序从素材量出来」「四角涉及三种以上地形时报错不猜」是旧显示层的。
- [ ] 可核对：代码仓 verify 全过。
