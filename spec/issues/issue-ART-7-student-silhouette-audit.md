# ART-7：九名学生补做剪影防撞审计

## 目标

九个人的黑剪影两两分得开，且每人都有一个进得了剪影的标志元素。

## 来源

- PRD：[`spec/prd-canon-hardening.md`](../prd-canon-hardening.md) 的 `US-006`
- 起因：[人物 · 剪影防撞审计](../../canon/characters/人物.md)写明「新增角色时必须做一次防撞审计」，判据是关掉颜色只看黑剪影 —— 而[学生群像](../../canon/narrative/学生群像.md)那九人一次都没做过

## 依赖

无。它与 `ART-8` 同形但对象不同，可并行。**排在 `ART-6` 之后那批人物帧之前** —— 剪影没定稿就开画，撞了只能重画，而 32px 下改剪影等于换角色。

## 验收标准

- [ ] 可核对：[学生群像](../../canon/narrative/学生群像.md)里九人的视觉锚点各答得出[记忆点四个杠杆](../../canon/characters/人物.md)的前三项（体型姿态剪影、签名色、一个大到能进剪影的标志元素），缺的补上。
- [ ] 可核对：审计结论**按对写出来**，至少覆盖铁砺／铁淬（差别现在只有两撮短须与瓶子数量，32px 下都看不见）与安桦／灯火（同为人类女、身高相近）。
- [ ] 可核对：分不开的那一对改**体型或大道具**，**不靠加小配件糊弄**（[人物 · 32×32 像素可读性规则](../../canon/characters/人物.md)那条）。
- [ ] 可核对：安桦有一个固定的标志元素 —— 她现在写的是「武器不固定、装备最杂」，等于没有。「装备最杂」若保留，写明它是**质感**而不是识别符。
- [ ] 可核对：[人物 · 剪影防撞审计](../../canon/characters/人物.md)点名的两类高危撞型（瘦削人类男性、军人老兵）各核一遍 —— 九人里林泽是前者、目前只有他一个。
- [ ] 可核对：**具体色值不在本条**。[人物 · 签名色分配的三条约束](../../canon/characters/人物.md)写明色值必须在暗色实机背景下校准后锁定，那是作者实机的事。
- [ ] 作者实机确认：九个黑剪影并排放一屏，逐对看分不分得开。
- [ ] 可核对：`python tools/check_docs.py` 0 项必须修复。
