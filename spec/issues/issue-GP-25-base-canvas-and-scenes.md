# GP-25：基地画布扩到 80×60，场景与建筑清单跟着改

## 目标

让基地大到摆得开建筑、耕地、畜牧区与装饰，并把「建筑有室内」「种植区是土地不是建筑」这两件事写进正典。

## 来源

- PRD：[`spec/prd-base-and-production.md`](../prd-base-and-production.md) 的 `US-001`
- 起因是一笔算得出来的账：可建造区 40×30 格 = 1200 格，俯视 1 倍缩放下**整个基地只有一屏宽**（`rules/Ui/CameraRig.cs` 的注释写明拿可建造区当钳制边界时横向不存在滚动）。

## 依赖

无。本条是这一批的第一件，`GP-26`／`ENG-22`／`DOC-15` 都等它先定建筑清单与尺寸。

## 验收标准

- [ ] [玩法定位 · 场景规模](../../canon/gameplay/玩法定位.md)写明可建造区 80×60 格（1280×960px）
- [ ] 同一张表新增「建筑室内（俯视）」一类场景，并写明**第一版只做一类当样板**、其余按生产相关四类加住宿补齐
- [ ] 水面写明落在**可建造区之外的周边地形**，不占可建造格
- [ ] [时间与经营 · 建造](../../canon/gameplay/时间与经营.md)的尺寸跟着改，建筑清单为八类且**按名列出**
- [ ] **种植区从建筑清单移出**，改写成可耕地（要开荒清理）
- [ ] 正文与全库都不再出现「第 N 类建筑」这种按序号引用清单的写法
- [ ] 建筑外观尺寸写明常规 7×4 格、封顶 8×6 格（长宽仍取 16 的倍数）
- [ ] `python tools/check_docs.py` 0 FAIL
