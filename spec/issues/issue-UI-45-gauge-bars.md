# UI-45：资源条：画的填充、回复时追、扣减时留一截

## 目标

资源条的样子全由作者画的槽与填充决定；回一大截时看得见它涨上来，挨一下时看得清掉了多少。

## 来源

- PRD：[`spec/prd-ui-art-baseline.md`](../prd-ui-art-baseline.md) 的 `US-007` 里资源条那几格（`FR-23`、`FR-25`、`FR-26`、`FR-27`）。
- 画法（明暗只许上下变、条头、浅色那一截）在[界面绘制约定 · 代码管什么、你画什么](../../production/界面绘制约定.md)，本条不复述。
- 理由：扣减那一截让玩家看清这一下掉了多少；回复的追让精准防御与精准闪避那两份回报看得见，而[`界面系统` · 常驻那一层：战斗与经营的抬头显示](../../design/界面系统.md)要求两者的回报分得开。

## 依赖

- `UI-44`：槽与填充从素材资源取。

- [x] 可核对：槽也换成画的那张。换完按 `assets/placeholder/ui/` 搜，引擎层与规则层只剩演示数据里的占位内容图 —— 这是 `UI-44` 那一条交过来的尾巴，理由在它的偏离里。资源条那两张占位图已删。
- [x] 可核对：资源条前面的标签是作者画的迷你图标，不再是文字。代码仓 `src/UI/LevelHud.cs` 与 `src/UI/BaseHud.cs` 从素材资源取那四张。
- [x] 可测试：一下子回一大截时，显示的长度每帧朝数值走一段、整像素、不越过数值；数值不变之后它停在数值上。判定在代码仓 `rules/UI/GaugeChase.cs`，测试在 `tests/UI/GaugeChaseTests.cs`。
- [x] 可测试：扣减时掉下去那一截先换成浅色那一条留在原地，停一段之后再缩到数值；停的过程中又挨一下，浅色那一截从当前位置接着算，不跳回去。同一份测试另钉了缩的过程中挨一下、追的时候挨一下、回复回到那一截之上与没回到之上。

- [x] 可核对：条头跟着末端走；值很低时填充被裁短，不是压扁。填充照数值改宽、右端那几列就在末端；长度不够放下两头那几列时，照两头那么宽画、再按长度裁。

## 实现笔记

> 由 `/note-it` 在实现和评审之后填写。

### 设计决策

- **先接画好的槽与填充，追与留一截随后。** 静态那一半先上，关卡里那三条马上就是作者画的样子；动的那一半要作者在检查器里调两个量，单独做。
- **「按槽里那一片裁」靠遮罩**：开场时从槽那张图里认出放填充的那一片（色板 `ember 3`，代码仓 `rules/UI/HudPalette.cs` 的 `GaugeChannel`），做成一张遮罩，填充只落在那一片上。认出来是空的当场报错。所以作者重画那张槽时，那一片要照旧画这一档，色板里那条也记了。
- **满的时候填充画到槽的右边**，出界的由遮罩裁掉：那一片右端是弯的、条头是斜的，按哪一行算满都会在别的行上漏一角。
- **值很低时裁短、不压扁**：九宫格窄过两头那几列会把两头压扁，所以填充最窄照两头那么宽画，再按长度裁。
- **槽中段拉伸、填充中段平铺**：槽中段每一列都一样，拉伸与平铺一个样；填充中段带亮点，只许平铺。
- **扣减时填充当场落下去，那一截停在原处。** 慢慢落的话这一下的轻重读不出来，而那一截正是拿来读轻重的。每挨一下，停的时间从这一下算起；缩的过程中又挨一下，它停在当时的位置。连着挨几下时它留到最后一下之后才缩，这一串一共掉了多少看得全。
- **回复到那一截之上，那一截就没了**；没回到它之上，它照停照缩到数值。它说的是掉了多少，回到那么多之后没有意思。
- **追与缩用同一个速度，单位是界面像素每秒。** 按像素算，长短不同的条看起来一样快（队友那一根比 HUD 那三条短）；缩不另开一个速度，是因为要调的就是那两个量。
- **那一截垫在填充下面画。** 两张的头一样斜，所以一样长时它整个被填充盖住，露出来的只有比填充长的那一段。
- **两个量放在一份资源里，由挂 HUD 的那个节点接。** 现在只有主场景挂着 HUD，那一份就放在主场景里。
- **主场景预览关卡那一套时，演示数据按一轮起伏走**：挨一下、停着时又挨一下、回一大截、闪避之后一点一点回、精准防御回一截法力、队友挨一下再被救回，一轮走完回到开头。它跟着世界暂停，所以手环开着时不走。

### 偏离

- **方案怎么说**：本条连精英血条一起换成画的那一套。
- **实际怎么做**：本条只换 HUD 的三条与队友那一根，精英血条交给 `UI-43`。
- **为什么**：画好的槽比精英血条现在高，要先把精英血条改成一样高，而那正是 `UI-43` 的一格（血条高与 HUD 资源条同一个数）；世界那一层又没有调用方，先换了也没人看得见。放进 `UI-43`，与尺寸、偏移一次改完，不先接一版尺寸不对的。

### 权衡

- 遮罩在开场时从图里认，而不是让生成器多出一张遮罩图：多一张就多一处要跟着槽一起改的图，而「哪一片放填充」本来就写在约定里、按色板一档认得出来。

### 待确认

- 那两个量的手感值归 `GP-6` 那一类实机校准，本条只要求它们在检查器里调得动、缺了报错。主场景那一份里的起步值实机看过，没有要改的。
