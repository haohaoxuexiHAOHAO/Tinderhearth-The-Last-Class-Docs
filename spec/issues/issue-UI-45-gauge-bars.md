# UI-45：资源条：画的填充、回复时追、扣减时留一截

## 目标

资源条的样子全由作者画的槽与填充决定；回一大截时看得见它涨上来，挨一下时看得清掉了多少。

## 来源

- PRD：[`spec/prd-ui-art-baseline.md`](../prd-ui-art-baseline.md) 的 `US-007` 里资源条那几格（`FR-23`、`FR-25`、`FR-26`、`FR-27`）。
- 画法（明暗只许上下变、条头、浅色那一截）在[界面绘制约定 · 代码管什么、你画什么](../../production/界面绘制约定.md)，本条不复述。
- 理由：扣减那一截让玩家看清这一下掉了多少；回复的追让精准防御与精准闪避那两份回报看得见，而[`界面系统` · 常驻那一层：战斗与经营的抬头显示](../../design/界面系统.md)要求两者的回报分得开。

## 依赖

- `UI-44`：槽与填充从素材资源取。

## 验收标准

- [ ] 可核对：资源条的填充是作者画的那几张，代码只改长度、不染色；队友血条与精英血条用同一套槽与填充。
- [ ] 可核对：槽也换成画的那张。换完按 `assets/placeholder/ui/` 搜，引擎层与规则层只剩演示数据里的占位内容图 —— 这是 `UI-44` 那一条交过来的尾巴，理由在它的偏离里。
- [x] 可核对：资源条前面的标签是作者画的迷你图标，不再是文字。代码仓 `src/UI/LevelHud.cs` 与 `src/UI/BaseHud.cs` 从素材资源取那四张。
- [ ] 可测试：一下子回一大截时，显示的长度每帧朝数值走一段、整像素、不越过数值；数值不变之后它停在数值上。
- [ ] 可测试：扣减时掉下去那一截先换成浅色那一条留在原地，停一段之后再缩到数值；停的过程中又挨一下，浅色那一截从当前位置接着算，不跳回去。
- [ ] 可核对：追多快、停多久是作者在检查器里调的两个量，代码里没有能用的默认值；缺了载入报错。
- [ ] 可核对：条头跟着末端走；值很低时填充被裁短，不是压扁。
- [ ] **作者实机确认**：回一大截与挨一下各看一次，追与停的那两个量调到顺手为止。
