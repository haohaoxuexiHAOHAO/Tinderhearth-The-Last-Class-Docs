# ENG-43：崖那两层接进游戏，配错按 F6 当场报

## 目标

崖那两层配错时，按 `F6` 当场报错、一次全报，说清是哪一层的 TileSet、哪一格、哪一种块；没有崖的场景照样按得了 `F6`。

## 来源

- PRD：[`spec/prd-outdoor-tile-sheet.md`](../prd-outdoor-tile-sheet.md) 的 `US-004` 前三格，`FR-17` 到 `FR-20`、`FR-22`。
- 做法：[俯视地图用图块表拼 · 高处照星露谷那样做：崖按顶、中、脚拼，崖面挡人，从南边的楼梯走上去](../../design/proposals/俯视地图用图块表拼.md)。

## 依赖

- `ENG-45`：崖那一片每一格是哪种块，在那份排法里。

## 验收标准

- [ ] 可测试（规则层单测）：任何一层的 `Enabled` 或 `Collision Enabled` 关着时报错；位置与数据层不一样时报错。
- [ ] 可测试：该挡人的块没画碰撞、不该挡人的块画了碰撞，各报一处；哪些块该挡，见那份需求的 `FR-19`、`FR-20`。
- [ ] 可测试：几处不对一次全报，每处写明是哪一层的 TileSet、哪一格、哪一种块、该不该带碰撞。
- [ ] 可核对：没有崖的场景不放崖那两层，也照样按得了 `F6`；放了没接齐时当场报错，说清缺谁。
- [ ] 可核对：代码仓 verify 全过。

崖在测试场景里的无头走一遍与作者实机，都在 [`ENG-42`](./issue-ENG-42-tile-sheet-e2e.md)。
