# ART-15：世界侧配色：角色、地形与物件的色板

## 目标

世界侧每一类要画的东西都能在同一张色板里取到色，而且会挨在一起的色带并排看分得开。

## 来源

- 色板本体在代码仓 `assets/self-drawn/palette.gpl`，**它是色值的唯一来源**；口径在[像素绘制原则 · 本项目的色带口径](../../production/像素绘制原则.md)，本条不复述。
- 检查入口是代码仓 `tools/palette_probe.py`，按需跑、**不进 `tools/verify.py`**：既有色板本来就有刻意接受的近邻，做成守卫会一直报。
- 界面用色也出自这一份色板，不另开一套；界面用哪几档、在暖炭背景上读不读得清归 `DOC-2`。两边的并排看是同一件事，`DOC-2` 落地时并进来。

## 依赖

无。

## 验收标准

**下面每一项都没有机器判据**，只能在 Aseprite 里并排看（[ADR-0009](../../decisions/ADR-0009-编辑器主导的开发模式.md)）。判的是同一件事：两样东西挨着的时候分不分得开、读不读得出各自是什么。不过的那一项回头改色板里那一条的值，不改素材去迁就。

**地形与季节**

- [ ] 秋草（`autumn`）对天然裸土（`soil`）
- [ ] 冬天的草地（`winter`）上放一块石头（`stone`）
- [ ] 湿耕地（`wet`）对干耕地（`rust`）与天然裸土（`soil`）

**作物与果实**

- [ ] 作物绿（`cropgreen`）压在耕地上
- [ ] 谷物黄（`cropyellow`）对 `gold`：读作一穗粮食，不读作一块金属
- [ ] 柠檬黄（`fruityellow`）对谷物黄（`cropyellow`）
- [ ] 玫红（`fruitpink`）对 `fruitred` 与 `gemred`
- [ ] 青绿（`cropteal`）对 `cropgreen` 与 `greenskin`
- [ ] 蓝紫（`fruitblue`）对 `fruitpurple` 与 `gemblue`
- [ ] `cropgreen` 第 5 档当菜帮：读作菜帮，不读作一片嫩叶

**灵能与失衡**（口径在[世界观 · 变异：吸收过量灵的另一条岔路](../../canon/world/世界观.md)）

- [ ] `spirit` 对 `ice` 与 `gemblue`：一团灵能光读作发光，不读作一块冰或一颗蓝宝石
- [ ] 同一台机器的芯用 `spirit` 与 `chaos` 各画一张并排看：正常运转与魔化一眼分得开
- [ ] 一个冒着 `chaos` 的魔化生物身上挂一层灼烧（`ember` 与 `flame`）：看得出挂上了。失衡另开一条、不借 `ember`，就是为了这一项
- [ ] `chaos` 对 `fruitpurple` 与 `fruitpink`：一团失衡的气不读作茄子或火龙果的颜色
- [ ] 变异那颗星换成现在的 `spirit` 之后，与传奇那颗（`ember`）并排仍是一冷一暖

**火与冰**

- [ ] 一团火照 `flame` 那条注释从外沿画到芯（`flame` 接 `ember` 的亮端）：读作同一团火，看不出两条色带的接缝
- [ ] 一块冰只用 `ice` 与 `highlight` 画：不发光、也没有另开的晶冰，照样读得出是冰

**人物**

- [ ] 褪紫（`mauve`）对 `ash` 与 `winter`：读作一块洗旧的紫布，不读作一块灰
- [ ] 褪紫（`mauve`）对 `night` 与 `fruitpurple`：与褪色的蓝布、与茄子那种艳紫都分得开
- [ ] 主角黑发里的银白发束（`winter` 或 `ice` 的亮档）紧挨面具（`ash` 亮的一半）：读作头发与金属两样东西
- [ ] 黑裤、黑靴贴地那一截照 `ash` 那条注释取色，踩在接地影（`shadow`）上：脚与影子分得开

## 实现笔记

### 设计决策

- **模糊点**：作物与果实那一族按什么长。原先是按品种一条条加的，于是色环上留着整片空白 —— 要画一样别的颜色时一条都拿不出来，而这不报错。
- **选择**：**按色相铺**，色带名说色相、品种只在注释里列；补了 `fruityellow`、`cropteal`、`fruitblue`、`fruitpink` 与 `cropgreen` 第 5 档，族内照色环排。
- **理由**：品种会一直加（自创的尤其），而色环上分得清的色相有限。与宝石按色相进表同一条，口径写进了[像素绘制原则 · 本项目的色带口径](../../production/像素绘制原则.md)。

- **模糊点**：灵能显形是什么颜色。正典原先只写灵无色无形、角色特效用签名色，而劳作的灵能光层与灵能元素不属于任何人，没有签名色可用。
- **选择**：**有秩序的灵显青蓝**：`spirit` 改成自发光、芯近白，变异那颗星同用这一条。正典写进[世界观 · 变异：吸收过量灵的另一条岔路](../../canon/world/世界观.md)。
- **理由**：另开一条的话，它与原来那条变异蓝的亮端只差二十来个单位，正是「两份近似色、迟早各画一半」那种撞法；而变异本来就是「灵给出来的极致」。

- **模糊点**：失衡怎么显形、显什么色。
- **选择**：**分两层**：周身漏出来的气（失衡灵流）读此刻，身上的变化是走深之后留下的。气走新开的 `chaos`（紫红、没有白芯），做成共用的叠加层、不画进角色的帧；身上的变化用那个生命自己色带的暗档。正典写进[世界观 · 活跃失衡的规模](../../canon/world/世界观.md)，画法写进[像素绘制原则 · 失衡灵流是一层叠加件，不画进角色的帧](../../production/像素绘制原则.md)。
- **理由**：一个角色全程只有一套素材，同一个生命失衡前后、救回来前后只能靠一层叠加件区分，阿石就是现成的例子。颜色为什么不借 `ember` 见下面「偏离」。

- **模糊点**：火与冰画不画得出。
- **选择**：火另开 `flame`（鲜红橙，火舌外沿与爆炸），与 `ember` 首尾接成一团火；冰不另开，`ice` 保持压闷。
- **理由**：`ember` 的红端偏褐，画不出火舌外沿那一段；而又青又亮的晶冰那一片是 `spirit` 的，另开就和灵能光撞在一起，所以冰改靠晶体的形状与趋白的高光读出来。

- **模糊点**：黑发、黑衣、灰发、银发缺不缺色。
- **选择**：都不另开，只在 `ash` 那条注释里写明两处要避开的档（贴地的黑、主角的银白发束）。
- **理由**：明度与冷暖都排得开 —— 冷黑、暖黑、蓝黑各有出处，灰与银也都有冷暖可挑。缺的是「哪几档会和别的东西粘在一起」，那是借用说明、不是颜色。

- **模糊点**：洗旧的紫布（三喜那身旧衣就是）从哪取。
- **选择**：另开 `mauve`（灰紫、低彩度），当布料用。它不是三喜签名色的锁定值，签名色照旧在实机背景下校准（[像素绘制原则 · 本项目的色带口径](../../production/像素绘制原则.md)）。
- **理由**：不另开就只能借 `ash`、`winter` 那几条灰，画出来读作灰、不读作紫；`fruitpurple`、`gempurple`、`chaos` 都太艳，而且各自有主。

- **模糊点**：角色的签名色画的时候从色板哪一档取 —— 正典只给色名，色值要在实机背景下校准才锁。
- **选择**：要角与常驻 NPC 先定起点，记在被借那一条的「签名色起点」里；学生与反派的签名色落在特效与发光上（招式、壳缝里透出来的光），画到那些时再定。苍冥是例外，她的惨青先定了取偏灰的 `water` 那一侧。
- **理由**：前两组的签名色在衣服与器物上，画小人那一刻就要用；发光与特效还没开画，而它们正是最要对着暗色背景校准的那一类。起点不是锁定值，锁定照旧在 Godot 里看。

- **模糊点**：苍冥的招式用惨青，挨着 `spirit`（有秩序的灵），靠形状分开撑不撑得住。
- **选择**：不等形状那一关，起点直接取偏灰的 `water` 那一侧。
- **理由**：撑不住时的退路本来就是往灰、往暗推。照色名取的参考色最近的就是 `water 7`，离 `spirit 4` 有 48.9（参考色是推断，锁定时在实机背景上再核一遍）。

### 偏离

- **方案怎么说**：失衡的灵借 `ember`，魔化的机器是芯从 `spirit` 换成 `ember`。
- **实际怎么做**：另开 `chaos`，`ember` 只管火。
- **为什么**：失衡从机器芯里的一个点变成了每个魔化生物周身的一团气，面积变了，代价才显出来。起步的敌人全是魔化生物，火元素借的就是 `ember`，同色的气会让灼烧看不出挂没挂上；云漪、铁焕、崔岚的签名色也都挨着那一片。

### 权衡

- **黄那一片**：在「放宽 `cropyellow` 外借」「加一条素黄」「认黄本来就少」之间选了加 `fruityellow`（小件、偏柠檬、整条更亮）。撞色只发生在作物黄那段明度上，往亮处错开一截就不撞。
- **青绿放在偏绿的那一段**，不放更偏青的那一片：西兰花一类没那么青；推到 `cropgreen` 那么艳，第 2 档就贴上 `gemgreen`。
- **蓝紫往紫偏、不取正蓝**：正蓝那一片的暗档贴着 `gemblue`，而蓝莓本来就偏紫。
- **`chaos` 放在 `fruitpurple` 与 `fruitpink` 之间那片空档里**：最暗一档仍挨着 `fruitpurple 1`，暗紫那一段本来就挤。

### 待确认

- 验收标准里那几项并排看。
- 失衡灵流那一层的素材，以及它的浓淡读什么，归 `ART-26`。
- 已知的缺口，第一次真要画到时再加，加之前照[像素绘制原则 · 本项目的色带口径](../../production/像素绘制原则.md)先问借不借得到：
  - **不透明的正蓝**（蓝漆、染得正的蓝布、蓝色塑料）：正蓝那一片只有 `gemblue`（透明晶体的画法）与 `spirit`（自发光），`night` 太压闷，`fruitblue` 往紫偏。
  - **中深的暖棕肤色**：`skin` 整条偏素。单个色凑得到（`copper`、`soil`、`fruitorange` 各有近邻），但拼成一条肤色要跨几条走向不同的色带。
  - **军绿与常绿**（制服那种橄榄绿、松柏那种四季不变的绿）：军绿的近邻在 `moss` 与 `spring` 上，那两条正是换季要换的；常绿的候选贴着 `greenskin`（兽人的肤色）。借了会不会跟着换季、常绿要不要单开一条，都看换季怎么换（`ART-22`），先等它定。
