# GP-134：长成那一晚掷一次变异，收上来带着变异

## 目标

作物长成那一晚按几率掷一次，掷中的那一株一直是变异的，直到收掉或枯死；收上来的东西带着「变异」交给产出那一手。

## 来源

- PRD：[`spec/prd-crop-sheet.md`](../prd-crop-sheet.md) 的 `US-002`、`US-004`（`FR-2` 到 `FR-5`、`FR-9`、`FR-13`）。
- 规则来自 [ADR-0030](../../decisions/ADR-0030-作物成熟时按几率变异.md) 与[`地块系统`](../../design/地块系统.md)，本条不复述。

## 依赖

- `GP-143`：引擎那一侧掷的时候用它算出的几率。规则层只收「这一次中没中」，不等它。
- 品质等 `GP-22`，睡后简报等 `GP-56`，那一位落盘等 `GP-54`：这三样不在本条的验收里，做完下面这几格之后本条照旧开着，等它们。

## 验收标准

- [ ] 可测试：随机源注入成必中时，长成那一晚这一格变成「变异」；注入成必不中时不变。
- [ ] 可测试：没到成熟的那几晚一次都不掷（必中也一样），掷的次数数得出来。
- [ ] 可测试：能反复收的作物收完那一位清掉，下一次长成重掷（先中后不中，两茬一变一不变）。
- [ ] 可测试：换季枯死与清掉枯株都清掉那一位；「变异」只在待收那一态为真。
- [ ] 可测试：变异那一株收获时，收获结果写着变异；件数照常按浇水算，与没变的同一套。
- [ ] 可核对：推进一天之后，这一晚变异的每一格各打一行输出 —— 睡后简报落地之前的替身。
- [ ] 可核对：输出面板那一行收获记录在变异时带一个「变异」标注。
