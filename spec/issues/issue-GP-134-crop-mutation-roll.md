# GP-134：长成那一晚掷一次变异，收上来带着变异

## 目标

作物长成那一晚按几率掷一次，掷中的那一株一直是变异的，直到收掉或枯死；收上来的东西带着「变异」交给产出那一手。

## 来源

- PRD：[`spec/prd-crop-sheet.md`](../prd-crop-sheet.md) 的 `US-002`、`US-004`（`FR-2` 到 `FR-5`、`FR-9`、`FR-13`）。
- 规则来自 [ADR-0030](../../decisions/ADR-0030-作物成熟时按几率变异.md) 与[`地块系统`](../../design/地块系统.md)，本条不复述。

## 依赖

- `GP-143`：引擎那一侧掷的时候用它算出的几率。规则层只收「这一次中没中」，不等它。
- 品质等 `GP-22`，睡后简报等 `UI-59`，那一位落盘等 `GP-153`：这三样不在本条的验收里，做完下面这几格之后本条照旧开着，等它们。后两样在[睡一觉能推进一天](../prd-sleep-advances-day.md)那份需求里。

## 验收标准

- [x] 可测试：随机源注入成必中时，长成那一晚这一格变成「变异」；注入成必不中时不变。
- [x] 可测试：没到成熟的那几晚一次都不掷（必中也一样），掷的次数数得出来。
- [x] 可测试：能反复收的作物收完那一位清掉，下一次长成重掷（先中后不中，两茬一变一不变）。
- [x] 可测试：换季枯死与清掉枯株都清掉那一位；「变异」只在待收那一态为真。
- [x] 可测试：变异那一株收获时，收获结果写着变异；件数照常按浇水算，与没变的同一套。
- [x] 可核对：推进一天之后，这一晚变异的每一格各打一行输出 —— 睡后简报落地之前的替身。打的是「[地块] 格坐标 的 作物标识 长成时变异了」。
- [x] 可核对：输出面板那一行收获记录在变异时带一个「变异」标注。

测试在代码仓 `tests/Economy/CropMutationTests.cs`；地块与收获结果在 `rules/Economy/Plot.cs`、`rules/Economy/HarvestResult.cs`，掷与那两行输出在 `src/World/Farm/FarmField.cs`。

## 实现笔记

### 设计决策

- **模糊点**：随机源以什么形状交给地块。
- **选择**：按天推进多一个参数，一个「掷一次、中了返回真」的回调；只在长成那一下调它。
- **理由**：规则层只该知道这一次中没中，几率怎么算是调用方掷之前的事（代码仓 `rules/Economy/MutationChanceRule.cs`）。回调而不是事先掷好的一个布尔值：事先掷就得每晚都掷一次，「掷的次数数得出来」那一格就测不出「只在长成那一晚」。

- **模糊点**：收获结果多出的那一格怎么交出去。
- **选择**：收获从「几件」改成一份收获结果，件数加上「是不是变异的那一株」。
- **理由**：多一个输出参数也行，但品质落地时还要往里加东西，一份结果只改一处。没收成时它是空的那一份：0 件、不变异。

- **模糊点**：那一位在哪几处清掉。
- **选择**：播种、收获、清掉枯株三处共用的那一段清零里带上它，换季枯死那一处单独清。
- **理由**：换季枯死本来就不走那一段（它不动土，当天浇过的土照旧是湿的），所以那一处要自己写；其余三处共用一段，漏掉一处不报错的那种错就少一处。

### 偏离

无。

### 权衡

- **换图一并做了**：待收且变异的那一格显示变异成熟那张，那一行在 `GP-144` 名下、读的是本条加的那一位，两边一起改才看得到效果。勾选记在 `GP-144` 的条目里。
