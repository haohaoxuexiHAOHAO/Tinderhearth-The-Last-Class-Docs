# GP-182：一轮两个阶段，一回合一件占回合的事

## 目标

一场仗一轮一轮往前走：谁先谁后、一回合里行动力怎么花、什么时候结束，都由规则层定。

## 来源

- PRD：[`spec/prd-first-grid-battle.md`](../prd-first-grid-battle.md) 的 `US-005`。倒下的人不排进出手顺序那一格在 `GP-184`。

## 依赖

- `GP-181`（已关闭）：一回合里走路用的是那一套，在代码仓 `rules/Combat/MovementMap.cs`。

## 验收标准

- [ ] 可测试：每轮开始按当时的敏捷排一次：我方阶段烬第一个，学生按敏捷从高到低；敌方阶段敌人按敏捷从高到低；敏捷一样时按站位在场景里的先后，不掷骰。
- [ ] 可测试：自己的回合开始时行动力回满，没用完的不留到下一回合。
- [ ] 可测试：点一格，走得到就沿代码仓 `rules/Combat/MovementMap.cs` 算出的那条路走过去、扣掉花的行动力；走不到的不动。
- [ ] 可测试：一回合只做得了一件占回合的事，第二件被拒；做完之后剩下的行动力减半、向下取整。
- [ ] 可测试：行动力用完、还没做占回合的事时，可以把那一件换成再走满一次；算得出用剩下的行动力走得到的格子，与换成再走满一次才走得到的格子。
- [ ] 可测试：行动力用完、占回合的事也做过了，这一回合自动结束；点结束回合也结束。
- [ ] 可核对：代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。
