# GP-108：考试成绩按这一科的书数折算

## 目标

多上几节课能让这个学生这一科考得更好，而不是由「玩家当初把书分给了谁」定死。

## 来源

PRD：`spec/prd-richness-and-feel.md` 的 `US-008`。

立项理由：现在成绩是这一科全部书的掌握度之和，而每本典籍全作只出现一次、不可丢卖。**于是玩家把书分给了谁，别人这一科就永远追不上，教再多也没用** —— 而考差零惩罚（那条是对的），所以也没人在乎。结果是中后期考试退化成一条播报，而它本该是教学反馈链的最后一步。

改法：成绩 = 这一科的掌握度**除以这一科的书数**，没有书的科目不计入。

## 依赖

无。文档侧可以现在就改；落地跟 `GP-21` 走。它是 `UI-29` 的输入（成绩明细那一处要显示折算之后的口径）。

## 验收标准

- [x] 算式改成**某一科成绩 = 他在这一科下持有的那几本书的掌握度平均值 ＋ 小幅随机区间**；写明「不计入」**不是「零分」**（没有书不是考了零分，是这一科他没学过）
- [x] 除的是**他手上那几本的本数**，不是这一科一共有几本 —— 后者会让没拿到的那几本一直算在他头上（见下面「偏离」，这一处验收原话没说清）
- [x] **总评是计入的那几科的平均** —— 用和的话总评就退回成「他手上有几本书」，那是同一条缺陷在总评那一层的副本
- [x] 掌握度的上限那一格：**它不是一个待定的值**，是归一化给的（零到满值，满值对每本书一律相同）。顺带写明**按书各给一个满值不行** —— 折算之后的成绩会因为他手上那几本的满值不同而不同
- [x] 那条硬约束按新算式重述：归一化加按本数折算之后，一次授课涨的那一截在成绩上有多大**不再随他这一科有几本书变**，所以它**现在判得到**（旧算式下要先问「他这一科有几本书」）
- [x] 反证写进[`教育系统`](../../design/教育系统.md)的验收并标成承重项：同一个学生在书数不同的两科上教同样多节课，得到可比的成绩；另加三条（不计入不等于零分、掌握度停在满值、授课涨哪几本）
- [x] 成绩随机区间仍归[数值模型](../../design/数值模型.md)，本条一个值都没给；那一行另加一句**「掌握度的上限不在本行」**，免得以后有人往那张表里补一个第二个家
- [x] `python tools/check_docs.py` 0 FAIL；动了[数值模型](../../design/数值模型.md)所以另跑 `python tools/simulate_week.py --check-doc`，也过

## 实现笔记

> 由 `/note-it` 在实现和评审之后填写。

### 设计决策

- **模糊点**：一次授课涨的是哪一本书的掌握度。原先那张产出表只写「书籍掌握度上涨」，没说涨哪一本 —— 按和算的时候这一格无所谓，**换成平均值之后它是承重的**。
- **选择**：**他已读的每一本各涨一截，不挑科目。**
- **理由**：只涨一本的话，成绩上的那一截就等于「那一截 ÷ 他这一科有几本书」，于是书多的学生每节课看到的变化更小 —— 那正好把本条要修的东西换了个方向重新造出来。**而这也是那条硬约束现在判得到的前提**：涨全部之后那一截在成绩上的大小不随本数变。
- **另一处**：由此**没有「今天教哪一科」这个选择**。「这个学生哪方面强」的来源已经是玩家安排谁读什么（那一份原先就这么写），再加一个按科目的选择等于给同一件事第二个来源，而它每天都要点一次。

### 偏离

- **方案怎么说**：`US-008` 与本条都写「成绩 = 这一科的掌握度**除以这一科的书数**」。
- **实际怎么做**：除的是**这个角色手上那几本的本数**。
- **为什么**：「这一科的书数」有两种读法，而**按全作本数除修不了这条缺陷** —— 没拿到的那几本会一直算在他分母里，于是「书分给了谁」照旧定死结果，只是从「追不上」变成「分母里多了几本永远拿不到的书」。按他手上那几本除，两个各持一本不同数学书的学生才可比，而教学才真的是那一科成绩的来源。
- **第二处（超出验收的必要补写）**：验收没提总评，但「没有书的科目不计入」讲的就是总评怎么汇总，所以必须答。**总评改成计入那几科的平均** —— 原话「总评是各科汇总」在和的读法下会让「手上书多」直接等于总评高。
- **第三处**：验收把掌握度上限写成「补上，或写明为什么不需要」。实际答的是**第三种**：它既不是「补一个值」也不是「不需要上限」，而是**归一化本身给的** —— 上限存在（满值），但它不是一个待校准的量。

### 权衡

也可以**保留按和算，另外给「没有书的科目」一条补救**（例如允许玩家抄一本副本、或让教学能从零开一本新书的掌握度）。否决理由有两层：抄副本要推翻正典那条「典籍读完即消耗、同一本只出现一次、抄也抄不出第二本」（[世界观 · 灵](../../canon/world/世界观.md)给了它世界内的依据）；让教学从零开一本新书，等于让「书」不再是掌握度的必要来源，而那条「阅读推到门槛、之后靠教学」的两段分工就没了。折算式不动任何一条既有结论，只改一个算式。
