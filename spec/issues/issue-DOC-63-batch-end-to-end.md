# DOC-63：这一批的端到端与交叉核对

## 目标

用一条命令加三轮人工对照，看出这一批有没有和正典打架、有没有改漏某处说法、有没有踩别人写死的不变式，并确认那两份新文档合起来真的走得通两条链。

## 来源

- PRD：[`prd-codex-and-city-map.md`](../prd-codex-and-city-map.md) 的 `US-009`
- 起因：本批同时动新文档、正典链接与好几份已交付文档，**两份以上互相引用的东西不可能各自独立跑绿** —— 所以要有一条专门在最后合并着验的条目。

### 端到端两条链

- [x] **图鉴那条**逐段指得到落点：取得一件物品／技能学会／敌人显形 → 调那一个写入口 → 进正式存档 → 关卡内也查得到 → 内容缺失时隔离不删除。

## 实现笔记

### 设计决策

- **模糊点**：按词那几轮怎么判「过期」—— 本批那几个词合起来上百处命中。
- **选择**：**分区。** 只有活文档（`canon/` 与 `design/` 根下，加 README、`WORKFLOW.md` 与 `decisions/`）里出现过期说法才算失败。
- **理由**：`spec/` 下的过程件在描述「从什么改成什么」，`archive/` 是只读历史 —— 不分区的话这几轮会报几十处命中，那等于没有检查。脚本因此只做机器做得了的三件事：**分区、列命中、自报行数**；判断留给人。

- **模糊点**：几轮怎么分才不重复。
- **选择**：按**词**（三遍：本批新词、容易互抄的那几组理由、写成散文的状态）、按**量级数字**、按**不变式**、按**编号搜两个仓加 `.kiro`**。
- **理由**：每一轮都查出过东西，而且互相查不出对方那一类 —— 按词查不出「同一个数两个家」，按数字查不出「理由互抄」，两者都查不出「新加的动作踩了别人写死的东西」。**本批实测：按词第二轮与按量级数字那一轮各抓到一类真错。**

### 偏离

- **方案怎么说**：按词那一轮「跑两遍以上」。
- **实际怎么做**：跑了三遍，**第二遍抓到一处真错**：新写的「图鉴不加步」那条理由与[`主线推进系统`](../../design/主线推进系统.md)那条同源。
- **为什么**：第一遍只问「新词有没有第二个家」，第二遍问的是「同一条结论的理由有没有互抄」—— 前者查不出后者。修法与根因记在 `DOC-60`：**根治是把抄在 PRD 与条目里的理由副本删掉，而不是同步它们。**

- **方案怎么说**：不变式那一轮列一串「应当一个字未改的文件」并逐份确认为空。
- **实际怎么做**：照做，但那张清单里**刻意排除了两处归档** —— `archive/spec/NR-11-progression-and-endgame/` 与[变更日志归档](../../archive/history/变更日志归档.md)。另有[`感知与视野系统`](../../design/感知与视野系统.md)也不在清单里。
- **为什么**：前两处是本批归档上一批的动作对象，把它们留在清单里会让那一轮报一个已知且已解释的失败；后一份加了一行「出」，理由记在 `DOC-60` 的偏离里。

### 权衡

**「把按词交叉核对落成 `tools/` 入口」第五次被排掉。** 本批又给它添了一个反例：机器看到的是好几页都写着「不加步」这个相同的短语，而要判的是那几条**理由**互不重复 —— 那一处真错正是这么被人看出来的。**判断一个入口该不该留，看它判的东西机器判不判得到，别看它长得像不像守卫。**

**「把台账每格 ≤360 落成守卫」同样仍然不做**（上一批判过一次）：机器判得到字符数，但 `DOC-17` 点名那三格是刻意超限的，守卫要给它们开白名单 —— 而白名单是每加一份就补一格的债。本批继续用 `temp/` 下那个量具，用完即删。

### 待确认

无。**假命中自己判掉了四处**，逐处写在 `DOC-60` 的「权衡」里（`生产系统` 的「执行地点」、`教育系统` 的另一种计数器、`人际系统` 那条不同依据的「不占一步」、`建造系统` 那处该在但不该带数字的「半秒」）。**机器分不出这一类，这是人看的那一半。**
