# DOC-165：撤掉手环、城里设施改名、去掉签名色、委托三类，两个仓里跟着改

## 目标

工作区根 desc/ 已经写了新规矩（[特殊建筑](../../../desc/特殊建筑.md)、[人物](../../../desc/人物.md)、[状态](../../../desc/状态.md)、[各类公式计算](../../../desc/各类公式计算.md)）。两个仓里还在讲旧说法的地方照它改，搜干净。

## 新规矩

| 旧 | 新 |
| --- | --- |
| 手环 | 撤掉这个设定；它的功能在背包界面里：打开背包界面能看地图、委托板、角色面板等 |
| 苏生所、配给枢纽、商会、建筑施工队、生产队 | 星空医院、物资中心、鲨鱼商会、老鸦建筑协会、星空补给队 |
| 秦炉生的铺子、赵来福的杂货铺 | 老秦铁匠铺、来福杂货店 |
| 长明坡、未来街、乞生巷、落袋街、灯下街 | 医院区、学院区、物资区、金融区、酒馆区 |
| 主角的训练基地 | 废旧训练场，名字玩家可以改；以后可以请老鸦建筑协会盖畜牧屋、炼金小屋、制造小屋、渔夫屋等 |
| 教职遴选、招收 | 教职筛选、招生；「院内」那段删掉 |
| 委托三类：采集资源、清理区域、护卫设施 | 采集资源、探索区域、清理区域；委托难度动态，板上一定有完成得了的；最晚晚上 10 点回来 |
| 失败：主角倒下、全体学生倒下、目标损毁 | 只有学生全部倒下才失败；黑屏后在星空医院醒来；部分倒下的战斗结束后以 1 点 HP 起身 |
| 签名色 | 去掉：认人靠头发、眼镜、衣服 |
| 角色定死的战斗定位（魔法、远程、辅助） | 去掉：由玩家决定 |

## 同一批要改的系统文档

- 护卫类委托撤掉：[`任务系统`](../../design/任务系统.md)（护卫对象存活、失败三条触发条件、单人出征、验收）、[`感知与视野系统`](../../design/感知与视野系统.md)（来源点）、[`回合系统`](../../design/回合系统.md)、[`角色动作状态系统`](../../design/角色动作状态系统.md)里「主角倒下即失败」那几处；探索区域（探索过指定比例的格子）补进任务的目标条目。
- 教学不直接给经验：[`教育系统`](../../design/教育系统.md)的「学生少量经验」「主角少量经验」两行，[`状态效果系统`](../../design/状态效果系统.md)里「授课给学生少量经验与增益」，[玩法定位](../../canon/gameplay/玩法定位.md)那张流程图。改成获得「训练充分」。
- 失败只剩学生全部倒下：[`界面系统`](../../design/界面系统.md)结算那一格的「失败（主角倒下那一类）」。
