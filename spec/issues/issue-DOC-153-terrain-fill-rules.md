# DOC-153：地面的纹理画在哪张图上，写进场景绘制约定

## 目标

画地面的人查一处就知道：16 张只画形状与交界，地面本身的纹理、阴影与高光画在每种地形一张的纹理图上，以及纹理图的规矩与理由；引着旧说法的几处跟着改。

## 来源

- PRD：[`spec/prd-terrain-texture.md`](../prd-terrain-texture.md) 的 `US-004`。

## 依赖

- `ENG-38`：新那几句要指到合成落在代码仓哪里、没配时照旧画，代码得先在。

- [x] 可核对：`ART-21` 的台账行跟着改：它只管一个个的东西，「只盖在纯色地面与纯水内部」改成不压交界那一圈。
- [x] 可核对：设计仓 `python tools/check_docs.py` 0 FAIL。

## 实现笔记

### 设计决策

- **规矩写在「双网格」那一节、紧跟纯色那一条**：画地面的人是在那一节读到「整张纯色」的，细节该画到哪里就写在同一处，纹理图不另开一节。
- **「交界里想保持原样的笔画不用主色」单独加粗**：合成按颜色认，主色的像素全会换成纹理，而这件事在 16 张里看不出来，铺开才发现。
- **纹理图的规矩里多写了一条光向**：凸起的上沿亮、正下方落影，凹缝本身暗、下沿迎光。它出自[像素绘制原则 · 统一视角与光源](../../production/像素绘制原则.md)的光从正上方来，写在这里是因为纹理图是地面上第一处要画阴影与高光的地方。
- **动态水那一节标题改成「动的是水那张纹理图，不写扰动着色器」**，引着这个标题的季节换色重着色贴图提案与 PRD 跟着改了。
- **水面动画记成 `ART-31`，明确后置**：这份需求只做静态纹理，要答的是几帧一循环、多快、浅水深水各动各的不。
- **`ART-21` 从「高」降到「中」**：它原先排高的理由是「没有它，一片地面就只有几个色」，这件事现在归纹理图，它只剩一个一个的东西。

### 偏离

- **方案怎么说**：验收只列了场景绘制约定、像素绘制原则与 `ART-21` 那一行。
- **实际怎么做**：另有几处复述着旧说法，一起改了：
  - [瓦片地图与地形](../../reference/godot/瓦片地图与地形.md)「本项目的地形口径」那几条，加一条地面纹理、动态水那一条跟着改；
  - [粒子、着色器与音频](../../reference/godot/粒子着色器与音频.md)第四节的标题原来说白闪是唯一一段着色器，改了标题、加「地面纹理那一段」一小节，第一节那张表与「不做非整数采样」那段跟着补；
  - 台账 `ART-12` 那一行存量不再复述旧的动态水做法，改成指到现行那一节；
  - [`ART-17`](./issue-ART-17-scale-test-pieces.md) 的动态水那一项挪到 `ART-31` 那一行；
  - 代码仓 `tools/check_dualgrid.py` 纯色那段注释原来写「高光与碎石归装饰层」。
- **还改了一处与这份需求无关的过时句子**：瓦片地图与地形「落在哪里，与一条硬要求」那一小节写着 `ENG-25` 卡在 `ENG-21`、翻译代码写成什么形状待定，而台账里 `ENG-25` 代码已落地、是 `[Tool]` 脚本。改成只写代码在哪、进度链到台账，那一小节的标题也不再写「落地状态」。这一篇本来就在改，留着它又给 `ENG-25` 的状态开了第二个家。
- **为什么**：目标那一句就是「引着旧说法的几处跟着改」；旧说法留着，读到的人会照旧做法画。

### 权衡

- **`ART-17` 的动态水那一项挪走，不留着等 `ART-31`**：留着的话那批试片要等一条没有排期的待办才关得上，而它卡着正式美术。代价是这批试片不再看水动起来时的接缝，那一眼挪到 `ART-31` 做完时看。

### 待确认

- 纹理图画出来好不好看、按纹理图边长重复看不看得出来：只有实机看得出来，在 `ENG-39` 的作者实机清单里。
- `ART-21` 降到「中」、`ART-17` 的动态水那一项挪到 `ART-31`：交付时请作者过目。
