# ENG-34：开发期调试键与输入绑定登在一处，冲突测试一起判

## 目标

开发期那几个直接读的调试键与输入绑定表登在同一处，「同一个物理位不被两个动作抢」那条测试把它们一起判。

## 来源

- PRD：[`spec/prd-items-in-bag.md`](../prd-items-in-bag.md) 的 `US-005`（调试键那一条）。
- 起因：背包要用 `B`，而 `B` 现在是农场里的换批调试键，直接读按键，代码仓 `tests/UI/InputMappingTests.cs` 那条冲突测试只扫绑定表，看不见它。

## 依赖

无。

## 验收标准

- [ ] 可测试：农场与训练房里那几个调试键各登一条（哪个场景、哪个键、做什么），登在代码仓 `rules/UI/InputBindings.cs` 那一处或紧挨着它；直接读按键的地方从这张表取键，不再各写一个字面量。
- [ ] 可测试：冲突测试把调试键与绑定表合起来判；故意让一个调试键与一条绑定撞同一个物理位，测试变红。
- [ ] 可核对：调试键照旧不进输入映射，不出现在玩家能改键的那份清单里。
- [ ] 可核对：代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。
