# UI-70：战斗界面：一间屋、标格子、瞄准、血条、出手顺序与技能栏

## 目标

打一场仗看得见、点得动：轮到谁、能走到哪、打不打得中、打了多少、谁被接管，一屏都看得出。

## 来源

- PRD：[`spec/prd-first-grid-battle.md`](../prd-first-grid-battle.md) 的 `US-010`，以及 `US-003`、`US-004`、`US-006`、`US-007`、`US-008` 画面那一半。
- 台账 `UI-43`（血条与伤害数字挂在头顶）在战斗里的那一份在这一条。

## 依赖

- `GP-184`：画的都是规则层算出来的东西。

## 验收标准

- [ ] 可核对：战斗场景先由我搭成灰盒：那一间屋（墙与地面）、站位与界面，节点的编辑器描述写明临时；代码要的节点缺了当场报错，说清缺谁。
- [ ] 可观察：墙与地面没有图时画「暂无」的灰框；学生与敌人画两格高的暂无框；烬用基地那套四向图。
- [ ] 可观察：轮到玩家操作的人时标出能走到的格子，剩下的行动力走得到的与换成再走满一次才走得到的形状不同；指着一格时画出要走的那条路；左键点格子走过去。
- [ ] 可观察：点一招进入瞄准，再点一次那一招或按 `Esc` 取消；瞄准时目标身上写命中几率与不暴击时的伤害；打中、暴击、打空的伤害数字样子各不一样，打空写「未命中」，从头顶往上飘。
- [ ] 可观察：每个人头顶一条血条；挂着「格挡」的人头顶一个状态小图标，没画写暂无。
- [ ] 可观察：一排出手顺序的小头像，标出现在轮到谁、谁被接管；没画的写名字的第一个字。
- [ ] 可观察：屏幕下方一行技能栏，放着现在操作的人会的招，旁边一个结束回合的按钮；还在冷却的招点不了。
- [ ] 可观察：镜头不动、不缩放，一屏看全那一间屋；走格子一格一格挪过去，出手朝目标冲一下，挨打闪白。
- [ ] 可观察：胜负一出弹一个窗，写胜利或失败，按一下结束这一场。
- [ ] **作者实机确认**：看得出现在轮到谁、能走到哪、打不打得中、打了多少、谁被接管；走、打、防御顺手。串在 `GP-185` 的清单里。
- [ ] 可核对：代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。
