# GP-184：倒下与胜负、接管学生、最低一档 AI

## 目标

一场仗自己打得完：没人操作的由 AI 动，玩家每轮能接管学生，HP 到 0 有后果，胜负判得出来。

## 来源

- PRD：[`spec/prd-first-grid-battle.md`](../prd-first-grid-battle.md) 的 `US-007`、`US-008`、`US-009` 规则那一半。胜负窗、出手顺序里标出接管在 `UI-70`。
- 台账 `GP-36`（战斗 AI 落地）的最低一档在这一条。

## 依赖

- `GP-183`：AI 出手用的是那一套。

## 验收标准

- [ ] 可测试：HP 降到 0 时，学生与烬倒下，还占着那一格、不再行动、不排进出手顺序；敌人死亡，从格子上拿掉。
- [ ] 可测试：敌人全部死亡判胜利；烬倒下或学生全部倒下判失败。胜负一出，不再有人行动。
- [ ] 可测试：在烬的回合里点那名学生，就接管他这一轮：轮到他时由玩家操作；每轮只能接管一人，接管不用掉烬那一件占回合的事；下一轮不点就回到 AI。
- [ ] 可测试：没被接管的学生与敌人照[战斗规则 · 战斗智慧](../../../desc/战斗规则.md)最低一档动：朝最近的对面的人走，进了施放距离就普通攻击；敌人先找走得到的学生，学生都够不着时才找烬；走不近也打不到时防御。
- [ ] 可测试：同一局面、同一串随机数，AI 做的是同一件事。
- [ ] 可核对：代码仓 `python tools/verify.py` 全绿；设计仓 `python tools/check_docs.py` 0 FAIL。
