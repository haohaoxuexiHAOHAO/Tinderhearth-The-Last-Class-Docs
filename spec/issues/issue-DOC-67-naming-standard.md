# DOC-67：命名口径立成规则，并按它统一现有不一致

## 目标

「这东西该起个什么样的名字」有一条查得到的规矩，而两个已经指向它的指针指得到真答案。

## 来源

- PRD：[`spec/prd-canon-hardening.md`](../prd-canon-hardening.md) 的 `US-008`
- 起因：[`物品系统`](../../design/物品系统.md)的名称字段与[`数值模型`](../../design/数值模型.md)那条「不占命名权」都写着「口径见[文案写作规范](../../production/文案写作规范.md)」，而那一页开头明写**不适用于机制说明**、全篇 R1–R10 讲的是怎么写风味散文，**一个字都没讲命名**；[人物 · 命名规则](../../canon/characters/人物.md)那两层管的是专有名的语体分层，答不了「面包该叫什么」

## 依赖

无。**它应当排在其余命名统一之前** —— 规则不先立，统一完下一批内容又会各写一套。

## 验收标准

### 先立规则

- [x] 可核对：[文案写作规范](../../production/文案写作规范.md)新增一节「命名口径」，写下两类与判据「它是不是这个世界特有的东西」：**特有之物**（状态、特质、技能、人物、地名、组织、器物级孤品）允许意名；**通用之物**（面包、啤酒、木料、石料、绳子这类现实里也有的东西）按它本来的名字叫、不修饰不雅化。
- [x] 可核对：通用之物那一条写出理由 —— 给面包起一个世界内的雅名，玩家要多记一层换算，而那层换算不带来任何决策；**判据是「玩家看到它要不要先翻译一次」，不是「好不好听」**。
- [x] 可核对：写下字数规矩 —— **表达需要几个字就用几个字，不为简短而缩短**；举例说明缩短会丢掉什么（「薪尽火传」砍成两字就只剩「传下去」，「烧尽」那一半没了）。
- [x] 可核对：该页开头「不适用：机制说明」那句**扩一格**：名称是标签、不是机制说明，所以命名归本页；效果与数值的说法仍不归本页。
- [x] 可核对：[人物 · 命名规则](../../canon/characters/人物.md)那两层**留在原处不动**，新那一节写链接引它、**不复述**；两处的分工各写一句（那边答「意名长什么样」，这边答「哪些东西可以意名」）。

## 实现笔记

### 设计决策

- **新那一节落在[文案写作规范](../../production/文案写作规范.md)的末尾，编号往后加一节，不插在中间。** 前面那几节的编号被别处按「§N」引过，插在中间会让它们静默平移 —— 与[WORKFLOW § 3](../../WORKFLOW.md)第 5 条第 ② 款是同一条理由。同一节开头写明它与 R1–R10 的适用面不同：那几条管怎么写句子，本节管怎么起名字，而名称是标签、一个词就得站住。
- **「普通」改品质这一侧，不改委托档位那一侧。** 委托档位的取值同时写在参数表（`mission_tier_reward_multiplier`）与三份系统文档里，品质这一侧只有[`物品系统`](../../design/物品系统.md)那张表一处 —— 改动面小的那一侧就是该改的那一侧。新名取「寻常」：与同表的粗劣／精良同为两字形容词，且现有档位阶梯里没有它。理由与判据写进了那张表下面，所以下一个读者看得出它为什么不叫「普通」。
- **药草／草药／药材三者收成两层，不是收成一个词。** 「药材」是类别名，定价那一层的分组名就是「药材类」（同一个词）；「药草」是参数表里一种具体作物的暂用名，它的类别是药材 —— 两者不在同一层，所以不是第三个词。[`数值模型`](../../design/数值模型.md)那条「不占命名权」同一处写明了这个分层。
- **饲养与畜牧统成「畜牧」。** 工位名、生活技能名与产出渠道名指的是同一件事，畜牧在后两处已经各有一处、饲养只在工位那一处，所以改工位。
- **医疗站统成「苏生所」。** 地名的家是[世界观 · 主要设施](../../canon/world/世界观.md)（第 1 级正典），[常驻NPC](../../canon/narrative/常驻NPC.md)那一侧跟着它。同一处补了一句「场所名一律用那一节的名字」，让下一批 NPC 不必再判一次。

### 偏离

- **多改了两处名字出现的地方**：[`背包系统`](../../design/背包系统.md)那句举例（「8 个普通木料」→ 寻常）与本台账 `NR-4` 那一行（医疗站 → 苏生所）。它们是被改的那两个名字的其余出现处，不改就等于改了一半。
- **多加了一条规矩**：命名口径里写了「同物同名，一件东西在全库只有一个名字」。验收没点名要它，但本条后半截统一的四组撞名都是它的实例 —— 只改实例不写规矩，下一批内容会再来一次。
- **顺带给两处指针加了节名**：[`物品系统`](../../design/物品系统.md)与[`数值模型`](../../design/数值模型.md)原来指整页，现在指「文案写作规范 · 命名口径」那一节，于是节名引用守卫也盯着它了。

### 权衡

- **「寻常」在散文里有「不寻常」这个常见用法。** 那不构成档名撞名（撞名指两套档位阶梯共用一个词），但读者可能一瞬间把它当形容词。接受这个代价：换成「常品」之类能彻底避开，代价是它与同表另外两个形容词不同构，而档名一套词读起来要像一套。
- **[人物 · 命名规则](../../canon/characters/人物.md)一个字未改。** 那一页答的是「意名长什么样」，本条答的是「哪些东西可以意名」—— 两个问题，所以两处各留一句分工、不合并。要改它就说明这条分工划错了。
