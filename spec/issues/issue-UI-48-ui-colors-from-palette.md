# UI-48：代码里还在设的界面色按名字取色板里的一档

## 目标

界面上的每一个颜色都出自同一份色板，改色板里一个色全游戏一起变，不会长出第二套近似色。

## 来源

- PRD：[`spec/prd-ui-art-baseline.md`](../prd-ui-art-baseline.md) 的 `US-004`。
- 实测 `rules/UI/HudPalette.cs` 里的颜色没有一个在代码仓 `assets/self-drawn/palette.gpl` 里。探针实测，那批占位色多数在色板里已有近邻或凑得出；法力那条在色板里没有近的，建议借 `spirit`。
- 色板口径在[像素绘制原则 · 本项目的色带口径](../../production/像素绘制原则.md)，本条不复述。

## 依赖

- `DOC-2`：用哪一档由作者挑定，挑定之前没有名字可对。
- `UI-45`：资源条的填充换成画的图之后，只为染色存在的那几个色才删得掉。

## 验收标准

- [ ] 可测试：代码里每一个还在设的界面色都按名字对应到色板里的一档，值也对得上；测试直接读那份色板文件，对不上就红并说清是哪一个。
- [ ] 可测试（反证）：把色板里被界面引用的那一档改一个值，上面那条红。
- [ ] 可核对：测试读色板时只读不写，定位仓库根靠向上找工程文件。
- [ ] 可核对：只为给资源条染色而存在的那几个颜色随染色一起删掉；那条「各条资源色明度两两分得开」的测试也删掉 —— 填充换成了画的图，它判不到图。
- [ ] 可核对：被借的色带注释里记了「借给界面」。
- [ ] 可核对：色板文件头那句「世界侧配色」与 `Name` 那一行改成界面与世界共用；那一句是界面另开一套时的说法。
- [ ] 可核对：代码仓 `ARCHITECTURE.md` 三轴表里「占位配色」那一行，[界面控件 · 八、排版量从哪来](../../reference/godot/界面控件.md)那句「颜色从 `HudPalette` 取」，以及设计仓 `tools/font-preview/main.gd` 那句「正式界面色板归 DOC-2」跟着改。
- [ ] **作者实机确认**：换色之后 HUD 与手环的字在暖炭背景上读不读得清。现在那组占位色是当初判定 12 像素中文可读性时用的配色，换掉它等于那次判断要重看一遍，所以这一格不能省。
- [ ] **作者实机确认**：三条战斗资源条转成灰度之后仍然分得开 —— 它替掉上面删掉的那条测试；色觉差异里最常见的是红绿难分。
