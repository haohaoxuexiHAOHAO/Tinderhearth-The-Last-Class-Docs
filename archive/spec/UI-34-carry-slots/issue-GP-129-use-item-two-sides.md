# GP-129：用道具两侧不同，稀有的先确认

> **历史背景·非依据。只读归档件，不得作为现行依据。** 现行事实见同目录 [`prd.md`](./prd.md) 的「归档三问」；状态与剩余动作在[待办台账](../../../spec/issues/README.md)，不在本页。

## 目标

基地里连着用掉好几样东西不用等；关卡里「什么时候喝药」仍然是个决策；标了要确认的那几件，
手滑一下不会就没了。

## 来源

- PRD：同目录 [`prd.md`](./prd.md) 的 `US-004`
- 判据与载体：[ADR-0026](../../../decisions/ADR-0026-一道确认由误触与收益的落差决定.md)
- 那处空白已经填了：[`角色动作状态系统`](../../../design/角色动作状态系统.md)经营侧那一节现在写明
  用道具当帧生效、不占姿态，以及它与战斗侧刻意不同的理由

## 依赖

- `UI-34`（随身栏那条六格）—— 没有「选中哪一格」就没有「用哪一样」。
- `GP-22`（物品：稀有度与品质两条轴落地）—— **那道确认读的是物品定义上一格显式声明**，
  物品定义不存在时那一格没有地方填。

## 验收标准

- [ ] 基地里用一样**没标要确认**的消耗品**当帧生效**，没有读条、没有弹窗
- [ ] 基地里连按 N 次用掉 N 个，中间不插入等待
- [ ] 基地里用一样**标了要确认**的消耗品先弹一次确认，通过之后**当帧生效、不再插入读条**
- [ ] 那次确认被取消时**不消耗物品**
- [ ] **关卡里同一件标了要确认的物品不弹确认** —— 这是反证，它挡的是「凡是标了就到处弹」
- [ ] 关卡里用消耗品走**既有的读条动作**，代码里没有第二条执行路径
- [ ] 关卡里读条被受击中断时**不消耗物品**
- [ ] 关卡里读条途中移动**取消且不消耗物品**
- [ ] 那一格缺声明时**载入被拒**，不给默认值
- [ ] 「走哪一套」读的是当前在场那台动作机，**不是一个新增的场景开关**
- [ ] 物品定义为本条新增的字段**恰好一个**（就是那个开关）
- [ ] 代码仓 `python tools/verify.py` 五步全绿
- [ ] **作者实机确认**：基地里连着吃几样东西顺不顺手
- [ ] **作者实机确认**：那道确认弹出的时机与措辞读不读得清
- [ ] **作者实机确认**：关卡里那一下读条的节奏与采集是不是一致
