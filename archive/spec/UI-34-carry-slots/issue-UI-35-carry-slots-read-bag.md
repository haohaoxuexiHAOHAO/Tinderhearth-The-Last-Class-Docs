# UI-35：随身栏改成读背包，不是第二个容器

> **历史背景·非依据。只读归档件，不得作为现行依据。** 现行事实见同目录 [`prd.md`](./prd.md) 的「归档三问」；状态与剩余动作在[待办台账](../../../spec/issues/README.md)，不在本页。

## 目标

随身栏显示的就是背包里那几样，玩家不用维护两份清单。

## 来源

- PRD：同目录 [`prd.md`](./prd.md) 的 `US-005`
- 那份需求把内容来源刻意切成两步：`UI-34` 先接一份种子清单顶着，本条把它换成背包投影，
  **而 `UI-34` 与 `GP-128` 的行为一个字不改** —— 换来源不重做载体

## 依赖

`GP-23`（背包与仓库重新设计）—— 没有容器与堆，投影没有对象。

## 验收标准

- [ ] 随身栏**不持有任何物品数据** —— 它显示的是背包前六格，唯一要存的仍然只有「选中第几格」
- [ ] 背包里那一堆用完之后，随身栏对应那一格当场变空
- [ ] 背包排序之后随身栏跟着变（它是投影，不是一次快照）
- [ ] 换掉来源之后，`UI-34` 与 `GP-128` 的验收标准**一条都不用改** ——
      这一条是本条的承重项，它证明那一刀切对了
- [ ] 代码仓 `python tools/verify.py` 五步全绿
- [ ] **作者实机确认**：背包里排一下序，随身栏跟着变那一下看不看得出来
