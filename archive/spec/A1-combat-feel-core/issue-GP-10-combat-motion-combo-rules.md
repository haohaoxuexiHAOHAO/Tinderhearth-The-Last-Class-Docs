## 实现笔记

> 由 `/note-it` 在实现和评审之后填写。四类都要过一遍，某类没有就写「无」并简要说明。

### 设计决策

- **模糊点**：SPEC §5 把运动与连段分成两台机顺序推进，但没写「出招时禁止闪避/冲刺」这条跨机规则落在哪；取消窗只说「后摇末尾」没定长度语义；跳跃冲量帧与重力的先后 SPEC 未涉及。
- **选择**：两台机（`MotorState`、`ComboStateMachine`）各自纯推进，`MotorState.Tick` 收一个 `attacking` 标志（来自连段机）来封锁地面移动/跳/闪/冲；取消窗取「后摇的最后 `ComboWindowFrames` 帧」（经典 cancel window）；跳跃冲量帧给满初速、当帧不扣重力。
- **理由**：跨机规则用标志传入，让「出招禁闪冲」也进得了单测（塞进引擎层就测不到）；cancel window 是动作游戏惯例；冲量帧跳重力让「跳跃初速」可精确断言，也更贴冲量语义。

### 偏离

- **方案怎么说**：SPEC 未把上面三点写死，属留白而非既定方案。
- **实际怎么做**：按上面「设计决策」定。
- **为什么**：**无实质偏离** —— 实现与 SPEC 契约（分层、`CombatInput`、`CombatFeel` 落点、`GP-9` 方向取按下瞬间、不做 `GP-4` 取消）逐条一致；留白处的选择已记在设计决策里，供作者判断是否回写 SPEC。

### 权衡

- **两台机 + 标志 vs 合成一台**：选两台。合成一台能把跨机规则收在一处，但更大、且 SPEC 已分别命名两台；两台 + `attacking` 标志在「分离」与「跨机可测」间取平衡。
- **帧步进（固定 60Hz）vs 秒 + delta**：选帧步进。判定窗口与连段衔接本就是逐帧的，帧为单位可精确断言；秒 + delta 引入取整歧义，而手感调的就是帧数。

### 待确认

- 手感帧初值（轻攻击前摇 4／命中 3／后摇 8／取消窗 6；无敌窗 2–12；跳跃初速 260、重力 980 等）都是占位，实机收敛归 `GP-6`。**作者对这批量级作为起点有无明显偏好，还是等 `GP-13` 能实机后再一起调？**
- 引擎侧 `InputRouter`／`ActorControl` 的真实签名待 `GP-12` 起手逐个核对；与 SPEC §10.3 假设有出入就按偏离修 SPEC（已由 `GP-12` 覆盖，此处仅作知悉）。
