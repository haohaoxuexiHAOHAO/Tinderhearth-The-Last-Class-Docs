# DOC-98：台账的状态收成机器读得出的字段

> **只读归档件，不是现行依据。** 本轮的现行事实在正典、[`design/`](../../../design/README.md) 那批系统文档、[待办台账](../../../spec/issues/README.md)与 `tools/check_docs.py` 那条守卫里；要引结论请引它们，不要引本文。

## 目标

台账里每个编号的状态是一个取自固定词表的值，工具读得出「这条关了没有」，不用去读一句散文。

## 来源

PRD：[`spec/prd-canon-reconciliation.md`](./prd.md) 的 `US-009`。

它是[`DOC-100`](./issue-DOC-100-closed-id-guard.md) 的结构前提 —— 那条守卫要判「引用的编号是否已关闭」，而在本条之前这件事只有一半读得出来：**已归档**自己占一张表（读得出），**已完成**是备注里加粗的一句话（读不出）。`DOC-97` 那一轮指错的几个编号全是后一类。

## 依赖

无。它不依赖任何未完成的编号，可以先做。

## 验收标准

- [x] 域表每一行的备注都以词表里的某个状态词开头；不合的行数为 0（写出改之前与之后两个数）
- [x] 词表写在[台账](../../../spec/issues/README.md)自己那一页，取值**互斥且穷尽**
- [x] 词表把**文档交付**与**条目关闭**分成两个取值：设计已交付但落地未做的仍然算开着
- [x] 收编那几行时只改开头的措辞，**理由与链接一个字不动**（`git diff` 逐行看过）
- [x] 不给台账加列 —— 表还是四列，改的只是备注单元格的开头
- [x] 那张词表能被一段十行以内的解析逻辑读出来（`DOC-100` 落地时就是照它写的，所以这一条在那一条里才最终兑现）
- [x] `python tools/check_docs.py` 0 FAIL

## 逐条复核结果

**词表定成五个值**，判据是「这个编号还开着吗」必须机器读得出，其余信息留在备注后半段：

| 状态词 | 关闭了吗 |
| --- | --- |
| 已完成 | 关闭 |
| 设计已交付 | 开着 |
| 进行中 | 开着 |
| 未开始 | 开着 |
| 明确后置 | 开着 |

**「设计已交付」不能并进「已完成」。** 它是本条最要紧的一条判断：文档交付之后落地往往还差一大截，合成一个词会让守卫把一批还开着的编号判成关闭 —— **那比没有守卫更坏**，因为它会让人照着一个错的答案去改文档。

**收编的行数比立账时估的多。** 按旧的宽口径量出来是 27 行不合；换成这张固定词表之后是 **36 行** —— 多出来的那几行原先以「文档侧已完成」「文档已交付」「提案已出」「问题未答」这类各写一遍的说法开头，它们表达的是同一批状态，只是每处换了个词。**这正是为什么要词表而不是靠约定。**

**逐行判过，不是机械替换。** 几个需要真判断的：

- **「文档侧已完成」「文档已交付」「提案已出」→ 设计已交付**。三种说法说的是同一件事：文档那一半交了，落地没做。
- **「问题未答」「问题已被别的编号回答」→ 未开始**。前者是还没答，后者是答了但本条降级成一次将来的复看 —— 两者都还没动手。
- **「正典明确第一版不做」→ 明确后置**，而不是已完成。刻意不做仍然是开着的账。
- **「守卫已删，结论已内化」「载体已删」「裁定仍然有效」→ 已完成**。它们都没有剩余动作，只是结局与当初设想的不一样。
- **「接缝已就位、内容类型还没有」「第一版已由作者逐项试过」「尺寸那一半已交付」→ 进行中**。都已经动手，且剩余动作写得出来。

**改动只落在开头**：理由、链接与依赖一个字没动（`git diff` 逐行看过）。

**自核**：域表开头不合 **0** 行。各值的分布与「关闭」的编号总数由入口当场数出来，**本页不抄那几个数** —— 它们会随每一条的推进变，抄下来就是又一份会过期的副本。

**已归档那张表刻意不在词表管辖内**：它本身就是状态，一个编号进了那张表就等于关闭。守卫要读两处，这一点写进了台账那一节。

**本条的条目文件被脚本整份覆盖过一次，后来按内容重建。** 起因是一条 PowerShell 里对**模式字符串**调了 `.Replace` 而不是 `Regex.Replace`，于是模式串被当成新内容写进文件；而当时那条命令**退出码是 0**、还打印了「没有未勾项」（因为文件里已经没有任何勾选框了），所以第一眼看着像成功。**教训按「退出码 0 不等于成功」记**：改文件的脚本要自己核一遍改完的样子，不能只看有没有报错。改文件优先用编辑工具，不要在 shell 里拼正则。
