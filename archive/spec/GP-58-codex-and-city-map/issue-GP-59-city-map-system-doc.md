# GP-59：`design/地图与导航系统.md`（含地点数据与那道快速旅行接缝）

> **只读历史归档，不得作为现行依据。** 现行事实在[`地图与导航系统`](../../../design/地图与导航系统.md)：城区是一张写死的拓扑、边界点两边各声明一次而载入时对账、目的地名读对侧那张图的显示名、相邻关系算出来而不另存邻接表、切换是世界里的动作、刻意不做「已发现哪几张图」。**这个编号还没做完** —— 文档已交付而代码一行都没写，落地顺序与状态在[待办台账](../../../spec/issues/README.md)，不在本文。

## 目标

让「一张城区图声明什么、边界怎么配对、目的地名从哪来」只写在一处，而且那一处**不与侧视转场合成一套**。

## 来源

- PRD：[`prd-codex-and-city-map.md`](./prd.md) 的 `US-003` 与 `US-004`
- 起因：[玩法定位 · 跨系统基础设施](../../../canon/gameplay/玩法定位.md)写明城区那几张图需要地图与目的地指示、快速旅行推后但地点数据要能支撑；[玩法定位 · 场景规模](../../../canon/gameplay/玩法定位.md)写明边界切换与那三层辨识度。而[`关卡系统` · 边界与非目标](../../../design/关卡系统.md)**明写不做地图与导航**，`design/` 根下也没有一份管城区的文档 —— 于是「一张图要声明什么」无主。
- **`US-003` 与 `US-004` 合成本条**：它们是同一份文档，拆成两条会让同一份文件有两处进度。

## 依赖

无阻塞依赖。**与 `GP-58`、`DOC-59`、`DOC-60` 互相引用**，四条一起写完一起验。**落地**要等作者搭城区场景，所以排在 `ENG-21` 之后或与它同批。

### 一张图要声明什么

- [x] 写成一张字段表：标识、显示名的文本键、场景引用、一组边界点、默认落点、**它在城区示意底图上的位置**，外加**可选**的进入条件；**每格写明缺了怎么办**，缺必填项载入报错（[ADR-0009](../../../decisions/ADR-0009-编辑器主导的开发模式.md)）。
- [x] 显示名是**文本键**，不是写死的中文串 —— 走文本外置那条既有路径，口径在[文案写作规范](../../../production/文案写作规范.md)。
- [x] 场景引用、边界点摆位、默认落点与示意底图上的位置都是**作者填的导出字段**（[ADR-0009](../../../decisions/ADR-0009-编辑器主导的开发模式.md)的分工），本页只定它们要存在。
- [x] 写明示意底图上那一格留着的理由：不留它，将来要在手环上画出镇子全貌就得回头给每张图补一次；**底图画不画、什么时候画归界面侧与美术侧**。
- [x] **不复述图张数** —— 那个数的家在[玩法定位 · 场景规模](../../../canon/gameplay/玩法定位.md)，本页写链接。
- [x] **不列有哪些图、哪些地点** —— 那是内容（`ENG-5`），世界内来源在[世界观 · 主要设施](../../../canon/world/世界观.md)，具体分图与命名归 `NR-1`。

### 边界怎么配对、导航读什么

- [x] **边界点成对校验**：一张图声明「朝某方向通向另一张图」时，对侧必须反向声明回来；不成对的拓扑**载入当场报错**，不静默接上。
- [x] 写明这条与[`关卡系统` · 接得上只有两个条件](../../../design/关卡系统.md)那条转场点成对是**同形、不同一份**，并写出判据：两者判的不是同一件事（一条判「这两块现在能不能进候选」，一条判「这张写死的拓扑有没有写错」），失败处置也不同（不进候选／载入报错）。合成一份会让同一条判定同时回答两种问题，而且会给「把两套切换也合成一套」开门 —— 而正典刻意让它们不同。
- [x] **目的地名读对侧那张图的显示名**，边界点上没有自己的名字字段（结构约束）；改一张图的显示名，指向它的每一处提示跟着变。理由写明：边界点上另写一个标签会让同一张图有两个名字，而两者不一致时不报错。
- [x] **相邻关系由边界点算出来**，全库没有第二张邻接表（结构约束）—— [`存档系统` · 派生量不单独存](../../../design/存档系统.md)那条判据的一次应用。
- [x] 边界切换是**世界里的动作**，不接管输入所以不暂停世界（[玩法定位 · 弹界面接管输入就暂停世界，世界里的动作不暂停](../../../canon/gameplay/玩法定位.md)）。
- [x] 那段持续时长的量级在[玩法定位 · 场景规模](../../../canon/gameplay/玩法定位.md)、**本页写链接不复述**；值归 `GP-6`（手感量，只能实机走一遍），理由与转场读条时长同侧。
- [x] **不持有边界的辨识度**：那三层里的地形语言与摆位归作者，发光边界是无障碍设置里的一个开关；本页只声明边界点在哪。

### 地点数据与那道快速旅行接缝

- [x] 一个地点写成一张字段表：标识、显示名的文本键、**它在哪张图**、**图内落点**；缺一格载入报错。图内落点是作者在 Godot 里摆的节点。
- [x] 写明**一次快速旅行需要的全部输入本页都有了**（目标地点 → 它在哪张图 → 图内落点），而本页**不实现它**：不做选点、不定代价、不定解锁条件。
- [x] 同一处写明为什么不顺手把代价定下来：往返时间要等城区真的走得起来才第一次把一天的时间预算顶起来（那件事已经记过账），现在写出来会是一条判不到的规则。
- [x] 写明本页**不给城区开传送口子** —— [ADR-0013](../../../decisions/ADR-0013-战斗片段就是一屏.md)已经在关卡那一侧排掉过一次，本页不开第二个。
- [x] 登记读者：学生日程（[时间与经营 · 学生与派工](../../../canon/gameplay/时间与经营.md)）、施工队下单（[时间与经营 · 建造](../../../canon/gameplay/时间与经营.md)）、委托源（[战斗与关卡 · 两层难度，职责不重叠](../../../canon/gameplay/战斗与关卡.md)）各读地点那一格；**那几样系统本身明确后置，本页只留那一格**。

### 接已有的钩子与时机，不新开

- [x] 边界切换触[`事件系统` · 三类事件与它们各挂哪些钩子](../../../design/事件系统.md)那个「进入场景时」，**不新开一处钩子**（正典把钩子位置定死了）。
- [x] 边界切换触[`存档系统` · 存档位与续玩点](../../../design/存档系统.md)里「进出场景」那次续玩点写入，**不新开写入时机**。
- [x] 一张图声明了进入条件时，读[`主线推进系统` · 谁报进来、它读谁、它出给谁](../../../design/主线推进系统.md)那两个现成读口（某个节点已完成／某位标记已置位）；**本页不新开任何记账**，未置位时读作未满足、不报错也不当成已满足。
- [x] 写明「进不进得去」（一道门，读别人的位）与「去过没去过」（一份记账，本页不做）是两件事。
- [x] 接口那一节写成「谁调它、谁读它」一张表，并写明**挂载点到此为止**。

### 存档与那两条「不做」

- [x] 按[`存档系统` · 进哪一侧：判据一句话](../../../design/存档系统.md)判出：拓扑与地点数据**是内容、不进任何一侧**；「玩家在哪张城区图」**只进临时续玩点**（正式存档写在睡眠那一刻，那时他在床上）。
- [x] 在「下游同步」里**自己声明那个只进续玩点的分片**，四格填齐。
- [x] 续玩点里**只记「在哪张图」，不记图内坐标**；恢复时落在他走进那张图的那个边界点，那个边界点不存在时落在这张图声明的**默认落点**（结构约束）。理由写明：存坐标要回答「作者改了这张图的地形之后旧续玩点里的坐标落在障碍里怎么办」，而那**不报错**，兜底又正是 [ADR-0009](../../../decisions/ADR-0009-编辑器主导的开发模式.md)要避开的形状；粒度上它与 [ADR-0013](../../../decisions/ADR-0013-战斗片段就是一屏.md)那条「记的是哪一屏不是一个坐标」同形。
- [x] **不做「已发现哪几张图」的记账**：全库没有这个集合（结构约束）。理由自己写 —— 正典没有这条要求，城区不是探索对象（探索感靠外域关卡），而一千人的镇子里居民彼此认识、入所就配发手环（[世界观 · 人类避难所“星空”](../../../canon/world/世界观.md)、[世界观 · 多功能手环与治理](../../../canon/world/世界观.md)）。同一处写明这与图鉴那条收录形状**刻意不同，不是漏抄**。
- [x] **每日结算不为本页加一步**（结构约束）。**理由写在那份文档里，本条不抄**；要求是它**与图鉴那一条以及别处任何一条都不同源**，而两份各自写明对方那条是什么、为什么不一样。同一处写明**不列那份名单**。

## 实现笔记

### 设计决策

- **模糊点**：边界成对要不要与[`关卡系统` · 接得上只有两个条件](../../../design/关卡系统.md)那条转场点成对共用一份判定。
- **选择**：**同形，不同一份。**
- **理由**：判据是「会不会让同一条判据有两个家」，而两者判的不是同一件事 —— 一条判「一张写死的拓扑有没有写错」（载入那一刻，报错），一条判「任意两块这一次能不能进候选」（拼装那一刻，不进候选）。合成一份要让同一条判定回答两种问题、带两套失败处置；更要紧的是它会给「把两套切换也合成一套」开门，而正典刻意让城区（朝边界持续移动）与侧视（按键加读条）不同。**共用的是「方向要配对」这个形状，不是同一段判定** —— 两处各写了一条同名不同物条目互指。

- **模糊点**：续玩点里「在城区哪儿」要不要存坐标。
- **选择**：**只记「在哪张图」**，恢复落在他走进那张图的那个边界点，那个边界点不存在时落该图声明的默认落点。
- **理由**：存坐标要回答「作者改了这张图的地形之后旧续玩点里的坐标落在障碍里怎么办」，**而那不报错**；接住它要加一条兜底，而兜底正是 [ADR-0009](../../../decisions/ADR-0009-编辑器主导的开发模式.md)要避开的形状。改成图加边界点之后，需要成立的只有那个边界点还存在，不存在有明确去处。粒度上与 [ADR-0013](../../../decisions/ADR-0013-战斗片段就是一屏.md)那条「记的是哪一屏不是一个坐标」同形。正典对基地与城区只要求恢复到「退出时的当天当刻」—— 那是时钟，不是位置。

- **模糊点**：要不要抄图鉴那条收录形状，做一份「已发现哪几张图」。
- **选择**：**不做**，而且把「刻意不做」写进文档。
- **理由**：正典没有这条要求；城区不承担探索（探索感靠外域关卡），而一千人的镇子里居民彼此认识、主角入所就领了整合身份与定位的手环 —— 没有「地图要自己走出来」的设定空间。**写出来是为了它不被当成漏抄**：本页与图鉴看起来同类，而这一处恰好相反。

- **模糊点**：「某张图进不进得去」要不要本页自己记。
- **选择**：图上一个**可选**的进入条件，读[`主线推进系统`](../../../design/主线推进系统.md)那两个现成读口。
- **理由**：自己记会给「某件事发生过没有」开第二个家，而全库只该有一处；而「不做这条机制」又会把一个内容决定（废弃旧城区先不开放）写死成结构。可选字段不填时行为与全开完全一样，所以它不堵任何一条路。**同一处写明「进不进得去」（一道门）与「去过没去过」（一份记账）是两件事。**

### 偏离

- **方案怎么说**：`DOC-60` 原写[`感知与视野系统`](../../../design/感知与视野系统.md)一个字不用改（那一条属于图鉴那一侧，记在 `GP-58` 的偏离里）。
- **实际怎么做**：本条另外动了两份方案里没点名的文档 —— [`建造系统`](../../../design/建造系统.md)与[`活跃失衡系统`](../../../design/活跃失衡系统.md)各改一行。
- **为什么**：按量级数字那一轮查出它们各有一份副本（前者复述了切换那段时长，后者复述了城区图张数）。**按「修就修根」当场改成不复述加链接**，而不是记一条新账 —— 它们与本批答的正是同一个量。

### 权衡

**拆篇判断过程记在 `GP-58` 的「权衡」里**（两样一起判才说得清），本条只记与地图直接相关的那一半：**边界切换带一个蓄势计时**（朝边界持续移动才切），按判据字面它像一台机器 —— 但它是一条计时不是一张流转表，与侧视那条「按键加读条」同量级，而那一条只是[`关卡系统`](../../../design/关卡系统.md)里的一节。**所以判据没有逼出拆篇；真正让它单独成篇的是「多读者无主」**：[`关卡系统`](../../../design/关卡系统.md)明写不做它，而 `design/` 根下没有一份管城区的文档。

**「另存一张邻接表」考虑过**，读起来最直接。没选：它与边界点两份会分叉，而分叉时没有任何东西判得出来哪一份过期了（[`存档系统` · 派生量不单独存](../../../design/存档系统.md)那条判据的一次应用）。

**「在边界点上写目的地名」考虑过**，那样同一张图在不同入口可以有不同叫法。没选：同一张图会有两个名字，而两者不一致时不报错。

**「走到边界就自动切换」与「像侧视那样加一次按键」都考虑过**。自动切换会让沿着城墙走被反复切走；按键在城区是纯多余的一次操作 —— [`关卡系统`](../../../design/关卡系统.md)那道门的全部理由是「被追着往回跑时不该被切走」，而城区里没人追你。正典给的手段（朝边界持续移动一段）同时挡住误触又不要按键。

**「现在就把快速旅行的代价与解锁形式定下来」考虑过**。没选：往返时间要等城区真的走得起来才第一次把一天的时间预算顶起来，现在写出来是一条判不到的规则。**接缝只留三格数据。**

### 待确认

无。**本批不为本页新建 ADR**：最像候选的是「边界成对不与转场点共用一份」，但撤销成本只是改那两处载入校验，而「两处切换刻意不同」那条硬约束的家在正典 —— 再写一份等于给同一条约束加第二个家。
