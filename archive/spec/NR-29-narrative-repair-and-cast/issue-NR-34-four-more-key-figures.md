# NR-34：反派与要角补四人

> **只读归档 · 历史背景，不是现行依据。** 四个人的现行设定在[反派与要角](../../../canon/narrative/反派与要角.md)自己身上（`N-7` 起），格局在[主线故事](../../../canon/narrative/主线故事.md)节点 11，对不上时以它们为准。

## 目标

[世界观](../../../canon/world/世界观.md)定了编制或点名了张力的位置，人物侧各有对应的角色 —— 学院一级与二级满编，商会决策层有人。

## 来源

PRD：`spec/prd-narrative-repair-and-cast.md` 的 `US-006` 与 `US-007`（两条合成本条：它们改的是同一份文档的同一批位置 —— 总览表、剪影审计、命名说明，分两条会让那张表被改两次）。

立项理由：[世界观 · 权力结构](../../../canon/world/世界观.md)定了领袖 1 名与武学导师 2 名，[反派与要角](../../../canon/narrative/反派与要角.md)只有两名文学导师。武学那一侧管作战与外域探索，也就是委托的来源 —— 玩家整个周目都在接他们的委托却见不到人；领袖是穹盾改造这类「永久改变全城生存方式」决定的签字人。商会那一侧只有一个「不是高层、不是决策者」的档案员，而商会是主角的债主、是「唯一能不看学院意志行事的力量」，那处「既定价又放贷」的制度缺陷也挂在它身上。

无。

## 要补的四个人

名字按[人物 · 命名规则](../../../canon/characters/人物.md)定，已避开全库用过的字与同音（「锋」因与峰刃、峰岚同音换掉）。

- **持衡**（学院领袖，一级）：全所决策的最终签字人，中立到软弱 —— 他是签字的人，却不想成为做决定的人，所以他等下面吵出结果。这让「重大判决要公示」那条制度活着，也解释了危机里制度为什么失灵。
- **慎行**（武学导师，二级）：当年把主角改派去文职的那个人。善意的错配者，而且全程以为自己当年做对了。
- **执戈**（武学导师，二级）：主张靠武力压住外域，与断岳气味相近但在编制内。
- **权息**（商会决策层）：商会里真正算账的人，知道商会垮了整个避难所的市场就没了，所以压价与追债都是为了让商会活下去。他是那处制度缺陷的人形。

- [x] 四人编号从 `N-7` 起连续，不与既有编号冲突、不复用已删编号
- [x] 总览表、剪影防撞审计、命名说明三处都加进了四人
- [x] 四人各有进剪影的大件、签名色与默认姿态；签名色相邻的写明靠什么兜（[人物 · 签名色分配的三条约束](../../../canon/characters/人物.md)）—— 本轮新写了三对相邻组，其中云契对权息是全页最近的一对**而且同屏**
- [x] 慎行与执戈进「军人老兵」那一组；持衡进「学院制式长袍」那一组（他不是武官）—— 原先那组叫「两名文学导师」，现在三个人穿同一件袍子，分别压在下摆长度上
- [x] 权息与云契的分工写明：云契是发现东西不对的那个，权息是决定怎么用这件事的那个
- [x] 节点 11 导师层裂缝那一节写明四名导师各说各的、四条路各有各的死人方式，且**仍然没有挂牌派别**（[世界观 · 权力结构](../../../canon/world/世界观.md)）；领袖在场不表态是那一节新的重量所在
- [x] 四人都不违反[世界观 · 立场：动机可以理解，行为仍要追责](../../../canon/world/世界观.md)那三句 —— 四人各自那一节都明写了它怎么适用

- [x] 权息的行为对得上[世界观 · 货币、信贷与私产](../../../canon/world/世界观.md)那句「压价放贷的商会未必想害谁，可它造成的债务困境是真的」
- [x] 四人的剪影实机确认并进 `NR-26`，本条不做
- [x] **顺带做掉了 `NR-36` 的一半**：主角进「军人老兵」那一组的审计随这张表一起写了（那一格反正要重写）。主角与慎行是那一组最要紧的一对 —— 都靠「一条手臂不对称」被认出来，而方向相反
