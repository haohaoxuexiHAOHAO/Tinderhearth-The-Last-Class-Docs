# PRD：叙事正典的矛盾修复与要角补位

> **只读归档 · 历史背景，不是现行依据。** 本轮的现行事实全部在[世界观](../../../canon/world/世界观.md)、[人物](../../../canon/characters/人物.md)、[主线故事](../../../canon/narrative/主线故事.md)、[反派与要角](../../../canon/narrative/反派与要角.md)、[学生群像](../../../canon/narrative/学生群像.md)、[常驻NPC](../../../canon/narrative/常驻NPC.md)与[`主线推进系统`](../../../design/主线推进系统.md)那几份自己身上；剩余动作在[待办台账](../../../spec/issues/README.md)。**与那些对不上时以它们为准，不以本页为准。**

## 1. 概述

`canon/` 四域读下来，故事骨架与机制咬得很紧，但有一批**正典内部字面互斥**的地方，以及一批**正典点名要过、却没有落点**的空缺。它们现在还只是文档问题；一旦开始写台词与演出（`NR-5` 起那几条），每一处都会分叉成两个版本。

三类问题：

- **矛盾**：五个主要反派活了三百年，而第 1 级正典写明灵不制造数百岁的存在；基地交接的时点在人物与主线故事两页各有一个答案；「节点 15 的选择影响关系能不能到最高档」与「关系只涨不降」「选择没有正确答案」三条不能同时成立；救回那条支线的完成判据会惩罚推进快的玩家，而正典自己那段论证正好反对这件事。
- **空缺**：学院上层（领袖与两名武学导师）、商会决策层在世界观里定了编制与张力，人物一个没有；主角真实形态的视觉全库没有家；节点 16 学生那条战线没写它是怎么呈现给玩家的。
- **撞车与遗留**：晦炎与峰刃的剪影都是「宽肩加两条粗臂」且在节点 16 正面对上；节点 19 那一条里有三段重复且结论相反的文字。

本需求把这些一次性收掉，不写台词、不做实现。

## 2. 目标

- `canon/` 四域之内没有两处字面互斥的事实；有分歧时以层级高的那一侧为准。
- 世界观定了编制或点名了张力的位置，人物侧各有对应的角色。
- 每一个会同屏的角色对，剪影上分得开，且有一条写下来的审计结论。
- 完美结局的每一条条件，一个按正典玩法走完的玩家都拿得到，不存在没说出口的时长门槛。
- 节点 16 两条战线各自怎么呈现，正典里查得到；「玩家只操作主角」那条不必开例外。

## 3. 上游约束

- [世界观 · 灵](../../../canon/world/世界观.md)：灵不按能力强弱延长最大寿命、不制造数百岁的统治阶层，主角的近乎永生是不可复制的异常。**这是三百年那条矛盾的上游，本需求不改这条规律，只让五个反派各有一条不违反它的存续方式。**
- [世界观 · 活跃失衡的规模](../../../canon/world/世界观.md)：掌握程度不足而失衡很高时增益是畸形的（智力大幅下降、不再闪避防御），掌握极高那一档只有主角到过。**约束那五个人的存续方式必须同时解释他们为什么仍然理性。**
- [世界观 · 权力结构](../../../canon/world/世界观.md)：学院内部四级，二级是文学导师 2 名与武学导师 2 名，一级是领袖 1 名；四名导师立场不同但没有挂牌派别。**这是要补哪几个位置的唯一依据，编制数不由本需求改。**
- [世界观 · 货币、信贷与私产](../../../canon/world/世界观.md)：抵押物由放贷商会自己的估值人员定价，这是一处已知的制度缺陷；商会是唯一能不看学院意志行事的力量。**这是商会那个新人物的位置与他的行为依据。**
- [世界观 · 立场：动机可以理解，行为仍要追责](../../../canon/world/世界观.md)：本作没有绝对的坏人，苦衷不免除责任，后果责任不以主观故意为前提。**约束四个新人物都不是纯粹的恶，也都不因出发点好而免责。**
- [人物 · 基地、债务与传承](../../../canon/characters/人物.md)：离开时基地交给学生，债务必须在那之前还清；他考取了教官凭据但遴选没排上，学院顾及身体损伤改提了文职位置。**前半是交接时点那条矛盾里层级更高的一侧；后半是那名武学导师的钩子出处。**
- [人物 · 面具、右臂与伪装](../../../canon/characters/人物.md)：本作不展示完整真容，灵手是有范围与消耗的外置工具、不是身体完整化也不是力量刻度。**约束真实形态的视觉不得摘面具、也不得把灵手写成等级仪表。**
- [人物 · 剪影防撞审计](../../../canon/characters/人物.md)：关掉颜色只看黑剪影判分不分得开，不能靠加小配件；审计要两个视角各做一遍。**这是晦炎那处撞车与四个新人物剪影的判据。**
- [主线故事 · 三条重要支线](../../../canon/narrative/主线故事.md)：救回那条「还在照护中永远算进行中」的理由是「拿一个他控制得了的时点去结算一条他控制不了的进度，等于把全部风险摊给玩家」。**这段论证就是改判据的全部依据 —— 本需求让它兑现另一半。**
- [战斗与关卡 · 玩家操作谁](../../../canon/gameplay/战斗与关卡.md)：玩家直接操作主角，队友由 AI 控制。**这条本轮不改** —— 节点 16 学生那条战线做成演出，所以它不需要例外。
- [`剧情演出系统`](../../../design/剧情演出系统.md)：跳过必须把脚本声明的状态变更一次性全部应用（承重项，有反证）。**这是那段演出可跳过的全部依据，本需求不新增机制。**
- [玩法定位 · 剧情演出：一律引擎内，不做视频](../../../canon/gameplay/玩法定位.md)：复杂度控制在镜头、站位、对话与简单动作，不做骨骼动画级演出。**这是那段演出只能是蒙太奇的上限来源。**
- [`主线推进系统`](../../../design/主线推进系统.md)：救回那条的上游约束里写着「完成就是救回成功」，支线三那一节按一位标记落地。**判据改了它要跟着改，属下游对齐。**
- [`人际系统`](../../../design/人际系统.md)：关系涨法只收正值，并有一条单调性反证。**这是节点 15 那条矛盾里不能动的一侧。**
- [ADR-0016](../../../decisions/ADR-0016-推进挂在曾经发生过的事上.md)：推进挂在曾经发生过的事上，解锁与关闭条件都不许引用天数。**约束新增的判据与那段剧情的触发都挂事件、不挂日期。**
- [ADR-0021](../../../decisions/ADR-0021-每个朝向各画一套不做水平翻转.md)：每个朝向各一套素材，所以挂在单侧的大件不会换边。**这是晦炎改单侧武化成立的前提。**

**依赖关系**：`NR-24`（救回对象的设计与剧情）的完成判据被本需求改动，本需求只改判据、不定那个人是谁。节点 16 那条战线的关卡与操作实现不在本需求内，本需求只定正典事实并记一条账。

## 4. 用户故事

### US-001：五个三百年前的人各有一条存续方式

**描述**：作为读正典的人，我想知道夙渊与四将首凭什么活到 3297 年，以便这几个角色不与灵的寿命规律冲突。

**做成什么**：铸霜灵殇之前就在做「把有意识的存在封存」的实验，灾难来时把自己与几名同行一起封了进去，解封条件是灵场恢复到某个程度 —— 所以他们不是活了三百年，是刚醒。夙渊另算：他是真正扛过那场灾难的人，代价就是苍冥那句现成的「不完全属于活人范畴」。望渚的成名年代改到近几十年，他本来就不需要是旧时代的人。

**验收标准**：

- [ ] 可核对：[世界观 · 灵](../../../canon/world/世界观.md)多一句边界——寿命那条管的是活着的时间，封存不延长寿命（被封存的人没有活过那段时间），所以它不是长寿的后门
- [ ] 可核对：夙渊、四将首总论、铸霜、苍冥四处各写明自己那一条存续方式，彼此不冲突
- [ ] 可核对：那几个人为什么仍然理性有答案（失衡是醒来之后才开始累积的）
- [ ] 可核对：[主线故事](../../../canon/narrative/主线故事.md)节点 7 与[反派与要角](../../../canon/narrative/反派与要角.md) N-1 对望渚是哪个年代的人说同一件事
- [ ] 可核对：`python tools/check_docs.py` 0 FAIL

### US-002：基地交接只发生在告别那一幕

**描述**：作为玩家，我想在主角真正离开时才看见基地易手，以便节点 18 之后我还在经营的那个基地不是一个已经交出去的东西。

**验收标准**：

- [ ] 可核对：节点 17 不再出现基地移交，只写世界稳定下来；真名与交接都在节点 19
- [ ] 可核对：节点 18 不再宣称基地已由学生运营
- [ ] 可核对：[人物 · 基地、债务与传承](../../../canon/characters/人物.md)那句「交接落在哪一幕」指向的位置与主线故事一致
- [ ] 可核对：全作只剩一次道别

### US-003：节点 15 的选择不再影响关系涨幅

**描述**：作为玩家，我想让每个学生的那次选择只改变后续内容，不改变我能不能拿到完美结局，以便那九次选择真的没有正确答案。

**验收标准**：

- [ ] 可核对：[主线故事](../../../canon/narrative/主线故事.md)节点 15 里「选择的结果影响关系能不能达到最高档」那句已删
- [ ] 可核对：[学生群像](../../../canon/narrative/学生群像.md)九人那节「影响关系」的说法改成影响后续内容（谁出现在哪一幕、说什么）
- [ ] 可核对：改完之后「关系只涨不降」「全员最高档是完美结局条件」「选择没有正确答案」三句同时成立

### US-004：救回那条支线分成三档，完美结局认中间那档

**描述**：作为一个把其他条件都做到了的玩家，我不想因为推主线推得快而拿不到完美结局，以便那条支线的进度不由一个我控制不了的时点结算。

**做成什么**：

| 档 | 判据 | 给什么 |
| --- | --- | --- |
| **完成** | 那个人被带回基地，且没有死 | 完美结局条件二认这一档 |
| **完满** | 他真的活过来了 | 一段属于他的戏；赶在节点 17 之前的话他还会站在黎明那一幕里 |
| **失败** | 他死了 | 终态，不能换对象重来 |

那段戏挂在「他活过来」这件事上，不挂任何节点 —— 救回本来就没有关闭时间点。演出方向定为**他第一次能说话**：世界观写明被侵蚀到失去自主的生命已经无法被沟通，所以玩家照护的一直是一个不能对话的人。机制上不给额外奖励，他活过来之后自然成为可建立关系的常驻 NPC，那就是回报。

**验收标准**：

- [ ] 可核对：支线三那一节改成三档，「完成」与「完满」两个词各只有一个意思
- [ ] 可核对：完美结局条件二读「完成」那一档，不读「完满」
- [ ] 可核对：「失败必须是可能的结局之一」原封不动成立，且仍只由那个人死掉触发
- [ ] 可核对：那段戏的触发条件里没有任何天数、日期或节点编号
- [ ] 可核对：[`主线推进系统`](../../../design/主线推进系统.md)上游约束里「完成就是救回成功」那句与支线三那一节跟着改；标记位怎么落由那一份自己定，本 PRD 不指定
- [ ] 可核对：台账 `NR-24` 的备注跟着改（判据变了）

### US-005：节点 16 学生那条战线是一段可跳过的演出

**描述**：作为玩家，我想看见学生们打赢他们那一场，又不想被一段没有悬念的对打困住，以便那场胜利我看得到、也不必坐着等。

**做成什么**：那条战线走剧情演出，不走关卡 —— **玩家全程仍然只操作主角**，那条正典不开例外。呈现形式是**蒙太奇**：把几个有重量的瞬间接起来，不从头打到尾。随时可跳过，而跳过不漏任何结果。它排在**主角路线之后**：先打完最终战、完全不知道学生那边怎么样，再看他们赢 —— 主角路线的压迫感因此不被提前泄掉，也正好对上「他们回来时，主角已经结束了另一条路线」。

**验收标准**：

- [x] 可核对：[主线故事](../../../canon/narrative/主线故事.md)节点 16 写明学生那条战线是演出而不是关卡，且排在主角路线之后
- [x] 可核对：那段演出的复杂度在[玩法定位 · 剧情演出：一律引擎内，不做视频](../../../canon/gameplay/玩法定位.md)写明的上限之内，不要求任何新素材
- [x] 可核对：跳过由[`剧情演出系统`](../../../design/剧情演出系统.md)既有那条承重约束覆盖，本需求不新增机制
- [x] 可核对：[战斗与关卡](../../../canon/gameplay/战斗与关卡.md)与[`角色动作状态系统`](../../../design/角色动作状态系统.md)两份在本轮**未被改动** —— 零改动正是选这个方案的理由
- [x] 可核对：那段演出的脚本内容记一条账（并进 `NR-20`），本需求不写

### US-006：学院上层补三人

**描述**：作为玩家，我想在那些改变全城的决定背后看见具体的人，以便学院不是一台没有脸的机器。

**做成什么**：新增 `N-7` 起三名角色，各带身份背景、性格、叙事功能、出场节点、视觉锚点与命名说明。

- **持衡**（领袖）：全所决策的最终签字人，中立到软弱 —— 他是签字的人，但不想成为做决定的人，所以他等下面吵出结果。这让「重大判决要公示」那条制度活着，也解释了危机里制度为什么失灵。
- **慎行**（武学导师）：当年改派主角去文职的那个人。善意的错配者，不是坏人，而且全程以为自己当年做对了。
- **执戈**（武学导师）：主张靠武力压住外域，与断岳气味相近但在编制内。

**验收标准**：

- [ ] 可核对：三人各有一节，节内小标题与既有要角同构
- [ ] 可核对：总览表、剪影防撞审计与命名说明三处都加进了他们
- [ ] 可核对：节点 11 导师层裂缝那一节写明加入武学两票之后的格局，且四名导师仍然没有挂牌派别（世界观那条）
- [ ] 可核对：三人都不违反「没有绝对的坏人」与「苦衷不免除责任」
- [ ] 可核对：慎行与主角那段过往不改[人物](../../../canon/characters/人物.md)已写的事实（没有人做错什么、结果照样是他进不去）

### US-007：商会补一名决策层

**描述**：作为玩家，我想在节点 5 与节点 9 面对一个能拍板的人，以便债务那条张力有对手而不只有一张柜台。

**做成什么**：新增 `N-10` **权息**。商会里真正算账的人，知道商会垮了整个避难所的市场就没了，所以压价与追债都是为了让商会活下去。他就是那个「既定价又放贷」制度缺陷的人形。与云契的关系写明：云契是发现东西不对的那个，权息是决定怎么用这件事的那个。

**验收标准**：

- [ ] 可核对：一节完整，含出场节点（节点 5、9，与云契同场但分工不同）
- [ ] 可核对：总览表、剪影审计与命名说明三处都加了他
- [ ] 可核对：他的行为对得上[世界观](../../../canon/world/世界观.md)那句「压价放贷的商会未必想害谁，可它造成的债务困境是真的」

### US-008：真实形态的视觉

**描述**：作为要画它的人，我想知道那一刻屏幕上变了什么，以便节点 16 那次转变画得出来。

**做成什么**：面具**不摘**（摘面具留给节点 19，两处不抢同一个揭晓）；灵手**显形**，这是全作唯一一次它作为力量而不是工具出现；剪影靠披风被灵流吹起加右侧多出一只手改变 —— 变化全落在原本「缺」的那一侧，不新加大件。

**验收标准**：

- [ ] 可核对：[人物](../../../canon/characters/人物.md)形象那一节写明这三样，且不与「本作不展示完整真容」「灵手不是力量刻度」冲突
- [ ] 可核对：它与主角常态剪影的分别写明（同一个人的两个形态要一眼看出是同一个人）
- [ ] 作者实机确认：那一刻的变化在侧视那一档读不读得出来
- [ ] 可核对：素材记一条美术账，本需求不画

### US-009：晦炎改单侧武化，并把跨页那几对审计补齐

**描述**：作为玩家，我不想在最终战把敌人和自己的学生看混，以便节点 16 那一场认得出谁是谁。

**做成什么**：晦炎的黑铁武化壳改成**只在一侧手臂**。峰刃那对厚臂铠是对称的，所以不对称就分开了 —— 而且它顺带说了一件事：他的研究是在自己身上做的，只做得起一边。同时补两处审计：晦炎对峰刃（跨页、节点 16 同屏），以及主角进「军人老兵」那一组（他的对外侧写就是停滞老兵，而凛术与断岳都会与他同屏）。

**验收标准**：

- [ ] 可核对：晦炎那节的大件改成单侧，「身体就是武器、手里不带东西」那条不变
- [ ] 可核对：[反派与要角](../../../canon/narrative/反派与要角.md)审计那节多一条跨页项写明晦炎对峰刃靠什么分开
- [ ] 可核对：「军人老兵」那一组里加入主角，写明他靠什么与凛术、断岳分开
