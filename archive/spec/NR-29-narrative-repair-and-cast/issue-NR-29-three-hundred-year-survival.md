# NR-29：五个三百年前的人各有一条存续方式

> **只读归档 · 历史背景，不是现行依据。** 现行事实在[世界观 · 灵](../../../canon/world/世界观.md)与[反派与要角](../../../canon/narrative/反派与要角.md)、[常驻NPC](../../../canon/narrative/常驻NPC.md)那几节自己身上，对不上时以它们为准。

## 目标

夙渊与四将首活到 3297 年这件事，与[世界观 · 灵](../../../canon/world/世界观.md)那条「灵不制造数百岁的存在、主角是不可复制的异常」不再冲突；并且他们为什么仍然理性也有答案。

## 来源

PRD：`spec/prd-narrative-repair-and-cast.md` 的 `US-001`。

立项理由：那五个人被写成「灵殇之前就已声名卓著」，正典没有给其中任何一个写存续机制。唯一的暗示（苍冥那句「夙渊已经不完全属于活人范畴」）解释不了苍冥自己，也解释不了另外三个。第二层冲突：他们都是高失衡的强者，而正典写明掌握不足而失衡很高时智力大幅下降、攻击欲极强、不再闪避防御 —— 那与「冷静的学者」「清晰的逻辑」对不上，而掌握极高那一档只有主角到过。

## 依赖

无。它是本轮优先级最高的一条，下游那批台词与演出都等它定。

## 验收标准

- [x] [世界观 · 灵](../../../canon/world/世界观.md)多一句边界：寿命那条管的是**活着的时间**，封存不延长寿命 —— 被封存的人没有活过那段时间，所以它不是长寿的后门
- [x] 铸霜那节写明他灵殇之前就在做「把有意识的存在封存」的实验，灾难来时把自己与几名同行一起封了进去，解封挂灵场恢复程度
- [x] 四将首总论写明他们是刚醒的人，不是活了三百年的人
- [x] 夙渊那节写明他是自己扛过来的那一个，代价就是「不完全属于活人范畴」（沿用苍冥那节现成的那句，不另造机制）
- [x] 苍冥那节与铸霜那条存续方式对得上（她也在被封存的那几个人里，或写明她另一条来路）
- [x] 「他们为什么仍然理性」有答案：失衡是醒来之后才开始累积的，时间不够长
- [x] 望渚的成名年代改到近几十年，[主线故事](../../../canon/narrative/主线故事.md)节点 7 与[反派与要角](../../../canon/narrative/反派与要角.md) N-1 两处说同一件事；他研究灵殇的材料来源不再含「对幸存者的访谈」（那些人早已过世）
- [x] 「为什么是现在」有答案：灵网重建到 3297 年才够浓，他们醒来与魔源逼近阈值同源，不是巧合

### 实现中查出的同类实例（同一条矛盾，并进本条）

写这一轮时按「灾前 / 灵殇后不久 / 避难所初建」搜了一遍 `canon/`，发现常驻 NPC 那一页还有几个人按字面也是三百岁。**它们不是新问题，是同一条矛盾的其余实例**，所以并进本条而不另开编号 —— 分开会让「三百年这件事」有两个归处。

- [x] **苏怀**（`C-5`）：「她父母在灵殇后不久生下她」与总览表「灵殇初代幸存者之女」都要改。名字那层意味（「苏醒的怀抱」、那时人们刚觉得活下去是可能的）**必须保住** —— 避难所三百年里有过好几次这样的时刻，把时间挪到几十年前的一次就够，不必绑在灵殇上
- [x] **三喜**（`C-9`）：「灾前就住在这一带的原住民」与「避难所初建时期的决策过程……她亲眼看到的不一样」都要改。她仍是最老的居民之一、仍记得别人不记得的事，只是跨度从三百年变成几十年 —— **改完「她亲眼看到」才真的成立**，她的核心功能（见过林泽的父母）本来就只需要几十年
- [x] **老苗**（`C-1`）：「他会开始说一些更老的事——包括避难所初建时期、某些人当时做的决定」要改成他这辈子里的事，或写明那是他听来的
- [x] **招娣**（`C-4`）那句不用改：「灾前就活在这里的家庭里这样取名的习惯延续了下来」说的是习惯延续，不是她本人的年纪 —— 核过原文，这一处成立
- [x] 改完再搜一遍那几个词，确认 `canon/` 下没有第二批漏网的（只剩招娣那一处，如上）
