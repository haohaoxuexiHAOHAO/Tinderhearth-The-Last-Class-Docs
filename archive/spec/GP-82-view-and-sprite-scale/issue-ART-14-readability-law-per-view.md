# ART-14：可读性铁律按视角分开写

> **历史背景·非依据。只读归档件，不得作为现行依据。** 现行事实见同目录 [`prd.md`](./prd.md) 的「归档三问」；待办见[待办台账](../../../spec/issues/README.md)。

## 目标

让剪影与签名色那套识别方法论在两种视角下各有一个准确的判定像素数 —— 防撞审计才有尺子可用。

## 来源

- PRD：同目录 [`prd.md`](./prd.md) 的 `US-006`

## 依赖

依赖 `GP-85` —— 本体高度按视角分是那份 ADR 的取舍，本条是它在第 2 级正典那一侧的落地。

**它动的是[人物](../../../canon/characters/人物.md)**，层级高于玩法定位，所以改之前那份 ADR 必须已经接受。

## 验收标准

- [x] [人物 · 可读性规则按视角分](../../../canon/characters/人物.md)改成**按视角分别陈述**，节名不再带俯视那个数
- [x] 「相机放大不增加信息量」那段按新结论重写 —— 侧视不再拉近，所以原来那句「屏幕上占 64px、素材只有 32px」不成立了；改写后还点出**由此少了一个陷阱**（不会再有人按放大后的余量加细节）
- [x] 那一节仍然主张主记忆点落在**剪影、签名色与一个大轮廓元素**上 —— 本条只改像素数，不改方法论
- [x] 写明侧视多出来的那一档可绘制信息量可以用在哪里（动作姿态的读数、大件的甩动），以及仍然不能用在哪里（脸与小道具照旧不是唯一识别符，理由是同一个角色不能在两个视角里靠不同的东西被认出来）
- [x] 写明**剪影防撞审计不必为水平翻转让步**（[ADR-0021](../../../decisions/ADR-0021-每个朝向各画一套不做水平翻转.md)）：不对称的大件不会换边，所以它可以放心当识别杠杆用 —— 而不对称本来就是剪影最有效的那根杠杆
- [x] **不写「什么算不对称」那条判据**：`ADR-0021` 把这个判断交回作者，写一条判据等于把它请回来。此处只记「不必让步」这个结果
- [x] 全库搜一遍，别处没有残留的旧像素数副本
- [x] `python tools/check_docs.py` 0 FAIL

**多写了两条**：

- **审计要两个视角各做一遍。** 俯视的轮廓与侧视的轮廓不是同一个形状，在一个视角里分得开的两个角色，在另一个视角里可能撞上。原先只有一个视角，所以这一层不存在。
- **信息量按俯视那一档判**（它更严，过了它侧视自然过），**但剪影两个视角各看一遍**。不分开写的话「两种都要过」会被读成什么都要判两遍。

**改名连带动了五处引用**：[学生群像](../../../canon/narrative/学生群像.md)两处、PRD 两处，加 [ADR-0020](../../../decisions/ADR-0020-侧视不拉近而把角色画大一档.md) 背景里一处。**ADR 那处只改链接文字，论点未动** —— 与 `GP-83` 改 `ADR-0013` 同一处理。归档件里还有一处，**按归档边界不改**（检查器也不判归档件）。
