# ART-11：地形交接的画法与基地要画哪几套

> **历史背景·非依据。只读归档件，不得作为现行依据。** 现行事实见同目录 [`prd.md`](./prd.md) 的「归档三问」；待办见[待办台账](../../../spec/issues/README.md)。

## 目标

让作者算得出「我还差几套瓦片」，并知道交接处那些光影细节哪一笔留得住、哪一笔换邻居就不对。

## 来源

- PRD：同目录 [`prd.md`](./prd.md) 的 `US-003`

## 依赖

依赖 `ART-10`（两种机制先写清）与 `GP-82`（地形种类那一行在正典）。

## 验收标准

- [x] 写明地形交接的两种画法及各自的套数增长：**配对法**（会挨着的每一对各一套）与**叠加法**（每种地形留透明后分层叠加），并给出什么时候该从前者切到后者的判据
- [x] 写明本轮**保持配对法**与理由（种类少时套数一样多，而交接处那几笔正是画面好看的地方）
- [x] 写明交接处光影细节的归属判据：**这一笔画的是本地形自己受的影响，还是对方长出来的东西** —— 前者（岸比水面高所以水面靠岸有一条暗带、水面反光）任何邻居都成立，留在本地形那一套里；后者（探进水里的草叶）才是配对法真正在买的东西
- [x] 写明切到叠加法时要动的只有「对方长出来的东西」那几笔，别的一笔不用改
- [x] 写明**天然裸土与已耕地是两样东西**，各走一种拼接；装饰性铺地**若做**才有，归的编号写链接不复述状态（这两条落在分层那一节，与 `ART-10` 同一张表，不重写第二份）
- [x] 写明基地会挨着的天然地形是哪几对，**种类数不复述**（写链接指内容规模基准那一行）
- [x] 写明「**让某两种地形之间总隔一圈别的**」是一条省素材的纪律，并写明哪一对现在靠它省掉了
- [x] 写明已耕地挨着任何天然地形都不需要配对贴图 —— 它是独立叠加层、硬边收口
- [x] 写明**耕地要干与湿两套**，形状相同只换色带；湿的必须逐格看得出来（看不出来玩家会重复浇或漏浇，与「哪一格锄过」是同一条逐格反馈）
- [x] 写明为什么不用代码统一压暗来做湿耕地（像素色带每一档都该有职责）
- [x] `python tools/check_docs.py` 0 FAIL

**多写了一条代价**：那条「隔一圈草」的纪律换来省一套素材，代价是**地图上从此不能出现泥滩直接入水那种地貌**。不写出来的话，将来画地图的人会以为它只是个建议，然后画出一片没有贴图能拼的岸。
