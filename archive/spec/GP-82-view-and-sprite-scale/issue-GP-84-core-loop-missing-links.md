# GP-84：核心循环图补上缺的环节

> **历史背景·非依据。只读归档件，不得作为现行依据。** 现行事实见同目录 [`prd.md`](./prd.md) 的「归档三问」；待办见[待办台账](../../../spec/issues/README.md)。

## 目标

让核心循环图上看得见接委托、吃饭与治疗 —— 这三样正典别处都写了，只有图上没有。

## 来源

- PRD：同目录 [`prd.md`](./prd.md) 的 `US-005`

## 依赖

无。它与本轮其余条目不相干，可以任何时候做。

## 验收标准

- [x] [玩法定位 · 核心循环](../../../canon/gameplay/玩法定位.md)那张图里出现**接委托**，并接在出征那一支的上游（委托板是出征唯一的来路）
- [x] 图里出现**粮食与吃饭**，并与精力那条闭环连上（断粮降精力上限，而精力是图里那个共同预算）
- [x] 图里出现**治疗与照护**，并与花钱那一环连上（与还款、建造并排，看得出是同一笔钱在抢）
- [x] 图里每个新增环节都能在[时间与经营 · 治疗与照护](../../../canon/gameplay/时间与经营.md)或[战斗与关卡 · 委托与关卡](../../../canon/gameplay/战斗与关卡.md)找到对应规则；**图本身不新增任何规则**
- [x] 图下面那段闭合点的说明跟着改，且不与图打架
- [x] 新增的三处**一个数都没写**：委托只写「有额度也有截止」、粮食只写流向、治疗只并进支出那一行
- [x] `python tools/check_docs.py` 0 FAIL

**闭合点从四处变五处**：**粮食单独算一条，不并进「金钱与材料」。** 理由写在图下面 —— 两者的失败方式不一样：金钱缺了只是买不起东西，粮食缺了直接压低明天的精力上限，而精力是图里那个共同预算。它同时是开局那条硬约束（粮食储备必须够撑到第一次收获）的来源。

**给三处新增各配了一句理由**，因为「图里为什么要有它」答不上来的话，下一个人会觉得图太挤又把它删掉：委托板是出征唯一的来路且带额度与截止；粮食是另一条账不是产出的一个例子；治疗是一笔支出不是善后步骤。

**一处观察到但没改**：图里原有的「教学（一天一次）」带着一个数。它是教学额度这条规则自身的形状（额度就是一次），不是可调数值，所以留着 —— 但它确实是图里唯一一个数字，记在这里免得以后被当成漏检。
