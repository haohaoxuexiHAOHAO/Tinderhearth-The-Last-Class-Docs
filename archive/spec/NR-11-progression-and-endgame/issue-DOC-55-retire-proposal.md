# DOC-55：处理掉那份标着「不得作为依据」的提案

> **只读历史归档，不得作为现行依据。** 结论是删，而仍然有用的那一半迁进了 [ADR-0016](../../../decisions/ADR-0016-推进挂在曾经发生过的事上.md) 的候选表；体裁规则仍在 [ADR-0010](../../../decisions/ADR-0010-文档体裁与系统文档归位.md)。

## 目标

让全库不再有一份标着「不得作为依据」的文档挂在索引里，并把 `proposals/` 空了之后体裁表怎么办这件事答掉。

## 来源

- PRD：[`prd.md`](./prd.md) 的 `US-006`
- 起因：`design/proposals/推进与时间轴.md` 从第 3 批起每一批都在非目标里写「不动它，届时重写或删」。本批就是那个「届时」。

## 依赖

`NR-11`（结论要先有落点，才判得出提案还剩什么问题没被回答）。

- [x] 结论是删的话：同批从[系统文档与提案索引](../../../design/README.md)的提案表里摘掉那一行，并从[待办台账](../../../spec/issues/README.md)「系统深化顺序」档 0 那一格里摘掉对它的引用（那一格由 `DOC-57` 一并改写，本条只负责「不再引用它」这一半）。
- [x] 结论是删的话：全库搜不到指向它的链接；**反引号里提到它名字的地方也过一遍**。

- [x] `python tools/check_docs.py` 0 项必须修复、**0 条提示**（「从 README 无法到达」那条提示尤其要看）。

## 实现笔记

### 设计决策

**逐节判「结论迁出之后它还回答什么问题」：**

| 它那一节 | 迁出之后还回答什么 |
| --- | --- |
| 三处对不上的账（主线年份与还债曲线、那个没有载体的全局量、关系那个量的第一版档位） | **零** —— 三处都已经不成立：年份读法在正典写清了、那个量由[活跃失衡](../../../canon/world/世界观.md)取代、关系早已收成一个量 |
| 四类解锁条件（含天数下限） | **零** —— 本批收成两类，而它被放弃的那一类作为候选写进了 [ADR-0016](../../../decisions/ADR-0016-推进挂在曾经发生过的事上.md) |
| 那个全局量的结构 | **零** —— 正典写明公共建设不是一个独立的量 |
| 共同体选择链的名单 | **零** —— 迁进[`主线推进系统`](../../../design/主线推进系统.md) |
| 结算里插一步推进检查 | **零，而且是反的** —— 本批的答案是不加步 |
| 六处「要正典自己补的话」 | **零** —— 已全部补过或作废 |

- **选择**：**删**。
- **理由**：它一个问题都不回答，而**仍然有用的那一半（被放弃的那条路与它的代价）已经迁进 `ADR-0016` 的候选表**；留着它就是留一份标着「不得作为依据」却还会被搜到的文档 —— 前七批每一批都要在非目标里写一句「不动它」，那一句本身就是它的维护成本。git 保存历史。

- **模糊点**：`proposals/` 空了之后那张体裁表怎么办。
- **选择**：**体裁表那一行不动**（只把「位置」那一格从指向被删文件的链接改成纯路径），「提案」那一节改成一句「现在没有进行中的提案」加一句体裁规则仍然有效。
- **理由**：体裁规则不因为「此刻恰好没有一份」而消失 —— `/to-design` 随时会再产出一份，而检查器那条体裁归位判定照旧管着它。删了那一行，下一个写提案的人无处可查；而留一张空表不如留一句话。

### 偏离

- **方案怎么说**：「`archive/` 一个字不改」是历批的边界。
- **实际怎么做**：改了一处 —— `archive/spec/GP-43-economy-and-building/issue-DOC-31-batch-end-to-end.md` 里那个指向被删文件的链接**去掉了链接、留下全部文字**，并在同一处注明那份提案已删。
- **为什么**：删文件让那条链接变成断链，而检查器对 `archive/` 下的断链同样判失败 —— 不改它，全库跑不绿。**去链接不改写内容**：一个字没删、一句理由没动，只是不再可点。这是两条纪律相撞时取的最小动作。

### 权衡

**「把它移进 `archive/` 而不是删」考虑过** —— 体裁表写着提案「结论迁出后归档」，归档才是常规处置。没选：它的结论不是「迁出」而是**被推翻**，归档件的作用是回答「当时为什么这么定」，而它从来没有被定过（整份标着未定草稿）。留一份论证天数下限与那个已作废全局量的文档在 `archive/` 里，只会让以后搜到它的人重新读一遍已经错了的前提。**而且移它同样要改那条 `archive/` 链接** —— 归档并不省下那一处。
