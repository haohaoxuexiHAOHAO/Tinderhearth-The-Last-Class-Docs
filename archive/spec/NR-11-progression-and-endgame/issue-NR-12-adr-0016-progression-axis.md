# NR-12：`ADR-0016` 推进挂在「曾经发生过的事」上，不挂日期

> **只读历史归档，不得作为现行依据。** 现行事实在 [ADR-0016](../../../decisions/ADR-0016-推进挂在曾经发生过的事上.md)，它的结构落点在[`主线推进系统`](../../../design/主线推进系统.md)。**这个编号还没做完** —— 那几条落地反证一条都没写，状态在[待办台账](../../../spec/issues/README.md)，不在本文。

## 目标

让「为什么主线不按年份或天数排期」有一份写下来的决策，从而不必每次读到正典那几个年份小标题时重新争一遍；并把它落地时必须被钉住的那几条写清。

## 来源

- PRD：[`prd.md`](./prd.md) 的 `US-003`
- 起因：[主线故事 · 二十个主线节点](../../../canon/narrative/主线故事.md)按「第一年／第二年……」分组，而那只是主题分组；同一页又写着无全局日期上限与「节点的实际落点由它自己的解锁条件决定」。**这个读法每次都会被重新问一遍**，而它同时决定了好几个系统的形状。

## 依赖

`NR-11`（决策的对象要先有形状）。**两条一起写完一起验。**

## 验收标准

- [x] 按 [ADR 模板](../../../templates/ADR.md)写全，编号 `ADR-0016`（现有最大 `ADR-0015`），`status: accepted`。
- [x] 背景里写明它**为什么够得上门槛**：影响多个系统（任务、事件、失衡、结算、存档、演出各有一处接它）、难以撤销、容易反复争论。
- [x] 同一处写明**够不上门槛的候选**以及为什么不写成 ADR —— 「那几位标记由谁持有」的理由已经分别在[`活跃失衡系统`](../../../design/活跃失衡系统.md)与[`人际系统`](../../../design/人际系统.md)，再写一份 ADR 等于给同一条判据加第三个家。
- [x] 真实候选至少摆出两条并各写代价：**按年份或天数排期**、**解锁条件里允许一条天数下限**（后者是那份被删掉的提案当时选的路）。
- [x] 决策写成一句话，并写明它的两半：解锁**只许有下限**、关闭**只由玩家自己的动作触发**。
- [x] 后果里写明**难撤销在哪**：节点声明与存档分片都按它写，换回日期等于重写全部节点声明。
- [x] 写明它**不改**[结算顺序（固定，不得改动）](../../../canon/gameplay/时间与经营.md)那张表的任何一步。
- [x] 落地那几条各要一条用例，外加一条把承重项钉住的反证（带天数的节点声明被拒）。
- [x] 接进 [ADR 索引](../../../decisions/README.md)（由 `DOC-57` 那一轮做，本条只要求那一行说得出它决定了什么、承重项是哪半句、被放弃的是哪几个）。

## 实现笔记

### 设计决策

- **模糊点**：这条取舍够不够 ADR 的门槛（影响多系统、难撤销、容易反复争论）。
- **选择**：够，立 `ADR-0016`。
- **理由**：三条都成立 —— 任务、事件、失衡、结算、存档、演出各有一处接它；节点声明与存档分片都按它写，换回日期等于重写全部节点声明；而[主线故事](../../../canon/narrative/主线故事.md)那几个年份小标题会让「按年份排期」这个读法反复回来，**那份已删的提案就是按那个读法写的**。

- **模糊点**：另一个候选（「那几位标记由谁持有」）要不要也写成 ADR。
- **选择**：不写。
- **理由**：它的两半理由已经分别在[`活跃失衡系统`](../../../design/活跃失衡系统.md)（那一位归推进侧）与[`人际系统`](../../../design/人际系统.md)（关系不需要闩锁）里，再写一份 ADR 等于给同一条判据加第三个家。这条判断写进了 ADR 的背景。

### 偏离

- **方案怎么说**：`US-003` 要求「真实候选至少摆出两条」。
- **实际怎么做**：摆了四条（含「解锁只读当前值」），另给关闭条件单独判了一次。
- **为什么**：关闭条件是正典要求的，不是本决策发明的 —— 不单独判一次，读者会以为「不许有截止」与「有一个节点必须在另一个之前完成」自相矛盾。

### 权衡

**「把它写成正典的一句话而不是一份 ADR」考虑过**（例如直接改[玩法定位 · 推进与胜负](../../../canon/gameplay/玩法定位.md)）。没选：正典写的是**意图**（不许有截止），而这份写的是**取舍**（为什么挂标记而不挂日期，以及放弃了哪几条路）—— 后者属于 ADR 那一档；而且正典那一节已经有那句意图了，再加一段论证会让它变成两层东西。

### 待确认

无。
