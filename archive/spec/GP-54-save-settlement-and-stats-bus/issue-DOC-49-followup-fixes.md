# DOC-49：这一批的连带修正，落在已交付的文档上

## 实现笔记

### 设计决策

- **模糊点**：那十来处「不设计存档序列化格式」要不要整句删掉 —— 落点存在之后，「不设计」这句话读起来像废话。
- **选择**：保留那半句，只在后面接上去处。
- **理由**：那半句是**边界**（「本页不做这件事」），而边界不因为别处做了就消失 —— 删掉之后，下一个人往那一份里加序列化细节时就没有东西挡他了。接一句去处只是让「那谁做」有答案。

- **模糊点**：[`战斗AI系统`](../../../design/战斗AI系统.md)那句「两个档号是派生量所以不单独存」本来是它自己的一条声明，现在[`存档系统`](../../../design/存档系统.md)给了通用判据与通用反证 —— 要不要把它那句删掉、只留链接。
- **选择**：留着，补一句「这条现在有一条通用反证钉着它」。
- **理由**：那句话回答的是「**本页**那两个量存不存」，而通用判据回答的是「什么样的量不存」。删掉它等于让一份文档不再声明自己的字段，而本批那条「各系统自己声明」的整个前提就是每一份都声明自己那一块。

### 偏离

- **方案怎么说**：PRD 的 `US-008` 列的是「那句『经营动作细节归各自实现与时间与经营』按本批的结果改写」。
- **实际怎么做**：那句话没有被改写，它**连同所在的旧位置一起不在了** —— 那一节整段从「接口」搬进「结构」并填开。
- **为什么**：改写它会留下一句「细节在本页下面」的指路语，而那一节现在就在正文里、紧挨着战斗侧那张流转表 —— 指路语指的是同一页的下一节，属于多余。

- **方案怎么说**：改文件只用编辑工具。
- **实际怎么做**：那二十处高度一致的替换写成了一个 `temp/` 下的 py 脚本，**每条替换都断言命中数恰好一次，命中数不对就整体不落盘**，跑完自报改了几份文件几处。
- **为什么**：禁的是 shell 批量替换（它不报命中数、也没法原子化）；二十处逐个手改的真实风险是改漏一两处而看不出来。**判据是「它报不报得出命中数」**，不是「用的是哪个工具」。

### 权衡

**「把各份文档里那一格存档声明收进[`存档系统`](../../../design/存档系统.md)一张表」考虑过** —— 那正好是 PRD `Q1` 被否决的那个候选。没选，理由在[`存档系统`](../../../design/存档系统.md)的「理由与取舍」里；本条只是它的连带结果：**每一格留在原处，只是变得可点。**

**那份替换清单漏了两处，而漏的原因值得记下来。** 它按**确切字符串**匹配，所以只覆盖它自己列出的形状：[`状态效果系统`](../../../design/状态效果系统.md)那条写的是「不设计存档**格式**」而不是「序列化格式」，[`日记系统`](../../../design/日记系统.md)那句「这三样是存档那一批的输入」根本不在任何一条规则里。两处都是 `DOC-52` 按词那一轮查出来的。**教训是一句话：替换清单不能当按词核对的替代** —— 前者只认它列出的形状，后者认的是「这句话现在还成不成立」。
