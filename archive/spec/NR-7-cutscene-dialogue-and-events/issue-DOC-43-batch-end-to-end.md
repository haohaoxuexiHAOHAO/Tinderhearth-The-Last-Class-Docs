# DOC-43：这一批的端到端与交叉核对

> **只读历史归档，不得作为现行依据。** 核对结论落在被核对的那几份文档自己身上（[`剧情演出系统`](../../../design/剧情演出系统.md)、[`事件系统`](../../../design/事件系统.md)、[玩法定位](../../../canon/gameplay/玩法定位.md)），没有单独落点。

## 目标

用一条命令加三轮人工对照，看出这一批的文档有没有和正典打架、有没有把某处说法改漏、有没有踩别人写死的不变式。

## 来源

- PRD：[`prd.md`](./prd.md) 的 `US-008`
- 起因：本批改了几份**已交付**文档与正典多处，而检查器查断链、查不出两份文档对同一件事的描述已经分叉。上一批留下的判据是**交叉核对分按词、按量级数字、按不变式三轮，一轮找不全**，本条照它做。

## 实现笔记

### 设计决策

- **模糊点**：三轮交叉核对要不要落成 `tools/` 里的入口。
- **选择**：**不落** —— 临时脚本跑完即删，与上一批一样。
- **理由**：机器搜得出一个词出现在几处，**判不出那几处说的是不是同一件事**。留一个没有判定能力的守卫比没有守卫更坏；而它判的东西在 Godot 里也看不出来，所以那条「看它判的东西实机看不看得出来」的判据在这里给不出保留理由。

### 偏离

- **方案怎么说**：条目里三轮写成「按词、按量级数字、按不变式」。
- **实际怎么做**：按词那一轮**跑了两遍** —— 第一遍扫本批的新词，第二遍扫容易撞的几组（暂停的适用范围、已触发过与记账、日记与回看、气泡的约束、种子与纯函数、结算不加步）。
- **为什么**：第一遍只查「新词有没有第二个家」，查不出「同一条结论在几处的理由有没有互抄」。第二遍正是靠这个查出那三处「不加步」各写了自己的理由、没有互抄。

### 权衡

- **不变式那一轮的证据形式**选了 `git diff --stat` 列一串「应当一个字未改的文件」而不是逐份读 —— 输出为空就是证据，而逐份读既慢又靠记性。
