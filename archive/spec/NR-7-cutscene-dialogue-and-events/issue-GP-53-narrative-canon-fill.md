# GP-53：正典补齐 —— 事件的声明与钩子、演出期间的世界、引导给一次之后还查得到

> **只读历史归档，不得作为现行依据。** 现行事实在[玩法定位](../../../canon/gameplay/玩法定位.md)那几节（随机事件的三条扩展点与它接住的那几条边界、剧情演出那两条推论、跨系统基础设施里持续引导那一行），结构在[`事件系统`](../../../design/事件系统.md)与[`剧情演出系统`](../../../design/剧情演出系统.md)。

## 目标

让正典一次说清「一件事怎么被触发、触发之后玩家从哪知道」与「演出期间世界是什么状态」，而不是让读者在两份系统文档之间拼。

## 来源

- PRD：[`prd.md`](./prd.md) 的 `US-002`
- 起因：本批答完的几件事都落在正典已经写下的句子上 —— [玩法定位 · 随机事件：事件可以晚做，扩展点现在就留](../../../canon/gameplay/玩法定位.md)只说钩子的位置定死、没说事件被询问的方式；[玩法定位 · 跨系统基础设施](../../../canon/gameplay/玩法定位.md)里持续引导只有一句；[玩法定位 · 剧情演出：一律引擎内，不做视频](../../../canon/gameplay/玩法定位.md)说了世界暂停、没说不由玩家操作的角色算不算。
- **它是两份新文档的正典反向链接落点** —— `type: system` 有「必须被正典链接到」的硬判定，文档一落地链接不在就当场 FAIL。

## 依赖

`NR-7` 那一半的 ADR（对话与演出的格式那条结论要先有依据）。**与 `NR-7`、`GP-52` 互相引用，一起验。**

## 验收标准

### 事件那一侧

- [x] [玩法定位 · 随机事件：事件可以晚做，扩展点现在就留](../../../canon/gameplay/玩法定位.md)那条「触发钩子的位置现在就定死」按本批答案收口：钩子的那几处照旧一个不多，但写明**事件只在钩子被触到的那一刻被询问，不自己轮询、不自己跑计时器**。
- [x] 同一处写明**每日结算那个钩子落在整条固定步序之外**（结算跑完之后才问事件），并写出理由 —— 事件的后果会去调那条序列里已经跑过的东西（改价格、往委托板加一条），插在中间就会撞上「补满至固定条数」与那条无门槛保底，**而那条失效不报错**。
- [x] 同一处写明它**与[`活跃失衡系统` · 它在每日结算里不占一步](../../../design/活跃失衡系统.md)那条不同源**：失衡不加步是因为它没有按天变的量，事件不加步是因为它要读结算的结果。**两条理由不许互抄。**
- [x] 同一处写明**事件分一次性与可重复两类**，判据是「它的后果可不可逆」；一次性的触发过就永不再来，可重复的受冷却与前置条件管。
- [x] 同一处写明**「已触发过」与冷却是事件自己的一份记账，进正式存档**，不记在被调用的那些系统里。
- [x] 同一处写明**关卡事件在拼装那一刻就定下来**，不在关卡内临时抽取 —— 否则[`关卡系统` · 一个种子，加一份关卡进度](../../../design/关卡系统.md)那条承诺会被绕掉，**而它不报错**。
- [x] 同一处写明**袭击事件的终止条件读[穹盾](../../../canon/world/世界观.md)那项改造的进度**，而那一侧的形状还没定（进度见[待办台账](../../../spec/issues/README.md)）—— 所以事件的前置条件表里要有「读推进侧标记」这一格，**格子现在就留、值等那边**。
- [x] **「事件」这个同名不同物在正典里写清**：随机事件、境况事件、关系小事件与统计事件总线上那条「事件」不是一回事，每处写全名。

## 实现笔记

### 设计决策

- **模糊点**：正典要不要把「事件不占每日结算一步」的理由写全，还是指向[`活跃失衡系统`](../../../design/活跃失衡系统.md)那条已有的说法。
- **选择**：**写全，并显式写明两条不同源。**
- **理由**：两条结论一样、理由不一样（一条是「没有按天变的量」，一条是「要读结算的结果」）。指过去会让改动其中一侧时另一侧静默失去依据 —— 这正是「事实只许有一个家」的反面：**理由不是同一个事实，不能共用一个家。**

- **模糊点**：持续引导那一行要写多少。
- **选择**：把「首次记在哪、两条出口、清单是读口、可以读队友档位」都写进那一行，规则细节指[`事件系统`](../../../design/事件系统.md)。
- **理由**：那一行原来只有一句话，而本批答的四件事全都落在它身上；不写进去的话正典就只有「首次遇到某系统时的提示」这一句，而读者无从知道提示给过一次之后还查得到。

### 偏离

- **方案怎么说**：条目里写「同一张表里剧情演出、气泡、正式对话与随机事件那几行挂上链接」。
- **实际怎么做**：气泡那一行挂的是 [ADR-0014](../../../decisions/ADR-0014-对话是演出脚本的一类指令.md)，不是系统文档链接。
- **为什么**：气泡本批没有系统文档（`NR-8` 记账），而它要说清的正是「它不共用那份格式」—— 依据在那份 ADR 上。

### 权衡

- **「事件」那个同名不同物写在随机事件那一节，而不是另起一节。** 另起一节会让读者以为那四样东西之间有什么共同机制，而它们只是撞了一个词。

### 待确认

无。本条改的都是正典措辞，结论都由 `NR-7`、`GP-52` 那两份与 `ADR-0014` 撑着。
