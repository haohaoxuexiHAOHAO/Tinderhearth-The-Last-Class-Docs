# GP-52：`design/事件系统.md`（含持续引导与关系小事件）

> **只读历史归档，不得作为现行依据。** 现行事实在[`事件系统`](../../../design/事件系统.md)，它的玩法规则在[玩法定位](../../../canon/gameplay/玩法定位.md)。**这个编号还没做完** —— 文档已交付而代码一行都没写，落地顺序与状态在[待办台账](../../../spec/issues/README.md)，不在本文。

## 目标

让「一件事怎么被触发、触发之后调谁」只写在一处，而且它一行效果都不实现；同一份收下持续引导与关系小事件，因为三者是同一条「触发 → 后果」管道。

## 来源

- PRD：[`prd.md`](./prd.md) 的 `US-004`
- 起因：[玩法定位 · 随机事件：事件可以晚做，扩展点现在就留](../../../canon/gameplay/玩法定位.md)写明扩展点必须现在就定，而三个后果入口到本批终于齐了（[`经济系统` · 事件调价从哪进来](../../../design/经济系统.md)、[`任务系统` · 谁改它、谁读它](../../../design/任务系统.md)、[`活跃失衡系统` · 境况事件声明它动哪几组，可正可负](../../../design/活跃失衡系统.md)）。
- 另一处起因是判据自己带出来的：按[`任务系统` · 任务与事件的分界](../../../design/任务系统.md)那条判据，**关系小事件只有「触发 → 后果」，所以它是事件**，而[`人际系统`](../../../design/人际系统.md)明写不做它 —— 它无家可归。
- 持续引导收进来的理由是记账：它与事件共用同一份「已触发过」的存储，**那两个问题本来就是同一个问题**。

## 依赖

`GP-53`（正典补齐，正典反向链接落点）、`NR-7`（事件的一条后果是播一段演出）。**与 `NR-7` 互相引用，一起验。**

## 实现笔记

### 设计决策

- **模糊点**：一条事件属哪一类（基地／关卡／城区）要不要有一个「类型」字段。
- **选择**：**不加字段** —— 类由它挂的钩子与它调的入口共同决定。
- **理由**：加字段就会长出「类型写基地、钩子挂关卡内」这种自相矛盾的数据，而它不报错。

- **模糊点**：袭击派生出的那条委托要不要开一类新任务（它是急事，3 天截止加占额度可能让玩家错过）。
- **选择**：**不开例外，它就是一条委托**，走与日常生成同一个构造路径。
- **理由**：[`任务系统`](../../../design/任务系统.md)那三类只在几格上不同，开第四类等于把它省下来的东西还回去；而「急事」这件事可以由内容表达（报酬与档位），不需要结构。

- **模糊点**：关系小事件的家。
- **选择**：**收进本页** —— 按[`任务系统` · 任务与事件的分界](../../../design/任务系统.md)那条判据它只有「触发 → 后果」。
- **理由**：[`人际系统`](../../../design/人际系统.md)明写不做它，所以它本来无家；留在那边它会长出自己的触发与自己的一次性判定，然后同一套东西有两处。

- **模糊点**：引导那份可回查清单是不是一份新存储。
- **选择**：**是触发记账的读口，不是第二份存储。**
- **理由**：「当场给过一次」与「清单里有这一条」是同一个事实的两种呈现；各存一份会分叉，而分叉的表现是「清单里查不到刚才那条提示」且不报错。**顺带的结果是这条答复没有让存档变贵** —— 字段一个都没加。

### 偏离

- **方案怎么说**：PRD 待确认问题八原来的推荐是「当场提示、不进手环通知列表」，那条选项下记着两条代价（多一份记录、「已给过」有两处表达）。
- **实际怎么做**：按作者答复改成**两条出口**（当场提示 ＋ 挂手环的可回查清单），而那两条代价**被消掉了** —— 清单做成记账的读口就不是第二份记录，「已给过」也仍然只有一处表达。
- **为什么**：引导是玩家教学的延续，给过一次就没了等于把「忘了怎么做」这件事留给玩家自己扛。同一条答复带出两处连带：**教学关教过的东西也各有一条引导条目**（否则第一天教的那些恰好是唯一查不到的部分），以及**那份清单与图鉴只共用收录形状、条目不互通**。

- **方案怎么说**：条目里写「不加第六处钩子」。
- **实际怎么做**：改成「不在正典那几处之外新开一处」。
- **为什么**：写「第六处」等于在本页抄一份钩子处数的副本（那个数的家在正典），而自计数守卫也当场报了一次。

### 权衡

- **考虑过把气泡也收进本页**（它同样是「条件成立 → 推一条短文本、不接管输入」）。**判据是记账语义**：引导是「首次之后不再主动出现」，气泡是「说过了进冷却池、还会回来」，同一份存储装不下两种。所以气泡留在外面、另立 `NR-8`。
- **考虑过让事件占每日结算一步**（好处是摘要能报出事件）。代价是委托板补满那一步会少补，「补满至固定条数」与那条无门槛保底静默失效 —— 而那种失效不报错。
- **关卡事件曾有两条路**：由种子定、或关卡内实时抽并进关卡进度。选前者是因为后者**很容易被实现成不进进度**，那时表现是「退出再进，那只稀有敌人不见了」且不报错。

### 待确认

- **袭击的终止条件读推进侧的标记，而推进骨架的形状还没定** —— 本页只留了那一格，值等那边。**它在那一侧还没定时读作「未满足」**（不报错、也不当成已满足），这条要在实现时钉住。
- **一个钩子一次触发几条的上限**要与内容量一起校准，现在只有量纲。
