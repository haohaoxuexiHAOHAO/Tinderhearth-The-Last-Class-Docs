# GP-27：技能分战斗与生活两类，开局物资档与战斗难度分开

> **只读历史归档，不得作为现行依据。** 现行事实在[角色与成长 · 技能分两类：放出来的动作，与做事的熟练度](../../../canon/gameplay/角色与成长.md)与[玩法定位 · 开局](../../../canon/gameplay/玩法定位.md)。

## 目标

在正典里把技能切成两类（战斗技能是放出来的动作、生活技能是熟练度），并新增一层只管经营侧的开局物资档。

## 来源

- PRD：[`prd.md`](./prd.md) 的 `US-004`，以及 `US-008` 里开局物资档那一半

## 依赖

无。它与 `GP-25`／`GP-26` 改的是正典的不同小节，可以并行。

## 验收标准

- [x] [角色与成长](../../../canon/gameplay/角色与成长.md)写明两类：战斗技能（占技能位、耗蓝、有读条与冷却）与生活技能（钓鱼、种植、畜牧、烹饪、加工、交易六项，不占技能位）
- [x] 写明统一的防刷判据 —— **凡是熟练度，只在真的做成那件事时涨**
- [x] 写明生活技能的持有方是将来的 `成长系统`（`GP-30`），本条只定两类与取值
- [x] 交易技能写明**只影响买卖点差**；定价那节另加一句「这三层之外不许再加乘数」当护栏
- [x] 正典新增一层**开局物资档**，只影响起始资金、粮食与材料
- [x] 同时写明[战斗与关卡](../../../canon/gameplay/战斗与关卡.md)那两层难度**仍然不改变资源产出与经济压力**，并写清理由（一个开关调两样，玩家调不准自己想要的）
- [x] 写明平衡判据按**物资最少的那一档**判定
- [x] `python tools/check_docs.py` 0 FAIL

## 实现笔记

### 设计决策

- **模糊点**：「开局物资按难度给」与正典那句「两层难度都不改变资源产出与经济压力」直接冲突。
- **选择**：不改那句，而是**另设一个开关** —— 开局物资档只管经营侧，战斗难度继续只管敌人。
- **理由**：那句话的理由是「一个开关同时调两样，玩家调不准自己想要的」，而两个开关恰好满足它。改成「难度也调物资」等于用今天的方便推翻一条仍然成立的理由。

### 偏离

- **方案怎么说**：`GP-27` 只要求在角色与成长写两类技能、在玩法定位加物资档。
- **实际怎么做**：多改了两处 —— [战斗与关卡](../../../canon/gameplay/战斗与关卡.md)那张难度表加了一行「（对照）开局物资档」，[时间与经营](../../../canon/gameplay/时间与经营.md)定价那节加了一句「这三层之外不许再加乘数」。
- **为什么**：都是护栏。难度表那行防的是「以后有人把物资档并进战斗难度」；定价那句防的是「交易技能变成第四个乘数」—— 那正是 `物品系统` 当初为品质挡过的同一件事。

### 权衡

生活技能的熟练度曲线**没有**写进正典，只写了「有哪六项 ＋ 只在做成时涨」。曲线、等级效果与显示留给 `成长系统`，因为那是会随实测调的东西，正典写了就会变成要反复改的地方。

### 待确认

无。各档物资的具体数额与熟练度曲线归 `GP-2`，已记在 `DOC-14`。
