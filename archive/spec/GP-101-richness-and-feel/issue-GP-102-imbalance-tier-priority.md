# GP-102：失衡畸形档优先于操作档，两侧各写明

> **只读归档 · 历史背景，不是现行依据。** 现行事实在本页正文点到的那几份活文档里；状态与剩余动作在[待办台账](../../../spec/issues/README.md)，不在本页。

## 目标

学生不闪避时有一个玩家看得懂的原因，而不是一个看起来像缺陷的现象；而畸形那一档不会因为「练熟了」就只剩便宜。

## 来源

PRD：`spec/prd-richness-and-feel.md` 的 `US-002`。

立项理由：[`活跃失衡系统`](../../../design/活跃失衡系统.md)的增益二维分档表在「掌握不足而失衡很高」那一档改行为（**攻击欲极强、不再闪避与防御**），而[`战斗AI系统`](../../../design/战斗AI系统.md)的操作档在老练那一档解锁「会闪避有预警的攻击」、在大师那一档解锁「掐得准防御时机」。**两张表都改行为、都没提对方，谁优先没写，不一致时不报错。**

**本条原先只有台账一行，没有条目文件** —— 偏离与权衡放不进备注那个字数上限，所以补建。

## 依赖

无。文档侧可以现在就改；反证跟 `GP-36` 与 `GP-100` 落地。**玩家那一侧看得懂原因的界面落点归 `UI-29`**，本条不做界面。

## 验收标准

- [x] 两份文档各写明优先关系，且各指向对方那一节：[`活跃失衡系统`](../../../design/活跃失衡系统.md)在二维分档表那一节写「畸形那一档的行为优先」，[`战斗AI系统`](../../../design/战斗AI系统.md)在两条轴那一节写「这两条轴解锁的是『他会不会』，不是『他一定会做』」
- [x] 优先关系**不是任选一边**：那两条轴答「他会不会」，畸形那一档答「他还愿不愿意」——**会而不愿的结果是不做**，所以它是一道门排在另一道之上，不是两张表打架
- [x] 两侧各写明这是**有意的代价**：高操作档角色会当场不再闪避与防御，玩家很可能读成缺陷；换来的是这一档真的是代价（否则力量敏捷涨、智力掉那半句会被练熟盖过去，它就只剩便宜）
- [x] 反证写进[`战斗AI系统`](../../../design/战斗AI系统.md)的验收：给一个高操作档角色挂上畸形那一档的增益，他**不执行闪避**（也不执行防御），并写明它挡的是哪种实现
- [x] **玩家看得懂的原因不新开载体**：境况档位的读口本来就在，接住它的那一页归 `UI-29`；另一半是越阈值那批行为表现（作者实机）。真要一条提示，走[`事件系统`](../../../design/事件系统.md)引导那条已有的管道
- [x] [`战斗AI系统`](../../../design/战斗AI系统.md)的「同名不同物」补一条：本页的 **SP 失衡**与**活跃失衡**是两回事（只写「失衡」时，「他失衡了所以不闪避」两种意思都读得通，而两种的时长差着一整天）

## 实现笔记

> 由 `/note-it` 在实现和评审之后填写。

### 设计决策

- **模糊点**：优先关系管到哪几条分档行为。立项时点名的只有闪避。
- **选择**：写成**一条通则**（畸形那一档声明的行为优先于两条轴上的任何一条分档行为），**不列一张「哪几条被盖掉」的清单**。
- **理由**：清单要随分档行为一起长，而漏补一条不报错；判据不会长。**它同时答掉了「攻击欲极强与配合档那几条怎么办」** —— 那是同一形状的第二处冲突（自发集火、主角被围时去解围都不是「追着最近的打」），逐条列清单的话它会被漏掉，而通则直接管到。
- **另一处**：这条通则写在[`战斗AI系统`](../../../design/战斗AI系统.md)**两条轴那一节**，不写在操作档五档那一节 —— 它管两条轴，写进其中一张表就等于把一条优先关系拆成若干条例外。

### 偏离

- **方案怎么说**：`US-002` 的反证是「给一个高操作档角色挂上畸形那一档增益，**他不执行闪避**」。
- **实际怎么做**：反证写成**闪避与防御都不执行**。
- **为什么**：正典[世界观 · 活跃失衡的规模](../../../canon/world/世界观.md)那句原话是「不再闪避**与防御**」，而操作档大师那一档解锁的正是「掐得准防御时机」—— 只钉闪避会漏掉那一档，而漏掉不报错。
- **第二处**：`US-002` 的描述只要求「学生不闪避时有一个我看得懂的原因」，没说那个原因落在哪。实际写成**不新开载体**：境况档位的读口已经在，页归 `UI-29`；越阈值的行为表现本来就要做。**这一条是刻意不发明东西** —— 本轮 `US-006` 正在给那四个读口找页，境况档位是其中一个，在这里再开一处就是给同一件事第二个家。

### 权衡

也可以让**分档行为优先**（练熟的角色照旧闪避，畸形那一档只改属性不改行为）。否决理由是它把这一档从代价变成纯收益：力量与敏捷涨、智力掉那半句是可以接受的交换，而「不再闪避与防御」才是真正让人不敢挂它的那一半 —— 拿掉之后玩家练熟一个学生就可以放心让他挂着。代价写明了：高操作档角色会当场不再闪避，而玩家读不出原因时会当成缺陷，所以那条原因必须有载体。

### 待确认

无。

**一处核过没改**：[`状态效果系统`](../../../design/状态效果系统.md)那一侧不用动。畸形那一档的增益是它的永久项，而本条改的是「行为谁优先」—— 那不是载体上的一格，载体照旧只装修饰。
