# NR-40：那批埋了几年的瞬间摊到战前与战后

> **只读归档 · 历史背景，不是现行依据。** 现行事实在本页正文点到的那几份活文档里；状态与剩余动作在[待办台账](../../../spec/issues/README.md)，不在本页。

## 目标

林泽指方向、兄妹那条线这些瞬间在真打这一版里仍然有落点，前几年埋的东西有回报。

## 来源

PRD：`spec/prd-richness-and-feel.md` 的 `US-016`。取舍在 [ADR-0024](../../../decisions/ADR-0024-学生那条战线改成一场真打.md)。

立项理由：[节点里的学生](../../../canon/narrative/节点里的学生.md)节点 16 那一节已经定了一批瞬间，判据是**每个瞬间都要兑现前面几年埋的某一条**。这些在自由 AI 战斗里不会自己发生 —— 它们是这条线全部的情感回报，丢了就只剩一场不会输的打斗。

改法：那一场的形状是**战前一段演出 → 一场不被打断的真打 → 战后一段演出**，**打斗当中一段演出都不插**。那批瞬间按**它兑现的是什么**摊到前后两段：说与被听的进战前，结果与代价的进战后，配合与补位交给 AI。

## 依赖

`NR-39`（叙事侧先定）、`NR-7`（剧情演出系统落地）、`GP-114`（那一场先打得起来）。**前后那两段演出不依赖战斗内部的任何触发点** —— 这一版比原先那一版少一条依赖。

## 验收标准

- [x] [节点里的学生](../../../canon/narrative/节点里的学生.md)节点 16 那一节改写，**逐个标出**哪一条进战前、哪一条进战后、哪些交给 AI；那一节的标题也跟着改（原先写着「是一段蒙太奇」）
- [x] 进演出的每一个仍写得出它兑现前面哪一条 —— **那条判据一个字不动**，另加一句写明**摊的依据是「它兑现的是什么」而不是「哪个好看」**
- [x] **打斗当中不触发任何演出**：正典那一节与[`关卡系统`](../../../design/关卡系统.md)两处都写明，后者另加一条边界「不为那一场声明进度点」，并写明输入因此只剩暂停（连跳过都没有对象）
- [x] 那三段怎么串起来**不新造机制** —— 它们是那条主线任务上的目标条目（[`任务系统`](../../../design/任务系统.md)），[主线故事](../../../canon/narrative/主线故事.md)节点 16 写了这一句
- [x] 可测试：跳过战前或战后那一段演出，它声明的状态变更一次性全部应用（[`剧情演出系统`](../../../design/剧情演出系统.md)那条既有的承重约束，不新造机制）
- [x] 台词不在本条，归 `NR-5`
- [ ] **作者实机确认**：前后那两段演出与中间那一场接得顺不顺
- [x] `python tools/check_docs.py` 0 FAIL

## 实现笔记

> 由 `/note-it` 在实现和评审之后填写。

### 设计决策

- **模糊点**：取消中途演出之后，那批瞬间按什么摊到前后两段。按「哪个最重」挑是第一反应，但那挑出来的是画面。
- **选择**：按**它兑现的是什么**摊 —— 说与被听的进战前（林泽指出弱点、云舒说出另一个将首在做什么、铁淬摆出两套机关、安桦分工），结果与代价的进战后（兄妹并肩、灯火那种平静又出现一次、谁带着伤、最后一下没有声音），配合与补位交给 AI。
- **理由**：这几条瞬间原先之所以要在打斗中间，是因为它们被写成了打斗动作；而**它们兑现的东西其实都不是动作** —— 林泽那条兑现的是「别人照着做」，云舒那条兑现的是「这一次有人接她的话」。把兑现那一半移到战前，反而比在打斗里更清楚：打斗里看到的是一群人同时打一侧，看不出那是谁的判断。

- **第二处：兄妹那条线的收束挪到战后。** 「一个顶一个进」是打斗动作，交给 AI 就不保证发生，而它是节点 6 起两人三次朝不同方向走的收束 —— 分量太重，不能押在一件不保证的事上。战后让两人并肩站着、不说话，兑现的是同一条（那个分别成了同一侧），而且它保证发生。
- **第三处：AI 那一段刻意留成不保证，而它换到了一样别的东西。** 配合档高的队伍真的会配合（[`战斗AI系统`](../../../design/战斗AI系统.md)那两条轴），所以玩家这几年的投入在那一段是**打出来的、不是演出来的**。这一条写进了正典那一节，免得「不保证」被当成缺口。
- **第四处：「谁带着伤」不由战后那一段自己定。** 它读的是学生身上那条养伤状态（`GP-115`），所以它是那一幕里**唯一保证兑现玩家投入**的一条 —— 另两类（战前的说与被听、战后的那几下）对任何周目都一样。

### 偏离

- **方案怎么说**：`US-016` 原先写「真打为主，关键节点插短演出：打到声明的进度点触发一段几秒的演出，演完接着打」。
- **实际怎么做**：**打斗当中一段演出都不插**，演出只在战斗之前与之后各一段。
- **为什么**：作者定的。原方案换掉之后**旧结论直接删掉、不留取代注**（作者明确要这样：设计方案消失无所谓），所以 [ADR-0024](../../../decisions/ADR-0024-学生那条战线改成一场真打.md) 那一条是就地改写的，没有新开一份 ADR。**跟着改的还有** PRD 的 `US-016` 与 `FR-24`、`US-022` 那条主路径、[ADR 索引](../../../decisions/README.md)那一行、`DOC-130` 那条主路径，以及[`关卡系统`](../../../design/关卡系统.md)里原先为中途演出留的两处。

- **第二处（少了两条验收，多了一条）**：原先那两条「演出触发时世界暂停、演完交还且双方状态一条不少」**没有对象了**（战斗里不触发演出），所以删掉；换成一条「打斗当中不触发任何演出」。**这不是放宽** —— 它把那两条要靠实现小心的事整个消掉了。
- **第三处（顺带答了一处「三段怎么串」）**：条目没问，但不答它落不了地 —— 一个节点派出的是一条主线任务或一段演出脚本，而这一场要「演出 → 关 → 演出」。答案是**那条主线任务上的三个目标条目**（剧情类那两个由脚本置位，形状是[`任务系统`](../../../design/任务系统.md)现成的），**不新造流程**。

### 权衡

**也可以把那批瞬间全部塞进战后那一段**，做成一次回望（打完之后镜头扫过几处）。那样一段就够、最省。否决理由：林泽与云舒那两条兑现的是「他说了、而这一次有人听」，回望里只剩「原来他说过」—— 兑现关系从「被听见」退化成「被追述」，而那两条是这一节最要紧的两条。

**也可以保留中途演出**（原方案）。作者已定不要，而它换到的东西写在 ADR 的代价那一节：那一场从头到尾不被打断，而节奏因此全压在打斗本身上。

### 待确认

- **那一场的节奏现在全靠打斗本身撑**，而中途演出原本顺带给它打拍子。处置是现成的：屏数与时长上限那两个量在[数值模型](../../../design/数值模型.md)的尚未给值表里，归作者实机收（`GP-114` 那一行）。
- **战前那一段会不会太像一次作战会议** —— 四条瞬间都摊在那里，说的人有四个。**这条没有机器判据**，归作者实机看；真的太长的话下一步是把其中一条（最可能是铁淬摆机关那条）挪给 AI 或战后。
- **AI 打不出配合那几下时，打斗那一段就只剩一场普通对打。** 它不报错，而它取决于队友 AI 落地之后的实际观感（`GP-36`）。
