# DOC-154：给地面铺纹理那几步写进指南

## 实现笔记

### 设计决策

- **新的一小节叫「给地面铺上纹理」，接在「让水挡住人」后面**，开头先说那一小节要先做完：运行时数据层的碰撞检查排在纹理前面，没改好就走不到铺纹理这一步，而仓里那份农场的数据层还关着 `Enabled`。
- **纹理图的交付规矩写成一张「要什么／怎么做」的表**：放哪、叫什么、多大、底色、四边怎么看、怎么导出、交之前跑什么。画法只链到场景绘制约定那一节，不复述。
- **文件名照代码仓 `CONVENTIONS.md` 的「文件与目录命名」**：新素材用下划线。同时写明代码不认文件名，名字只是给作者找图的。
- **写明纹理图的左上角对着世界原点**，编辑器里是两条坐标轴的交点，跑起来是窗口左上角。这样看接缝时知道该盯哪几条线。
- **写明 `TerrainDisplay` 的 `Material` 那一格会出现代码挂的材质、别动它**：作者点开显示层时会看到它，不说的话容易当成要自己管的东西清掉或改掉。
- **症状表照代码里的报错原文**，一处问题一行；表前那一句说总报错的开头长什么样、编辑器里是警告而按 `F6` 是报错。另加几行不靠纹理报错认的症状：改了没点按钮、交界里的笔画用了主色、看得出一张一张重复、按 `F6` 先报数据层的碰撞。
- **「跑一遍验收」新加的那几行**：**草铺到界线**、**看不出格线**、**放大一档**、**两边的草一样**、**刷一笔就铺上**、**裸土与耕地分得开**对 PRD `US-001` 的作者实机那几格；**配错了会报**是作者能亲手走一遍的失败路径。

### 偏离

- **方案怎么说**：验收只写了第二步那一小节、它的症状表与「跑一遍验收」。
- **实际怎么做**：另外几处跟着补：
  - 同一篇「卡住了：按症状查」加一行指到新那一小节；「接下来」里把天然地形画好那一条补一句纹理图的画法在哪；
  - [从哪里开始](../../../reference/godot/从哪里开始.md)那一格的「你搭」「我写」「台账」跟着补；
  - 同一节里有两处过时的说法，删了：「地形先用引擎内置的四边拼接，双网格留到后面」那条实现建议，与「不进里程碑的那几件」那张表里双网格那一行。双网格的代码已落地，这一篇第二步就在用它。实现建议那一行的标题原来自带条数，改成不带数。
- **为什么**：`DOC-152` 加水挡人时，同一个形状补过从哪里开始那一格。过时的两处与新补的几格在同一节，留着它们，读到的人会先去做内置拼接。
