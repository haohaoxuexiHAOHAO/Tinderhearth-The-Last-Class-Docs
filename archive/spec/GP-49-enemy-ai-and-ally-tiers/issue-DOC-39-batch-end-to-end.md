# DOC-39：这一批的端到端与交叉核对

> **只读历史归档，不得作为现行依据。** 核对结论落在被核对的那几份文档自己身上（[`战斗AI系统`](../../../design/战斗AI系统.md)、[`感知与视野系统`](../../../design/感知与视野系统.md)、[战斗与关卡](../../../canon/gameplay/战斗与关卡.md)、[玩法定位](../../../canon/gameplay/玩法定位.md)），没有单独的落点。留下的判据是：**交叉核对分按词、按量级数字、按不变式三轮**，以及**纯文档批次里跑不了的反证记「不适用（已记账）」**。状态在[待办台账](../../../spec/issues/README.md)，不在本文。

## 目标

用一条命令加两轮人工对照，看出这一批的文档有没有和正典打架、有没有把某处说法改漏、有没有踩别人写死的不变式。

### 设计决策

- **模糊点**：本条要求「按词一轮 ＋ 按量级数字一轮」，但没说搜到之后按什么标准判「算不算分叉」。
- **选择**：判据取两条 —— ① 一个**事实**只许有一个家，别处必须是链接或明确的「本页不复述」；② 一个**接口常量**（档数、种类数、类数、指令条数、上限数）在它家之外**一个数字都不许出现**。凡满足其中任一条的命中都逐行看过，不满足的（工作文档里的验收项、`archive/` 里的只读件）跳过并写明为什么跳过。
- **理由**：不定判据的话「命中 124 行」这种结果只能得出「看过了」，而看过什么、凭什么放过说不出来 —— 那正是「退出码 0 不等于成功」在人工核对这一侧的样子。

### 偏离

- **方案怎么说**：本条只核对、不改文档。
- **实际怎么做**：**改了六处**（见下面验证结果里那三行「通过（已修）」）。
- **为什么**：交叉核对的产出本来就是「查出来的分叉」，而分叉留着不改等于把它记在一份将来没人读的条目里。六处里有两处是**正典与已交付系统文档里的过期句**（正典那句「三个方向同一条规则」与 `关卡系统` 那句「不要求全歼所以往回走带着敌人」），它们在本批之后读起来是错的，不改就是留了两个坑。

### 权衡

**考虑过把「按量级数字搜」落成 `tools/` 入口**，让它每批自动跑。没落，理由与上一批相同且本轮又验证了一次：机器能搜出「48px」出现在几个文件里，**判不出那几处说的是不是同一件事** —— 本轮 25 处「48px」命中里，有的是家、有的是「那个数的家在……本页不复述」（正确）、有的是借它命名一个章节（正确）、只有两处是真副本。**留一个没有判定能力的守卫比没有守卫更坏**，所以它继续是人工步骤，判据写在上面「设计决策」里。

### 待确认

无。
