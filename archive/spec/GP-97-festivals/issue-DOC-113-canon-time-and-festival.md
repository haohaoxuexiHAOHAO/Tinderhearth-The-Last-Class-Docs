# DOC-113：正典里节日那几处改口

> **只读历史归档，不得作为现行依据。** 现行事实在[时间与经营 · 作息与熬夜](../../../canon/gameplay/时间与经营.md)；状态在[待办台账](../../../spec/issues/README.md)。

## 目标

让正典那句「节日可以晚做」指得到新交付的那一份，并让散场时刻与醒来、熬夜、强制结束那几个时刻住在同一节。

## 来源

- PRD：[`prd.md`](./prd.md) 的 `US-006`

## 依赖

`GP-97` —— 要指过去的那一份得先存在。

## 验收标准

改的是[时间与经营](../../../canon/gameplay/时间与经营.md)，只改下面点名的几处：

- [x] 「作息与熬夜」那节里**节日那句改口**：不再说「可以晚做」，改成指得到新交付的那一份（形式与天气那句同形）
- [x] **散场时刻那个值写进同一节**，紧挨着熬夜起点与强制结束；写明它必须早于熬夜起点，以及为什么这个数住在正典而不进参数表（它与那几个时刻是同一类东西 —— 一天的时刻边界）
- [x] 该上升的那两条立场进正典：**节日不拒绝任何玩家动作**、**节日那天不抽天气**。判据与天气那一轮同一条 —— 它们决定玩家看到的东西，而理由与时间无关
- [x] **「季节影响的那几处」一个字不动**：节日本来就在那一句里，这一轮不动它
- [x] **恶劣天气那几种的名字与条数一个字不动**
- [x] 每季多少天、熬夜起点、强制结束那几个既有的数**一个都不重写**
- [x] 改完跑 `python tools/check_docs.py`，报出来的「引那一节的上游约束要复核」逐条核过，再用 `--repin` 重录指纹
