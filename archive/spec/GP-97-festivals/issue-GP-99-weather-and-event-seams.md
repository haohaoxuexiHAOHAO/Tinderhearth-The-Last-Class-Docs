# GP-99：两处既有系统文档各加一格

> **只读历史归档，不得作为现行依据。** 现行事实在[`天气系统`](../../../design/天气系统.md)那一节与[`事件系统`](../../../design/事件系统.md)那张后果表；状态在[待办台账](../../../spec/issues/README.md)。

## 目标

让天气知道「节日那天不抽」、让事件那张后果表装得下「开一场比赛」，而两份文档除这一格之外一个字不动。

## 来源

- PRD：[`prd.md`](./prd.md) 的 `US-005` 与 `US-006`

## 依赖

`GP-97` —— 节日那一份要先定形，否则这两格指不到东西。

## 验收标准

**天气那一份**（[`天气系统`](../../../design/天气系统.md)）：

- [x] 多一节说明节日那天不抽天气、取默认态；方向写明是**天气读节日**那个已有读口，节日不写天气的账
- [x] 它的接口表多一行「读节日」
- [x] 写明这条**一律成立、不按节日各给一位**，理由写明
- [x] 验收节里加两条：节日那天取到的天气恒为默认态；**非节日那天的权重算出来与本轮之前一致**（反证，钉住抽法没改）
- [x] 那张声明表、权重与预报三处**一个字未动**（`git diff` 里看得出来）
- [x] 它的「边界与非目标」里那句「不做节日」改口 —— 现在节日有家了，那一句要指得到

**事件那一份**（[`事件系统`](../../../design/事件系统.md)）：

- [x] 后果表多一行「开一场比赛」，指到节日那一份的那个入口
- [x] 写明这一行是按它自己那条判据填的（「这件事已经有人做了吗」），不是开例外
- [x] 钩子那几处、记账、一次性与冷却四处**一个字未动**
