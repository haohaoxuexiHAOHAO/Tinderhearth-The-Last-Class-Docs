# 七天推演：玩法定位

> **本文件已归档，只读，不得作为现行依据。** 现行玩法事实见[canon/gameplay/](../../canon/gameplay/玩法定位.md)，现行待办见[台账](../../spec/issues/README.md)。

> 派生自：[`prd-gameplay-positioning.md`](./prd-gameplay-positioning.md) 的 `US-012`。规则依据是 [canon/gameplay/](../../canon/gameplay/玩法定位.md) 四份正典。

## 1. 目的与方法

把第一周的循环在纸上手算一遍，检验的是**结构**而不是平衡：

- 每一天玩家**有没有可行动作**（不会出现「不知道该干什么」）
- 时间、体力、金钱、材料、学员状态五类账**能不能逐日闭合**（不出现凭空产生或凭空消失）
- 三条失败路径**有没有出路**（不死锁）

**本推演不产出数值。** 数值归 `GP-2`。凡是需要具体数字才能判断的地方，本文记作「待 `GP-2`」并汇总在第 5 节 —— 那份清单就是 `GP-2` 必须先算的东西。

## 2. 推演前提

按[玩法定位 · 开局](../../canon/gameplay/玩法定位.md)：基地已有住宿、一小块种植区、一个仓储；起始资金只够买第一批种子；债务本金已挂账；学员先给 2–3 人。一天 6:30–25:30，共 19 游戏小时。

## 3. 推演结果

逐日推演与三条失败路径的明细已随过程叙述删除，见 Git 历史。**结论：核心循环闭合，时间／体力／金钱／材料／学员状态五类账逐日对得上，破产、学员全部养伤、委托超期三条失败路径全部有出路、无死锁。**

## 5. 发现的问题

推演的价值在这一节。以下八条只读正典发现不了。

- [x] **F-1 三个数字互相不一致。** 已解：常规出征编队改为**主角 + 1 至 4 名学员**（下限 1，所以开局 2–3 人照样能出门）；主角单人只限采集类；剧情单人任务另算。
- [x] **F-2 起始装备没定。** 已解：**宝物栏与宝石孔开局全空**，第一天只有基础动作。
- [x] **F-3 起始粮食储备没定，而断粮有后果。** 已解：写成硬约束 —— 开局粮食必须够撑到第一次收获，差一天就是设计错误而非难度。
- [x] **F-4 债务计息周期没定。** 已解：**按季计息，第一季免息。** 与季节循环对齐，玩家有明确还款节点；不按天计息，那会在玩家还没有收入时先涨债。
- [x] **F-5 破产兜底缺执行体。** 已解：**委托板必须始终保留至少一条无门槛委托**（不要材料、不要装备、低强度）。没有它，「没有全局失败」就只是句空话。
- [x] **F-6 主角能否单人出征没定。** 已解：能，但**只限资源采集类**。而且不需要额外惩罚 —— 队友本来就会自动采集场景物件，所以单人产出天然更低，机制自己压住了。
- [x] **F-7 开局委托板必须有一条第 1 天可完成的低难度委托。** 已解，写成硬约束。
- [x] **F-8 第一季的采购偏好公示时机没定。** 已解：**开局即公示当季偏好。**

### 推演后续又补出的五条（均已落正典）

- [x] **F-9 三类委托的完成标准只写了护卫设施那一类。** 采集与清理区域的通关条件是空的。已补，并且清理区域刻意定成**清除指定目标而非清空全部敌人** —— 推进式关卡里漏一只杂兵会让玩家满地图找。
- [x] **F-10 达成目标后关卡怎么结束没定。** 已定：**不自动结束，返回入口点撤离。** 这让「达成目标」与「榨干这一关」成为两个独立决策，且复用撤退的同一个动作。
- [x] **F-11 委托的三档难度（普通／精英／噩梦）作者早先拍过，却从未落进正典。** 一个已定的决定丢了。已补，并且把它与开局全局难度的分工写死：**全局难度改敌人数值与 AI，委托档位改这一关的敌人配置**，两层职责不重叠，且都不改经济。
- [x] **F-12 关卡目标进度没有要求可见。** 已补：进度必须始终可见 —— 看不见的目标等于没有目标。
- [x] **F-13 背包在关卡内装满时的处理没定。** 已定：无法继续拾取并提示，**不自动丢弃** —— 替玩家决定丢什么是最招骂的一类自动行为。

## 6. 待 `GP-2` 先算的数字

六条已迁入[玩法定位 · 留给 `GP-2` 的数值前提](../../canon/gameplay/玩法定位.md)，本页不再重复。

## 7. 结论

**核心循环闭合，五类账逐日对得上，三条失败路径全部有出路、无死锁。**

十三条发现全部处理完毕并落进正典。其中三类值得记住：`F-1` 是数字互相打架，`F-5` 与 `F-7` 是「只在讨论里说过、从没写进文档」的规则，`F-11` 是**一个已经拍过的决定丢了**（委托三档难度）。后两类只有把循环真的跑一遍才会掉出来 —— 这也是本次推演的主要产出。

`US-012` 通过。剩余依赖只有第 6 节那六个数字，归 `GP-2`。
