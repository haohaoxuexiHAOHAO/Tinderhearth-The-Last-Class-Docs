# UI-6：界面层级、导航栈与手环容器骨架，含栅格与边距规范

## 目标

界面有一套集中定义的层级与导航栈，手环是带标签页的统一容器，并交出一组写下来的排版单位供后续所有界面与 `DOC-2` 使用。

## 来源

- PRD：[`spec/prd-ui-framework.md`](prd.md) 的 `US-004` 与 `US-005`（两条合并：排版单位要在容器上落地才算定下来）
- 手环形态取"统一容器带标签页"由作者 2026-08-30 定；[世界观](../../../canon/world/世界观.md)原写"手环的界面形态与交互结构待玩法与界面设计确定"

## 依赖

`UI-3`。

## 验收标准

- [x] 层级自下而上固定为 世界(0) → 世界空间 UI(10) → HUD(20) → 面板(30) → 弹窗(40) → 过场遮罩(50)，定义在 `rules/Ui/UiLayer.cs` 一处；层号留 10 的间隔，将来插一层不必重编号。启动日志实测打出这条链
- [x] 世界空间 UI 单独成层并开 `FollowViewportEnabled` —— 读条要跟着角色走，混进 HUD 层就会固定在屏幕角落
- [x] 导航栈支持压入、弹出、逐层返回；重复压入同一层只提到栈顶不重复叠
- [x] **栈空时返回键不吞输入**（吞掉的表现是「按了没反应」，玩家会以为卡死）—— 有单元测试
- [x] 手环容器有标签页，关卡内操作类禁用、查看类可用。实测：可用 `notice`／`codex`／`party`／`prices`，禁用 `assign`／`order`／`build`
- [x] 当前页在进入关卡后变得不可用时会自动退出该页（容易漏的一种状态残留）
- [x] 标签页 id 拼错时**抛异常而不是静默判成不可用** —— 否则「拼错」和「确实不可用」长得一模一样
- [x] 关卡内打开背包**不暂停**：暂停由导航栈整体决定（`WorldShouldPause`），不由各面板自己设。背包声明 `PausesWorld: false`，弹窗声明 `true`，有测试盯着切换
- [x] 关卡内管理类面板被拒绝并打出原因，而不是静默不动
- [x] 骨架里没有任何绝对像素坐标，全部锚点与容器（`MarginContainer` → `VBoxContainer` → `HBoxContainer`）
- [x] 规则与节点分开：判定在规则层有单元测试盯着，引擎层只把结果翻译成显隐与 `SceneTree.Paused`。13 条新测试，`verify.py` 报 23 条／期望 23 条
- [x] 作者实机确认（作者 2026-08-31 随 `UI-8` HUD 一起实机看过，未发现问题）

## 交付给 `DOC-2` 的排版单位

实现在 `rules/Ui/UiMetrics.cs`，启动日志每次都会打出来。**这些数之间的关系有单元测试盯着**，改一个数破坏关系会当场失败。

| 项 | 值 | 依据 |
| --- | --- | --- |
| 基础单位 | 16px | [玩法定位 · 像素基准](../../../canon/gameplay/玩法定位.md) |
| 逻辑分辨率 | 640×360（**宽度是下限**） | 作者 2026-08-30 定；`UI-3` 实测 `expand` 会撑宽 |
| 字号／行高 | 12／16 | [ADR-0008](../../../decisions/ADR-0008-中文像素字体选型.md) 实测 |
| 排版栅格 | 8px | 基础单位的一半。16 太粗做不出「12px 文字加一圈内边距」，4 太细等于没栅格；8 同时整除 640 与 360 |
| 面板内边距 | 4px | 1 + 4 + 12 + 4 + 1 = 22 ≤ 24，正好让一行文字连边框塞进 24px 高的面板 |
| 元素间距 | 4px（同组）／8px（跨组） | 同上一格与一格栅格 |
| 屏幕安全边距 | 8px（一格栅格） | 不是为电视过扫描，而是 `expand` 下贴边元素离屏幕边缘会忽远忽近 |
| 图标档位 | 16px 与 32px | 界面符号与角色。**不设中间档** —— 见 32px 铁律 |
| 侧视有效视野 | 320×180 | 正典定侧视相机 2 倍缩放，所以只看得到一半 |
| 满宽汉字数 | 53（去掉安全边距后 52） | 地板数不是定值 |

## 实现笔记

> 实现落在更早的窗口（代码仓已提交），本节据验收标注、交付的排版单位表与 2026-08-31 收尾复核重建。

### 设计决策

- **层级用 10 的间隔编号**（世界 0 → 世界空间 UI 10 → HUD 20 → 面板 30 → 弹窗 40 → 过场遮罩 50，定义在 `rules/Ui/UiLayer.cs` 一处）。理由：将来插一层不必重编号。
- **世界空间 UI 单独成层并开 `FollowViewportEnabled`**：读条要跟着角色走，混进 HUD 层会固定在屏幕角落。
- **暂停由导航栈整体决定（`WorldShouldPause`），不由各面板自设**：背包 `PausesWorld=false`、弹窗 `=true`，有测试盯着。理由：关卡内打开背包不暂停是正典要求，各面板自设必然漂移。
- **标签页 id 拼错抛异常而不是静默判不可用**：否则「拼错」与「确实不可用」长得一样。
- **排版单位选定**：栅格 8（基础单位一半，同时整除 640 与 360）、内边距 4（1+4+12+4+1=22≤24，一行文字连边框塞进 24px 高面板）、间距 4／8、安全边距 8（`expand` 下贴边元素离屏边缘忽远忽近）、图标 16／32（不设中间档，32px 铁律）。四个数与图标档位已交付 `DOC-2`。
- **规则与节点分开**：判定在规则层有单元测试，引擎层只翻译成显隐与 `SceneTree.Paused`。

### 偏离

- 无偏离方案。`US-004` 与 `US-005` 合并实现（排版单位要在容器上落地才算定下来），已在「来源」注明。

### 权衡

- **手环取「统一容器带标签页」**（作者 2026-08-30 定）：关卡内操作类页禁用、查看类可用。备选是每个功能独立窗口，但那样导航栈与返回逻辑要各自发明一套。
- **层号留 10 的间隔 vs 连续编号**：间隔多占几个号，换来插层不重编号 —— 稳定性压过紧凑。

### 待确认

- 无新增。手环页内内容跟各自功能实现走（不在本条）；`DOC-2` 的色彩定稿依赖本条交付的排版单位（已交）。
