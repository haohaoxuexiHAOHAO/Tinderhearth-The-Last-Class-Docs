# 角色绘制约定

> 每个角色长什么样写在[人物](../../desc/人物.md)各人的「外形」那一行；本页写画角色时的通用规矩与防撞检查；怎么逐帧交付在[像素绘制原则](./像素绘制原则.md)。
>
> **判定尺寸只有俯视那一档**：基地、城区与战斗区域用同一套小人，相机不缩放，屏上尺寸就是素材尺寸。那一档多大、为什么一个角色全程只有一套素材，见[像素绘制原则 · 像素基准](./像素绘制原则.md)，本页不写像素数。

## 1. 写身体，不写脸

**外形只写身体，不写脸，也不写好不好看。** 这个尺寸画不出五官；更要紧的是脸与美验收不了：画出来的那张脸就是那张脸，「长相秀气」既约束不了它，也判不出对错（[ADR-0009](../decisions/ADR-0009-编辑器主导的开发模式.md) 的分工）。

**不写**：脸型、五官、眉眼、颧骨、表情，以及「英俊／甜美／秀气／好看」这类评价。

**改写成身体特质，每个角色给全这几样：**

| 给什么 | 写到什么程度 |
| --- | --- |
| 年龄档 | 年轻／中年／中年偏上／年长，写在「年龄」那一行，外形里不写岁数 |
| 身高与体宽档 | 「比人类矮一个头」「中等偏高」这类相对档，不写像素 |
| 体态与重心 | 挺或塌、肩展或收、重心在前、在后还是偏一侧 |
| 身上一处具体的东西 | 手、肩线、四肢比例、旧伤、职业留下的痕迹；挑一处就够，但必须具体 |
| 肤色与发型 | 明度与体块，不写发丝 |
| 衣着与随身 | 进得了剪影的大轮廓：下摆到哪、往哪边撑出去 |

**「身上一处具体的东西」必须具体**：「他很结实」画不出来，「他的手掌能整个包住刀柄」画得出来，而且同时说出了他是谁。**神态也落到身上**：不写「眼神清亮」，写遇险时肩不缩、手不抬。

**主角的面具是唯一的例外**：它是器物，不是脸，笑弧、眼缝与磨痕照写。

**这条不设守卫**：一句长相描述，读那一页的人当场看得见；禁用词表却会连主角的面具一起拦下。

## 2. 记忆点的杠杆

这个尺寸下脸几乎不存在，记住一个人靠下面几层，按重要性排：

1. **剪影**：体型加姿态的轮廓，关掉颜色也认得出是谁。
2. **头发与衣着**：发型的体块、眼镜、衣服的大轮廓与明度。
3. **一个大件**：大到能进剪影的道具或特征，比如长耳、面具、背上的高背架、肩上的巨刀。
4. **动态签名**：只属于这个角色的动作习惯，落在走路与站着的帧里，比如跛着走、转身分两下才转完。

**脸、小道具、发丝、服装纹样与表情在这个尺寸里都会糊掉**，留下的只有轮廓、明度块与大件。所以主记忆点落在剪影、头发与衣着的大块、一个大件上；小道具只当质感，不当唯一识别符。**每个朝向各看一遍**：正面、背面与侧面不是同一个轮廓。

**灵能的颜色按灵的状态分，不按人分**（[世界观 · 灵的样子](../../desc/世界观.md)）：一个人的灵能特效认不出是谁的，认人只靠上面这几层。

> **总原则**：剪影认体型，头发与衣着认人，一帧动作认性格。任一样单独成立就记得住，叠在一起就过目难忘。

## 3. 剪影防撞审计的做法

**新增角色必须做一次防撞审计。** 高危撞型是实测出来的，直接当检查项：

- **瘦削人类男性**：群像里最大的记忆隐患。脸认不出，只能靠姿态剪影、体型、头发与衣着合起来分；姿态能用的轴有体型大小、含胸或挺拔、重心前倾或后倾、肩缩或展。
- **军人老兵**：靠年龄、性别、义肢或战疤、随身大件、扫视的姿态分，通常分得开。

**判据：关掉颜色只看黑剪影，两个角色分不分得开。** 分不开就改体型或大件，不靠加小配件糊弄。

- **先分组，同组才逐对看**：按种族与身形、年龄与性别、会不会同屏分组，跨组的两个人剪影差得远。跨组、跨批却同屏或同型的那几对，单独写出来。
- **每个朝向各做一遍**：一个朝向里分得开的两个人，换个朝向可能撞上。
- **不必为水平翻转让步**：每个朝向各画一套（[ADR-0021](../decisions/ADR-0021-每个朝向各画一套不做水平翻转.md)），挂在单侧的大件不会换边，挎包、肩带、靠肩的刀、单侧断翼都能当识别杠杆。不对称是剪影最有效的杠杆，所以不为省素材把角色画成对称。

## 4. 可读性规则

- **会丢的**：刘海遮脸、清冷表情、大众长相，面部细节在这个尺寸画不出来。
- **救法**：改由剪影、发型体块、衣着轮廓与大件承载。
- **靠小道具建立特征的角色，必须另有一个进得了剪影的主钩子**（体型、发型或大件），小道具只作质感。
- **状态变化表达机制，不表达情绪**：魔纹由暗转亮只在主动过载或外力灌注时发生，是风险状态，不是愤怒的指示。

## 5. 主角剪影

**主角是全员的标杆**：认他靠面具、黑发里不规则的银白发束、空着的右袖与到脚踝的长披风（外形见[人物 · 烬](../../desc/人物.md)）。画他守这几条：

- **面具的磨痕与修补要读得出**：它是器物，不是脸。
- **左右不对称画在身上**：左侧明显比右侧发达、左肩略高。单手适配不靠一句说明，它长在身上。
- **灵手不进常态的剪影**：它只在具体操作时出现（[人物 · 力量与边界](../../desc/人物.md)），平时右边就是那只空袖；它不画成手臂长回来，也不当力量刻度。
- **他也进「军人老兵」那一组的审计**：他对外就是个停滞的老兵，结论在「防撞审计：反派与要角」那一节。

## 6. 真实形态的剪影

**真实形态在画面上必须还是同一个人。** 变什么、不变什么见[人物 · 真实形态](../../desc/人物.md)，本节写为什么这么定。多出来的只有右边那只本来缺着的手，不新加任何大件：

| 变的 | 为什么这么定 |
| --- | --- |
| 面具不摘 | 摘面具全作只有告别那一幕一次（[人物 · 面具与真容](../../desc/人物.md)）；这里摘了，两处抢同一个揭晓 |
| 右边的灵手显形 | 只有这时它作为力量而不是工具出现。「他不一样了」靠这只本来不存在的手说出来，比换一套衣服有效：那只空袖玩家从开局看到这里 |
| 披风被灵流从下往上吹开 | 唯一改变剪影外形的一样：轮廓由垂着的一整块变成张开的 |

认得出是同一个人，靠面具与发型一点没动。**不加魔纹，也不加「反派视觉红线」那一节里的任何元素**：他不是反派。配色不换；灵手显什么光，照[世界观 · 灵的样子](../../desc/世界观.md)。

**那一刻读不读得出只能实机看**：俯视那一档里「披风张开、多一只手」够不够明显，本页判不了。

## 7. 反派视觉红线

反派与魔化造物只用钢铁的壳、熔岩、断翼轮廓、无规则的魔纹这类幻想元素。**钢铁本身不是反派的记号**：谁手里的刀、身上的护具都可以是钢，记号是裹在外面的那层壳。

**禁止**现实信仰标志、国家或组织旗帜、极端团体制服、经文排版、可识别的手势与真实事件构图。恐惧来自环境失衡与行为后果，不来自现实符号。**魔纹必须无规则扩散**，绝不形成成套徽记。

## 8. 防撞审计：学生

**先按种族分组，同组之内才可能撞**；跨组的两个人剪影差得远，不逐对看。

| 组 | 谁 | 组内靠什么分开 |
| --- | --- | --- |
| 兽人 | 崔刃、崔岚 | 崔刃宽肩、两条手臂被臂铠整段加粗、光头；崔岚明显窄，卷曲的短发让头部外扩一圈，手里是一根细直线。**硬要求**：短棍必须细于她的手臂，否则与臂铠混成一团；崔刃的臂铠必须左右对称，理由见「防撞审计：反派与要角」里他与晦炎那一对 |
| 矮人 | 铁钧、铁焕 | 身高同档，分别全压在体宽与瓶子的挂法上：铁钧体宽接近人类、腰间挂满一圈瓶子，剪影是下半身外扩的梯形；铁焕明显窄、瓶子竖插在背后的高背架里且架顶出肩，剪影是纵向加高的窄身形。方向相反，并排看得出 |
| 精灵 | 云舒、云漪 | 同样偏小、同样的长耳，分别压在头发上：云舒的高马尾往上拉长，云漪的散发把肩部横向撑宽，发色也一冷一暖。**硬要求**：云漪任何一帧都不束头发 |
| 人类 | 安桦、林泽、灯火 | 见下面 |

**人类那一组最危险**：身高都在中等上下，没有种族外形兜底。

- **安桦与灯火**：分开靠大件的位置与头部轮廓。安桦是斜挎过身的布挎包（鼓在一侧腰旁）加颈后贴头的低发髻；灯火是长围巾（移动时拉成一条横线）加发梢外翘的短发（头两侧各外扩一点），身形也比安桦略高、明显更细。**这一对最需要实机逐帧看。**
- **林泽**：学生里唯一的「瘦削人类男性」，组内没有同型；常年戴着的兜帽把头和脖子连成一块，是学生里独一份的头部轮廓。
- **「军人老兵」这一型学生里没有**，它的对象在「防撞审计：反派与要角」。

**跨组要盯一处：林泽的连帽短斗篷与主角的长披风**，都是「身上一大块布」。主角那件到脚踝、没有帽子，加空右袖与面具；林泽那件到腰、有帽、双袖齐全。

## 9. 防撞审计：常驻 NPC

**这一批没有人属于高危撞型。**「瘦削人类男性」最近的是小满，而他是还没长足，不是瘦削；「军人老兵」一个都没有。所以撞车风险来自年龄与性别同档，按那个分组：

| 组 | 谁 | 组内靠什么分开 |
| --- | --- | --- |
| 年轻女 | 玉娘、招娣 | 外扩方向相反：腰前一条只向身前撑开的长围裙，对腰后支出的一摞表单；头部轮廓也相反：高盘发在头顶收出一个尖，对贴头的短发。招娣还总倚着点什么 |
| 年长女 | 苏怀、三喜 | 姿态先分开：苏怀站着、背挺得很直，三喜总坐着。再加罩衣宽而平的底边，对膝上横撑出去的大竹笸罗 |
| 年轻男 | 小满、阿旺、秦炉生 | 大件各占一个方向：背上把背影撑成一个圆的出诊布包／一侧肩上搭着垂到腰的外衣／从胸前罩到膝的皮围裙。体格也分档：还没长足／精瘦／中等。阿旺与秦炉生一侧肩上都搭着东西（外衣、铁钳），分开靠皮围裙与体格 |
| 中年男 | 老苗、陈稳、赵来福 | 体态各不相同：老苗重心偏在左腿、右肩下沉（跛），陈稳笔直收肩，赵来福最圆、没有腰线、身体往后靠。大件：斜拄在地上的短拐杖／端在胸前的登记板／横在胸前的大算盘。陈稳与赵来福的大件都在胸前，分开靠体态；老苗与赵来福都偏厚，所以老苗那副不对称的站姿最要紧 |
| 兽人 | 阿石，加学生崔刃、崔岚 | 大件各占一个方向：阿石背后一只从肩斜到另一侧腰的长信筒，崔刃靠宽肩、整段加粗的双臂与光头，崔岚手里一根细直线。阿石还比兽人该有的样子瘦一圈，崔刃、崔岚都比人类宽壮 |
| 工匠 | 秦炉生，加学生铁钧、铁焕 | 身形先差一大截：秦炉生是中等身高的人类，铁钧、铁焕是矮人。大件也各在一处：秦炉生胸前到膝的皮围裙加高低肩，铁钧腰间一圈瓶子，铁焕背后出肩的高背架 |

**跨页要盯一处：苏怀的药箱与安桦的挎包**，都是「一只包」。苏怀提在手里，在手边垂出一块；安桦斜挎过身，从肩斜到另一侧腰旁。两人一个年长、一个年轻。

## 10. 防撞审计：反派与要角

**按会不会同屏、是不是同型分组**，跨组的不逐对看。

| 组 | 谁 | 组内靠什么分开 |
| --- | --- | --- |
| 四将首 | 晦炎、苍冥、铸霜、匿芒 | 大件各占一个方向：晦炎只加粗右臂（横向、中段、单侧），苍冥的长袍下摆铺在地上（横向、下端），铸霜背上的方形封存匣顶出肩线（纵向、上端），匿芒什么都不突出、像一根上下等粗的柱子（靠「没有」认）。方向两两不同，关掉颜色并排也认得出 |
| 长袍 | 顾全、方立章、司徒衡 | 都穿长袍，分别压在下摆长度（到小腿／到膝／垂到脚面）、体态（偏胖溜肩、重心后坐／瘦挺居中／中等身材、站得很平）与身侧外扩物（腋下一叠文书／两手空着／手里一支笔）上。司徒衡那支笔进不了剪影，所以他与方立章那一对全靠下摆：垂到脚面那件走动几乎不摆，下半身是一整块看不见腿的梯形 |
| 「军人老兵」 | 夙渊、岳如磐、薛举贤、慎行、戈守疆，加主角 | 这一型的对象就是这一组。主角必须算进来：他对外是停滞的老兵，岳如磐、慎行会与他同屏，薛举贤也可能。逐人见下表 |
| 最终战两段 | 夙渊、灾狱 | 灾狱没有自己的身体，第二段附在谁身上、长什么样待定（[人物 · 灾狱](../../desc/人物.md)）；定下来以后照这一组再对一遍 |

| 谁 | 体格与姿态 | 大件在哪 |
| --- | --- | --- |
| 岳如磐 | 最厚重，重心压得极低，站着像一块立起来的石头 | 肩上斜靠一把厚背巨刀，把肩线又抬高一块 |
| 戈守疆 | 比岳如磐薄一档，下巴略抬、重心在前脚 | 背后交叉两根长柄兵器，柄端从两侧肩上斜伸出去，是这一组唯一左右对称的双出头 |
| 夙渊 | 高大宽肩，前倾下沉 | 背后单侧的断翼残甲 |
| 薛举贤 | 军姿挺拔，展肩、重心居中 | 一条斜挂过胸的教官肩带，不带大型武器 |
| 慎行 | 结实，肩往里收、重心在后脚，一条腿慢半拍 | 左臂一整段旧护臂 |
| 主角 | 中等身高与体宽，左肩略高 | 右边的空袖、到脚踝的长披风、面具 |

**主角与慎行是这一组里最要紧的一对**：两人都靠一条手臂的不对称被认出来，方向正好相反，主角右边少一条，慎行左边多一块。单侧大件不换边（[ADR-0021](../decisions/ADR-0021-每个朝向各画一套不做水平翻转.md)），所以这一对在任何朝向都分得开。主角另有面具与到脚踝的披风兜底，这一组里到脚踝的披风只有他一件。

**跨组要盯的几处**：

- **晦炎与学生崔刃，最要紧**：最终战学生那条战线上（节点 16）两人正面对上，都是宽肩的人形。分开靠对称：崔刃两条手臂由臂铠对称加粗，晦炎只粗右臂、右肩高于左肩。所以崔刃的臂铠必须对称，晦炎的武化壳只许在一侧，改了任一边就撞上。
- **铸霜的封存匣与白问津的卷宗筒**，都是「背上一件东西」。匣子高出肩线、方、有体积；卷宗筒斜背、细、贴着背，只算质感。白问津的识别符是那根立起来高出头顶的长测杆。
- **简察微与权息**：赎回那一幕（节点 9）同屏，体型相近，分别压在外扩的位置上：简察微是贴在一侧髋骨上的方形档案匣（侧面），权息是胸前垂到腰的长链（身前）。那一幕权息坐在柜台后，简察微站在他旁边。
- **戈守疆的双出头与铸霜的方块**：两人不同屏，形状仍要不同：戈守疆是两根细杆从两侧肩上斜伸出去，铸霜是背上一个有体积的方匣、顶出肩线。
