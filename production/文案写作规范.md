# 文案写作规范（玩家可见的叙述性文本）

> **适用**：一切“讲故事而非讲机制”的玩家可见文本——个人档案的身份故事、装备 / 道具 / 孤品的来历与风味、天赋与指令的风味句、档案库（内部代码名 `Codex`）的引语、学员独白与日常掠影、场景氛围散文池。
> **不适用**：机制说明（效果、数值、代价、条件）。机制文案必须由共享生成函数产生，保证同一规则在各页面说法一致；风味文案负责叙事留白。两者不得混在同一句里。
>
> **继承说明**：本文的写作规则（R1–R10）完整继承自前作《火种》，与具体剧情无关。文中提到的“第四章”“实装剧本”等前作章节结构**不继承**；示例中的兑现锚点在新故事（`NR-1`）确定后需重新指定。
> **要达到的效果**（作者定的标准）：初读只觉得"这句有点意思"，玩通剧情后回头再看**起鸡皮疙瘩**。做到这一点靠的不是把句子写重，而是 R7–R10 那套延迟兑现——写的时候压住，兑现留给玩家。
> **为什么要有这份规范**：教官档案的身份故事曾因凭空补写来历、混入机制说明和复述剧情而反复返工。后续装备、道具和孤品的故事会批量使用同一方法，因此先固定写作与自查口径。

## 1. 硬规则（R1–R6 基本功 · R7–R10 延迟兑现）

### R1 · 给一个瞬间，不给一段简历
写**某一次具体的、能看见的事**，而不是概括一段经历。人物的性格、处境与来历，由那个瞬间里的动作反推。

> 依据：契诃夫给弟弟的信里主张抓住小细节、组合起来让读者闭上眼就能看见画面（见 [Show, don't tell](https://en.wikipedia.org/wiki/Show,_don't_tell)）。后世流传的"别告诉我月光皎洁，让我看见碎玻璃上的反光"是对这句的概括（考据见 [Quote Investigator](https://quoteinvestigator.com/2013/07/30/moon-glint/)）。*内容已改写以符合引用限制。*

- 反例：「多年行伍练就的临阵指挥与救护——把伤亡压到最低，是老兵的本分。」（简历 + 自我评价）
- 正例：「测验那天你把手环递给监考员，没有低头去看它显示了什么。」（一个动作，性格与处境由它反推；注意不能续写"那位置是你自己挑的"，那违 R6）

### R2 · 只写八分之一，但你必须知道全部八分之八
把最关键的那一层留在水面下，让玩家自己拼。**前提是作者自己清楚被省略的部分**——不知道而省略，留下的不是留白而是空洞。

> 依据：海明威的冰山理论（省略法）——作者若真懂自己在写什么，省略掉的部分读者依然感受得到；只因为不懂而省略，写出来的地方就是空的（见 [Iceberg theory](https://en.wikipedia.org/wiki/Iceberg_theory)）。*内容已改写以符合引用限制。*

落到本项目：正典（[人物](../canon/characters/人物.md)、[世界观](../canon/world/世界观.md)）就是那水下的八分之七。**写之前先查正典**，不许现编。例如，把主角来历写成“被难民车队捎来”，就会与“主动潜入并以经验型老兵身份通过测验”的正典事实冲突。

### R3 · 每个细节都要有用（契诃夫之枪）
出现在文本里的物件、动作、数字都得承担叙事职能：铺垫伏笔、透露处境、或与末句咬合。删掉它若不损失任何东西，就该删掉。

- 检查方式：逐句问"删了它，读者少知道什么？"答不出来的句子删。

### R4 · 末句回扣，不许硬贴
最后一句必须与前文**同源**——回扣前面已经出现过的那个物件或那句话。想埋的暗示，要提前把载体放进场。

- 反例：前三行讲入职经过，末句忽然出现"手环上那几个读数很多年没动过"（作者原话：跟前面一点关系都没有）。
- 修法：让手环在第二行就出场（递给监考员），末句回到同一圈读数。伏笔与回扣咬合，好奇心才成立。

### R5 · 器物由人来讲
装备 / 道具 / 孤品的来历，写**谁用它做过什么**，不写资料条目式的产地、材质、年代罗列。让物件带着人的动作与态度。

> 依据：魂系游戏把叙事织进世界本身，物品描述是玩家获取叙事的主要通道之一（见 [Narrative Design in Dark Souls · Game Developer](https://www.gamedeveloper.com/design/narrative-design-in-dark-souls)）。*内容已改写以符合引用限制。*

- 反例：「据点工坊用回收的旧镜片磨出来的高精度观测器材。」
- 正例：「据点工坊用回收的旧镜片磨的。透过它看战场，他总能先一步看出谁要挨那一下。」

### R6 · 伏笔只写可观测的事实，不写原因、意图与自我供认
这是本项目**最容易犯、代价最大**的一条：主角的身份与力量是全作核心悬念（见 [人物 · 面具、右臂与伪装](../canon/characters/人物.md)），任何把"他能做到什么"直接说出口的句子，都等于提前交底。

> 依据：伏笔的线索要种在"读起来像别的东西"的地方——初读时它自然属于场景、有一个无害的解释；等到揭示之后回看，它才显出第二层意思（见 [Foreshadowing and payoff · inkshift](https://inkshift.io/resources/foreshadowing-and-payoff)、[How to Use Foreshadowing Effectively · Editor World](https://www.editorworld.com/article/how-to-use-foreshadowing-effectively)）。*内容已改写以符合引用限制。*

三条落地规则：

1. **只写看得见的事实**（读数是多少、他有没有低头看、手停在哪儿），**不写原因与意图**。"读数停在不高不低的位置"可以；"——那位置是你自己挑的"不行，那是供认。
2. **必须留一个无害的解释**：初读的玩家应该能用世界内的平凡理由说得通（旧伤停滞、设备老旧、这人向来不在意数字）。如果一句话只有"他在作假"这一种读法，它就不是伏笔。
3. **知情用回避表现，不用陈述**：角色心里清楚而不愿承认的事，靠**动作的缺席**传达——不去看、不接话、把东西合上。让玩家自己觉出不对劲，比告诉他更有效。

**禁用词表**（叙述性文本里一律不出现，除非剧情已在正典中公开该信息）：自己挑的 / 刻意 / 故意 / 伪装 / 假的 / 其实 / 真身 / 从不外露 / 无人看穿 / 他能……而不被发现。

**自检办法**：把句子给一个"完全不知道主角底细"的读者看——如果他读完能推出"主角在造假/主角深不可测"，这句就废了；如果他只觉得"这人有点怪"，才算成立。

---

以下四条针对作者要的那种效果：**初读不知其中意，剧情通完回头再看起鸡皮疙瘩**。R1–R6 保证"不写坏"，R7–R10 决定"能不能兑现那一下"。

### R7 · 一句两读：同一句在"不知情"和"已通关"下都读得通，且意思不同
这是整份规范的最高目标。写出来的句子要能被读两次：**第一次有一个平凡、无害、完全说得通的解释；第二次（玩家已知全部真相）指向另一件事，而且更重。**

> 依据：石黑一雄《别让我走》的叙述者用职业委婉语（照护者、捐献、完成）叙述自己的处境——初读像一套行业用词，读透后才知道它们指的是什么；这类第一人称"有限意识"叙述是他的核心手法（见 [Never Let Me Go 语言分析 · ResearchGate](https://www.researchgate.net/publication/351586995_NEVER_LET_ME_GO_UNDERSTANDING_THE_LANGUAGE_USED)、[Ishiguro 的不可靠叙述者研究](https://reference-global.com/download/article/10.2478/amph-2022-0031.pdf)）。纳博科夫更直接：书只能被"重读"，好读者是重读者；那阵战栗（tingle）是**用脊椎**读到的（见 [Lectures on Literature 引语](https://www.goodreads.com/quotes/676091-one-cannot-read-a-book-one-can-only-reread)、[On Rereading · NYRB](https://www.nybooks.com/online/2015/07/11/rereading-unlocking-the-mind/)）。*内容已改写以符合引用限制。*

- **构造法**：`可观测事实（R6）＋ 一个平凡动机`。平凡动机写进文本供初读用，真实动机**只存在于正典**、一个字都不进文本。
- **双读检验**（必做）：把句子放到两种读者眼前——A 完全不知情，B 已通关。A 读完顺畅且不起疑到"看破"的程度；B 读完得到的意思**必须比 A 更重**。两者其一不成立就重写：A 卡住＝写晦涩了；B 没有增量＝这句不是伏笔，只是描写。
- 反例（只有一读）：「你的读数从来不准。」——A 也只能读成"这人在造假"，没有平凡解释。
- 正例（两读）：「你说读数难看不代表人难带。」——A 读成一句护着学员的教育信条；B 读成他自己就是反向的活证据。

### R8 · 延迟解码：先给感觉，后给解释，单条文本内部不许闭环
写出角色/镜头**当下能觉察到的那一点**就停手，含义的解释推后——推给后续剧情，甚至推给玩家的第二次阅读。

> 依据：伊恩·瓦特论康拉德的"延迟解码"（delayed decoding）——先给意识接收到的即时印象，再让理解它的过程慢一步跟上（见 [delayed decoding 术语引述](https://filmmakermagazine.com/32159-the-blue-velvet-project-27/)、[Watt《Essays on Conrad》](https://archive.org/details/essaysonconrad0000watt)）。*内容已改写以符合引用限制。*

- 落地：文本里出现的反常**不在这条文本里解释**。解释的责任归正典与后续剧情。
- 判定：如果读者读完这一条就"懂了"，它只是信息，不是伏笔。留下的应该是一个说不上哪里不对的钩子。
- 与 R6 的分工：R6 管"不许交底"，R8 管"解释放在别处"。二者一起才有延迟。

### R9 · 认出的时刻留给玩家，不让角色代劳
不写角色自陈觉悟，不写旁白点题。把材料摆齐，让玩家自己在某一刻把两处对上——**玩家自己拼出来的那一下才是鸡皮疙瘩，被告知的只是设定**。

> 依据：亚里士多德《诗学》把"认出"（anagnorisis，由无知转为知）与"突转"（peripeteia，境况反向）并列为复杂情节的两个要件，最好的情节让二者同时到达，俄狄浦斯是他的样板（见 [Anagnorisis · Wikipedia](https://en.wikipedia.org/wiki/Anagnorisis)、[Recognition, Tragedy & Catharsis · Britannica](https://www.britannica.com/art/anagnorisis)）。*内容已改写以符合引用限制。*

- 落地到本项目：档案 / 物品 / 风味文本是**认出所需的材料**，不是认出本身。那一刻发生在玩家脑子里，不发生在文本里。
- 越是想让玩家震动的那句，越要写得平。把力气花在"提前把载体放进场"（R4），不花在句子的音量上。

### R10 · 一件可触之物承担情绪，并且跨文本复现
每个角色、每条母题选定**一件具体可触的东西**（手环与那圈读数、外墙的排班表、修补过的面具、义肢的轻响），让它在不同文本里反复出现、每次略有变化。情绪由物件承担，不由形容词承担。

> 依据：艾略特的"客观对应物"——表达情绪的唯一办法是找到一组物件、一个情境、一串事件，充当那种情绪的"公式"，外部事实给足了，情绪自然被唤起（见 [Objective correlative · Poetry Foundation](https://www.poetryfoundation.org/education/glossary/objective-correlative)、[Britannica](https://www.britannica.com/art/objective-correlative)）。中国诗学同一路：司空图《二十四诗品·含蓄》讲"不著一字，尽得风流"，意思要靠不说出来的部分成立（见 [不著一字 · wisdomlib](https://www.wisdomlib.org/definition/bu-zhe-yi-zi)）。*内容已改写以符合引用限制。*

- 一件物在**三处以上**文本出现才成为母题；只出现一次的物件是道具，撑不起回看。
- 复现时**改一点点**：位置变了、多了一道划痕、这次他看了 / 这次他没看。变化即叙事。
- 建立母题前先确认它在正典里站得住（谁做的、为什么在他身上），否则复现越多、破得越快。

### R7–R10 的前置条件：兑现锚点必须写下来
双读句只有在**存在兑现点**时才成立——玩家通关后必须真的碰到那个揭示，回头才会起鸡皮疙瘩；没有兑现点的暗示是空洞（R2），是欺骗。

每写一处双读句，在需求工作文档里记一行：`文本位置 → 它由哪段正典/剧情兑现`。例：教官档案的“那圈读数没动” → 由[人物 · 停滞老兵侧写](../canon/characters/人物.md)与后续“主角大规模释放时附近手环量程外报错”的剧情场面兑现。锚点写不出来的，就把这句删掉。

## 2. 交付前自查清单

- [ ] **查过正典**：涉及的人物经历、地名、时间线、称呼均与正典一致；不确定的宁可不写。
- [ ] **有一个可看见的动作**（递、划掉、擦、锁、垫、退半步…），不是纯状态陈述。
- [ ] **形容词与自我评价清零**：没有"英勇""可靠""了不起"这类替读者下结论的词。
- [ ] **不复述玩家已经玩过的剧情**：档案 / 物品文本不是剧情回放，要给剧情**没说的那一面**。
- [ ] **末句与前文同源**（R4），不是另起一个话题。
- [ ] **删得动的句子已删**（R3）。
- [ ] **伏笔没有自带答案**（R6）：不含禁用词；每处反常都留了一个无害解释；不知情的读者读完只会觉得"这人有点怪"，推不出"他在造假"。
- [ ] **过了双读检验**（R7）：不知情读者读得顺，通关读者读到的意思更重；两个读法都写下来对照过。
- [ ] **本条内部没有闭环**（R8）：反常没在同一段里被解释掉。
- [ ] **没有替玩家点题**（R9）：没有角色自陈觉悟、没有旁白总结。
- [ ] **物件是复现的母题**（R10）：用的是已经立住的那件东西，不是临时新造一个道具。
- [ ] **兑现锚点已登记**：写清这句由哪段正典/剧情兑现；写不出来就删。
- [ ] **不含固定称呼**：学员如何称呼主角随性格与关系变化，任何文本都不写死"人称××"。
- [ ] **不含开发术语与元信息**：占位、口径、模板、里程碑编号、UI 方位词（"下方""上面那栏"）一律不出现。
- [ ] **机制与风味分离**：效果数值写在机制字段（`Description` / 效果说明），故事写在风味字段（`Flavor` / story），不互相夹带。
- [ ] **中英双语同步**：英文不是逐字直译，允许调整句式以保住画面感与省略；两边的**事实**必须一致。

## 3. 体裁与篇幅（供估算，不是硬上限）

| 体裁 | 篇幅 | 结构建议 |
| --- | --- | --- |
| 个人档案身份故事 | 中文约 100–140 字、3–4 行 | 一个场景细节 → 一次具体动作 → 一句对话或抉择 → 末句回扣 |
| 装备 / 孤品来历（`Flavor`） | 1–2 句、约 25–50 字 | 谁用它、做过什么、留下什么痕迹 |
| 道具风味 | 1 句、约 15–30 字 | 一个使用瞬间即可，不必交代出处 |
| 天赋 / 指令风味 | 1 句 | 像师徒之间说过的一句话 |
| Codex 引语 | 1 句、带引号 | 世界内某人说的话，不是旁白总结 |
| 学员独白 / 掠影 | 1 句 | 只写此刻在做什么、心里过了什么，不总结性格 |

### 3.1 换行与孤字（多行文本必看）

显式分行的多行文本（如档案身份故事，用 `\n` 分行）必须在**实际目标容器**中检查。字体、语言、字号和容器宽度都会改变一行能放多少字，因此不设全项目通用的字符上限。

- 避免“孤字 / 孤行”：自动换行后，下一行只剩一个字或一个很短的词组；英文排版也要避免段末只剩一个短词。
- 文案先按语义断句，界面再负责正常自动换行。不要为了卡某个字符数把一句话切成难读的碎片。
- 中文和英文都使用最长已知文本验收；字体、字号或容器宽度变化后重新检查。
- 如果同类文本频繁出现孤字，先核对容器宽度与字号层级，再决定精简文案，不能只靠手写换行掩盖布局问题。

## 4. 标点与语气

- 不用感叹号（例外：战斗内台词等即时反应）。破折号与省略号克制使用，一段里各不超过一次。
- 档案 / 装备文本用**第二人称（你）或第三人称（他）之一，全篇不混**。个人档案页统一第二人称。
- 不用书面语套话（"综上""可谓""不失为"），不用网络语。
- 数字尽量少；出现的数字要有意义（读数、名字个数、次数），不做无关精确化。

## 5. 示例：教官档案身份故事

**不合格版（复述剧情）**：那晚在锈月酒馆你听见杂役提起无人接手的九人班 → 第二天去应聘 → 测验只露中等偏上 → 卡塞尔把九人交给你 → 手环读数很多年没动过。
问题：①玩家刚玩过这段，复述提供不了新信息；②全是概括没有瞬间（违 R1）；③末句的手环与前文无关（违 R4）。

**不合格版二（伏笔自带答案 · 违 R6）**：「测验那天你把手环递给监考员，读数停在不高不低的位置——**你自己挑的**。」
问题：破折号后那半句是主角的自我供认，直接告诉玩家"他能任意控制手环读数"。全作最大的悬念被一句风味文案交底（作者反馈）。这不是伏笔，是剧透。

**及格但不够（旧版 · 只做到"不犯错"）**：……卡塞尔问"为什么要最难带的一班"，你答"他们不难带，是没人肯多看" → "那圈读数和你来时一样，没动"。
问题：R1–R6 都过了，但通关读者回头再看**拿不到增量**——对话讲的是学员，读数讲的是他自己，两条线各说各的，末句只完成了"回扣"，没完成"翻面"。另外"为什么要最难带的一班"暗示是他挑的班，与正典"卡塞尔按岗位需求交班"不符。

**现行版（R7 双读成立）**：
> 学院外墙的排班表换过好几轮，那九个名字被挪来挪去，没有一次落到底。
> 测验那天你把手环递给监考员，没有低头去看它显示了什么。
> 卡塞尔说这一班没人接。你说读数难看不代表人难带，是没人肯多看。
> 你的那圈读数和来时一样，没动过。那九个名字，你不打算再让谁挪走。

成立之处：
- **双读的枢轴是第三行那句台词**（R7）。初读：一句护着学员的教育信条——数字难看不等于人不行。通关后：说这话的人自己的读数**好看得恰到好处又永远不动**，同一条原则反过来正好解释了他为什么能站在这儿。他嘴里的道理，是他赖以藏身的道理。
- **第四行把"你的"点出来**，与第三行的"读数"并置，玩家自己就会把两处对上（R9）；文本一个字都没解释。
- **反常有平凡解释**（R6 第 2 条）：读数不动＝旧伤停滞的老兵，这是对外公开的侧写；不低头看＝这人不在意这种数字。
- **手环是复现母题**（R10）：外墙排班表、手环那圈读数在正典多处出现（读数失真、量程外报错、人工复核凭证），不是为这段临时造的道具。见[世界观 · 多功能手环与治理](../canon/world/世界观.md)。
- **兑现锚点**：[人物 · 难民伪装 / 停滞老兵侧写](../canon/characters/人物.md) + 后续剧情中“主角大规模释放时附近手环量程外报错”的场面。玩家玩到那里之后，第四行才真正变重（R8）。**新故事的具体锚点位置待 `NR-1` 确定。**
- 基本功仍在：手环第二行入场、末句同源（R4）；“挪来挪去 / 不打算再让谁挪走”首尾咬合（R3）；一问一答替代性格描述（R1）。交付时还要在档案实际容器中检查中英文换行。
